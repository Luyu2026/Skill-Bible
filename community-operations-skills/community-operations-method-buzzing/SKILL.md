# 《Buzzing Communities》· 社区管理方法论

> 目标驱动框架 + 贡献者金字塔 + 密度×质量 + 成员生命周期，判断社区怎么管理、活跃怎么提升。

## 核心框架

### 1. 社区目标驱动框架（目标 → 指标 → 机制）
- **适用场景**：社区规划/诊断的起点
- **步骤**：定双重目标（组织+成员）→ 配可量化指标 → 设计机制（机制为目标服务）
- **输出物**：社区目标-指标-机制表

### 2. 贡献者金字塔（核心-活跃-潜水）
- **适用场景**：活跃机制设计、资源分配
- **步骤**：分层（核心10%/活跃20%/潜水70-90%）→ 培育核心层（荣誉/授权）→ 激活中间层（低门槛参与）→ 服务潜水层（不强制）
- **输出物**：成员分层策略 + 各层激励设计

### 3. 成员生命周期运营
- **适用场景**：成员全周期管理
- **步骤**：引入（招募）→ 激活（30天引导）→ 贡献（消费→创作）→ 留存（价值供给）→ 召回（预警+针对性触达）
- **输出物**：成员生命周期运营方案

## 决策规则（8条）

1. 社区没目标 → 先定双重目标（组织+成员）
2. 设计活跃机制 → 机制必须服务目标（不为热闹而热闹）
3. 核心贡献者少 → 培育核心层（感谢/授权/特权），不是泛泛激励
4. 新成员进来就流失 → 做新成员引导（30天激活计划）
5. 社区不活跃 → 看密度与质量——密度低做连接，质量差做治理
6. 衡量社区 → 用"密度×质量"双维度，不用单一活跃数字
7. 社区活跃但无价值 → 质量稀释，做内容治理与聚焦
8. 成员流失 → 按生命周期召回（针对性触达而非群发）

## 检查清单

- [ ] 社区双重目标明确（组织+成员）
- [ ] 目标配了可量化指标
- [ ] 机制与服务目标对应
- [ ] 成员分层清楚（核心/活跃/潜水）
- [ ] 新成员有引导流程（30天激活）
- [ ] 活跃度看"密度×质量"而非单一数字
- [ ] 有流失预警与召回机制

## 反模式

- 没有目标就建群
- 只看活跃数字不看贡献结构
- 只做活动不治理质量（噪音赶走核心用户）
- 新成员没人管
- 机制与目标脱节
