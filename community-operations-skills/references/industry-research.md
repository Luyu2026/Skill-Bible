# 社区运营 · 行业基本概念调研（Phase 1 产物）

> 调研时间：2026-09-30 · 方式：行业领域知识 + 公开资料交叉验证
> 服务于 community-operations-skills 套件的构建坐标系

## 1. 行业画像

社区运营（Community Operations）是负责**建设、维护、活跃一个用户社区（社群/论坛/粉丝群/兴趣小组等）**的岗位。区别于私域运营（企微/社群卖货导向）、用户运营（用户分层/生命周期）、活动运营（单次活动）、新媒体运营（内容平台账号），社区运营的核心职责是：**社区定位与规则 → 成员招募 → 活跃与互动机制 → 内容生态 → 社区活动 → 商业化（变现/转化）→ 数据复盘**。本质是"经营一群人的关系与归属感"，对社区规模、活跃度、留存、转化负责。

## 2. 核心工作流（高频场景 7 个）

| # | 工作场景 | 产出物 |
|---|---|---|
| 1 | 社区定位与规则设计 | 社区定位卡（人群/主题/调性/规则） |
| 2 | 成员招募与冷启动 | 招募方案（渠道/话术/种子用户） |
| 3 | 活跃与互动机制设计 | 活跃机制方案（话题/仪式/激励/等级） |
| 4 | 内容生态建设 | 内容规划（UGC 引导/官方内容/精选） |
| 5 | 社区活动策划 | 活动方案（线上/线下/比赛/分享） |
| 6 | 商业化与转化 | 变现路径（会员/电商/广告/导流） |
| 7 | 数据复盘与治理 | 复盘报告 + 社区治理（违规/舆情/流失预警） |

## 3. 高频决策场景（4-5 类）

- **社区形态选择**（微信群/知识星球/自建APP/论坛/Discord 风格）→ 依据：目标人群、规模、互动深度、商业化需求、成本
- **冷启动方式**（种子用户从哪来、怎么留住）→ 依据：种子用户质量、核心成员（早期贡献者）识别
- **活跃机制取舍**（要不要等级/积分/签到/仪式）→ 依据：社区阶段（冷启动/成长期/成熟期）、用户动机、运营成本
- **内容治理边界**（管多严、哪些内容容忍）→ 依据：社区调性、合规风险、用户流失风险
- **商业化时机与方式**（何时变现、怎么变现）→ 依据：社区成熟度、用户信任、变现与体验的平衡

## 4. 能力地图

- **社区战略**：定位、形态选择、生命周期、商业价值论证
- **成员运营**：招募、冷启动、核心成员/志愿者体系、KOL 培育
- **活跃与互动**：话题、仪式、激励（等级/积分/勋章）、活动设计
- **内容生态**：UGC 引导、官方内容、内容精选与沉淀
- **治理与风控**：规则、违规处理、舆情、合规（群聊监管/个保法）
- **商业化**：会员制、电商、广告、知识付费、导流

## 5. 中国语境特点

- **平台生态差异**：微信群（私域+裂变基因，但功能简陋、群聊监管严）、知识星球（付费社群）、豆瓣小组（兴趣社区）、贴吧（流量衰退）、Discord 类自建（游戏/极客）——形态选择影响打法
- **群聊合规**：微信群主需对群内容负责（网信办群聊监管），违规内容风险高，需治理机制
- **私域变现导向**：中国社群商业化普遍（付费社群/带货/知识付费），"社群即渠道"是特色
- **关系链红利**：微信生态的熟人关系链利于裂变招募（老带新进群）
- **运营人力密集**：社区运营依赖人工（群管理/活动执行），规模化依赖机制与工具（群机器人/SCRM）

## 给 Skill 化的提示

按「定位 → 招募 → 活跃 → 内容 → 活动 → 商业化 → 复盘」七模块结构化沉淀，并为每模块附中国语境配置项（微信群合规、私域变现、关系链裂变），这套套件将区别于海外社区模板。
