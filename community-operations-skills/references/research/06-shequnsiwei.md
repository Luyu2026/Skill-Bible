# 《社群思维》方法论提炼

## 一、核心框架

### 1.1 社群三角模型（连接 × 信任 × 价值）
- **适用场景**：社群诊断与设计的基础框架，任何社群项目第一步
- **步骤**：
  1. **连接**：成员之间建立关系（破冰/自我介绍/小组/线下）
  2. **信任**：规则清晰、承诺兑现、透明治理（信任是商业化的前提）
  3. **价值**：持续输出价值（内容/资源/人脉/成长）
  4. 三要素缺一，社群失衡——用模型诊断短板补足
- **输出物**：社群三角诊断表（连接/信任/价值分别打分+短板补足方案）

### 1.2 社群商业路径（先社群后商业）
- **适用场景**：社群变现决策、商业化时机判断
- **步骤**：
  1. **经营关系**：先建立连接与信任（不急于变现）
  2. **验证信任**：小范围测试转化（社群内口碑/小额付费）
  3. **商业化**：在信任基础上做变现（会员/电商/知识付费）
  4. **持续经营**：变现后继续经营关系（不涸泽而渔）
- **输出物**：社群商业化路径方案（阶段/时机/方式）

### 1.3 社群运营 = 人设 × 内容 × 互动（情感经营）
- **适用场景**：社群日常运营、社群温度建设
- **步骤**：
  1. **人设**：立灵魂人物/群主IP（有温度有观点）
  2. **内容**：价值输出节奏（干货/资讯/资源）
  3. **互动**：仪式与活动（问候/打卡/话题/线下）
- **输出物**：社群日常运营 SOP（人设/内容/互动节奏）

## 二、决策规则（8条，标注章节）

1. **如果**社群不活跃，**则**用三角模型诊断——连接弱做破冰，信任弱做规则，价值弱做内容（第2章 三角模型）
2. **如果**社群要变现，**则**先验证信任（小范围测试），信任不够先经营关系（第5章 社群商业）
3. **如果**社群死气沉沉，**则**立人设+给温度（群主IP/问候/仪式），不是加促销（第3章 情感经营）
4. **如果**社群无规则，**则**先立规则（进群/发言/广告边界），规则是信任基础（第4章 治理）
5. **如果**社群要规模化，**则**设计裂变机制，但先过合规检查（微信裂变限制）（第6章 裂变）
6. **如果**社群活跃但无转化，**则**检查信任与价值（不是加广告频率）（第5章 商业）
7. **如果**群主缺席，**则**社群失去温度与凝聚力，需立人设或志愿者代位（第3章 人设）
8. **如果**建新社群，**则**先定三角怎么满足（连接/信任/价值），再选平台（第2章 三角模型）

## 三、检查清单

- [ ] 连接机制（破冰/自我介绍/小组/线下）
- [ ] 信任机制（规则/兑现/透明）
- [ ] 价值供给（内容/资源/人脉/成长）
- [ ] 灵魂人物/人设明确
- [ ] 日常互动节奏（问候/打卡/话题）
- [ ] 变现前验证信任（小范围测试）
- [ ] 裂变合规检查（微信规则）

## 四、反模式

- 把社群当流量池（只收割不经营）
- 建群就发广告（没有关系积累）
- 死群靠促销救（用交易代替经营）
- 无灵魂人物（群没温度没凝聚力）
- 裂变过度（伤害体验+微信合规风险）

## 五、边界声明（≥3条）

- 方法论基于中国社群语境（微信群/知识星球等），海外社区需适配
- 社群商业案例有营销叙事成分，效果不可简单复制
- 情感经营依赖个人投入，规模化时温度难维持
- 作者立场：社群布道者，有"社群万能"倾向，产品/服务力仍是基础
