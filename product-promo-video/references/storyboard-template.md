# 产品宣传视频镜头脚本

每一场只推动一个理解动作。屏幕文字放关键词，旁白补充逻辑；两者不要逐字重复。

| 时间 | 这一场要让观众明白什么 | 真实画面 / 素材 | 屏幕文字 | 旁白 | 证据来源 | 转场 |
| --- | --- | --- | --- | --- | --- |
| 0-3s | 用户场景或核心结果 |  |  |  |  |  |
| 3-8s | 产品承诺与品牌 |  |  |  |  |  |
| 8-18s | 证明 1：关键产品动作 |  |  |  |  |  |
| 18-28s | 证明 2：任务如何完成 |  |  |  |  |  |
| 28-35s | 可信事实 / 结果（可选） |  |  |  |  |  |
| 35-40s | CTA |  |  |  |  |  |

## 审阅问题

- 没有声音时，能看出谁在用、解决什么任务吗？
- 每张截图是否真的证明旁白，而不是只做背景？
- 数字和用户评价是否有来源，且不因视觉效果被放大？
- 删掉任一场后，是否更聚焦？如果是，删掉它。
- CTA 是否只有一个，并与发布目标一致？
