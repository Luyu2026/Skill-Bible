# 产品宣传视频

把真实产品资料做成可以发布、可以继续迭代的宣传片。

它不从“选一个酷炫风格”开始，而是先确定目标用户、核心承诺、真实证据和 CTA；再用真实产品界面、动效、字幕、配音与配乐渲染为 MP4。你给出个人产品、官网或截图即可开始。

## 你会拿到什么

- 一份发布 brief：受众、目标、核心承诺、证据、渠道和 CTA；
- 可拍可审的镜头脚本，而不是一段泛泛旁白；
- 静帧预览，先检查产品画面、文案与证据，再渲染成片；
- 带字幕、配音、配乐和动效的 MP4，以及可继续修改的 brief、素材和时间轴；
- 发布后的首轮验证指标，知道该改开场、卖点还是 CTA。

## 适合什么时候用

- 新产品或新功能上线，需要官网、发布会或社媒宣传片；
- 有产品截图和功能说明，但讲不清视频该突出什么；
- 想做应用商店或信息流短视频，又不想用虚构 UI 和无出处数据；
- 需要把同一产品按不同渠道重新讲清，而不是简单裁切画幅。

## 怎么开始

把本页面链接发给正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/product-promo-video

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：装在了哪里，以及我下一句该怎么调用它。
```

装好后，直接说：

```text
请使用「产品宣传视频 Skill」为这个产品制作一条宣传视频。

产品链接 / 截图 / 录屏：
这次发布什么：
目标用户和他们此刻的使用场景：
投放渠道：官网 / 应用商店 / 抖音或小红书 / 发布会 / 其他
希望观众看完做什么：
我可以提供的数据、用户反馈或事实证据：

请先完成发布 brief 和镜头脚本；用真实界面和可追溯事实制作，先给静帧预览再渲染成片。
```
