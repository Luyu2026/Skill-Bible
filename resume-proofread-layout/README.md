# 简历纠错与排版

## 适合什么场景

用户提供已有简历，希望纠正错字、统一格式、解决拥挤或导出前检查，而不是凭空编写经历。

已有材料可以直接发来，不需要先整理成标准问卷。

## 解决什么

把已有简历中的事实矛盾、表达错误和阅读阻碍逐项修正，交付保留真实经历的干净正文与可实施排版规格。

先处理眼前问题，避免拿到一堆难以采用的泛泛建议。

## 一个重要机制

将确定错误、需本人确认的疑点和风格建议分开。

排版修复不能掩盖日期冲突、数字口径或个人贡献不清。

这让结果既能直接用，也能看出哪些地方还需要你确认。

## 你会拿到什么

- 可复制的修订正文及逐条修改记录
- 排版规格、事实待确认项和投递前检查
- 有工具时附实际文件；无工具时明确交付为正文与操作步骤

完整的模拟输入与成品见 [演示](DEMO.md)。

## 怎么开始

1. 直接贴出现有材料。
2. 告诉我这次最想解决的一个问题。
3. 补充限制，例如语气、方法、时间或输出形式。
4. 拿到结果后，只需回传当前仍不满意或没理解的一处。

建议提供：

- 简历原文或文件；截图需先核对识别出的姓名、日期、数字
- 目标岗位 JD 可选；没有 JD 仍可纠错但不做岗位匹配判断
- 输出用途：在线投递、打印、Word 或 PDF，以及页数要求

工具无法读取附件时，可以先粘贴核心文字；仍能得到与这些文字对应的结果。

## 可直接复制的调用模板

```text
请使用 resume-proofread-layout。
我的材料：
（粘贴原稿、题目、照片描述或当前处境）

这次最卡的是：
（只写当前要解决的一件事）

请保留的事实或限制：
（写不能改的事实，以及你希望采用的语气、方法或输出形式）

请直接给本轮成品；无法确认的内容单列，不要替我补造事实。
```
