# 简历纠错与排版

## 适合什么场景

用户提供已有简历，希望纠正错字、统一格式、解决拥挤或导出前检查，而不是凭空编写经历。

贴完整简历，保留原换行、日期和数字；截图可遮住联系方式。

## 解决什么

把已有简历中的事实矛盾、表达错误和阅读阻碍逐项修正，交付保留真实经历的干净正文与可实施排版规格。

只说“润色简历”常把参与写成主导，或把页面挤到难以阅读。本技能先锁定事实与改动权限，再分开验收文字、版式和实际文件。

## 一个重要机制

将确定错误、需本人确认的疑点和风格建议分开。

排版修复不能掩盖日期冲突、数字口径或个人贡献不清。

原文日期倒序、百分比口径不一属于待本人确认；错别字、标点和同一术语大小写属于可直接修正。

## 你会拿到什么

- 可复制的修订正文及逐条修改记录
- 排版规格、事实待确认项和投递前检查
- 有工具时附实际文件；无工具时明确交付为正文与操作步骤

可查看 [完整模拟成品与边界案例](references/review-validation.md#模拟运行成品)。

## 怎么开始

1. 贴完整简历，保留原换行、日期和数字；截图可遮住联系方式。
2. 说清要 Word/PDF、在线投递还是打印，以及允许改到什么程度。
3. 有 JD 一并贴来；拿到稿后只核对待确认项，导出文件再看分页。

图片不清时逐项问姓名、日期和数字中的不清字符；其他可读段落先纠错。

用户下一步只需确认疑点或回传导出预览；未确认的核心身份、时间和成果问题解决前，不标为可直接投递。

## 可直接复制的调用模板

```text
请使用 resume-proofread-layout。

原稿：运营实习生 2025.06-2025.08，负责社群运维，提生用户活跃度，参与策划3场活动。
已确认：无活跃结果数据，不把参与改成主导。
用途：一页 Word；暂时无 JD。
请给干净正文、修改表、具体排版参数及未完成验收项。

已有材料以我提供的为准。
无法确认的内容放在正文之外说明。
```
