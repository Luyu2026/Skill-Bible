# 朋友圈活动海报制作

## 它适合什么场景

把门店活动文字、品牌素材和发布要求变成可发布的朋友圈海报；适用于活动通知太乱、不会排版、需要活动海报成品或修改旧海报的场景。

从一份已经有的材料开始即可，不需要先学一套方法。

## 它解决什么

普通聊天往往只给设计建议；这里把已有活动信息变成一张信息准确、手机上能读清的海报，并交付可编辑源稿。

它会先处理你当前卡住的一件事，再给能直接使用的结果。

## 一个重要机制

先区分活动招募、商品促销和营业通知；只突出一个主行动。

标题负责让人知道是什么活动，利益点负责说明为什么参加，规则负责防止误解。

这个区分会影响先做什么，以及最后交付哪一种结果。

## 你会拿到什么

- 可编辑海报源文件；工具支持时同时给 PNG。
- 一份完整文案与发布前仍需确认的事实。
- 一句发布配文，沿用海报事实且只保留一个行动。
- 验收以内容准确、缩小可读、入口可用、文件可打开为准。

## 怎么开始

1. 发来你已有的原文、记录或草稿。
2. 说明现在希望解决的卡点和本轮目标。
3. 写出会影响处理的时间、渠道或方法限制。
4. 收到结果后直接使用；有新反馈时带回原话或实际产物。

不必补齐所有背景；会先使用已有材料，只有关键缺口才追问。

## 可直接复制的调用模板

```text
请使用 social-event-poster 帮我完成这次任务。
我已有的材料：
（在这里粘贴原文、草稿或提供可访问文件）

我现在最卡的是：
（描述具体问题）

本轮希望拿到：
（说明成品形式和长度）

需要遵守的限制：
（时间、渠道、边界或可用方法）

请先使用现有材料，区分事实与待确认信息，给可直接用的结果和下一步。
```
