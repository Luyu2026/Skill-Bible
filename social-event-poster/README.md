# 朋友圈活动海报制作

## 它适合什么场景

门店活动信息已经齐了，但海报里日期、优惠和报名入口挤在一起。

也适合修改旧海报：指出看不清的文字或提供手机截图即可。

## 它解决什么

把活动事实整理成一张可编辑海报，优先保证标题、规则和行动入口读得清。

价格、名额和截止时间逐项核对；缺失的事实会列为待确认，不写进发布版。

## 一个重要机制

一个主行动，五层信息。

标题让人知道活动是什么，时间地点和利益帮助决定，限制说明适用条件，最后才是报名方式。

长规则先改文案或换行，不靠缩小到难读来塞满。

## 你会拿到什么

- 可编辑 SVG 或可用设计源稿。
- 工具支持时导出的 PNG，标明实际尺寸。
- 与海报一致的朋友圈配文。
- 价格、时间和入口的待验清单。

## 怎么开始

1. 发活动原文或旧海报，附真实日期、地点、优惠限制。
2. 提供可用 logo、图片与想要的尺寸；没有图片也能做。
3. 说明只要源稿还是还要 PNG。
4. 收到后用手机预览；把裁切或难读的位置截图带回。

## 可直接复制的调用模板

```text
请使用 social-event-poster。

活动：2026年11月8日书店读书会，14:00—16:00。
地点：青禾路8号小禾书店。
规则：免费20席，提前到店报名。
素材：没有logo和照片，不要虚构二维码。
渠道：朋友圈，1080×1440。
请交可编辑海报源稿和配文；能导出时附PNG，不能时注明。
```
