# 人生选择分支模拟

## 适合什么场景

用户想体验人生重来、模拟一个选择的不同走向，或比较留在原处与尝试新路径。

写出正在纠结的两个选项，或说只想玩虚构故事。

## 解决什么

以用户当前处境和约束为起点，把同一个选择展开成有因果链的虚构分支，让用户看见代价、偶然因素和可尝试的小行动。

普通聊天容易为喜欢的选项写好结局，却忽略两条路消耗同一份时间。本技能把选择、资源与事件连在一起，交付可以继续选择的虚构节点和现实试探。

## 一个重要机制

先区分故事娱乐和现实选择梳理；故事结局不作为预测或建议证据。

分支差异来自决定、资源约束与事件，不来自对用户的性格定命。

至少知道一个选择和一个硬约束；仅有“重开人生”时提供故事起点供选，不索要真实隐私。

## 你会拿到什么

- 共同起点、两个可比较分支及明确的虚构标记
- 关键假设变化和一个现实试探动作
- 含当前节点、资源变化、下一选项的续玩存档

可查看 [完整模拟成品与边界案例](references/review-validation.md#模拟运行成品)。

## 怎么开始

1. 写出正在纠结的两个选项，或说只想玩虚构故事。
2. 给可用时间、成本底线和想看到的时间点；收入可保持不公开。
3. 选择一个节点继续；隔天续玩时把存档一起贴回。

用户不愿提供年龄或收入时，用阶段、可用时间和预算上限代替；不要求身份资料。

续玩存档包含已选项、时间点、剩余资源、未决事件；下轮从存档续接，不能声称无人运行时自动演进。

## 可直接复制的调用模板

```text
请使用 life-choice-simulator。

模式：现实选择梳理。
选择：系统学插画，还是先轻量体验。
约束：保留工作，每周最多六小时，不买长期课程。
观察到三个月后；比较代价和关键假设，给一个可逆试探和续玩存档。

已有材料以我提供的为准。
无法确认的内容放在正文之外说明。
```
