# 人生选择分支模拟

## 适合什么场景

用户想体验人生重来、模拟一个选择的不同走向，或比较留在原处与尝试新路径。

已有材料可以直接发来，不需要先整理成标准问卷。

## 解决什么

以用户当前处境和约束为起点，把同一个选择展开成有因果链的虚构分支，让用户看见代价、偶然因素和可尝试的小行动。

先处理眼前问题，避免拿到一堆难以采用的泛泛建议。

## 一个重要机制

先区分故事娱乐和现实选择梳理；故事结局不作为预测或建议证据。

分支差异来自决定、资源约束与事件，不来自对用户的性格定命。

这让结果既能直接用，也能看出哪些地方还需要你确认。

## 你会拿到什么

- 共同起点、两个可比较分支及明确的虚构标记
- 关键假设变化和一个现实试探动作
- 含当前节点、资源变化、下一选项的续玩存档

完整的模拟输入与成品见 [演示](DEMO.md)。

## 怎么开始

1. 直接贴出现有材料。
2. 告诉我这次最想解决的一个问题。
3. 补充限制，例如语气、方法、时间或输出形式。
4. 拿到结果后，只需回传当前仍不满意或没理解的一处。

建议提供：

- 当前年龄阶段、生活处境和真正纠结的一个选择
- 已有资源：时间、预算、关系支持和已有能力
- 不能牺牲的底线，以及希望模拟到什么时候

工具无法读取附件时，可以先粘贴核心文字；仍能得到与这些文字对应的结果。

## 可直接复制的调用模板

```text
请使用 life-choice-simulator。
我的材料：
（粘贴原稿、题目、照片描述或当前处境）

这次最卡的是：
（只写当前要解决的一件事）

请保留的事实或限制：
（写不能改的事实，以及你希望采用的语气、方法或输出形式）

请直接给本轮成品；无法确认的内容单列，不要替我补造事实。
```
