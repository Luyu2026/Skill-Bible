# 伴侣需求沟通

## 它适合什么场景

你想说“我希望你多陪陪我”，一开口却成了“你根本不在乎我”。

适合愿意沟通的伴侣，围绕一次具体事件讨论陪伴、分担和回应偏好。

## 它解决什么

把抱怨改成可开口的需求表达，再提出一个允许拒绝和调整的动作。

先解决这一次想怎样相处，不替缺席的一方判断动机。

## 一个重要机制

爱的语言只用来探索偏好。

真正决定约定的是双方说出的需要、可行时间与明确同意。

“我建议”与“我们已经答应”会分开记录。

## 你会拿到什么

- 一段自然的开口话。
- 对方愿意、犹豫、拒绝时的承接句。
- 一个首选请求与轻量替代方案。
- 已同意的约定或仍未解决的分歧。

## 怎么开始

1. 给最近一次具体事件和双方原话。
2. 说清你想看到的一个改变。
3. 补充对方已经明确的偏好、限制或拒绝。
4. 先试一个请求，带回真实回应再调整。

## 可直接复制的调用模板

```text
请使用 couple-needs-dialogue。

事件：昨晚晚饭时对方一直看手机，我说了“你根本不爱我”。
我想改变：吃饭时能专心聊当天的一件事。
对方观点：还不知道，不要替对方解释。
限制：不想翻旧账，也不想用爱不爱施压。
请写开口、三种回应的承接和一个可协商动作；未答应的不要写成约定。
```
