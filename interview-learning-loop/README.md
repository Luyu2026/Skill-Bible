# 面试训练循环

把每天零散的练习、模拟和真实面试反馈，沉淀进一份会持续更新的面试训练档案。

## 学员如何开始

创建或提供一份面试训练档案，然后每天直接对 Agent 说当天发生了什么。例如：

```text
我今天练了自我介绍，30 秒能说完，但被问到为什么选这个策略时又卡住了。
请更新我的面试训练档案，并告诉我今天下一步只需要做什么。
```

## 档案里会发生什么

- 顶部永远显示今天最该做的一件事。
- 每次反馈都会以倒叙记录沉淀，方便回看进步和卡点。
- 系统按当前问题联动备书、模拟、逐字稿去 AI 味、复盘、岗位核验或谈薪等 Skill。
- 已有知识库权限时，按任务调用少量相关材料，而不是全量翻阅。

这不是每天刷题的计划表。它的作用是让学生每次只做当下最有价值的一步，同时把真实反馈持续变成后续训练材料。
