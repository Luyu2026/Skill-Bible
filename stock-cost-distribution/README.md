# 股票成本分布估算

## 适合什么场景

分析股票筹码截图或按用户提供的逐笔、日线数据估算成本分布，交付图表、口径与敏感性检查。适用于输入股票代码并附数据、解读筹码峰或比较分布变化；不承诺识别主力持仓。

你已经有材料，却卡在把它变成可使用结果的这一步。
可以提交初稿、截图或片段，不必先重新整理。

## 解决什么

把用户提供的行情或筹码截图转成可追溯的成本分布解释与估算图，解决把成交量分布误认成真实持仓的问题。

本轮围绕一个具体卡点完成交付。
事实不够的地方会标清，已能完成的部分先交付。

## 一个重要机制

供应商筹码、成交量价格分布和持仓成本估算是三类不同输出

OHLCV 不能反推出真实投资者持仓和身份

这样你能知道哪些结论有材料支持，哪些仍需确认。

## 你会拿到什么

- 输入质量与数据来源摘要
- 带单位、日期和模型标题的分布图或可编辑底表
- 密集区与敏感性解释
- 缺字段时给可执行补数清单和降级输出

结果以可复制文本或可编辑表格呈现。
若相关工具可用，再按你的要求生成文件。

## 怎么开始

1. 贴出现有材料或提供可读取的文件。
2. 说清当前卡点和本轮想拿走的结果。
3. 补充使用场景与不可改变的限制。
4. 收到成品后，按其中一个下一步复交即可。

优先提供：代码、交易市场、截止日期与用户想核对的现象。
可选补充：优先使用已有筹码截图、导出数据及供应商算法说明。
