# 股票成本分布估算

## 适合什么场景

你想看懂筹码截图，或用自己的行情数据复算成本分布。

适合比较同口径不同日期的峰区；只有代码时需先补数据。

## 解决什么

把图上的含义、模型假设和不能判断的事情分开，提供可复算底表。

本轮围绕你提交的材料完成一份可使用的结果。
缺失项会明确标出，已有材料不需要重新整理。

## 一个重要机制

先区分供应商筹码图、成交量价格分布和带衰减假设的存量模型。

没有换手率就只做成交量分布；峰区不能证明主力身份或未来涨跌。

## 你会拿到什么

- 数据质量与复权、单位、日期口径摘要
- 带轴单位的图或可编辑分布底表
- 峰区、中位数和明确口径的分位区间
- 分箱及窗口敏感性、具体补数字段

结果优先给可复制正文或可编辑表格。
如需文件，会说明实际生成和验证到哪一步。

## 怎么开始

1. 给代码、市场、截止日期和你要核对的现象。
2. 附供应商截图或行情 CSV，不只给股票名称。
3. 说明价格复权、成交量单位和换手率分母。
4. 需要比较变化时交回另一截止日的同口径数据。

只有截图也能做可见内容解读，但不能凭图片补出精确权重。

可先查看 [完整模拟案例](references/review-example.md) 了解成品形式。

## 可直接复制的调用模板

```text
请使用 stock-cost-distribution。
市场与代码：[填写]
截止日期：[填写]
材料：[截图或含 date/low/high/close/volume/turnover_rate 的数据]
口径：[币种、复权、成交量单位、换手率定义]
想核对：[某个峰区或日期变化]
请区分成交量与存量模型，给可复算底表及敏感性，不推断账户或主力身份。
```
