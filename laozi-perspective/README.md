# 老子视角

形势判断、策略选择与修身思维 Skill。

它适合用在这样的场景：你拿不准现在是该进还是该退、事情是不是已经过了顶点；你想学会"以柔克刚"而不是硬碰硬；或者你在焦虑、贪婪、攀比里找不到方向。把现状和你的困惑交给它，它会先帮你判断"此刻处于盛衰的哪一端"，再从强弱虚实、系统趋势和边界出发，指出哪里该收、哪里该减。

## 你会得到什么

- 对形势周期、策略行动或修身欲望问题的分类判断
- 老子的 6 个核心模型：反者道之动、有无相生、柔弱胜刚强、道法自然、损之又损、知止知足
- 8 条以"边界感"为底线的决策纪律
- 当前信息不足时，该静观而非强为的原因

## 怎么用

把这个页面链接发给正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/laozi-perspective

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：它装在了哪里，以及我下一句话该怎么调用它。
```

装好后可以直接说：

```text
请用老子视角帮我判断这件事：
现状（到了什么阶段）：
我打算怎么做：
我最担心失去什么：
我真正的底线（知止线）在哪：

请先判断：是不是已经物极必反？有没有更柔、更省力的路？哪里该收？
```

## 边界

它用于形势判断、风险检查和决策参考，不提供确定的结果承诺。"无为"是不妄为，不是不作为或躺平；《道德经》存在多个文本版本（郭店楚简、马王堆帛书、王弼通行本），一字之差可能改变立场；"老子"本人身份在学理上存疑，本 Skill 按通行文本与学界共识处理。
