# 《增长五线》· 增长战略方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

## 核心框架

### 框架1：增长五线（增长全景图）
- **适用场景**：设计增长战略、评估增长路径、判断增长质量时
- **步骤**：
  1. **撤退线**：什么情况下退出/止损，保住底线
  2. **成长底线**：基本盘是什么，稳不稳
  3. **增长线**：进取的增长路径（产品/渠道/市场）
  4. **爆发线**：可能指数级增长的杠杆（爆款/网络效应）
  5. **天际线**：天花板在哪，增长空间的极限
- **输出物**：增长地图（五线定位 + 目标线）
- **来源**：《增长五线》全书框架

### 框架2：结构增长 vs 机会增长
  - **适用场景**：判断增长质量
  - **步骤**：区分增长来自"单一机会"（不可持续）还是"结构组合"（可持续），把机会增长转化为结构增长
  - **输出物**：增长质量判断 + 结构强化建议
  - **来源**：增长结构章节

## 决策规则（节选）

1. **如果**要定增长战略，**则**先画五线图，明确当前位置和目标线。（增长地图章节）
2. **如果**增长靠单一爆款/红利，**则**判定为机会增长，尽快补结构。（结构章节）
3. **如果**资源有限，**则**把资源投到"增长线"上的最大杠杆点。（增长线章节）
4. **如果**看不清是否该继续投入，**则**画撤退线——明确什么条件下退出。（撤退线章节）

## 检查清单

- [ ] 是否定位了五线中的当前位置
- [ ] 成长底线（基本盘）是否稳固
- [ ] 增长线是否有明确的进取路径
- [ ] 是否识别了可复制的爆发杠杆
- [ ] 是否知道天际线（天花板）在哪
- [ ] 是否区分了结构增长与机会增长

## 反模式

- 只有增长线，没有撤退线（不懂止损）。
- 把机会增长当战略（不可持续）。
- 画了地图不落地（战略与执行脱节）。

- 战略框架偏静态，快速变化的市场需配合验证。
