## 1. 场景与目标

**背景**：某内容平台 App（知识付费方向，注册用户 500 万，DAU 80 万），收入来源：会员订阅（占比 55%）、单次课程购买（30%）、广告（15%）。连续两个季度营收下滑：Q1 ¥1,800 万 → Q2 ¥1,620 万 → Q3 ¥1,430 万（累计 -20.5%）。

**问题**：收入为什么跌？是会员、课程还是广告的问题？怎么止损？

**约束**：
- 会员续费率 58%（低于健康线 60%）
- 单次课程转化率 3.2% → 2.6%（持续下滑）
- 广告 eCPM 基本没变（不是广告端问题）
- 股东要求 Q4 止跌回升

**目标**：定位主因（证据分级），给出止损 + 验证 + 长期三组动作。

---

## 2. 核心判断（结论先行）

**主因：会员续费率下滑（58% 低于健康线）+ 新增用户付费转化变弱，双线收缩吃掉收入。**（证据等级 B：数据 + 逻辑推理）

**为什么不是广告问题**：广告收入占比 15% 且 eCPM 稳定，广告端不是主因。
**为什么不是大盘问题**：行业知识付费大盘 Q3 环比基本持平（第三方数据监测），排除了"市场整体变冷"。
**为什么是会员+新客**：收入拆解显示——
- 会员收入环比 -12%（占收入 55%，是最大失血点）
- 课程收入环比 -8%（转化率 3.2%→2.6%）
- 广告收入环比 -2%（基本稳定）

---

## 3. 指标拆解

```
营收 ¥1,430万（Q3，环比 -11.7%）
├── 会员 ¥786万（环比 -12%）← 最大失血点
│   ├── 存量续费：续费率 58%（< 60% 健康线）
│   └── 新增付费：新注册付费转化 2.1% → 1.6%
├── 课程 ¥429万（环比 -8%）
│   └── 单次购买转化率 3.2% → 2.6%（内容吸引力下降？）
└── 广告 ¥215万（环比 -2%，基本稳定）

健康度检查：
- 续费率 58% < 60% 健康线 ❌
- 单用户 LTV ≈ ¥86，CAC ≈ ¥32 → LTV/CAC = 2.7（< 3 健康线）⚠️
```

**关键发现**：**LTV/CAC 跌破 3**——说明获客的经济性也在恶化，这不是单纯"老客流失"问题，而是"拉来的新客也没以前值钱"。

## 4. 现象定位与归因

| 因素 | 判断 | 证据等级 |
|------|------|---------|
| 会员续费率 58% 低于健康线（权益感知下降） | 主因 | B（续费数据 + 用户访谈） |
| 新增付费转化 2.1%→1.6%（新客质量或内容吸引力下降） | 次因 | B（转化漏斗数据） |
| 内容供给增速放缓（头部课程数量 -20%） | 待验证 | C（内容库数据） |
| 竞品推出更便宜的年卡 | 待验证 | C（需竞品调研） |
| 定价未变、功能无重大变化 | 排除 | A（产品日志） |

**保留的分歧**：续费率下滑到底是"权益感觉不值"还是"竞争分流"——需要用户访谈 + 竞品调研确认，这直接决定动作方向。
