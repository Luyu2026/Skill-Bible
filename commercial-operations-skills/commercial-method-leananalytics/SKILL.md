# 《精益数据分析》· 数据驱动方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

## 核心框架

### 框架1：第一关键指标（OMTM）
- **适用场景**：指标太多不知看哪个、团队没对齐重点时
- **步骤**：
  1. 列出当前阶段所有候选指标
  2. 选出唯一一个"现在最重要"的指标（OMTM）——它最能反映业务健康与增长
  3. 所有实验和目标围绕 OMTM，其他指标只作参考
  4. 阶段变化（如从验证期到成长期）就换 OMTM
- **输出物**：当前阶段的 OMTM + 选择理由
- **来源**：第一关键指标章节

### 框架2：AARRR 漏斗定位
  - **适用场景**：定位经营链路最弱的环节
  - **步骤**：按 获取-激活-留存-收入-推荐 五环节看数据，定位瓶颈，一个个打透
  - **输出物**：当前最薄弱环节 + 优化动作
  - **来源**：AARRR 章节

### 框架3：实验循环（精益验证）
  - **适用场景**：不确定的商业决策
  - **步骤**：提出假设 → 设计最小实验 → 执行 → 用数据看结果 → 达标放大/不达标换假设
  - **输出物**：已验证的实验结论或"未通过"记录
  - **来源**：实验章节

## 决策规则（节选）

1. **如果**指标太多，**则**选一个 OMTM，聚焦打透，不平均用力。（OMTM 章节）
2. **如果**要验证商业决策，**则**先设"达到 X 就放大"的过线标准再实验。（实验章节）
3. **如果**要看瓶颈，**则**用 AARRR 找最弱环节，单点突破。（漏斗章节）
4. **如果**数据与直觉冲突，**则**以数据为准（但先验证数据可信度）。（数据决策章节）

## 检查清单

- [ ] 是否明确了当前阶段的 OMTM
- [ ] 是否用 AARRR 定位了最弱环节
- [ ] 每个实验是否有假设 + 过线标准
- [ ] 是否单次只改一个变量
- [ ] 是否区分了虚荣指标与可行动指标

## 反模式

- 盯着一堆虚荣指标（下载量/注册数）而忽略真实价值。
- 没有 OMTM，各做各的。
- 实验无过线标准，永远没结论。

## 边界声明

- 方法源自互联网/软件创业，传统行业需适配（数据颗粒度不同）。
- 实验需要足够样本，样本不足时参考性有限。
