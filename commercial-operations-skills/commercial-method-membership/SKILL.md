# 《订阅经济》· 订阅模式方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

## 核心框架

### 框架1：经常性收入模型（订阅的本质）
- **适用场景**：评估是否引入订阅/会员模式、设计订阅结构时
- **步骤**：
  1. 确认产品或服务是否具备"持续价值"（用户愿意反复付费的理由）
  2. 设计订阅结构（月度/季度/年度、分层档位）
  3. 用 MRR/ARR（月/年经常性收入）作为核心经营指标
  4. 用留存与续费驱动增长，而非一次性拉新
- **输出物**：订阅模式可行性判断 + 订阅结构设计
- **来源**：经常性收入章节

### 框架2：续费率 = 生命线（留存驱动）
  - **适用场景**：订阅业务的健康度评估
  - **步骤**：持续跟踪续费率/流失率；续费 < 60% 先查价值交付，不盲目拉新
  - **输出物**：续费健康度判断 + 改进动作
  - **来源**：留存与续费章节

### 框架3：客户终身价值（LTV 思维）
  - **适用场景**：定获客预算、评估订阅经济性
  - **步骤**：LTV = ARPU × 客户寿命；LTV/CAC ≥ 3 才健康；获客预算以 LTV 为上限
  - **输出物**：LTV/CAC 测算 + 获客预算建议
  - **来源**：LTV 章节

## 决策规则（节选）

1. **如果**要上订阅模式，**则**先确认产品有没有"持续价值"——没有持续价值做不了订阅。（订阅前提章节）
2. **如果**续费率 < 60%，**则**先查价值交付与权益，不急着拉新。（留存章节）
3. **如果**定获客预算，**则**以 LTV 为上限，LTV/CAC < 3 要收紧。（经济性章节）
4. **如果**设计档位，**则**用锚点档让主力档显超值，年付折扣锁定长期。（定价章节）

## 检查清单

- [ ] 产品是否有持续价值（用户反复付费的理由）
- [ ] 是否以 MRR/ARR 为核心指标
- [ ] 是否持续跟踪续费率/流失率
- [ ] 是否用 LTV/CAC 评估经济性
- [ ] 是否设计了宽恕机制（暂停/降级/挽留）

## 反模式

- 没有持续价值硬做订阅（用户取消率高）。
- 只拉新不重留存（续费崩盘）。
- 获客成本超过 LTV（越做越亏）。

## 边界声明

- 方法源自 SaaS/订阅消费品牌，非订阅业务（如一次性交易）需适配。
- 订阅经济性因行业差异大，具体数字需结合业务测算。
