# 《我看电商》· 零售效率方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

## 核心框架

### 框架1：生意三问（判断电商模式值不值得做）
- **适用场景**：评估一个新的电商模式/品类/店
- **步骤**：
  1. 问"它解决什么真实需求、提升什么效率"（进销存/周转/匹配）
  2. 问"靠什么赚钱、毛利够不够、现金流能否转起来"
  3. 问"能否持续，而不是依赖一次性流量/补贴"
- **输出物**：模式可行性判断（值/暂缓/放弃 + 理由）
- **来源**：第一章「零售本质」

### 框架2：三倍周转（效率致胜）
  - **适用场景**：经营层面选效率杠杆
  - **步骤**：从库存周转、商品组织、供应链三个环节找最大提升点，一次打一个
  - **输出物**：本周期的效率优化重点
  - **来源**：库存/供应链章节

## 决策规则（节选，可追溯）

1. **如果**一个电商模式讲不清怎么赚钱，**则**判定为不可持续，回到生意本质验证。（第1章）
2. **如果**要判断GMV真伪，**则**看利润与现金流是否为正，而非只看成交规模。（第4章）
3. **如果**要设计长期经营，**则**把供应链与商品组织能力放第一位，流量只是手段。（第6章）
4. **如果**某个环节损耗（退货/售后/物流）占比升高，**则**把它作为优先优化对象，它直接吃掉利润。（第7章）

## 检查清单

- [ ] 是否讲清真实用户需求与提升的效率
- [ ] 是否算清毛利/现金流/周转，而非只看 GMV
- [ ] 是否识别了会侵蚀利润的隐形损耗环节
- [ ] 是否有可复购或可持续的模式，而非单次流量驱动

## 反模式

- 只冲 GMV 不赚钱的玩法
- 依赖补贴/低价/流量投机驱动
- 忽略库存/售后/物流等"看不见的坑"
