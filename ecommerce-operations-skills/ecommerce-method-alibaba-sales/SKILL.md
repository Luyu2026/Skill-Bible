# 《阿里铁军销售法》· 目标与成交方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

## 核心框架

### 框架1：目标倒推法（从目标反推动作）
- **适用场景**：定月度/大促销售目标，并把目标拆成可执行的每日动作
- **步骤**：
  1. 定目标（GMV/件数）
  2. 倒推：目标 → 成交单数 → 需要多少有效沟通/流量 → 需要多少动作（触达/跟进）
  3. 落到人：谁、每天做多少、什么时间做
  4. 每日检查：实际 vs 进度，偏差即调整动作
- **输出物**：目标拆解表 + 每日动作清单
- **来源**：目标管理章节

### 框架2：客户分层与推进（把客户管成进度）
  - **适用场景**：店铺客户/意向用户太多，不知优先跟进谁
  - **步骤**：
    1. 分层（按意向/价值：A 高意向高价值 → D 低意向低价值）
    2. 不同层不同话术与动作（A 层重点跟进，D 层批量触达）
    3. 每层设定推进标准（下一步动作是什么、多久跟进）
    4. 定期复盘层间转化，优化分层
  - **输出物**：客户分层表 + 分层话术与跟进节奏
  - **来源**：客户管理章节

### 框架3：话术 SOP（把转化经验固化成流程）
  - **适用场景**：客服/主播/销售转化不稳定，靠个人发挥
  - **步骤**：把高转化的话术拆成"开场-探需-异议处理-逼单-收尾"标准结构，形成可培训、可复制的 SOP
  - **输出物**：一套话术 SOP + 常见异议应对表
  - **来源**：话术章节

## 决策规则（节选）

1. **如果**目标总完不成，**则**用目标倒推法把它拆到"每天几个动作"，动作层面的缺口才是真问题。（目标章节）
2. **如果**资源有限，**则**按客户分层优先服务 A 层（高意向高价值），不平均用力。（分层章节）
3. **如果**转化不稳定，**则**把高手的成交话术固化成 SOP，让平均水平的执行者也能达标。（话术章节）
4. **如果**要带团队/带新人，**则**用 SOP + 日检查的方式复制能力，而不是靠个人悟性。（铁军文化章节）

## 检查清单

- [ ] 目标是否倒推到"每日可执行动作数"
- [ ] 客户是否分层，且有分层动作与跟进节奏
- [ ] 关键转化环节是否有话术 SOP
- [ ] 是否有人对进度做日检查

## 反模式

- 目标只到数字，不到动作（完不成的目标）
- 所有客户同等对待，高价值客户被淹没
- 转化靠个人发挥，没有可复制的 SOP

## 边界声明

- 方法源自 B 端销售团队（阿里铁军），电商零售场景需适配（把"拜访"换成"触达/直播/客服"）
- 铁军文化偏强执行与高压，个人/小团队需按自己的节奏吸收
- 目标倒推依赖对转化率的估算，估算不准则拆解失真
