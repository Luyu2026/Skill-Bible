# 《增长黑客》· 增长实验方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

## 核心框架

### 框架1：增长实验循环（Hacking 循环）
- **适用场景**：想系统、低成本地找到某个经营指标的增长点
- **步骤**：
  1. 定北极星指标（唯一关键指标）
  2. 提出假设（如果做X，指标Y会提升Z%）
  3. 设计最小实验（成本最低的验证方式）
  4. 执行 + 用数据看结果（达到过线标准？）
  5. 达标放大 / 不达标换假设，循环
- **输出物**：一个已验证的增长实验或"未通过"记录
- **来源**：增长循环章节

### 框架2：北极星指标
  - **适用场景**：指标太多不知看哪个 / 团队没对齐
  - **步骤**：选一个能代表核心价值的指标，所有实验围绕它
  - **输出物**：北极星指标 + 拆解路径
  - **来源**：增长框架章节

## 决策规则（节选）

1. **如果**想验证一个增长想法，**则**先设"达到 X 就放大、没到就换"的过线标准再实验。（实验章节）
2. **如果**要做实验，**则**单次只改一个变量，否则无法归因。（A/B 章节）
3. **如果**需要选增长重点，**则**以北极星指标为准，不看无关联的虚荣指标。（北极星章节）
4. **如果**一个实验多次未过线，**则**及时止损换方向，不恋战。（迭代章节）

## 检查清单

- [ ] 是否先定了北极星指标
- [ ] 每个实验是否有明确假设 + 过线标准
- [ ] 单次实验是否只改一个变量
- [ ] 是否有"未过线就止损"的机制

## 反模式

- 一次改很多变量导致无法归因
- 只做增长实验没有北极星，各做各的
- 追求虚荣指标而偏离核心价值

## 边界声明

- 方法源自互联网产品增长，对需要重资产/强供应链的电商环节需结合
- 实验需要足够流量/样本，长尾店样本不足时参考性有限
- 北极星指标选择因人而异，需结合业务定
