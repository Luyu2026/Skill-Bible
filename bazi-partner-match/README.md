# 八字搭档娱乐匹配

## 适合什么场景

两人愿意用传统八字做文化娱乐对照，并借此聊清合作分工。

可使用已排好的四柱或出生记录；用 A/B 代号即可。

## 解决什么

交付能逐项核对的传统符号对照与现实合作对话清单。

本轮围绕你提交的材料完成一份可使用的结果。
缺失项会明确标出，已有材料不需要重新整理。

## 一个重要机制

把排盘口径、传统规则和现实行为分开，缺时辰不补盘。

合冲只是所选体系的符号关系，不形成精确兼容分，也不证明人格。

## 你会拿到什么

- 两人输入、缺柱和历法口径记录
- 有明确规则依据的条件化娱乐对照
- 分工、反馈和分歧处理问题
- 能直接讨论的合作约定草稿

结果优先给可复制正文或可编辑表格。
如需文件，会说明实际生成和验证到哪一步。

## 怎么开始

1. 先确认双方愿意提供哪些资料。
2. 给四柱及来源，或注明历法、地点时区和出生时间精度。
3. 说清现实合作中想讨论的一件事。
4. 先讨论约定；排盘有歧义时补工具口径再更新对照。

无可靠排盘工具时会交核对单和合作沟通版，明确传统对照尚未完成。

可先查看 [完整模拟案例](references/review-example.md) 了解成品形式。

```text

双方已同意本次文化娱乐对照。
A：[已有四柱或出生记录及时间精度]
B：[已有四柱或出生记录及时间精度]
来源与口径：[工具、历法、时区、换日规则]
合作情境：[例如初稿与反馈的时间冲突]
请列规则依据和未知项，再给合作约定草稿，不做命运保证或匹配总分。
```
