# 朋友圈文案自然化改写

## 适合什么场景

用户已有朋友圈草稿，觉得像 AI、像广告或不像本人，希望在不丢事实的前提下改得自然。

贴需要修改的原文，尽量保留标点和换行。

## 解决什么

对照用户原稿和日常说话习惯，找出最突兀的表达，只改妨碍真实感的部分，交付可以直接发的本人语气版本。

泛泛“去 AI 味”常把原稿统一改成俏皮短句，甚至补出不存在的感受。本技能锁定原意与本人语气，只改最突兀的表达，并逐项回查信息损失。

## 一个重要机制

自然感以用户习惯为准，不能统一改成网络俏皮话。

文案自然化是表达修改，不声称能够通过 AI 检测。

有日常原话时提取语气；没有时明确采用中性日常语气，不声称已经像本人。

## 你会拿到什么

- 保守版与更口语版两条完整文案
- 最关键的改动及推荐理由
- 用户指出哪句不像自己后进行一次定向修订

可查看 [完整模拟成品与边界案例](references/review-validation.md#模拟运行成品)。

## 怎么开始

1. 贴需要修改的原文，尽量保留标点和换行。
2. 标出不能删的事实、活动入口；有自己的两句原话也一起贴。
3. 拿到版本后标一处不像自己的话，或直接给你会怎么说。

没有口吻样本时采用克制中性表达，并邀请用户用一句平时说法校准。

用户下一轮只需标出不像自己的句子并给一句原话；优先修该句，暂停继续批量变体。

## 可直接复制的调用模板

```text
请使用 moments-natural-rewrite。

原稿：在快节奏的都市生活中，今天和朋友一起跑了五公里，感受自律带来的无限能量，让我们一起奔赴更好的自己！
要求：平常一点、不加表情，不补新的感受。
口吻参照：我通常说“今天跑完啦”。
请给保守版和口语版，推荐一版并说明最关键的改动。

已有材料以我提供的为准。
无法确认的内容放在正文之外说明。
```
