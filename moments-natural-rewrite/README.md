# 朋友圈文案自然化改写

## 适合什么场景

用户已有朋友圈草稿，觉得像 AI、像广告或不像本人，希望在不丢事实的前提下改得自然。

已有材料可以直接发来，不需要先整理成标准问卷。

## 解决什么

对照用户原稿和日常说话习惯，找出最突兀的表达，只改妨碍真实感的部分，交付可以直接发的本人语气版本。

先处理眼前问题，避免拿到一堆难以采用的泛泛建议。

## 一个重要机制

自然感以用户习惯为准，不能统一改成网络俏皮话。

文案自然化是表达修改，不声称能够通过 AI 检测。

这让结果既能直接用，也能看出哪些地方还需要你确认。

## 你会拿到什么

- 保守版与更口语版两条完整文案
- 最关键的改动及推荐理由
- 用户指出哪句不像自己后进行一次定向修订

完整的模拟输入与成品见 [演示](DEMO.md)。

## 怎么开始

1. 直接贴出现有材料。
2. 告诉我这次最想解决的一个问题。
3. 补充限制，例如语气、方法、时间或输出形式。
4. 拿到结果后，只需回传当前仍不满意或没理解的一处。

建议提供：

- 需要修改的原稿，保留原始标点和换行
- 用户愿意提供的日常说话例句，可选
- 不能删的事实、活动信息或必须保留的句子

工具无法读取附件时，可以先粘贴核心文字；仍能得到与这些文字对应的结果。

## 可直接复制的调用模板

```text
请使用 moments-natural-rewrite。
我的材料：
（粘贴原稿、题目、照片描述或当前处境）

这次最卡的是：
（只写当前要解决的一件事）

请保留的事实或限制：
（写不能改的事实，以及你希望采用的语气、方法或输出形式）

请直接给本轮成品；无法确认的内容单列，不要替我补造事实。
```
