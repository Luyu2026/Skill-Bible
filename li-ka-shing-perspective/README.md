# 李嘉诚视角

商业判断与投资决策思维 Skill。

它适合用在这样的场景：你看到一个机会或资产想出手，却拿不准现在是该进还是该退；你在纠结要不要加杠杆；或者你想学他那套"稳健"到底是怎么做到的。把标的、价格、现金流和负债情况交给它，它会先逼你想最坏情况，再从现金流、杠杆和周期位置出发，指出你还没想清楚的退出路径。

## 你会得到什么

- 对投资、风险控制或人生选择问题的分类判断
- 李嘉诚的 6 个核心模型：失败预演、生存优先、晴天修屋顶、不赚最后一个铜板、建立自我追求无我、好谋而成
- 8 条以生存为底线的决策纪律
- 当前信息不足时，不该强行下结论的原因

把这个页面链接发给正在使用的 Agent：

```text

安装完成后告诉我：它装在了哪里，以及我下一句话该怎么调用它。
```

装好后可以直接说：

```text

标的 / 机会：
当前价格与估值：
我打算投入多少、要不要加杠杆：
我计划持有多久：

请先判断：最坏情况扛不扛得住？现金流正不正？现在是该进还是该退？
```

## 边界

它用于研究、风险检查和决策参考，不提供确定的收益承诺或买卖建议。李嘉诚"好谋而成"依赖的信用、关系和谈判地位难以复制；他的模式也与特殊时代和制度背景深度绑定，不能机械套用。
