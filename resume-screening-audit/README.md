# 简历筛查可读性诊断

## 适合什么场景

检查简历文本解析、JD 要求覆盖和经历证据，提供可解释的诊断与改稿。适用于担心 ATS 筛查、想核验简历可读性或分析“AI 评分”；不推测雇主内部评分、不承诺绕过筛选。

你已经有材料，却卡在把它变成可使用结果的这一步。
可以提交初稿、截图或片段，不必先重新整理。

## 解决什么

从简历实际文本与目标 JD 找出解析障碍和证据缺口，交付可验证修正，解决用不透明 AI 分数制造焦虑的问题。

本轮围绕一个具体卡点完成交付。
事实不够的地方会标清，已能完成的部分先交付。

## 一个重要机制

解析失败、岗位证据不足和表达冗余是三个不同问题

用户自己的文件提取成功不等于所有 ATS 都会成功

这样你能知道哪些结论有材料支持，哪些仍需确认。

## 你会拿到什么

- 文件解析结果与验证边界
- 逐项 JD 证据覆盖表及修正优先级
- 可复制的重点段落改稿或纯文本版
- 缺证问题、复验方式及材料使用说明

结果以可复制文本或可编辑表格呈现。
若相关工具可用，再按你的要求生成文件。

## 怎么开始

1. 贴出现有材料或提供可读取的文件。
2. 说清当前卡点和本轮想拿走的结果。
3. 补充使用场景与不可改变的限制。
4. 收到成品后，按其中一个下一步复交即可。

优先提供：实际投递文件和可复制正文，优先读取已有简历。
可选补充：目标 JD、投递系统要求或用户看到的评分截图。
