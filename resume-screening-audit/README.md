# 简历筛查可读性诊断

## 适合什么场景

你担心投递文件被读乱，或不知道 JD 中的关键能力有没有写出证据。

也可核查第三方 AI 评分的解释，但无法推测雇主内部规则。

## 解决什么

把文件解析问题与经历证据缺口分开，并直接修好重点段落。

本轮围绕你提交的材料完成一份可使用的结果。
缺失项会明确标出，已有材料不需要重新整理。

## 一个重要机制

每条 JD 要求都回到简历原句和本人补证，区分明确支持、部分支持与未体现。

“没写出来”不等于“不会”；改稿本身不会生成新经历。

## 你会拿到什么

- 实际文件解析记录及验证边界
- 区分必须项与优先项的 JD 证据表
- 可复制改稿和修正优先级
- 补证问题、文件复验步骤与材料使用说明

结果优先给可复制正文或可编辑表格。
如需文件，会说明实际生成和验证到哪一步。

## 怎么开始

1. 附实际投递文件及可复制正文。
2. 给目标 JD 或投递系统显示的具体问题。
3. 补充可确认的动作、日期、职责和结果。
4. 修改后交回最终文件，先检查关键字段和顺序。

只贴文本也能做证据审查，但不会声称已经验证 PDF 或招聘系统。

可先查看 [完整模拟案例](references/review-example.md) 了解成品形式。

## 可直接复制的调用模板

```text
请使用 resume-screening-audit。
简历：[文件或完整正文]
目标 JD：[原文]
已确认项目事实：[动作、时间、个人贡献、结果依据]
当前问题：[解析错乱/要求没体现/评分解释]
请给证据映射、优先级和可直接替换的段落。未知事实不要补写，并注明实际测试范围。
```
