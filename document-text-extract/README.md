# PDF 与图片文字提取

## 适合什么场景

你要复制 PDF、扫描件或截图里的文字，直接复制却乱码或顺序错乱。

你需要把表格转成可编辑数据，并保留原页核对位置。

支持局部页码；混合 PDF 会逐页区分文字层与扫描图。

## 解决什么

恢复正文阅读顺序和表格行列关系，交付可复制的提取稿。

金额、日期、编号和单位会优先核对，无法看清就保留待核标记。

提取保留原文，清洗或校订另给版本，不悄悄更改原数值。

## 一个重要机制

每页单独选择文本提取或视觉/OCR，不以第一页代表整份文件。

双栏按阅读顺序组织，表格先锁定列标题再逐行填写。

空白单元格与识别不清的单元格不同，不能把模糊值挪到邻列。

## 你会拿到什么

- 以文件名和页码分隔的可复制正文。

- 固定列数的 Markdown 表或正确转义的 CSV。

- 关键字段的核验状态与异常位置。

- 已处理、未处理页及扫描区域的覆盖清单。

## 怎么开始

1. 上传 PDF 或清晰原图，说明需要哪些物理页。

2. 指定要正文、表格、批注还是图片中的文字。

3. 说明是否保留页眉页脚、版面顺序，以及输出表格格式。

4. 有待核项时补交指定页和区域的高清图，继续定点修复。

## 可直接复制的调用模板

```text

请使用 document-text-extract。

材料：附上的 PDF。范围：物理第 1–3 页。

提取正文和所有表格，保留页码，正文按阅读顺序。

表格输出 CSV；金额、小数点、日期和单位优先回核。

看不清的字段标待核，不按常识修正。

没有 OCR 时交可提取部分并列出未处理的扫描区域。

```
