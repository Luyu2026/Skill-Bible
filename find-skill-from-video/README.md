# 从视频找到原 Skill

## 适合什么场景

看到视频演示某个 Agent 技能，想知道它叫什么、从哪里获得，以及是否适合自己的环境。

## 解决什么

从字幕、画面和实际操作追踪原 Skill，并核验源仓库及真实 SKILL.md。只有同类工具时，会明确标注“替代”。

## 一个重要机制

先快速找原版，预计 1–2 分钟；沿视频、作者和直接链接找上游，确认就结束，不要求先跑脚本或下载全片。

未确认原版时，先告诉你当前情况，并询问是否找能实现类似功能的 Skill，预计另用 1–3 分钟。你同意后才查 GitHub、SkillHub，给出核验过的替代入口及功能差异，不自动切换。视频不可读但分享文案已说明功能时，也可以依据该描述找同类，不冒充看过视频。

身份与能力分开判断：同名、效果相似或被聚合站收录，都不足以证明是视频里的原作。证据不够会说明缺什么，不会靠扩大搜索掩盖缺证。

短链先锁定原视频/笔记 ID，公开浏览器可读的介绍和章节优先使用，不拿另一条相似视频的名单充数。合集分别报告入口、已识别项和已核验文件数量；作者要求私信领取的资料包，会如实提供公开获取方式，不冒充开源包。

`web_fetch`、`curl`、`video_search` 等只得到 JS 空壳、错误或其他视频时，若当前宿主已提供可直接使用且无需新增授权的浏览器工具，会优先读取同一原视频页面，不先交付“疑似原版”。已有只读页面访问权限视为已授权，不需要再说“可以用浏览器”。浏览器也失败后才按证据降级，并记录失败阶段、URL 和具体阻断；未尝试不会写成“无法使用浏览器”。

当前会话未提供浏览器工具不代表本机没安装浏览器。启动尚未授权的本机浏览器、启用尚未授权的官方控制、安装扩展或修改设置，以及登录、提交表单、下载/上传、安装或执行第三方内容等改变系统状态或产生外部副作用的操作，仍须先征得明确同意。不默认用 headless 或改 UA 绕过平台限制。无可用且已授权的浏览器路径，或浏览器尝试后正文仍不可读时，会请你任选一项补证：一张关键画面截图、字幕/逐字稿、分享文案 + 作者主页。补证不代表同意查找同类。

## 你会拿到什么

结论、原 Skill 或替代链接、视频时间点和上游证据，以及兼容性、许可证和获取限制。结果状态包括已找到原作、疑似原作、仅替代、未找到和需要补证。

已读到真实上游文件但身份仍缺证时，可以先拿到“待核验线索”；这不等于确认原作。不会把聚合站摘要标为已核验上游，也不保证搜索结果必然正确。

## 怎么开始

安装后，直接粘贴整段视频分享口令或链接，加一句“帮我找到这个视频的 Skill”即可。时间点、截图等是可选补充，不用先填写参数表。它优先使用当前 Agent 已有的视频理解、字幕或浏览器能力；仅在降级使用采集脚本时需要 Python 3 和 yt-dlp，抽帧才需要 ffmpeg。不会为查找而自动安装依赖或候选 Skill。

## 可直接复制的调用模板

```text
<直接粘贴视频分享口令或链接>

帮我找到这个视频的 Skill。
```

若希望省去询问，可加“找不到原版就直接找同类”。时间到会返回已核验部分，不保证指定时间内一定找到。需要自动化结果时可另外要求 JSON 和运行记录。

自动执行时可加 `--summary` 只返回简要记录；完整视频证据保存在输出目录，搜索用 `--output` 保存完整数据，避免重复读取大段原始响应。

继续补证时可复制：

```text
继续上次的查找。这是新增的字幕/截图及时间点：<补充材料>。
请更新证据和结论，说明哪些身份疑点已经解决、哪些仍未解决。
```
