# 飞书简历模板导出

你已经在飞书里写好了简历，但投递前还要反复排 Word、导 PDF，而且一导出就乱版。这个 Skill 的作用，是把飞书文档里的结构化内容直接做成一份按固定样稿排版的 Word 和 PDF。

它不是把飞书文档“另存为 Word”。它会以样稿为版式标准，重新排出身份信息、头像、分区标题、经历条目、日期和项目符号，让最终文件可以直接用于投递。

## 你会拿到什么

- 与样稿同一套版式的 `.docx`；
- 与 Word 内容一致、字体嵌入且跨设备不易乱版的 PDF；
- 顶部姓名、联系方式和头像的协调布局；
- 左侧公司/项目与角色、右侧日期的简历条目；
- 一页放得下就保持单页，内容更多时自然延展，避免把文字压得不可读。

## 适合怎样的飞书文档

文档至少应包含：姓名与联系方式、个人总结、工作经历、教育经历、技能。经历建议按下面的结构填写：

```text
公司/项目｜角色　时间
一句职责概述
- 关键动作、判断和结果
- 下一条经历或成果
```

没有的经历可以不写。不要为了填满模板编造公司、职责、数字或结果。

## 这个 Skill 的边界

它负责排版和导出，不负责替你补经历或虚构事实。PDF 默认由 Skill 直接生成，避免不同办公软件转换时出现中文字体、行距和表格错位。简历内容还没有写好时，建议先使用“JD 定制简历”或“简历去 AI 味”，再用这个 Skill 输出最终投递文件。
