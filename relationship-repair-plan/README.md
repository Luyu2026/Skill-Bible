# 亲密关系修复行动

## 它适合什么场景

迟到、失约或一句伤人的话引发争吵，想道歉却怕继续刺激对方。

## 它解决什么

把“怎么挽回”缩小成当前可做的一次承担或一次暂停。

## 一个重要机制

先看对方是否愿意接收消息，再决定有没有可发送版本。

对方明确要求空间时，你会拿到保存草稿和停止条件。

不会用连发消息逼出回应。

## 你会拿到什么

- 联系或暂停的明确结论及依据。
- 事实与解释分开的冲突地图。
- 一条修复主稿，注明发送条件。
- 责任、边界和一项可协商约定。

## 怎么开始

提供争执前后必要原话、最近一次联系状态、你的目标与底线。

可删除姓名、住址及无关聊天；不用交出完整聊天史。

若暂时没有原话，会标注单方陈述，先处理能确认的行为。

对方回应后带回原句；只推进实际发生的分支。

## 可直接复制的调用模板

```text
请使用 relationship-repair-plan。
双方原话：我说“你太敏感”；对方说“今晚不想聊”。
事情经过：我迟到且没有提前告知。
当前目标：承担我的行为，不催对方原谅。
请先判断现在是否应联系，再给草稿和停止条件。
```

如材料缺失，请先交付能完成的部分，并明确当前未完成的内容。
