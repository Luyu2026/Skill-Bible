# 短视频分镜脚本创作

## 适合什么场景

你需要有选题或素材却不知道如何开口、如何拍成短视频。
已有零散材料也可以开始，不必先整理成标准格式。
如果只想处理一小段，请明确本轮范围。

## 解决什么

从用户真实素材写出能开口、能拍摄、能剪辑的一条短视频脚本，而不是泛泛列爆款技巧。

以已有材料为起点，区分确认事实和仍需核对的内容。
先完成一版可以使用的结果，再按反馈修改。

## 一个重要机制

传播目标与拍摄条件一起决定脚本，不写现场拍不了的镜头。

开头承诺必须在正文兑现，不用虚假悬念或伪造效果。
遇到无法确认的地方会留下具体位置，不会悄悄补写。

## 你会拿到什么

- 可拍分镜表：时间、镜头、口播、字幕与素材
- 完整口播稿及两个可选择的开头
- 拍摄准备清单和当前无法核实的事实

交付会说明处理范围，以及哪些材料还没有覆盖。
工具无法生成目标文件时，会提供可复制的文字版本并说明差异。

## 怎么开始

1. 直接提供现有材料，附上你最想解决的问题。
2. 说明本次处理范围、使用对象和希望的输出形式。
3. 如果已有旧稿或参考风格，一并提供。
4. 收到结果后，指出需要修改的具体位置和原因。

不确定格式时，可以先要求一个小范围成品。
请只提供你有权使用的材料；分享范围也可以一起说明。

## 可直接复制的调用模板

```text
请使用 short-video-script。
我的任务：有选题或素材却不知道如何开口、如何拍成短视频。
现有材料：粘贴文字或附上文件。
本轮范围：填写页面、时间段、主题或章节。
使用对象与目标：填写给谁看、希望完成什么。
输出形式：可复制文稿；如工具支持，再生成可编辑文件。
必须保留：填写事实、表达或格式要求。
请标明无法确认的内容，先交付本轮成品和必要下一步。
```

### 看一个小例子

模拟输入：30 秒桌面口播；只有笔记本电脑。讲“开会前整理问题”，材料是三个字段：现象、影响、希望谁决定。

可以先按这个范围试用，再决定是否处理其余材料。
