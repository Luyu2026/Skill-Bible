# 短视频分镜脚本创作

## 适合什么场景

你有一个选题、真实经历或产品资料，却不知道第一句怎么说。

你想拍一条视频，但现有文稿像文章，现场不知道该拍什么。

适合单条口播、教程或产品演示；先把一条拍得出来，再扩系列。

## 解决什么

把一个观看理由变成从开头到结尾连贯的分镜脚本。

每段写清怎么拍、说什么、屏幕放什么，而不只给创意方向。

先受现有人物、场地和道具约束，再决定镜头。

## 一个重要机制

开头作出的承诺，必须在正文的某个具体镜头兑现。

说“三个方法”就要给三个不同动作，只有一个事实就讲一个方法。

缺少素材的画面会换成可拍的口播或演示，不留下空泛镜头建议。

## 你会拿到什么

- 时间连续的分镜表：画面、口播、字幕、声音和道具。

- 可以直接试录的完整口播稿。

- 一个备用开头及适用语气，主稿已选定。

- 拍摄清单和时长状态；估算与实际口读会明确区分。

## 怎么开始

1. 给选题、现有台词或事实材料，说明观众是谁。

2. 写出目标时长，以及看完希望观众知道或做什么。

3. 列出手头能用的人、场地、道具和不能出镜的信息。

4. 试录后交回卡词句或粗剪时间点，修对应分镜。

## 可直接复制的调用模板

```text

请使用 short-video-script。

选题：开会前整理问题。观众：初入职场的同事。

真实素材：三个字段，现象、影响、希望谁决定。

条件：一个人、笔记本电脑、桌面拍摄。时长：30 秒。

目标：观众能按三行结构写出一个会议问题。

输出连续分镜、完整口播、备用开头和道具清单。

```
