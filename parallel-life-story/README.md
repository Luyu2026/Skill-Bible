# 平行人生故事模拟

## 适合什么场景

你想看看毕业、搬家或转行那次选择，如果走另一条路会怎样，并希望读到生活场景而不只有利弊表。

可以直接贴现有材料，不必先写一份标准报告。
本轮聚焦你眼前的一件事；缺失信息会写清影响。

## 解决什么

从用户指定的人生分岔点写两条共享背景却因选择产生不同代价的虚构时间线，交付可续写存档，避免把遗憾写成必然更好的人生。

先处理足以判断的部分，再列真正影响结论的缺口。
不会把没有来源的数字、盘面、评价或人生事件写成你的事实。

## 一个重要机制

两条人生共享起点和外部事件，差别由选择和资源变化产生。未走之路也有代价，续写会保留旧余额和未完成事项。

你能看见结论来自哪项材料，以及哪些条件变了就要重做。
不需要为了开始，把不相关的私人信息也一起提交。

## 你会拿到什么

- 共同起点与明确虚构标记。
- 两条有场景、因果和代价的完整人生故事。
- 关键假设的替代结尾及双线续写存档。

[查看完整模拟成品](references/review-validation.md)。
示范标明了模拟设定、实际产物和未验证范围。

## 怎么开始

1. 给一个过去分岔点与两项选择，人物可以用代号。
2. 说明当时已知的资源和不能改写的背景；不想给金额可写未知。
3. 指定观察多久、叙述语气和不想涉及的题材。

不确定的字段写“不详”即可，不必猜填。
结果标为待核验时，按对应缺口补来源或参数，再续接同一轮。

## 可直接复制的调用模板

```text
请使用 parallel-life-story。
分岔点与当时已知背景：
A 选择／B 选择：
共同资源和不能改写的事实：
观察时长、语气和题材边界：
已有存档（续写时）：
请写两条明确虚构的完整故事，给共同事件、替代结尾和可复制续写卡。
```

续接时贴上上一版成品与新材料，说明哪一项需要改。
只处理受新信息影响的部分，保留仍然成立的依据。
