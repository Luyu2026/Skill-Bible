# 平行人生故事模拟

## 适合什么场景

用户想看如果当年换条路、同一起点两种人生或希望继续一段平行人生互动故事时。

你可以直接贴现有材料、截图文字或原稿，不需要先整理成标准报告。

## 解决什么

从用户指定的人生分岔点写两条共享背景却因选择产生不同代价的虚构时间线，交付可续写存档，避免把遗憾写成必然更好的人生。

会区分已经能判断的部分和还需要核验的部分。
不会为了让答案显得完整而补造事实。

## 一个重要机制

本技能主餐是反事实叙事；现实职业选择可转交已有 life-choice-simulator。

事实截止在分岔点，不把今天才知道的结果赋给当年的角色。

这会直接影响哪些结论能写进本轮成品。

## 你会拿到什么

- 共同起点与明确虚构标记。
- 两条有场景、因果和代价的完整人生故事。
- 关键假设的替代结尾及双线续写存档。

可以先看 [明确模拟示范](demo.md)，了解输入不足时如何交付。

## 怎么开始

1. 说清当前想完成的一件事。
2. 贴上已有材料，保留来源和时间信息。
3. 说明不能改动的条件与希望的输出长度。
4. 收到成品后，只补影响关键判断的缺口。

优先给这些材料：

- 用户愿意分享的一个过去分岔点、两项选择和共同起点。
- 截至分岔时已经知道的能力、资源、关系和限制。
- 明确不可改写的人物事实与不希望涉及的题材。

## 可直接复制的调用模板

```text
请使用 parallel-life-story。
我本轮的目标：
我已有的材料（直接粘贴或附文件）：
材料来源、时间和已确认事实：
必须保留的限制：
希望交付的形式和长度：
请先利用已有信息产出可用成品；缺失项写清影响，不要编造。
```

需要续接时，把上一轮成品和实际反馈一起贴回即可。
