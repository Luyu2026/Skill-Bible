# 平行人生故事模拟

## 一句话主餐

从用户指定的人生分岔点写两条共享背景却因选择产生不同代价的虚构时间线，交付可续写存档，避免把遗憾写成必然更好的人生。

普通聊天容易把未选之路写得完美。本技能从同一个过去起点展开两条有生活细节的虚构故事，用共同事件和资源账解释不同代价，并留下可续写节点。

## 输入

- 用户愿意分享的一个过去分岔点、两项选择和共同起点
- 截至分岔时已经知道的能力、资源、关系和限制
- 明确不可改写的人物事实与不希望涉及的题材
- 故事观察年限、篇幅、叙述视角及真实感或奇幻偏好
- 现有人生材料只作授权范围内背景，不推断隐秘经历

### 材料处理

- 优先读取已给原稿、附件和记录，不要求重复填写。
- 只追问会改变当前路径的缺口，其他缺失放在相关判断旁。
- 来源无法打开时使用用户摘录，并写明尚未独立核验。
- 用户事实、工具结果、合理推断与纯模拟分别标记。
- 不把演示数据移植成真实用户材料。

## 核心判断

1. 本技能主餐是反事实叙事；现实职业选择可转交已有 life-choice-simulator。
2. 事实截止在分岔点，不把今天才知道的结果赋给当年的角色。
3. 两线必须共享初始条件和主要外部事件，差异由选择与资源变化解释。
4. 虚构事件标注，不输出无依据成功率或宣称另一条人生实际发生过。
5. 不把留下写成失败、离开写成成功；两线各有收益、代价和未知。
6. 续写时沿用存档，不重置债务、技能、关系与已发生事件。

### 本轮执行门槛

- 已给分岔点与两种选择：直接写同一观察期的双线故事。
- 只有“如果当年”：只追问发生在哪个选择；用户不想分享时提供明确虚构起点，不冒认其经历。
- 资源未给数字：记录宽裕、有限或未知，不编真实收入；数字化设定须明示为虚构。
- 用户要现实择业建议：说明故事不能证明结果，先交本轮故事；用户明确转任务后再用选择梳理流程。

## 编号工作流

### 1. 建立事实锚点

- 从材料提炼分岔发生前的共同背景。
- 区分用户确认事实、叙事假设和不可改写事实。
- 只确认影响故事方向的缺失条件。
- 记录不希望出现的人物或题材。
- 交付共同起点卡。

### 2. 定义分岔与时间窗

- 将选择收窄为同一时点可以采取的两个动作。
- 两线共享起始预算、技能和人际支持。
- 明确叙述到多久以后。
- 未来行业环境如需事实核验，应区分真实历史与虚构设定。
- 交付 A/B 分支条件。

### 3. 布置共同事件

- 设一个两线都要面对的外部事件。
- 说明事件如何因所在环境不同而产生不同影响。
- 不以中奖、突然成名或灾难惩罚推动普通现实故事。
- 每次额外资源都给出来源与代价。
- 交付共用事件表。

### 4. 展开两条时间线

- 每条线按近期、中期和观察终点写完整片段。
- 每段包含行动、反馈、资源变化及关系影响。
- 使用用户允许的生活细节，隐私不足则用抽象场景。
- 让两线都有具体收获和具体牺牲。
- 交付有场景和因果的故事正文，不仅是对比表。

### 5. 对照转折与敏感条件

- 并排展示两线关键决定与代价。
- 挑一个影响最大但未经确认的假设。
- 改变该假设后写一个替代短结尾。
- 明确这是叙事敏感性，不是统计预测。
- 询问式反思允许用户拒绝故事赋予的意义。

### 6. 保存可续写节点

- 记录每线当前时间、地点、预算状态、技能与关系。
- 保留未解事件和已承诺事项。
- 给两项符合当前资源的下一选择。
- 用户更改起点时新开版本，不悄悄改写存档。
- 交付正文、对照与可复制续写卡。

## 直接交付与下一步

- 共同起点与明确虚构标记。
- 两条有场景、因果和代价的完整人生故事。
- 关键假设的替代结尾及双线续写存档。

### 时间线与资源账

共同起点记录时点、已知经历、资源、底线及不愿写的题材。
过去分岔后所有事件是反事实虚构；真实历史事件另附来源和适用地区。
每条线至少写起步、受共同事件影响、观察终点三个具体场景。
场景包含角色做了什么、现实反馈、付出什么及留下什么；不能用结尾对比表替代故事。
金钱账写期初余额、收入、支出、期末余额；未知金额保持未知。
可用时间扣除工作和休息，再安排学习，不让角色同时消耗同一段时间。
两线面对同一时段的外部事件，反馈可因地点或准备不同而异。
额外帮助说明由谁、何时、代价是什么；不凭空抹掉债务或任务。

### 假设变化与续写存档

仅改变一项关键假设，其他条件保持不变，再写替代短结尾。
正文明确说明这不是预测，也不代表用户现实经历的替代真相。
存档字段：版本、事实截止、当前月份、A/B 地点、资金、技能、关系、未决事项、下一选项。
故事人物名和背景可改成代号；用户没授权的私密细节不编成真实经历。
两线各给一个符合剩余资源的选项；用户选一线后只续写该线，另一线存档暂停。
新一轮先读取旧存档，再加本轮收入支出；没有存档时请用户贴回或明确重建。
用户改起点则开新版本，不能在旧故事中偷偷修正已发生选择。

### 完成与工具降级

完成需要双线正文、共同事件、代价对照、单因素替代结尾和续写卡。
用户只想阅读时到故事结束即可，不强加现实练习或价值观总结。
无行业资料时使用标明虚构的行业背景，不借现实职位编薪资和就业概率。
不能保存文件时给可复制存档，不承诺跨会话自动记忆或无人运行时推进。
续写有资源矛盾时先修正状态并说明影响，再往下写新情节。
用户不认同故事意义时保留其解释，不用“另一个你一定更幸福”替代体验。

## 外部参考与延展

- **何时研究**：两线趋同、明显偏袒一线、资源不守恒或需要陌生行业生活细节时启动。
- **去哪找**：研究交互小说分支机制、情景规划；行业和历史背景查统计局、行业原始报告或机构档案，检索“interactive fiction branching state tracking”。
- **看什么**：重点比较共同冲击、资源账、延迟后果与分支汇合，不复制他人角色和剧情。
- **怎么用**：只引入改善当前失效节点的一项机制，用同一起点重写两线并检查事实截止、代价和资源延续。
- 比较相邻 life-choice-simulator 的资源账与 [ink 官方交互教程](https://www.inklestudios.com/ink/web-tutorial/) 的变量和条件选项：借用状态随选择更新的机制，纯故事不引入代码依赖；用一次续写验证余额和旧选择保留。
- 来源热度只用于发现，不代表方法有效；原始规则优先于二手总结。
- 材料已经足够时直接交付，不机械追加联网研究。
- 外部方法只改变执行机制，不能创造用户经历、报价或个体事实。
- 若实际复用受许可约束内容，保留所需声明；独立改写不等于可以忽略许可。

### 交付前验收

1. 每个确定结论都能回到材料、计算或明确设定。
2. 关键数字、日期、资格和限制没有在改写中发生变化。
3. 交付与用户当前目标一致，没有串入无关阶段。
4. 复制正文即可使用，依赖工具的暂停部分有可操作恢复条件。
5. 不把模拟验证称为真实用户效果，不承诺未经测量的收益。

### 明确模拟的执行示范

小禾从20000元起步；A半年后26000元，B半年后3000元。完整双线故事后续写B：到账2000、支出2500，余额2500元，A仍停在原节点。
