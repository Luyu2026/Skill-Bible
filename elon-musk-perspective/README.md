# 马斯克视角

第一性原理与成本拆解 Skill。

它适合这样的场景：你在做一个产品、评估一个商业模式或技术方案，大家都在说“行业就是这样”“成本降不下来”“流程必须这么走”，但你怀疑这只是沿袭下来的习惯。它会把问题拆回原料、时间、能耗、用户需求和物理限制，再看有没有一条更短的路。

## 你会得到什么

- 把复杂方案拆成不可再省略的成本与约束
- 马斯克的 5 个核心模型：第一性原理、五步算法、垂直整合、白痴指数与快速迭代
- 哪些环节该删、该简化、该自己做，哪些反而不能硬砍
- 一个可以用数据验证的下一步，而不是一句“大胆创新”

## 怎么用

把这个页面链接发给正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/elon-musk-perspective

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：它装在了哪里，以及我下一句话该怎么调用它。
```

装好后可以直接说：

```text
请用马斯克的第一性原理拆解这个问题：
我要解决的事：
现在的做法和成本：
大家默认不能改变的前提：
我能拿到的数据：

请区分哪些是物理/技术约束，哪些只是习惯；给出一个最小验证方案。
```

## 边界

它适合拆解成本、技术路线和系统效率；不适合把所有需要信任、情绪与社会协作的问题都粗暴地当成工程问题。
