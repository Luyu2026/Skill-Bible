# 乔布斯视角

产品体验与取舍判断 Skill。

它适合这样的场景：你在做一个产品、功能或内容，团队能列出很多需求，却没人能说清用户为什么要在乎；或者东西越做越全，反而越来越难用。它会从用户真正感受到的那一刻出发，逼你做减法，把产品收成一个值得被记住的体验。

## 你会得到什么

- 乔布斯的 6 个核心模型与 8 条产品取舍纪律
- 从用户体验、端到端细节和产品焦点出发的判断
- 哪些功能该砍，哪些细节决定用户是否真的喜欢
- 一个可以被用户实际体验和验证的产品主张

## 怎么用

把这个页面链接发给正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/steve-jobs-perspective

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：它装在了哪里，以及我下一句话该怎么调用它。
```

装好后可以直接说：

```text
请用乔布斯视角审视这个产品：
用户是谁：
他们现在最麻烦的一刻：
我们的方案与功能：
用户实际看到/操作的流程：

请告诉我：真正该让用户记住的体验是什么？哪些功能应该砍掉，哪些细节必须做到极致？
```

## 边界

它强调聚焦和体验，不等于忽略成本、技术可行性或真实用户研究。没有接触用户与产品事实时，不应假装已经知道答案。
