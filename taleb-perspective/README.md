# 塔勒布视角

反脆弱与尾部风险 Skill。

它适合这样的场景：一件事过去一直很顺，你却担心它只是暂时没出问题；或者一个选择看起来收益不错，但一旦出错代价会很大。它会先看你最扛不住的损失、隐藏的脆弱点和“黑天鹅”暴露，而不是只算平均收益。

## 你会得到什么

- 塔勒布的 6 个核心模型与 9 条风险纪律
- 对尾部风险、脆弱性、激励是否对齐的检查
- 区分“看起来稳定”和“真正抗打击”的判断
- 可执行的减损、冗余和小步试错建议

## 怎么用

把这个页面链接发给正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/taleb-perspective

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：它装在了哪里，以及我下一句话该怎么调用它。
```

装好后可以直接说：

```text
请用塔勒布视角检查这个决定：
我要做的事：
最好的结果：
最坏的结果：
我能承受的最大损失：
我现在依赖的前提：

请判断：哪里最脆弱？有没有隐藏的尾部风险？怎样把方案改得更抗打击？
```

## 边界

它用于识别风险和提高韧性，不预测具体黑天鹅事件，也不构成金融、法律或医疗建议。
