# PDF 页面处理与可追溯提取

## 适合什么场景

适合从几十页报告中取指定正文页、把附件分开保存，或将扫描表格转为可核对文字。

扫描件依赖 OCR 或清晰页面图；识别不清的数字会保留待核对标记，不会用猜测补齐。

## 解决什么

普通聊天容易把 PDF 内容读成一团；这里把指定页面变成能回到原页核对的文字或页面文件。

先读取现有材料，直接处理你指定的这一轮任务。
需要确认的口径会和可用成品分开列出。

## 一个重要机制

带封面的文件中，“文件第 2 页”可能才是“正文第 1 页”；每段提取结果都保留两者的对应关系。

你能核对修改依据，并针对具体问题复交。

## 你会拿到什么

- 带文件页序的提取文本或表格
- 按需求生成的拆分、合并或旋转 PDF
- 页面映射与识别疑点清单

另有一份[模拟演示](demo.md)，可先看实际交付长什么样。
真实任务的核验范围会随文件与工具环境说明。

边界示例见[复审案例](references/review-cases.md)。

## 怎么开始

1. 上传 PDF，指定提取内容或拆分、合并、旋转目标。
2. 说明页码按文件页序还是页面印刷数字。
3. 扫描件请说明是否允许 OCR，是否必须核对金额或编号。
4. 指定输出 TXT、CSV 或新 PDF；加密文件提供合法读取方式。

扫描件依赖 OCR 或清晰页面图；识别不清的数字会保留待核对标记，不会用猜测补齐。
收到成品后，如仍有问题，回传具体位置和希望调整的结果即可。

## 可直接复制的调用模板

```text
请使用 pdf-page-extract。
PDF：[附件/路径]
任务：[提取文字/表格/拆分/合并/旋转]
目标页：[文件页序 2–5，或印刷页码并注明]
关键核对项：[金额、编号、表头等]
输出：[TXT/CSV/PDF]；OCR：[允许/不需要]
请保留原件，提供页映射、识别疑点和实际核验范围。
```
