# PDF 页面处理与可追溯提取

## 适合什么场景

从现有 PDF 按页提取文字、表格或执行拆分合并旋转，保留页码与原文定位。用户要整理 PDF、抽取指定页面、扫描件转文字或核对提取结果时使用。

你手里已有材料，希望直接得到可使用的结果。
只有方向而没有材料时，也可先明确缺什么和本轮能做的范围。

## 解决什么

普通聊天容易把 PDF 内容读成一团；这里把指定页面变成能回到原页核对的文字或页面文件。

保留来源与待确认项，避免为了看起来完整补造事实。
围绕当前卡点交付，不把多个无关任务捆在一起。

## 一个重要机制

每段提取结果绑定原页，页面操作绑定明确映射，OCR 疑点保留而不猜填。

结果可以回到原材料核验，而不只是看起来更漂亮。

## 你会拿到什么

- 带文件页序的提取文本或表格
- 按需求生成的拆分、合并或旋转 PDF
- 页面映射与识别疑点清单

另有一份[模拟演示](demo.md)，可先看实际交付长什么样。
真实任务的核验范围会随文件与工具环境说明。

## 怎么开始

1. 提供原始材料或可读取的文件路径。
2. 用一句话说明本轮最想完成什么。
3. 告诉我必须保留的内容、口径和输出格式。
4. 已经有模板或旧成品时一并提供，优先沿用。

材料不足时会先交能可靠完成的部分，并列出具体缺口。
有问题时回传问题所在页、行、段落或数据记录即可继续。

```text
已知问题：[目前最卡的一处]

请直接制作成品，说明核验结果和仍需我确认的事项。
```
