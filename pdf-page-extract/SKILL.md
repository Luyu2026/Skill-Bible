# PDF 页面处理与可追溯提取

## 一句话主餐

普通聊天容易把 PDF 内容读成一团；这里把指定页面变成能回到原页核对的文字或页面文件。

## 输入

优先读取用户已经给出的材料，不要求为本 Skill 重新抄写。

- 源 PDF、密码权限及目标页码范围
- 本轮目标：提取文字、表格，或页面拆分合并旋转
- 是否扫描件、是否允许 OCR，以及输出文件格式

未指定页码时先展示页数和目录线索；无解密权限不绕过保护，OCR 不可用时交页码清单与可见页转录范围。

输入识别要求：
- 保留原始材料和来源定位，生成文件默认另存。
- 区分真实用户材料、待确认项与明确模拟输入。
- 用户目标明确时直接制作；只有影响结果的歧义才提出具体问题。
- 一次只解决本轮目标，不顺手扩展为其他业务流程。

## 核心判断

- 文本层、扫描图和混合页面逐页识别，不按整个文件一刀切。
- 文件页序与印刷页码不同，输出同时标注且明确采用哪一种。
- 可见但提取乱码的文字不能当空白页；需要 OCR 或人工核对。
- 分栏阅读顺序、表格行列与视觉位置分别检查。
- 页面旋转和裁切不等于安全删除；真正脱敏需要清除内容并验证。
- 数字签名文件经页面处理可能失效，保留原件并告知变化。

比较文本层提取、坐标块重排和 OCR：优先复用有效文本层，只有扫描或编码失败页才启用识别。
借鉴 Excel 清洗的异常隔离：低可信字符另列疑点，不用金额合计正确来反推原文一定正确。

### 容易误判的边界

- 页范围默认按文件页序从 1 计数，API 调用才减 1；印刷页码须另建映射。
- “第 1 页”存在封面歧义时先列候选对应关系；不要在确认前执行破坏性页选择。
- 页面操作与内容提取分支运行：仅拆分旋转无需 OCR，仅提取文字无需重写 PDF。
- 仅疑似数字可辨时标记如 [待核对：1/7] 并保留页号与位置，不用上下文猜字符。

## 编号工作流

### 1. 确认页面任务

- 读取页数、加密状态、页面尺寸与方向。
- 把用户说的第几页映射到从 1 开始的文件页序。
- 页面操作写成输入页序到输出页序的映射。
- 产出任务页清单，避免误删或漏页。

### 2. 逐页判断提取方式

- 抽查文本层是否可读、是否覆盖可见内容。
- 扫描页进入 OCR，混合页避免重复识别已有文字。
- 记录每页使用原文本层、OCR 或人工转录。
- 产出处理策略与无法自动读取页面清单。

### 3. 提取并保留位置

- 文字提取保留页边界、段落与必要的坐标块。
- 多栏页面按视觉顺序重排，页眉脚作为单独内容处理。
- 数字、单位和否定词对照页面，不根据语义补写。
- 产出带页序与定位线索的文本。

### 4. 处理表格

- 根据框线或文本对齐判断行列，先保留表头。
- 合并单元格与跨页表头标注来源，不静默填充空白。
- 金额列抽查小数点、负号与千分位，合计独立核对。
- 产出 CSV 或 Markdown 表格及疑似错位单元格。

### 5. 执行页面变更

- 拆分、合并和旋转仅执行已指定的页面映射。
- 保留需要的书签时验证目标页更新情况。
- 另存新文件，不覆盖原 PDF 或误称已保留签名有效性。
- 产出页面文件及变更前后页数。

### 6. 核验提取结果

- 逐页对照首尾句、关键数字、表头和段落顺序。
- OCR 不确定字符用待核对标记，禁止用顺口的文字猜测。
- 核对输出页数、顺序、方向与任务清单。
- 产出缺失、乱码、错位与未验证项目列表。

### 7. 选择降级交付

- 无 PDF 库时先使用可用系统阅读器或文本工具。
- 无 OCR 时只交可可靠读取部分，不能声称完成整篇识别。
- 没有渲染器时交页面映射与提取结果，说明未视觉复核。
- 产出当前可用成果与解除剩余阻塞所需工具。

### 8. 闭环问题页

- 用户回传问题页截图或确认字符后修订对应段。
- 保留修订前值、确认后值和原页定位。
- 不为了修单页重排整份文档，避免引入新误差。
- 完成条件为指定页任务完成且所有疑点可定位。

## 直接交付与下一步

默认交付以下成果；按用户目标裁剪，不为凑齐数量生成无关附件。

- 带文件页序的提取文本或表格
- 按需求生成的拆分、合并或旋转 PDF
- 页面映射与识别疑点清单

交接规则：
- 先给可使用的成品入口，再说明仍影响使用的缺口。
- 核验必须写明执行了什么、结果如何、哪些能力没有执行。
- 本轮能完成的一次性交付到此结束，不附加通用调研作业。
- 需要继续时，只要求用户交回具体异常位置、确认口径或新材料。
- 复交后沿用已确认事实，检查本次修复及其影响的原有部分。

工具不可用时：

无 OCR 时输出有效文本层和扫描页清单，附文件页序；用户可对清单页导出清晰图像交回。无 PDF 写入工具时提供阅读器“打印→指定文件页序→存储为 PDF”步骤与页映射，不将文本文件改名为 PDF。

### 外部参考与延展

- 出现乱码、跨栏顺序错误、表格错位或扫描页时启动研究。
- 查 PyMuPDF 官方 Text、Page、OCR 文档，以及所用 PDF 库官方页面操作文档。
- 比较文本块排序与版面分析，观察坐标、阅读顺序、中文字体与跨页表格。
- OCR 方案先看语言包、扫描分辨率和数字准确性，不只看速度。
- 选择一张失败页面验证方法，确认关键数字后再批量运行。
- 脱敏任务另查真正 redaction 的实现与验证，不用白色遮盖替代。

官方资料入口：[PDF 页面处理与可追溯提取相关资料](https://pymupdf.readthedocs.io/en/latest/recipes-text.html)。
已有材料足够时直接交付；研究只围绕当前失败点，不重复搜集无关项目。
实际采用外部内容时保留必要许可与来源；仅比较机制不复制正文。
