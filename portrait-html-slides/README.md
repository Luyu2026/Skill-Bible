# 讲稿转极简竖屏 HTML 演示

## 适合什么场景

将用户现有讲稿转为极简科技风竖屏演示，输出离线可打开的单文件 HTML。用户要乔布斯风演示、科技发布会竖屏幻灯片或讲稿生成 HTML Slides 时使用。

你手里已有材料，希望直接得到可使用的结果。
只有方向而没有材料时，也可先明确缺什么和本轮能做的范围。

## 解决什么

普通聊天只列大纲；这里将讲稿压成一屏一意的竖屏页面，直接交付带导航与演讲备注的单文件 HTML。

保留来源与待确认项，避免为了看起来完整补造事实。
围绕当前卡点交付，不把多个无关任务捆在一起。

## 一个重要机制

把屏幕文案和讲者备注分开，一屏只保留一个判断，完整论证仍可排练。

结果可以回到原材料核验，而不只是看起来更漂亮。

## 你会拿到什么

- presentation.html：含样式、导航和备注的单文件
- 逐屏脚本与原讲稿映射
- 离线和设备适配验证记录

另有一份[模拟演示](demo.md)，可先看实际交付长什么样。
真实任务的核验范围会随文件与工具环境说明。

## 怎么开始

1. 提供原始材料或可读取的文件路径。
2. 用一句话说明本轮最想完成什么。
3. 告诉我必须保留的内容、口径和输出格式。
4. 已经有模板或旧成品时一并提供，优先沿用。

材料不足时会先交能可靠完成的部分，并列出具体缺口。
有问题时回传问题所在页、行、段落或数据记录即可继续。

