# 讲稿转极简竖屏 HTML 演示

## 适合什么场景

适合拿着一份产品讲稿，想在手机或竖屏展示中用一屏一意的节奏讲清主线。

交付格式为 HTML；如果必须提交 PPTX，需要另做格式转换并检查版面，不能直接改文件后缀。

## 解决什么

普通聊天只列大纲；这里将讲稿压成一屏一意的竖屏页面，直接交付带导航与演讲备注的单文件 HTML。

先读取现有材料，直接处理你指定的这一轮任务。
需要确认的口径会和可用成品分开列出。

## 一个重要机制

“3 步变 1 步”可以做主屏标题；它不等于耗时下降 67%，解释范围保留在演讲备注中。

你能核对修改依据，并针对具体问题复交。

## 你会拿到什么

- presentation.html：含样式、导航和备注的单文件
- 逐屏脚本与原讲稿映射
- 离线和设备适配验证记录

另有一份[模拟演示](demo.md)，可先看实际交付长什么样。
真实任务的核验范围会随文件与工具环境说明。

边界示例见[复审案例](references/review-cases.md)。

## 怎么开始

1. 提供完整讲稿，指出听众和希望听众采取的行动。
2. 说明时长、手机或竖屏展示尺寸。
3. 标明必须保留的数字、限定条件和原话。
4. 上传允许使用的品牌素材，默认输出离线单文件 HTML。

交付格式为 HTML；如果必须提交 PPTX，需要另做格式转换并检查版面，不能直接改文件后缀。
收到成品后，如仍有问题，回传具体位置和希望调整的结果即可。

## 可直接复制的调用模板

```text
请使用 portrait-html-slides。
讲稿：[正文/附件]
听众与目标：[人群、行动请求]
预计时长：[分钟]；设备：[屏幕尺寸/手机]
保留内容：[数字、来源、原话]
品牌与素材：[附件/黑白加单色]
请制作 9:16 单文件 HTML，带导航、页码和备注，并说明离线及适配验证状态。
```
