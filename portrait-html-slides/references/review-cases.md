Node 实际执行该文件的内嵌脚本，使用 DOM 替身验证：首屏向前不越界、向后翻页、方向键、末屏边界和备注显示均通过。

这些检查没有使用真实浏览器，不能证明可读字号、触摸或目标屏幕无溢出。
新增边界审查：讲稿若含 HTML 标签，应转义后作为文本显示；当前模拟文案不含标签，不声称已验证恶意字符串运行行为。
