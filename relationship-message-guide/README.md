# 关系消息沟通参谋

## 适合什么场景

从消息事实与可能解释出发，交付自然的澄清回复和下一轮分支，避免把读心猜测当成事实。

贴最近一轮完整原话，补充你要确认安排、表达感受还是澄清含义。

可以只处理眼前的一件事，不要求先整理完整档案。

## 解决什么

把已有材料推进为本轮能使用的结果，并说明哪些判断还缺证据。

例如：用户问伴侣“周六见吗”，对方答“再看吧”。尚无确定约定，用户需周五安排周末。

本轮会完成一个明确目标，后续问题按实际反馈继续。

## 一个重要机制

确认安排：先找已有日期、地点和确认期限，回复必须能落实或取消安排。

输入不足会改变交付范围，缺失事实不会用猜测补齐。

关键步骤会解释依据，方便你发现哪里不符合实际。

## 你会拿到什么

- 事实与解释分栏判断。
- 推荐回复及语气替代版。
- 不同回应下的下一句。
- 同时说明关键缺口与结论适用范围。

可看 [完整模拟成品](references/review-validation.md)，输入与输出一一对应。

## 怎么开始

1. 贴最近一轮完整原话，补充你要确认安排、表达感受还是澄清含义。
2. 写明本轮最想拿到的结果和不能接受的做法。
3. 先使用返回的本轮成品，注意其中标明的执行前提。
4. 如果要继续，交回真实结果或指出最不适用的一处。

无法打开链接或截图时，直接粘贴关键文字也能开始。

## 可直接复制的调用模板

```text
使用 relationship-message-guide。
最近对话：我问周六见吗，对方说再看吧
本轮目标：确认安排
时间限制：周五要安排周末
我的语气：简短、自然，不想像审问
请先交付本轮能直接使用的成品，说明关键缺口和下一步。
```
