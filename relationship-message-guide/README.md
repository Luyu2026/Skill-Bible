# 关系消息沟通参谋

## 适合什么场景

不知道对象一句话是什么意思、想回复家庭聊天、希望确认见面安排时，可以从手头材料开始。

- 最近一轮完整对话与时间间隔。
- 本次想达成的目标。
- 可以只处理眼前的一件事。

## 解决什么

从消息事实与可能解释出发，交付自然的澄清回复和下一轮分支，避免把读心猜测当成事实。

- 不用先写完整报告。
- 信息不够时会指出具体影响。
- 结果回到你实际提供的材料。

## 一个重要机制

沉默和短回复只证明消息行为，不证明不爱或出轨。

明确拒绝应被尊重，不能教用户绕过拒绝。

这决定怎样理解材料，以及哪些结论可以直接使用。

## 你会拿到什么

- 事实与解释分栏判断。
- 推荐回复及语气替代版。
- 不同回应下的下一句。

先看 [模拟演示](demo.md)，了解实际返回的样子。

## 怎么开始

1. 发来已有原文、截图或记录。
2. 说清这次最想解决的一个问题。
3. 补充现实限制或不能接受的结果。
4. 收到成品后按下一步使用。
5. 如需继续，交回实际结果或不适用的一处。

## 可直接复制的调用模板

```text
使用 relationship-message-guide。
我的情况：
已有材料：
最想解决的问题：
必须遵守的限制：

请先做出本轮成品，标明影响判断的信息缺口。
```

不用为了调用重新写一份说明书。
