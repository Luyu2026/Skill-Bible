# 网页转原型

## 输入
网页链接、要研究或保留的页面、目标用户任务、允许改动范围、技术栈偏好。

## 核心判断
网页复刻不是复制现成页面。先理解用户任务和信息结构，再做一个团队可继续改的本地版本，并清楚标记不可见逻辑。

## 工作流
1. 打开网页，记录关键页面、路径、状态与交互。
2. 区分视觉层、前端交互和不可见的后端逻辑。
3. 搭建本地可运行原型，优先复刻用户要讨论的关键任务。
4. 按原始任务走查，输出已还原、未还原和需要补充的信息。

## 延展
当页面涉及登录、数据或复杂状态时，研究可替代的公开演示和通用交互模式，避免假装复制了不可见能力。
