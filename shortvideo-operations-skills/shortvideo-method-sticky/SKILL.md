# 《让创意更有黏性》· 内容传播方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

## 核心框架

### 框架1：SUCCES 六原则（让内容被记住）
- **适用场景**：设计短视频内容、检查脚本可记忆性时
- **步骤**：
  1. **Simple 简单**：一句话核心，剥离废话
  2. **Unexpected 意外**：打破预期，制造"没想到"
  3. **Concrete 具体**：具象表达，不用抽象词
  4. **Credible 可信**：有证据/细节，不说空话
  5. **Emotional 情感**：引发情绪，人因情绪记住
  6. **Stories 故事**：放进叙事，信息搭车传播
- **输出物**：脚本黏性检查（每原则对应内容哪里）
- **来源**：全书六章

### 框架2：意外钩子（打破猜测）
  - **适用场景**：设计前 3 秒钩子
  - **步骤**：先制造"猜不到"（反常识/悬念/反转），再用内容补足
  - **输出物**：钩子设计思路
  - **来源**：意外章节

## 决策规则（节选）

1. **如果**要设计脚本，**则**先写"一句话核心"，多余的全删。（简单章节）
2. **如果**要设计开头，**则**打破预期（意外），让人猜不到接下来。（意外章节）
3. **如果**内容难懂，**则**换成具象场景/类比（具体章节）。
4. **如果**要增强说服，**则**补细节证据（可信章节）。
5. **如果**要可传播，**则**加情绪或套故事（情感/故事章节）。

## 检查清单

- [ ] 能一句话说清核心吗
- [ ] 开头是否有"意外"
- [ ] 是否用了具象表达而非抽象词
- [ ] 是否有可信细节/证据
- [ ] 是否引发情绪
- [ ] 是否套了故事/叙事

## 反模式

- 什么都想讲（没有一句核心）。
- 开头温吞（没有意外）。
- 抽象堆砌（用户看不懂记不住）。
- 空口无凭（没有可信证据）。

## 边界声明

- 原则来自传播学研究，案例偏传统传播，短视频场景需结合平台特性。
- 原则是增强器：选题与内容价值不行时，黏性技巧救不了。
