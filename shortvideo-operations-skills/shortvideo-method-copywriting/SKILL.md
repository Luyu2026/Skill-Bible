# 《文案的基本修养》· 文案表达方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

## 核心框架

### 框架1：洞察优先（写之前先想透）
- **适用场景**：写口播稿、旁白、标题之前
- **步骤**：
  1. 找到"用户真实处境/心理"的洞察（不只是需求，是"人性的那一下"）
  2. 用洞察定表达方向（对谁说、说什么、怎么说）
  3. 文案为洞察服务，不为辞藻服务
- **输出物**：一句话洞察 + 表达方向
- **来源**：洞察章节

### 框架2：沟通逻辑（文案是沟通不是炫技）
  - **适用场景**：脚本结构、口播逻辑
  - **步骤**：说人话（像交谈不像宣读）→ 有逻辑（因果/递进清晰）→ 有分寸（语气匹配场景）
  - **输出物**：沟通型文案检查
  - **来源**：沟通章节

### 框架3：基本修养（功夫在诗外）
  - **适用场景**：长期文案能力提升
  - **步骤**：积累（对生活的敏感/大量输入）→ 克制（删比加难）→ 真诚（不说假话不装）
  - **输出物**：日常训练清单
  - **来源**：修养章节

## 决策规则（节选）

1. **如果**文案没感觉，**则**先补洞察（用户真实处境是什么），不硬憋辞藻。（洞察章节）
2. **如果**要写口播，**则**像说话一样写，先能"念顺"再谈文采。（沟通章节）
3. **如果**文案过长，**则**删到不能再删——克制是高级。（修养章节）
4. **如果**要制造共鸣，**则**找"人人有但没人说破"的那个点。（洞察章节）

## 检查清单

- [ ] 是否有一个真洞察（而非泛泛需求）
- [ ] 表达逻辑是否顺畅（先讲什么后讲什么）
- [ ] 是否说人话（能念顺、像交谈）
- [ ] 是否克制（有没有可删的）
- [ ] 是否真诚（不装、不说假话）

## 反模式

- 辞藻堆砌无洞察（华丽但空洞）。
- 又长又绕（用户划走）。
- 故作高深/端着（距离感）。

## 边界声明

- 方法源自广告文案领域，短视频口播/旁白可迁移但需适配口语节奏。
- "修养"是慢功夫，与追求快速产出的内容节奏有张力。
