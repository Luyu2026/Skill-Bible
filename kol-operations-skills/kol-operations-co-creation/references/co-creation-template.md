# 内容Brief模板

本文件是 kol-operations-co-creation 的参考模板。生成内容Brief时按此结构输出，每个章节的说明文字是写作指引（不要原样复制到最终文档里），根据实际需求填充内容。

---

## 文档头部

```markdown
# 内容Brief

日期：（当天）
数据范围：（如有数据，注明口径）
```

## 一、项目背景与产品信息
- 项目背景（1-2 句）
- 产品核心卖点（3 个，用户语言）
- 品牌调性

## 二、内容方向建议（2-3 个）
| 方向 | 内容形式 | 植入方式 | 适合达人类型 |
|------|---------|---------|-------------|
| 深度测评 | 开箱+测评 | 口播+对比 | 测评类 |
| 场景演示 | 教程/Vlog | 使用场景植入 | 生活类 |

## 三、必须包含
- 核心卖点 ≥1 个
- CTA（折扣码/链接）
- #ad 合规标注

## 四、底线与禁忌
- [ ] 无夸大/无错误信息
- [ ] 无竞品踩踏
- [ ] 无敏感内容

## 五、交付要求
- 条数/时长/平台/截止日

## 六、审核清单
- [ ] 卖点准确
- [ ] 植入自然（用户视角）
- [ ] 合规标注
- [ ] CTA 清晰
- [ ] 品牌一致
