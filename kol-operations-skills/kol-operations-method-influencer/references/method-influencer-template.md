# 达人合作方案模板

本文件是 kol-operations-method-influencer 的参考模板。生成达人合作方案时按此结构输出，每个章节的说明文字是写作指引（不要原样复制到最终文档里），根据实际需求填充内容。

---

## 文档头部

```markdown
# 达人合作方案

日期：（当天）
数据范围：（如有数据，注明口径）
```

## 一、KPI 与目标
**作用**：先定"为什么做、看什么数"，KPI 未定不选人。

- campaign 目标：（曝光 / 转化 / 拉新 / 品牌）
- 核心 KPI：（CPM / 互动率 / CPA / ROAS）
- 目标决定层级与定价逻辑

## 二、分层定位
| 达人 | 层级（nano/micro/macro/mega） | 粉丝量 | 互动率 | 画像匹配 | 内容质量 | 匹配评分 |
|------|------------------------------|--------|--------|---------|---------|---------|
| ... | ... | ... | ... | ... | ... | ... |

> 互动率 =（赞+评）÷ 发布时粉丝数（非总粉丝）

## 三、费率测算
**定价公式**：分发费 + 人才费 = 报价

| 五要素 | 权重 | 评分（1-10） | 加权 |
|--------|------|-------------|------|
| 粉丝数 | 20% | | |
| 互动率 | 30% | | |
| 内容质量 | 20% | | |
| 知名度/专业度 | 15% | | |
| 粉丝画像匹配 | 15% | | |

- **谈判锚定**：完美10分达人心里价位 $___，按实际表现扣分
- **费率卡**：tier × 平台 × 形式 × 权益分档

## 四、谈判策略
- 使用互动率数据为筹码（高互动中微观 > 低互动大V）
- usage rights / exclusivity 单独计价
- 替代方案：样品+佣金 / 低报价+创意自由度（编辑式共创）

## 五、合同核验清单
- [ ] 交付物范围（条数/形式/平台/排期）
- [ ] 付款条款（预付/尾款）
- [ ] 使用权限单独计价？
- [ ] 独占期
- [ ] FTC 披露（#ad）已写入
- [ ] 取消/终止条款
- [ ] 知识产权归属

## 六、复投评估
- 互动率/转化复盘（70/30 原生:商业比监控）
- 高价值达人 → 长期大使
- 溢出价值：额外素材/转发换复购
