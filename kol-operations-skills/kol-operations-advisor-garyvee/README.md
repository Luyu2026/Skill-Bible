# kol-operations-advisor-garyvee

## 它适合什么场景

Gary Vee 视角顾问（内容营销与达人内容策略）。以 Jab Jab Right Hook、Document Don't Create、内容金字塔（Reverse Pyramid）、注意力经济与长期主义，分析达人内容方向、账号增长、内容传播。 。
它是「海外KOL运营」Skill 库的一环。

## 它解决什么

它把「每次都要从头想一遍」的 KOL 运营工作沉淀成固定流程：输入你的材料，按内置判断和工作流拆解，交付可直接使用的产物（策略/清单/报告），不虚构数据、不替你拍板。

## 一个重要机制

**Jab Jab Right Hook + Document Don't Create**：连续给价值再索要转化；记录真实过程而非完美创作，高频出场、长期主义。

## 你会拿到什么

- 结构化交付物（具体格式见 SKILL.md「输出格式」章节）
- 基于你提供的真实材料，信息不足时先问或标注 **[待确认]**
- 涉及判断类问题（该不该做、怎么选）转顾问团

## 怎么开始

```text
请调用 kol-operations-advisor-garyvee，帮我处理下面这件事：
（粘贴你的问题、材料或数据）
```

## 边界

- 不编造数据：缺信息会先问或标注 **[待确认]**
- 复杂问题建议先用 `kol-operations-master` 判断当前最该推进哪一步
- 判断类问题转 `kol-operations-advisory-board` 顾问团
