# 《Contagious: Why Things Catch On》→ 海外KOL运营方法论（判断框架版）

## 1. 书籍概述（74字）
沃顿教授 Jonah Berger 用实证研究回答"什么让内容被主动分享"，提出 STEPPS 六原则与高唤醒情绪理论。核心主张：流行由内容自身属性驱动、可被设计，而非靠少数关键人物。

## 2. 核心框架

### 框架一：STEPPS 六原则（内容传染性设计）
| 原则 | 含义 | KOL 场景用法 |
|---|---|---|
| Social Currency 社交货币 | 分享让分享者显得聪明/内行 | 给 KOL 提供"可炫耀"素材（独家信息、内幕、测评资格） |
| Triggers 诱因 | 高频环境线索唤醒记忆 | 把品牌绑定到高频场景（早晨咖啡、发薪日、通勤），而非一次性热点 |
| Emotion 情绪 | 高唤醒情绪驱动分享 | 兴奋/敬畏/愤怒/焦虑 > 悲伤/平静 |
| Public 公共性 | 可见才可模仿 | 让"用了/买了"留下可观察的行为残留（晒单、开箱、口播复读） |
| Practical Value 实用价值 | 有用的东西被传 | 教程、省钱攻略、避坑清单，且易转述 |
| Stories 故事 | 信息搭故事的便车 | 特洛伊木马：信息深嵌故事，不讲故事就说不出口 |

- **适用场景**：KOL 内容选题评审、brief 撰写、campaign 传播策略设计
- **步骤**：① 定目标动作（转发/评论/收藏）→ ② 用六原则逐项检视内容 → ③ 至少命中 2 个维度（理想 2-3 个叠加）→ ④ 小样本试发验证分享率
- **输出物**：单条内容的 STEPPS 评分表 + 内容改造建议

### 框架二：情感唤醒（Arousal）维度
- **依据**：Berger & Milkman 对《纽约时报》近 7000 篇文章的实证研究（控制版面位置、作者知名度、实用性、趣味性后仍成立）
- **高唤醒（促分享）**：敬畏、愤怒、焦虑、兴奋、搞笑
- **低唤醒（抑分享）**：悲伤、满足、平静、无聊
- **适用场景**：情绪导向内容的立项与调性决策
- **步骤**：① 标注内容预期情绪 → ② 判断唤醒度高低 → ③ 低唤醒内容补"高唤醒钩子"（反转、悬念、惊叹点）
- **输出物**：情绪-唤醒度检查记录，防止"卖惨文/平淡种草"误投

### 框架三：可传播性设计（Transmissibility by Design）
- **依据**：书中核心论点——"社会流行由产品/思想的内在属性驱动，而非少数特殊影响者"（p.206）；且当年仅 7% 的口碑传播发生在线上（p.11），说明分享动机在内容本身
- **适用场景**：预算有限、无法持续追投头部 KOL 时的内容策略
- **步骤**：① 放弃"找大V带量"单一路径 → ② 把分享动机设计进内容结构（给分享者理由）→ ③ 逐条内容做"分享动机测试"：观众转发后能得到什么？
- **输出物**：每季度一份"无付费分享率"复盘，倒逼内容自传播能力

## 3. 决策规则（8条）
1. **如果**内容不能让分享者"显得更聪明/更内行"，**则**不配做 KOL 转发型内容，改为纯展示型内容。—— Social Currency 章
2. **如果**想持续被想起，**则**把品牌绑定到一个高频、独特、与使用时机匹配的诱因上（如"周五"之于 Rebecca Black），而不是一次性蹭热点。—— Triggers 章
3. **如果**内容触发的是悲伤/平静等低唤醒情绪，**则**预期分享率显著低于均值，必须改造为高唤醒（敬畏/愤怒/焦虑/兴奋）。—— Emotion 章 / Berger & Milkman JMR 论文
4. **如果**想让用户模仿使用行为，**则**让行为可见并留下"行为残留"（开箱、晒单、口播固定句式），看得见才传得开。—— Public 章
5. **如果**内容是实用信息类（教程/省钱/避坑），**则**要把它压缩成"可一句话转述"的版本，并明确"转给谁有用"。—— Practical Value 章
6. **如果**想把品牌信息传播出去，**则**把它嵌入一个人们愿意主动讲的故事，且深到"不讲故事就说不出口"（特洛伊木马）。—— Stories 章（书中原句见 p.201）
7. **如果**一条内容只命中 1 个 STEPPS 维度，**则**视为低传染风险，需叠加至少 1 个维度再投放。—— STEPPS 综合应用
8. **如果**预算有限，**则**优先改造内容自身的传染性，而非加码投放或追投头部 KOL。—— 全书核心论点（p.206）

## 4. 检查清单（KOL 内容上线前）
- [ ] 分享后，观众能否显得更聪明/更内行/更前沿？remarkability 点在哪？
- [ ] 是否绑定了高频、独特、与场景匹配的诱因（而非单次热点）？
- [ ] 内容情绪是高唤醒还是低唤醒？低唤醒是否有改造钩子？
- [ ] 使用/购买行为是否可见？是否设计了口播复读/行为残留？
- [ ] 实用信息是否可一句话转述？是否指明"转给谁"？
- [ ] 核心信息是否深嵌故事（去掉故事就说不出口）？
- [ ] 本条内容命中几个 STEPPS 维度？（目标 ≥2）
- [ ] 给 KOL 的 brief 里，是否写明了"观众转发的理由"而不只是产品卖点？

## 5. 反模式（3条）
1. **一次性蹭热点**：诱因不重复、不绑定场景，曝光一次即死，无法沉淀"想起来就找你"。
2. **为情绪而情绪**：刻意卖惨/煽情（低唤醒悲伤），数据上反而压制分享——情绪要选"高唤醒"那一侧。
3. **故事变广告**：把品牌信息"外挂"在故事末尾，观众可跳过故事只取信息，特洛伊木马失效；硬广式口播同理。
4. **只堆卖点不给理由**：brief 全是产品参数，没有回答"观众转发后能得到什么"，传播停留在曝光层。

## 6. 边界声明
1. **传播 ≠ 转化**：STEPPS 解释的是"被分享"，不保证购买/下载/关注，需另行验证转化链路。
2. **时效与平台差异**：书中关键数据基于 2013 年前语境（仅 7% 口碑在线发生，以邮件/口口相传为主）；短视频算法推荐平台的机制已变，诱因与公共性设计需按平台重做。
3. **充分非必要条件**：内容质量、价格、分发、竞争仍是基础变量；STEPPS 无法救活无价值产品（该书批评者也指出此点）。
4. **伦理与负外部性**：同一机制可放大谣言与有害信息；品牌须为"传播了什么"负责。
5. **统计基础限制**：核心实证来自新闻文章（文字内容）与实验室场景，外推到短视频/直播时相关性≠因果，需以自身数据验证。
