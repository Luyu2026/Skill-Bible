# AI 视频创作方案

## 适合什么场景

你有账号方向或一段草稿，却不知道第一条视频具体拍什么。

适合手机口播、教程屏录或小规模实拍；可提供现有照片、评论和产品资料。

## 解决什么

把一个受众问题收成可开拍的一条视频，而非一串选题。

本轮围绕你提交的材料完成一份可使用的结果。
缺失项会明确标出，已有材料不需要重新整理。

## 一个重要机制

先看标题承诺是否有证据镜头兑现，再安排口播和拍摄顺序。

如果缺镜头，会明确补拍动作或替代画面；提示词不会被当成已生成成片。

## 你会拿到什么

- 推荐选题和暂缓另一选题的理由
- 逐秒分镜：画面、完整口播、字幕及素材来源
- 按场地排序的拍摄清单和缺素材替代办法
- 成片复交时优先检查的一个理解断点

结果优先给可复制正文或可编辑表格。
如需文件，会说明实际生成和验证到哪一步。

## 怎么开始

1. 说出受众当前最想解决的一个问题。
2. 给出现有稿子或素材，并说明是否露脸。
3. 补充设备、平台和目标时长。
4. 先拍一版，交回成片或看不懂的具体秒段。

只用手机也能开始；未提供机型时，具体操作入口会保留待确认。

可先查看 [完整模拟案例](references/review-example.md) 了解成品形式。

## 可直接复制的调用模板

```text
请使用 video-creation-planner。
我的方向：手机摄影，面向新手。
本轮主题：窗边人像亮度跳变。
现有素材：窗边场景、可自行录屏。
限制：不露脸，一部手机，30 秒。
请给我完整口播、逐秒分镜和补拍顺序；按钮细节不确定时标出。
```
