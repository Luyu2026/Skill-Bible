# 逐字稿分阶段验收表

仅在学生交回本轮作业时读取。不要把后续阶段的检查项提前发给学生。

## 第 1 阶段：公司/项目经历概述

每段按复杂度控制在 1-3 分钟，必须有：业务场景、本人职责、目标与起点数据、一个有数据或反馈支撑的问题判断、2-3 项关键动作、结果数据和方法总结。数字口径未确认可标“待确认”，但不能因此把数据完全从概述中删掉。

通过：学生不看稿也能讲清业务、自己做什么、问题为什么在这里、做了什么、结果如何；老师能听懂整段任职/项目经历，并知道后续该深挖哪一个简历项目。

## 第 2 阶段：经历深挖

只针对通过概述的主经历。检查背景 → 任务 → 问题/判断 → 行动 → 结果 → 复盘是否连贯；方案为何这样选；数据的指标、周期、归属与边界；个人贡献与团队贡献是否分开。

通过：能回答“为什么判断问题在这里”“为什么选这个方案”“数据怎么算”。

## 第 3 阶段：逐题回答

每段最多 3-5 道主问题。优先：讲讲经历 → 为什么这样判断 → 怎么做 → 数据/个人贡献 → 复盘。追问必须围绕同一经历下钻。

通过：主问题 60-90 秒，追问 20-45 秒；不答非所问，不新编数字。

## 第 4 阶段：口述训练

检查能否脱稿、被打断后回到主线、关键数字和事实边界不出错。此时才处理 AI 腔、长句和表达节奏。
