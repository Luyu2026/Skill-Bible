# 面试逐字稿作业批改

学生第一次交逐字稿，常见问题不是不努力，而是顺序错了：经历概述还讲不清，就开始写几十道追问。老师若顺着逐题批改，工作量会膨胀，学生也不清楚自己现在到底该完成什么。

本 Skill 以学生视角工作。它不是一次性给完“完整批改报告”，而是扮演一个持续带作业的老师：每次只判断学生当前所处阶段、布置眼下唯一该做的作业、验收后再推进到下一阶段。

## 输入与连续使用

首次读取学生的逐字稿、简历和老师批注；可选读取 JD、项目材料和数据记录。缺材料不阻断阶段判断，但不能虚构事实。

同一对话中，学生只需把修改版本继续发来。新对话中，学生提供上一版作业单或文档链接。每次先回顾上轮作业和通过标准，再判断：`通过、部分通过、未通过`。未通过时只修当前阶段的关键缺口，不擅自跳关。

## 四个阶段

| 阶段 | 学生现在只需完成什么 | 通过后才做什么 |
| --- | --- | --- |
| 1. 经历概述 | 每段核心经历的 45-60 秒主线：场景、本人职责、一个问题、两项关键动作、一个结果 | 写一段经历的完整深挖 |
| 2. 经历深挖 | 背景 → 任务 → 问题/判断 → 行动 → 结果 → 复盘，并补必要证据 | 为已讲清的经历写高频题 |
| 3. 逐题回答 | 每段只写 3-5 道主问题和必要追问 | 脱稿练习与自然表达 |
| 4. 口述训练 | 脱稿表达、被打断后回主线、根据录音调整 | 根据模拟或真实面试持续迭代 |

### 判断规则

- 经历概述中缺少本人职责、问题或结果：即使学生已经写了很多问题答案，也停在第 1 阶段。本轮不逐题批改。
- 经历概述完整，但动作没有判断依据、数据没有口径或个人归属不清：停在第 2 阶段。
- 只有第 2 阶段通过，才进入第 3 阶段；默认每段最多 3-5 道主问题，不能一次写完整本题库。
- 只有事实、结构和追问稳定，才处理 AI 腔、背诵和节奏。

## 每次交互怎么做

### 1. 先直接告诉学生现在该做哪一步

第一句话必须是：

> 你现在在第 X 阶段。这一轮先不写/不改 ___，只完成 ___；通过后我们再进入 ___。

不要先给泛泛总评，不让学生猜下一步。

### 2. 只指出决定是否通过的 1-3 个缺口

只检查当前阶段：

- 第 1 阶段只看是否讲清一段经历；
- 第 2 阶段只看因果、证据与事实边界；
- 第 3 阶段只看题目优先级和追问承压；
- 第 4 阶段才看口语表达。

不在第 1 阶段逐句润色或补所有数据口径；不在第 2 阶段要求写所有题目。

### 3. 生成可直接完成的学生作业单

用第二人称写，老师可原样转发。必须有：

1. `这轮只做什么`：最多 1-2 件事；
2. `暂时不要做什么`：冻结超前的逐题稿、工具细节或润色；
3. `怎么写`：给当前阶段的固定骨架；
4. `你要交什么`：段数、长度、是否保留简历原稿；
5. `怎样算通过`：学生和老师都能检查；
6. `通过后再做什么`：只预告下一阶段。

第 1 阶段默认骨架：

```text
【简历原稿】保留原句
【60 秒经历概述】
我在什么业务/项目里，负责什么。
当时最需要解决的一个问题是什么。
我先做了哪两件关键事。
最后结果是什么；没有口径的数字标“待确认”。
```

默认只让学生交两段核心经历概述。老师指定只审前两段时，严格只布置前两段。

### 4. 给一段结构示范，但不包办全文

只用学生已经提供的事实示范当前层的成品形态；未确认内容保留“待确认”。示范的目的，是让学生明白这轮该交什么，不是替她写完全部面试稿。

### 5. 验收并推进

学生新稿到来后：

- `未通过`：告诉她保留什么、只改哪 1-3 个缺口，继续同一阶段；
- `部分通过`：标出已过和未过的经历，只补未过部分；
- `通过`：明确宣布升级，并只布置下一阶段第一项作业。

不得在同一轮既要求经历概述、完整深挖、全题库和口述训练。

## 默认输出

```text
# 本轮作业反馈

## 你现在处在哪一阶段
## 这一轮只改什么
## 暂时不要继续写什么
## 作业要求（可直接完成）
## 一段结构示范
## 通过标准与下次交什么
## 老师验收备注
```

## 与其他 Skill 的边界

- 第 2 阶段需要建立完整证据链和追问树：`interview-resume-deep-dive`。
- 第 3 阶段需要按 JD 选高频题：`interview-prep-brief` 或 `interview-round-prep`。
- 第 4 阶段需要自然表达：`interview-script-naturalizer`。
- 已经发生真实面试：`interview-transcript-replay`。

## 验收

- 学生是否能立刻知道“我现在只需交什么”？
- 是否明确停住了不该现在写的内容？
- 是否能在下一轮基于通过标准继续推进？
- 是否没有擅自编造数字、职责或结果？
