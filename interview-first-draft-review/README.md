# 面试逐字稿作业批改

学生交来第一版逐字稿时，常见的问题不是不会写，而是顺序错了：经历概述还没讲清，就已经在写几十道问题的完整答案。

这个 Skill 像老师一样持续带学生做作业。它先判断学生现在处在哪一阶段，只布置眼下该完成的 1-2 项作业；学生交回后再验收、补缺口、推进下一阶段。它不会一上来要求学生重写整本逐字稿。

## 你会拿到什么

- 一句明确判断：你现在先做“经历概述、经历深挖、逐题回答、口述训练”中的哪一步；
- 一份可以原样转发给学生的作业单；
- 明确冻结的超前内容；
- 当前阶段的一段结构示范；
- 学生交回后可快速判断的通过标准。

## 它解决什么

它按四层推进，不跳关：

```text
经历概述 → 经历深挖 → 逐题回答 → 口述训练
```

例如学生还没写稳经历概述，Skill 会要求她先交两段 60 秒经历概述，暂停所有逐题答案；通过后才写一段核心经历的深挖。

## 适合什么时候用

- 学生第一次交面试逐字稿或经历树；
- 辅导者想一次讲清学生该怎样整体回改；
- 逐字稿内容很多，但还没有形成可练、可追问的项目主线；
- 想先审结构和证据，再去改“AI 味”或口语表达。

它不用于真实面试录音复盘；已经面完的录音请使用 `interview-transcript-replay`。如果稿件结构和事实已经稳，只是表达太书面，则使用 `interview-script-naturalizer`。

## 怎么开始

把本页面链接发给你正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/interview-first-draft-review

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：装在了哪里，以及我下一句该怎么调用它。
```

装好后，直接说：

```text
请使用「面试逐字稿作业批改 Skill」批改学生的第一版逐字稿。

学生的简历：
第一版逐字稿：
目标岗位 / JD（如有）：
项目材料或数据截图（如有）：

要求：先判断她现在处在哪一阶段。不要替我全文润色，也不要一次布置所有阶段的任务。
直接生成一份可转发给学生的作业单：这轮只做什么、暂时不要做什么、交付格式、通过标准和通过后的下一步。
她交回新版本后，继续只验收当前阶段，再决定是否进入下一阶段。不要编造数据、职责或结果。
```

## 最后的练习方式

学生不需要在第一轮背完整篇。当前阶段通过后再升级，最后才处理自然表达和临场应对。
