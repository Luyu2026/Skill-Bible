# 面试逐字稿作业批改

## 它适合什么场景

学生第一次交来一整份面试逐字稿，里面已经混入几十道问题、工具细节和追问，但“介绍下你在这家公司/项目做了什么”还没讲顺。老师想一次讲清她现在该改什么，又不想自己逐题批改整篇时，就用它。

## 它解决什么

它先接住学生原稿，找出可保留的事实、当前真正卡住的点和应暂停的超前内容，再只派发眼下能完成的作业。它不会一上来要求学生重写整本逐字稿，也不会替老师把所有问题逐题批改。

## 一个重要机制

它按四层推进，但首轮只处理学生当前所在的一层：

```text
经历概述 → 经历深挖 → 逐题回答 → 口述训练
```

例如学生还没写稳“介绍下在 A 公司做了什么 / 在 B 项目做了什么”，Skill 会先保留她简历里的原句，指定两段最值得讲清的经历，并为每段给一版只使用已有事实和关键数据的 1-3 分钟示范。所有逐题答案先暂停；通过后才写某一简历项目的深挖。

## 你会拿到什么

- 对学生原稿的具体诊断：什么可以保留、为什么暂时不能继续写逐题答案；
- 一句明确判断：现在先做“经历概述、经历深挖、逐题回答、口述训练”中的哪一步；
- 一份可原样转发的作业单，以及明确冻结的超前内容；
- 每段被指定经历的简历原稿与 1-3 分钟概述示范；
- 待核对的数据、个人归属或时间口径，以及学生交回后可直接验收的通过标准。

## 不适合什么

它不用于真实面试录音复盘；已经面完的录音请使用 `interview-transcript-replay`。如果稿件结构和事实已经稳，只是表达太书面，则使用 `interview-script-naturalizer`。

## 怎么开始

把本页面链接发给你正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/interview-first-draft-review

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：装在了哪里，以及我下一句该怎么调用它。
```

装好后，直接说：

```text
请使用「面试逐字稿作业批改 Skill」批改学生的第一版逐字稿。

学生的简历：
第一版逐字稿：
目标岗位 / JD（如有）：
项目材料或数据截图（如有）：

要求：先判断她现在处在哪一阶段。不要替我全文润色，也不要一次布置所有阶段的任务。
直接生成一份可转发给学生的作业单：这轮只做什么、暂时不要做什么、交付格式、通过标准和通过后的下一步。
她交回新版本后，继续只验收当前阶段，再决定是否进入下一阶段。不要编造数据、职责或结果。
```

## 最后的练习方式

学生不需要在第一轮背完整篇。当前阶段通过后再升级，最后才处理自然表达和临场应对。
