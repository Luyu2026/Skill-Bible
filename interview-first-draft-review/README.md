# 面试逐字稿初稿审阅

学生交来第一版逐字稿时，最怕的不是错别字，而是整篇看上去很认真，实际仍然说不清：这段经历到底做了什么、为什么这么做、数据怎么来的、被追问时怎么回答。

这个 Skill 会先把这些问题在第一轮找出来。它不会直接把稿子改得更漂亮，而是把每段经历重排成真正可用于面试的结构，并给学生一份能照着回改和练习的清单。

## 你会拿到什么

- 当前初稿最该先改的三件事；
- 一张经历地图：哪些内容值得进入主线，每段应证明什么能力；
- 逐段重构建议：从哪里改起、该补什么事实和数据；
- 一段代表经历的主线示范、事实边界和三层追问；
- 一份可执行的回改与脱稿练习清单。

## 它解决什么

普通润色只会把一句话改得更顺。

但面试稿真正会出问题的地方往往是：背景、任务、问题和动作混在一起；数字只在结尾出现，没有推导过程；团队结果被说成个人成绩；或者写得很完整，却只能逐字背诵。

这个 Skill 先解决结构和证据，再进入口语化。每段主经历都会按下面的逻辑校正：

```text
简历原稿 → 经历简述 → 背景 → 任务 → 问题/判断 → 关键动作 → 结果 → 复盘
```

它会特别检查：每个动作是不是由上一环的事实或数据推导出来，结果有没有指标口径、时间范围和个人贡献边界。

## 适合什么时候用

- 学生第一次交面试逐字稿或经历树；
- 辅导者想一次讲清学生该怎样整体回改；
- 逐字稿内容很多，但还没有形成可练、可追问的项目主线；
- 想先审结构和证据，再去改“AI 味”或口语表达。

它不用于真实面试录音复盘；已经面完的录音请使用 `interview-transcript-replay`。如果稿件结构和事实已经稳，只是表达太书面，则使用 `interview-script-naturalizer`。

## 怎么开始

把本页面链接发给你正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/interview-first-draft-review

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：装在了哪里，以及我下一句该怎么调用它。
```

装好后，直接说：

```text
请使用「面试逐字稿初稿审阅 Skill」审阅学生的第一版逐字稿。

学生的简历：
第一版逐字稿：
目标岗位 / JD（如有）：
项目材料或数据截图（如有）：

要求：不要先替我全文润色。先告诉我这版最该改的三件事；
逐段说明每段经历要证明什么、问题在哪里、该如何重构、需要补什么证据；
选一段代表经历给出主线骨架、事实边界和三层追问；
最后给学生一份最多 5 项的回改与口述练习清单。不要编造数据、职责或结果。
```

## 最后的练习方式

学生不需要背完整篇。回改后，先记住每段经历的 4-6 个逻辑锚点，再脱稿讲 60-90 秒。练习时重点检查：能否说清问题从哪里来、动作为什么这样排、数字具体代表什么；能答住再进入自然表达的打磨。
