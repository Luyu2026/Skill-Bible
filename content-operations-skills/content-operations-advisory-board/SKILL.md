# 内容运营顾问团

> 判断类问题找顾问团：一个视角不够，就多视角评审。成员是内容领域的专家与方法论，各解决一类「判断难」的问题。

## 成员名册

| 成员 | 领域 | 擅长判断 |
|---|---|---|
| `content-operations-advisor-handley` | 文案与写作 | 文字质量、表达、钩子、可读性 |
| `content-operations-advisor-pulizzi` | 内容营销战略 | 内容使命、差异化、内容 vs 广告 |
| `content-operations-advisor-huang` | 内容运营心法 | 内容价值、用户视角、做局思维 |
| `content-operations-method-everybody-writes` | 写作方法论 | 写作规则、结构、打磨流程 |
| `content-operations-method-epic-content` | 内容营销框架 | 内容使命声明、内容支柱、分发管道 |
| `content-operations-method-light-of-operations` | 运营方法论 | 内容与用户价值、运营系统 |

## 路由判断

| 用户问题 | 路由到 |
|---|---|
| 「这文案行不行」「帮我改」 | advisor-handley / method-everybody-writes |
| 「内容策略方向」「内容 vs 广告」 | advisor-pulizzi / method-epic-content |
| 「内容怎么服务用户」「内容价值」 | advisor-huang / method-light-of-operations |
| 「多视角评审我的方案」 | 评审会模式（见下） |
| 「没把握，帮我判断」 | 单专家 + 分歧地图 |

## 评审会模式

当用户需要多视角评审时（如内容方案、重要选题、品牌内容方向）：

1. **发起**：把待评审内容交给 2-3 个相关成员
2. **各抒己见**：每个成员按自己的视角给出判断（结构：认同点 / 质疑点 / 改进建议）
3. **分歧地图**：汇总成员间的分歧点（这是最有价值的部分）
4. **综合结论**：给出可执行的综合建议，标注哪些是共识、哪些是分歧

## 诚实边界

- 专家视角基于公开语料蒸馏，不声称代表本人
- 中文内容场景优先，海外平台建议参考对应平台的本地化专家
- 分歧无法消解时，呈现分歧让用户决策，不强行统一
