# 《Everybody Writes》· 写作方法论

> 「人人皆写手的时代，好内容是效用×灵感×共情，靠日常习惯与流程产出，而非天赋。写作是给读者递车票。」——Ann Handley

## 适用场景

- 写博客/文章/邮件/落地页/社媒长文
- 评估一篇内容值不值得发布
- 标题、首段、CTA 的质量把关
- 改稿与重写

## 核心框架

### F1：写作心法——「给予」不是「索取」
质量公式 = **效用 × 灵感 × 共情**（乘法非加法，任一项为 0 则整体为 0）
- 效用：读者拿去能干什么
- 灵感：有数据/创意、听得出是你
- 共情：眼里是读者（「读者读到会不会有 it's me 的感觉」）

**用法**：选题立项/发布前价值判断。三项任一不达标 → 回炉或毙掉。

### F2：4U 原则（标题与首段的质量闸门）
- **Useful**（有用）：读者能省时间/少踩坑？
- **Unique**（独特）：换掉品牌名还认得出是你？
- **Ultra-specific**（极度具体）：具体到可信（数字/场景/对象）
- **Urgent**（紧迫）：为什么是「此刻」而非永远？

**用法**：写标题、邮件主题行、首段、CTA、社媒头一行。四关不过 → 重写。

### F3：写作流程（7 步）
1. 定业务目标（与卖货/获客的关系）
2. 问「So what?」并把答案钉在文档顶部当锚点
3. 收集数据与例证，列提纲（先批提纲再动笔）
4. 快速写「丑陋初稿」（TUFD），不纠结语法
5. 走开留白 → 第二稿：先发展性编辑（结构/删段），后行编辑（词句/冗词）
6. 写标题与导语，末句收尾
7. 找人审校，读出声检查可读性

## 决策规则（发布前自查）

- 一句话/一段删掉意思不变 → 删掉（砍冗余、副词、行话）
- 开头两段都是铺垫 → 砍掉前两段，最重要的话放句首
- 标题没过 4U 四关 → 重写直到全过
- 遮掉品牌名与竞品无差别 → 停产重写（消息卡拉 OK）
- 公司内部动态读者用不上 → 不发布，归档
- 多人审批 → 先只批提纲，只求 OK 不求意见
- 写不出来 → 想象写给一个爱你的人，先产丑陋初稿

## 反模式

- 委员会写作（多人轮番改出四不像）
- 行话/副词堆砌（Frankenwords：learnings、incentivize）
- 自嗨内容（只讲公司，不讲读者）
- 为 SEO 牺牲可读性

## 诚实边界

- 方法论基于英文写作语境，中文表达需本地化调整
- 4U 是质量闸门，不是爆款保证（选题决定上限）
- 流程偏重深度图文，短视频/直播场景需另行适配
