## 填写指引（增强版）

> 本节为逐项填写指引，实际交付文档时**不复制**本段，仅作为填写参考。

### 一、分发诊断
- 按漏斗逐层拆，标出每一层转化率与流失率，找到跌幅最大的断层作为主攻点
- 每个问题写明「影响面多大 + 紧急度 + 修不修的判断依据」
- 给出 2~3 个可执行修复动作，每个注明负责人与截止时间

### 二、平台矩阵
- 先定义「要做成什么样（量化目标）」，再写「怎么做到（动作 + 负责人 + 时间）」，最后写「怎么知道做成了（验收指标）」
- 每个字段尽量给具体例子（数字 / 场景 / 文案），不要留空或只写形容词
- 写清依赖与协作：谁提供什么输入、谁验收什么输出

### 三、发布计划
- 计划拆到「周 × 动作 × 负责人 × 产出物」
- 每个动作标注优先级（P0 必做 / P1 应做 / P2 可做）
- 写明检查方式：每周几、由谁、看哪几个指标验收

### 四、投流建议
> 通用填写指引同上：量化目标 → 动作+负责人+时间 → 验收指标；字段给具体示例；写明依赖协作。

## 填写示例（格式演示）

> 以下为**格式演示**（中性假数据），仅说明"每格怎么填"，实际交付时替换为真实业务内容。

| 字段 | 怎么写 | 演示 |
|---|---|---|
| 目标 | 数字 + 时间 + 责任人 | Q3 核心指标较 Q2 提升 20%，负责人：XX，数据组周报跟踪 |
| 策略/动作 | 动词开头 + 对象 + 预期结果 | 针对 XX 人群做 XX 动作，预期 XX 指标提升 X% |
| 排期 | 时间点 + 里程碑 + 依赖方 | W1 完成方案评审（依赖：设计组），W2 上线（依赖：研发组） |
| 风险 | 场景 + 概率 + 影响 + 预案 | 内容合规风险（中，影响：下架），预案：上线前敏感词自检 + 法务预览 |
| 复盘 | 实际 vs 目标 + 原因 + 下一步 | 目标 X 实际 Y（差 Z%），原因：渠道转化低于预期，下一步：换素材 A/B |
