# 《Epic Content Marketing》· 内容营销框架

> 「以持续、高价值、利他的内容替代打扰式广告。先有强大的 WHY，再有 WHAT。」——Joe Pulizzi，内容营销之父

## 适用场景

- 从零搭建内容体系 / 年度复盘
- 内容同质化、增长停滞、被大玩家碾压
- 立项审批、团队方向分歧

## 核心框架

### 框架 A：内容使命宣言（Content Mission Statement）
**公式（XYZ 法）**：「我们公司是 **[受众X]** 找到 **[内容Y]** 获得 **[收益Z]** 的地方。」
- 明确：谁（受众）→ 什么（内容领域）→ 为什么值得（收益）
- 压缩为一句话，全员背诵
- 审批时刻的判定标准：这内容是否服务于使命？
- **WHY（使命）先于 WHAT（渠道）**——无强大 WHY 就没有史诗内容

### 框架 B：内容倾斜 / 差异化利基（Content Tilt）
1. **收窄利基**：「越小越好」——不是「宠物主」，是「带小狗露营的探险旅行者」
2. **找交叉点**：独特专长 ∩ 受众具体需求
3. **加倾斜**：找一个竞争几乎为零的角度（别人看不到、你看得到）
4. **XY Pitch 检验**：「这是讲 X 的项目，不同于其他讲 X 的项目，只有我们 Y」——敢押声誉才算及格

### 框架 C：内容营销 7 步法
1. **商业论证**：一年后成功长什么样？内容要对四类问题负责（带动销售/省成本/提升留客/扩大社区）
2. **受众画像**：基于真实访谈，不是拍脑袋；画像数量不超过能单独触达的资源容量
3. **故事/内容**：定义参与周期（画像×销售流程×购买周期 → 内容分段网格，找缺口与重复）
4. **渠道**：策略先于渠道；先单平台做到最好（过早多平台分散是最大错误）；从社媒向自有资产（邮件/官网）迁移订阅者
5. **流程**：编辑日历 + C-level 支持（无支持失败概率高 300%）+ 内容团队工作契约
6. **指标**：只测 Consumption / Sharing / Leads / Sales 四维；**订阅者才是第一指标**（社媒粉丝 < 邮件订阅 < 可控数据）
7. **优化**：按指标复盘，把表现最好的格式/主题复制放大

## 决策规则

- 没有 C-level 背书 → 不启动长期内容项目，先做商业论证
- 无法一句话回答「这个主题上我们是不是世界级领先」→ 收窄利基
- 内容同质化 → 加倾斜（找零竞争角度）
- 流量涨但订阅不涨 → 缺订阅引导，先修承接
- 多平台都想做 → 先单平台做到最好
- 内容不服务使命 → 不做

## 反模式

- 内容 vs 广告的干扰式思维
- 过早多平台分散（最大错误）
- 流量崇拜（流量无意义，订阅者才有）
- 无使命驱动的随机内容生产

## 诚实边界

- 方法论偏 B2B/内容营销语境，B2C 平台型内容需调整
- 「订阅者第一」与纯流量平台（如抖音推荐流）逻辑有张力
- C-level 支持假设在个人创作者场景不适用（个人即决策者）
