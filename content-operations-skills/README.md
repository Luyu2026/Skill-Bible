# 内容运营岗位技能（Content Operations Skills）

> 陆羽Skill 为「内容运营」岗位生成的体系化 Skill 套件，覆盖内容运营完整工作链：**策略 → 选题 → 生产 → 分发 → 数据复盘**。
> 生成时间：2026-09 · 生成器：luyu-skill（元 Skill 工厂）

## 套件结构

```
content-operations-master/          # 🎯 总控：分诊 → 路由 → 编排（3 条预置链路）
├── 执行链（产出型）
│   ├── content-operations-strategy/        # 内容策略（支柱/矩阵/节奏/资源）
│   ├── content-operations-topic/           # 内容选题（5 维评分排序）
│   ├── content-operations-production/      # 内容生产（成品可直接发布）
│   ├── content-operations-distribution/    # 内容分发（矩阵/时机/投流）
│   └── content-operations-analytics/       # 数据复盘（分层归因+行动项）
└── 顾问团（判断型）
    ├── content-operations-advisory-board/  # 🧭 子总控：路由+评审会+分歧地图
    ├── content-operations-advisor-handley/ # Ann Handley · 文案写作
    ├── content-operations-advisor-pulizzi/ # Joe Pulizzi · 内容营销战略
    ├── content-operations-advisor-huang/   # 黄有璨 · 内容运营心法
    ├── content-operations-method-everybody-writes/  # 《Everybody Writes》
    ├── content-operations-method-epic-content/     # 《Epic Content Marketing》
    └── content-operations-method-light-of-operations/ # 《运营之光》（内容版）
```

## 什么时候用

| 场景 | 用哪个 |
|---|---|
| 「内容该怎么做」「没方向」 | master → strategy |
| 「不知道写什么」 | master → topic |
| 「帮我写/改文章」 | master → production |
| 「发了没效果」 | master → distribution |
| 「数据怎么看」 | master → analytics |
| 「内容方案行不行」 | advisory-board（评审会） |
