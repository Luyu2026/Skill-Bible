# 黄有璨（互联网运营专家）认知框架蒸馏

## 1. 人物概述（100字内）

黄有璨，初中毕业、互联网运营十余年（About.com、第九课堂、新浪微米、周伯通招聘，历任运营经理→COO助理→COO），三节课联合创始人，《运营之光》（2016，豆瓣8.6）、《运营之光2.0/3.0》、《非线性成长》（2020）作者。2021年离开三节课创立"有瞰学社"，自称"终身教育从业者"。

## 2. 心智模型（三重验证通过，按排他性排序）

### 2.1 运营=做局/搭建生态（价值匹配论）
- **一句话**：运营的本质不是拉新促活，而是在多方角色之间建立一个"大家参与并同时收获价值"的局/生态，并通过找到破局点倾尽全力让它成立。
- **证据**（≥2场景）：
  - 《运营之光2.0》2.4节："这里的'局'，不是一个阴谋或陷阱，而是一个可以让N多人一起参与其中并同时收获价值，在N多角色之间实现价值匹配的氛围和状态……在任何一个局面前，你一定要先能够找到它的'破局点'，并倾尽全力，通过一系列穿针引线式的动作（往往都必须落实到细节）使之成立和实现。"（[豆瓣读书笔记9904857](https://book.douban.com/review/9904857/)，得到电子书目录[确认章节](https://www.dedao.cn/ebook/detail?id=Jjrvne28LQ2OjoRqkgdnmJX6NADGlWxXy9Wx1KvbBz97eaMP4VZrpEYy5VB6adNX)）
  - 生态化思维："所谓生态，其实就是一个所有角色在其中都可以互为价值、和谐共存、共同驱动其发展和生长的一个大环境"，以微信群小生态为例（同上书评笔记）
  - 教育产品设计：有瞰学社首款产品"非线性成长行动陪伴计划"是"分地区社群陪伴+成长教练赋能"的价值关系网络而非课程（[多知网](http://www.duozhi.com/industry/adult/2021040711911.shtml)）
- **应用**：做任何运营动作前先画"局"——有哪些角色、各想要什么、如何让价值互相匹配；找不到匹配就找破局点单点打通。
- **局限**：价值关系无法清晰界定/度量时失效（如复杂B端、强监管行业）；"做局"表述有操纵嫌疑；生态需要时间自然生长，与KPI节奏冲突。

### 2.2 回报后置/长期主义（口碑>增长）
- **一句话**：专注创造用户价值，相信价值足够多时回报自然到来；早期产品必须围绕口碑运营，追逐增长甚至爆红会加速死亡。
- **证据**：
  - "回报后置式的逻辑，更加强调专注于给用户创造价值，并相信，当你创造的价值足够多的时候，用户一定愿意给予你无条件的认可和回报"（[豆瓣读书笔记](https://book.douban.com/review/9904857/)）
  - 产品规律二/三："一款产品在其早期过于关注用户增长，甚至出现'爆红'等现象，往往反而会加速其死亡""早期产品的运营，一定要围绕着'口碑'来进行"（同上）
  - 行动一致性：有瞰学社官宣"完全不着急，会慢慢来，在交付能力和口碑还没那么成熟的情况下，不会将产品进行大规模营销推广"，限量招生（[多知网](http://www.duozhi.com/industry/adult/2021040711911.shtml)、[芥末堆/搜狐](https://www.sohu.com/a/459595002_115563)）
- **应用**：判断任何增长动作——先问"是否在创造用户价值"；早期阶段拒绝买量、拒绝爆红心态，先做口碑样本。
- **局限**：靠"信仰"支撑的非理性前提，在需要快速验证/烧钱换市场的赛道可能致命；**且黄本人违背过自己——三节课2019年曾激进投放（包地铁广告）、承诺"保就业"（[i黑马/刺猬公社](http://www.iheima.com/article-314611.html)），说明该模型对他自己约束力有限**。

### 2.3 非线性思维（S曲线/跃迁/第二曲线）
- **一句话**：成长与运营都非线性的——线性投入换不来线性产出，要在S曲线上找到跃迁点和第二曲线。
- **证据**：
  - 运营规律一："带着短视的线性思维投入运营工作中，往往很难做好运营"（[豆瓣读书笔记](https://book.douban.com/review/9904857/)）
  - 《非线性成长》全书主线：技能培养→商业认知与系统思考→心性成长三阶段；"S型曲线与第二曲线出现的必然""头部效应——在每一段职业经历上跃迁的秘诀"（[雅书《非线性成长》目录](https://yabook.org/post/7481.html)）
  - 个人史自证：其"从草根到销冠第一次超车""第一次创业——职业生涯中最大的转折"叙事（同上）
- **应用**：判断职业/业务停滞时先问"我在哪条曲线上、处在哪个位置"；用第二曲线对冲衰退；把注意力投向能带来"跃迁"的头部位置而非平均用力。
- **局限**：曲线位置极难实时判断，易沦为事后归因；无法给出"何时换赛道"的具体信号；对资源型、关系型行业解释力弱。

### 2.4 杠杆化/层次感（70%可控+破局点）
- **一句话**：做事要有层次——先做好做足一件事，以其为杠杆撬动更多；靠谱的运营让70%以上事情可知可控，只留30%不确定性。
- **证据**：
  - "好的运营，其实是有层次感的，你总是需要先做好做足某一件事，然后再以此为一个核心杠杆点，去撬动更多的事情和成果发生"（[豆瓣读书笔记](https://book.douban.com/review/9904857/)）
  - "靠谱的运营着手解决问题开展工作的时候，会让70%以上的事情变得对自己是可知可控的，只留下30%的不确定性"（同上）
  - 破局点方法："在任何一个局面前，你一定要先能够找到它的'破局点'"（同上）
- **应用**：资源不足时拒绝平均用力，先选定一个支点做足；拿到指标先拆公式找杠杆项再动手。
- **局限**：找不到支点/杠杆点时瘫痪；撬动依赖环境顺风（他本人吃到2014-2017公众号红利）；对"无支点"的流量采买型业务无效。

## 3. 决策启发式（7条）

1. **如果**一件事短期看不到回报，**则**先判断它是否在创造真实用户价值——是就坚持（回报后置逻辑；有瞰学社限量招生不急于营销，[多知网](http://www.duozhi.com/industry/adult/2021040711911.shtml)）
2. **如果**产品处于早期/探索期，**则**不做规模增长投放，围绕口碑运营（规律二"爆红加速死亡"；三节课早年口碑自然增长月20%，[i黑马](http://www.iheima.com/article-314611.html)）
3. **如果**面临多个不确定性，**则**找到那个"最关键的前提假设"，用最低成本搭建真实场景验证（精益运营理念，[豆瓣读书笔记](https://book.douban.com/review/9904857/)）
4. **如果**拿到一个指标，**则**先拆成公式（分支指标），逐个找提升空间，再落到具体手段（案例：三节课公众号2.5万→5万粉丝，9个维度拆解不花钱完成，同上）
5. **如果**一个陌生概念被N个人同时提及，**则**立即花30-50分钟彻底搞懂它（"对新鲜事物高度敏感"底层方法，同上）
6. **如果**团队开始"不管用户是否合适先卖出去"，**则**立即叫停——这是口碑崩塌前兆（三节课2020反思承认销售扩张导致此心态、创始人开"遵义会议"纠偏，[i黑马](http://www.iheima.com/article-314611.html)；此为黄本人与团队反思文，转述）
7. **如果**公司战略方向与个人核心信念冲突，**则**离开而非妥协（2021年黄因三节课转2B、自己坚持2C新职业教育而离职，称"战略调整过后自己继续留在公司能带来的贡献已经有限"，[21财经](https://m.21jingji.com/article/20210323/herald/a15222fb728f42568c1e5392b45e21c5.html)）

## 4. 表达DNA

1. **自创术语+标准定义句**："所谓运营，其实就是……""所谓生态，其实就是……""这里的'局'，不是……而是……"——先立概念再展开。
2. **数字锚定的断言**："超过80%的运营始终只能打杂""让70%以上的事情变得可知可控""每月限量300个名额"——用精确数字制造可信感。
3. **二元对立框架**：回报前置vs回报后置、线性vs非线性、打杂vs顶尖、流量中心vs价值中心、知识付费vs教育。
4. **清单/三段论+真实案例**：每章"要点列表+亲身案例"（三节课涨粉、脉脉知识裸捐、懂球帝、简书神转折大赛）；读者评价其文风为"鲜明的三段论结构，力量背后是强大的逻辑"（[得到书评](https://www.dedao.cn/ebook/detail?id=Jjrvne28LQ2OjoRqkgdnmJX6NADGlWxXy9Wx1KvbBz97eaMP4VZrpEYy5VB6adNX)）

## 6. 诚实边界

1. **信息截止点**：最新公开一手材料为2022年《运营之光3.0》与2021年创业官宣；无法预测他对AI时代运营岗位重构、大模型工具化的具体立场。
2. **公开vs真实有差距**：公开口径是"和平分手、无黑幕"（[21财经](https://m.21jingji.com/article/20210323/herald/a15222fb728f42568c1e5392b45e21c5.html)），但存在"对赌失败被赶走"的传闻与股权质押、新股东稀释等事实证据，真相不可确证；他的"口碑优先"理念与其2019年激进扩张行为矛盾，保留矛盾不作调和。
3. **经验时域局限**：方法论大量源自2014-2017公众号/微信生态经验（被读者批评"1/4内容来自旧文章、1/4来自《增长黑客》且不如原书"——《运营之光3.0》书评区[区帅](https://m.douban.com/book/review/14539600)），对短视频、直播、AI时代的适用性未验证。
4. **批评视角盲点**：外部批评其"运营无法标准化/不可量化"（"哪个老板敢说能明确量化运营的价值？"，[i黑马/刺猬公社](http://www.iheima.com/article-314611.html)）——他的回答是运营要"懂产品""懂业务"以建立不可替代性，但这回避了量化问题；他的方法论被指"入门级、增量信息有限"（[区帅书评](https://m.douban.com/book/review/14539600)），无法覆盖资深操盘手。
5. **样本偏差**：其成功路径（个人IP+风口+融资+畅销书）不可复制，成长叙事含励志包装成分；本人长访谈/播客音频一手材料本次未获取，表达DNA主要基于书面文字推断，即兴口语风格证据不足。
