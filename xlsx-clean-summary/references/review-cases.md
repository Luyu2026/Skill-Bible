# 模拟复审：月报汇总与同号冲突

真实问题：合并月报后有效净额是多少，哪些订单不能计入？这是可定位的文件任务。
完整详尽：增加互斥行状态、整组冲突隔离和 CSV 导入降级，避免重复计数或误删。

## 输入与执行结果

实际读取 demo-input.xlsx：001/100、001/100、002/-20、003/空值。
业务口径已在此模拟中确认：订单号主键，完全重复折叠，空值隔离。

| 源行 | 订单 | 主状态 | 有效金额 |
| --- | --- | --- | --- |
| 2 | 001 | 有效 | 100 |
| 3 | 001 | 完全重复 | 不计 |
| 4 | 002 | 有效 | -20 |
| 5 | 003 | 字段异常 | 不计 |

可直接使用的汇总：销售有效订单 2 笔，净额 80 元；支持订单金额待补。
行数平衡：4 = 2 有效 + 1 重复 + 0 冲突 + 1 异常。
新增模拟订单 004/100 与 004/120：两行都标冲突，不纳入有效净额。

下一步只需确认 003 金额及 004 应保留哪笔；本轮不要求重整所有月报。

Python Decimal 实际聚合得到 80；重新读取现有输出簿，汇总仍为 80，001 为文本。
本次未验证宏、外链和图形保真；原演示不含这些对象。
