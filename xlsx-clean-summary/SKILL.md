# Excel 清洗与核对汇总

## 一句话主餐

普通聊天容易只给公式；这里直接把用户的工作簿整理成能交付的明细、异常清单和汇总表。

## 输入

优先读取用户已经给出的材料，不要求为本 Skill 重新抄写。

- 源 XLSX、工作表名称与需要保留的公式或图表
- 汇总维度、金额单位、日期范围及业务主键
- 已知错误示例、重复记录处理口径、最终接收软件

没有去重主键时保留疑似重复并另列，不擅自删行；金额口径未确认则先按原单位分组。

输入识别要求：
- 保留原始材料和来源定位，生成文件默认另存。
- 区分真实用户材料、待确认项与明确模拟输入。
- 用户目标明确时直接制作；只有影响结果的歧义才提出具体问题。
- 一次只解决本轮目标，不顺手扩展为其他业务流程。

## 核心判断

- 格式差异和业务差异分开：空格可清理，客户别名不能自动认定同一主体。
- 订单号、手机号和编码按文本保留，前导零不能消失。
- 空值不是零；无法解析的金额进入异常表，不参与已核对总额。
- 退货负数保留；同号不同金额视为冲突而非重复。
- 公式文本与缓存值分开读取；写入公式不等于已经完成重算。
- 含宏、外部链接或复杂图表时先识别保真风险，另存副本并报告范围。

执行前比较：以现有材料为事实源，比较直接转换与先建立结构再转换的代价。
本 Skill 采用先定位问题、再执行变更、最后核对原材料的路径。
工具选择以可保留关键语义和能验证结果为准，不以文件生成成功代替任务完成。

## 编号工作流

### 1. 盘点工作簿

- 读取 sheet 名、使用区域、表头候选、隐藏行列和合并区域。
- 记录每个源表的行数、主键列、金额列及公式数量。
- 区分标题说明行与数据行，不能用整张表第一行直接当表头。
- 产出字段映射表，保留源文件、sheet 与原始行号。

### 2. 定义数据口径

- 按用户目标选主键、分组字段、时间字段和统计字段。
- 同名字段含义冲突时分列，不按名称强行拼接。
- 列出单位转换、日期解释与重复处理规则。
- 产出本次清洗规则，未确认项采用保守保留策略。

### 3. 清洗并隔离异常

- 统一可确认的空格、日期表示和数值格式。
- 使用 Decimal 或整数分处理金额，避免二进制误差。
- 身份证、编码不做数值化；金额中的千分位按地区解释。
- 无法解析的行进入异常表，并附原值与失败原因。

### 4. 去重与冲突处理

- 只按已确认的业务主键判断重复。
- 完全重复可折叠，记录保留行及被折叠行。
- 同主键不同内容进入冲突清单，不覆盖任一原值。
- 产出保留、重复、冲突三种行状态。

### 5. 生成汇总

- 从清洗明细生成部门、月份等指定维度的汇总。
- 将有效明细金额与汇总金额逐项勾稽。
- 显式区分原始行数、去重后行数及异常行数。
- 产出包含计数与金额的汇总表，不凭展示值再次求和。

### 6. 制作可交付工作簿

- 分别写入清洗明细、汇总、异常和规则说明工作表。
- 设置筛选、冻结表头、适当列宽与金额日期格式。
- 避免合并数据区单元格，不让颜色成为唯一状态标识。
- 如用公式，保留静态核对数并标注是否经计算引擎重算。

### 7. 重新打开核验

- 重新加载生成文件，检查 sheet、行数和关键单元格。
- 用独立聚合核对金额，抽查负数、空值、前导零。
- 检查公式是否仍为公式，源文件未被覆盖。
- 产出核验记录及无法保真的对象说明。

### 8. 交接异常复核

- 先交可用工作簿，再列影响结果的业务疑问。
- 用户只需确认冲突和异常，不必重新整理全部材料。
- 收到确认后仅重跑受影响的行与汇总。
- 完成条件为勾稽一致且未解决异常可单独定位。

## 直接交付与下一步

默认交付以下成果；按用户目标裁剪，不为凑齐数量生成无关附件。

- cleaned.xlsx：清洗明细、汇总、异常、规则四表
- 字段映射与修改计数，可回溯到原始行
- 金额勾稽结果及需要确认的冲突清单

交接规则：
- 先给可使用的成品入口，再说明仍影响使用的缺口。
- 核验必须写明执行了什么、结果如何、哪些能力没有执行。
- 本轮能完成的一次性交付到此结束，不附加通用调研作业。
- 需要继续时，只要求用户交回具体异常位置、确认口径或新材料。
- 复交后沿用已确认事实，检查本次修复及其影响的原有部分。

工具不可用时：
- 明确区分内容成品、结构校验、视觉或运行验证的完成状态。
- 交付当前可执行的替代物与操作顺序，不能把文本改后缀冒充目标格式。
- 核心结果无法生成或验证时说明具体阻塞，不将其描述成完成。

### 外部参考与延展

- 遇到公式缓存为空、复杂对象丢失或日期系统不一致时研究。
- 优先查 openpyxl 官方教程、Microsoft Excel 日期与公式文档；关键词 data_only、1900 1904 date system。
- 对比表格转换与工作簿编辑：前者方便聚合，后者更适合保留单元格语义。
- 观察公式缓存、宏保留、外部链接与对象保真边界，不只比较读写速度。
- 先在副本验证受影响对象，再把适用的转换接入步骤 3 或 6。
- 不能证明保真时交付新建工作簿与对象清单，保留源文件。

官方资料入口：[Excel 清洗与核对汇总相关资料](https://openpyxl.readthedocs.io/en/stable/tutorial.html)。
已有材料足够时直接交付；研究只围绕当前失败点，不重复搜集无关项目。
实际采用外部内容时保留必要许可与来源；仅比较机制不复制正文。
