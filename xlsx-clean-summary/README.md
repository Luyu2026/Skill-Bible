# Excel 清洗与核对汇总

## 适合什么场景

适合把多个部门月报合成一份可核对报表，或在汇报前找出重复订单、缺金额和单位混用。

没有业务主键也能先清洗格式和生成疑似重复清单，但不会擅自删除疑似重复。

## 解决什么

普通聊天容易只给公式；这里直接把用户的工作簿整理成能交付的明细、异常清单和汇总表。

先读取现有材料，直接处理你指定的这一轮任务。
需要确认的口径会和可用成品分开列出。

## 一个重要机制

例如订单 001 出现两次且金额均为 100，可以按确认口径折叠；同号出现 100 和 120 则整组待确认。

你能核对修改依据，并针对具体问题复交。

## 你会拿到什么

- cleaned.xlsx：清洗明细、汇总、异常、规则四表
- 字段映射与修改计数，可回溯到原始行
- 金额勾稽结果及需要确认的冲突清单

另有一份[模拟演示](demo.md)，可先看实际交付长什么样。
真实任务的核验范围会随文件与工具环境说明。

边界示例见[复审案例](references/review-cases.md)。

## 怎么开始

1. 上传待合并的月报，说明哪些工作表是明细。
2. 给出订单号等业务主键；不确定时说明不能自动删记录。
3. 明确金额单位、退货负数和空金额如何处理。
4. 指定按部门还是月份汇总，以及要保留的公式或宏。

没有业务主键也能先清洗格式和生成疑似重复清单，但不会擅自删除疑似重复。
收到成品后，如仍有问题，回传具体位置和希望调整的结果即可。

## 可直接复制的调用模板

```text
请使用 xlsx-clean-summary。
原始工作簿：[附件/路径]；明细表：[名称]
主键：[订单号/组合字段/尚未确认]
汇总维度：[部门、月份]；金额单位：[元/万元]
重复规则：[完全重复折叠，同号不同金额待确认]
必须保留：[前导零、公式、宏或图表]
请另存清洗工作簿，给出行数平衡、金额勾稽和异常定位。
```
