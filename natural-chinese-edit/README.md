# 中文稿件去套话与自然表达

## 适合什么场景

适合通知充满铺垫、复盘只剩大词、邮件读不出行动请求，或文章变得不像本人。

只有空泛想法时先收窄表述；缺少的经历、成效和具体数字不会被编进定稿。

## 解决什么

普通润色常把套话换成更华丽的套话；这里以原稿事实为边界，把一篇稿子改成具体、自然、可发布的中文。

先读取现有材料，直接处理你指定的这一轮任务。
需要确认的口径会和可用成品分开列出。

## 一个重要机制

“预计下月覆盖部分客户”不能润色成“下月全面上线”；自然流畅也必须保留时间和确定性边界。

你能核对修改依据，并针对具体问题复交。

## 你会拿到什么

- 可直接复制发布的中文定稿
- 关键修改前后对照与简短理由
- 影响可信度的事实缺口及复交方式

另有一份[模拟演示](demo.md)，可先看实际交付长什么样。
真实任务的核验范围会随文件与工具环境说明。

边界示例见[复审案例](references/review-cases.md)。

## 怎么开始

1. 粘贴原稿，或上传可读文本。
2. 说明给谁看、发在哪里、希望对方做什么。
3. 圈出不能改的原话、数字、立场或术语。
4. 希望接近本人语气时提供一小段自己认可的旧稿。

只有空泛想法时先收窄表述；缺少的经历、成效和具体数字不会被编进定稿。
收到成品后，如仍有问题，回传具体位置和希望调整的结果即可。

## 可直接复制的调用模板

```text
请使用 natural-chinese-edit。
原稿：[正文/附件]
读者与渠道：[同事邮件/客户通知/个人文章等]
希望读者采取的动作：[具体动作]
必须保留：[事实、限定词、原话]
语气参考：[本人旧稿/朴素书面语]
请给一个可直接使用的定稿及关键对照，不新增事实或成效数字。
```
