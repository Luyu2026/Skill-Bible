# 中文稿件去套话与自然表达

## 适合什么场景

根据用户中文原稿、读者和发布渠道去掉模板腔、修复空泛表达，保留事实、立场与个人语气。用户说去 AI 味、写得自然一点、删套话或像本人表达时使用。

你手里已有材料，希望直接得到可使用的结果。
只有方向而没有材料时，也可先明确缺什么和本轮能做的范围。

## 解决什么

普通润色常把套话换成更华丽的套话；这里以原稿事实为边界，把一篇稿子改成具体、自然、可发布的中文。

保留来源与待确认项，避免为了看起来完整补造事实。
围绕当前卡点交付，不把多个无关任务捆在一起。

## 一个重要机制

先建立事实保护清单，再删套话；缺信息就收窄判断，绝不靠编造细节增加真实感。

结果可以回到原材料核验，而不只是看起来更漂亮。

## 你会拿到什么

- 可直接复制发布的中文定稿
- 关键修改前后对照与简短理由
- 影响可信度的事实缺口及复交方式

另有一份[模拟演示](demo.md)，可先看实际交付长什么样。
真实任务的核验范围会随文件与工具环境说明。

## 怎么开始

1. 提供原始材料或可读取的文件路径。
2. 用一句话说明本轮最想完成什么。
3. 告诉我必须保留的内容、口径和输出格式。
4. 已经有模板或旧成品时一并提供，优先沿用。

材料不足时会先交能可靠完成的部分，并列出具体缺口。
有问题时回传问题所在页、行、段落或数据记录即可继续。
