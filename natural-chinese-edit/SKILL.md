# 中文稿件去套话与自然表达

## 一句话主餐

普通润色常把套话换成更华丽的套话；这里以原稿事实为边界，把一篇稿子改成具体、自然、可发布的中文。

## 输入

优先读取用户已经给出的材料，不要求为本 Skill 重新抄写。

- 原稿全文或需要修改的段落
- 读者、渠道、写作目的及希望读者采取的动作
- 必须保留的措辞、事实、立场与可参考的本人旧稿

没有风格样本时用朴素明确的书面中文，不冒充某人的经历或语气；缺事实的段落只能收窄表述或列待补问题。

输入识别要求：
- 保留原始材料和来源定位，生成文件默认另存。
- 区分真实用户材料、待确认项与明确模拟输入。
- 用户目标明确时直接制作；只有影响结果的歧义才提出具体问题。
- 一次只解决本轮目标，不顺手扩展为其他业务流程。

## 核心判断

- 空泛来自信息不足时不能只换词，要定位缺少对象、动作还是证据。
- 自然表达不等于口语化，公文、工作邮件和社交帖按渠道选语气。
- 强结论不能因润色变得更确定，保留原有条件和不确定性。
- 引号中的原话与引用出处不随意改写，必要时移到正文解释。
- 用户的立场、第一人称和有辨识度的习惯表达优先保留。
- 不承诺通过 AI 检测；验收看信息、读者理解与风格匹配。

比较禁词替换与基于事实的句子重写：优先恢复谁做什么、时间和行动请求，禁词表仅用于发现疑点。
借鉴面试深挖的证据边界机制，保护用户贡献和因果强度；不照搬其题量、评分或训练计划。

### 容易误判的边界

- 原文“有望、预计、可能、部分”均进入保护清单，改稿不能升级为“必然、全部、已经”。
- 正式通知先保证生效时间、对象和动作可读；私人叙事先保留人称与情绪，不统一改成公文。
- 没有本人旧稿时称朴素中文改写，不称精准复刻本人风格。
- 同一术语在专业文稿中保留一致，不能为避免重复换成不等义近义词。

## 编号工作流

### 1. 锁定沟通目的

- 用一句话归纳谁对谁说、希望读者知道或做什么。
- 辨认当前是通知、说服、说明、复盘还是个人叙述。
- 用户只要求局部修改时锁定该段及必要上下文。
- 产出本次编辑范围与目标语气。

### 2. 建立事实保护清单

- 摘出数字、日期、专名、责任主体、因果与限制条件。
- 区分用户明确说过的事实和编辑者的解释。
- 引用与用户独特表达列为保留项。
- 产出不可失真的内容清单。

### 3. 诊断套话来源

- 标注抽象名词堆叠、空洞总结、重复转折和无主语动作。
- 识别无证据的宏大结论及机械整齐的排比。
- 每一类问题解释它怎样妨碍当前读者。
- 产出少量高优先级问题，不给全文贴标签。

### 4. 按信息重写句子

- 把抽象表达落到原稿已有的对象与动作。
- 可删除的铺垫直接删，事实缺口不靠编例子填平。
- 把过长句拆成前后相承的短句，保持逻辑关系。
- 产出第一版可替换正文。

### 5. 恢复自然节奏

- 合并重复结论，按读者问题重排必要段落。
- 保留合适的长短句差异，不把所有句子改得同样短。
- 渠道正式时减少语气词；个人叙事保留原稿情绪。
- 产出与渠道一致的连续文稿。

### 6. 回看事实和语气

- 逐项比对数字、专名、限定词和立场是否变化。
- 删去编辑新增的未经证实细节与强行升华。
- 读一遍看是否出现无来由的跳跃或隐含责备。
- 产出可发布正文与实质改动说明。

### 7. 提供必要对照

- 默认交一个推荐版，用户明确比较风格时再给另一版。
- 挑有代表性的原句与改句解释取舍。
- 只保留影响判断的待补问题，不让问卷淹没成品。
- 产出简短对照与事实缺口。

### 8. 接收真实反馈

- 让用户指出不像本人或读者没读懂的具体句子。
- 区分个人偏好与可泛化的表达问题。
- 仅修受影响段落，再核对事实保护清单。
- 完成条件为正文可直接替换且事实与立场未失真。

## 直接交付与下一步

默认交付以下成果；按用户目标裁剪，不为凑齐数量生成无关附件。

- 可直接复制发布的中文定稿
- 关键修改前后对照与简短理由
- 影响可信度的事实缺口及复交方式

交接规则：
- 先给可使用的成品入口，再说明仍影响使用的缺口。
- 核验必须写明执行了什么、结果如何、哪些能力没有执行。
- 本轮能完成的一次性交付到此结束，不附加通用调研作业。
- 需要继续时，只要求用户交回具体异常位置、确认口径或新材料。
- 复交后沿用已确认事实，检查本次修复及其影响的原有部分。

工具不可用时：

无法读取附件时请用户粘贴需要修改的正文，可先改已读段落；不把未读附件说成已通篇处理。无法确定事实的句子给保守可发布版，把核实问题放正文之外，不强行填细节。

### 外部参考与延展

- 用户反映不像本人、专业语义被改坏或渠道风格陌生时研究。
- 优先看用户本人已授权旧稿、目标渠道编辑规范和同类公开原稿。
- 关键词围绕具体场景，如工作邮件行动请求、产品更新说明、中文易读性。
- 对比信息顺序、主语动作、证据密度和句长，不能只做禁词替换。
- 只借结构与编辑机制，不复制他人经历或有辨识度的表达。
- 将新规则用在一个原段落，对照事实与用户反馈后再推广。
