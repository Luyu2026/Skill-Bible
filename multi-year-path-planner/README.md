# 1、2、5 年路径推演

它适合这样的场景：你已经围绕一个职业、项目或长期目标想了很久，Agent 的会话和项目材料里也积累了不少零散信息，但你不知道这些行动是否真的把你带向想要的方向。你只需要让 Agent 读取它实际可见的对话和材料，它会把事实、信号和待验证假设整理出来，推演接下来 1、2、5 年可能的路径，并给出眼下最值得推进的一步。

它不替你预测人生，也不因为某一个短期信号让你改变方向。它会先区分已经发生的事实、正在出现的信号和仍待验证的假设，再判断你正在做的事情处于探索、验证、稳定做法还是长期积累的阶段。

## 它怎么工作

1. 从当前会话与 Agent 可访问的历史、项目材料中提取真实信息。
2. 将每个方向放进“探索 → 验证 → 稳定做法 → 可积累资产”的链路。
3. 以条件化方式推演 1、2、5 年，而不是承诺结果。
4. 只在关键假设被新的事实、重复模式或约束变化改写时调整路径。
5. 最后给出一个本周唯一主押注，以及明确的通过与停止条件。

## 第一次使用

直接把这段发给 Agent：

```text
请使用 multi-year-path-planner 为我做一份 1、2、5 年路径推演。

请优先使用你在当前会话、可见历史会话和当前项目里已经看到的信息；看不到的内容不要假装知道。

我的长期目标：
我当前的角色、时间与现实约束：
我正在推进的项目、选择或学习：
已经发生的结果、反馈或重复模式：
我希望减少或避免的状态：

请把事实、推断和待验证假设分开。不要把条件化推演写成确定承诺，也不要因为单一信号建议我做不可逆决定。
请分别推演 1、2、5 年最可能发生的路径，并最终只给我一个本周主押注：要验证什么、做出什么、什么算通过、什么情况停止。
```

## 它不会做什么

- 不读取 Agent 实际不可见的聊天或文件。
- 不替代投资、法律、医疗或心理专业意见。
