# 1、2、5 年路径推演

把 Agent 可见的历史会话、项目材料和你的最新行动，整理成一份会持续更新的 1、2、5 年发展推演。

它不替你预测人生，也不因为一条内容爆了就让你换赛道。它会先区分已经发生的事实、正在出现的信号和仍待验证的假设，再判断你正在做的事情究竟属于内容分发、交易验证、可重复交付，还是公司资产。

## 它怎么工作

1. 从当前会话与 Agent 可访问的历史、项目材料中提取真实信息。
2. 将每个方向放进“免费入口 → 交易 → 产品 → 资产”的链路。
3. 以条件化方式推演 1、2、5 年，而不是承诺结果。
4. 只在真实付费、复购、重复使用、数据或 SOP 出现时调整路径。
5. 最后给出一个本周唯一主押注，以及明确的通过与停止条件。

## 第一次使用

直接把这段发给 Agent：

```text
请使用 multi-year-path-planner 为我做一份 1、2、5 年路径推演。

请优先使用你在当前会话、可见历史会话和当前项目里已经看到的信息；看不到的内容不要假装知道。

我的长期目标：
我现在的工作、现金流和时间约束：
我正在做的内容、产品、服务或项目：
已经发生的付费、用户使用或反馈：
我最不想回到的工作模式：

请把事实、推断和待验证假设分开。不要预测我一定会赚多少钱，也不要因为热度建议我冲动辞职。
请分别推演 1、2、5 年最可能发生的路径，并最终只给我一个本周主押注：要验证什么、做出什么、什么算通过、什么情况停止。
```

## 它不会做什么

- 不读取 Agent 实际不可见的聊天或文件。
- 不把粉丝、点赞或等待名单当作商业验证。
- 不把咨询、社群或单点 Skill 自动贬低或自动当成公司；只看它们是否积累可复用资产。
- 不替代投资、法律、医疗或心理专业意见。
