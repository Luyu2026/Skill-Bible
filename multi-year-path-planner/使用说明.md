# 1、2、5 年路径推演：使用说明

这个 Skill 适合在你需要整理长期方向、比较多个选择，或定期复盘一条正在推进的路径时使用。它会把 Agent 看得到的上下文转成条件化推演，而不是替你预言结果。

## 使用前：Agent 能看到什么

不同 Agent 能读取的内容不同。这个 Skill 只能使用它实际看得到的材料：

| 场景 | 可作为输入的内容 |
| --- | --- |
| 当前对话 | 你在本次对话中说过的事实、目标、顾虑与行动 |
| 历史会话 | 仅当 Agent 或平台明确提供会话历史时可用 |
| 项目材料 | 你明确让 Agent 读取的文件、文档、笔记或代码库 |
| 手动补充 | 你粘贴的周报、复盘、记录、数据或决策材料 |

如果 Agent 无法读取某段历史，它应该标为“待补充”，而不是编造。

## 三种常用方式

### 1. 第一次做完整推演

把下面这段发给已安装 Skill 的 Agent：

```text
请使用 multi-year-path-planner 为我做一份 1、2、5 年路径推演。

请优先使用当前会话、你可访问的历史会话和我明确提供的项目材料；看不到的信息请标为待补充。

我的长期目标：
我当前的角色、时间与现实约束：
我正在推进的项目、选择或学习：
已经发生的结果、反馈或重复模式：
我希望减少或避免的状态：

请区分事实、推断与待验证假设。用条件化方式推演 1、2、5 年，并给出本周唯一主押注：要验证什么、做出什么、什么算通过、什么情况停止。
```

### 2. 每周更新一次

适合已经做过首版，希望用新事实校准路径：

```text
请使用 multi-year-path-planner 更新我的 1、2、5 年路径推演。

这是本周新增信息：
- 完成的行动：
- 得到的结果：
- 新反馈或重复模式：
- 发生变化的约束：

请先判断路径是否需要调整；若不需要，请明确写“路径不变”。最后只给一个下周主押注，并写清量化完成标准与停止条件。
```

### 3. 基于一个项目做专项推演

适合判断某个项目、职业选择或学习方向是否值得继续：

```text
请使用 multi-year-path-planner 分析这个方向未来 1、2、5 年可能如何发展：

方向：
它解决的问题或提供的价值：
我已经投入的时间、资源与能力：
已经出现的结果或反馈：
我能承担的最大成本与风险：

请不要替我承诺结果。请指出：它现在属于探索、验证、稳定做法还是可积累资产；接下来最值得验证的一个假设是什么；通过与停止分别意味着什么。
```

## 你会得到什么

每次输出通常包含四部分：

1. **总判断**：长期路径是否调整，以及原因。
2. **证据卡**：已确认事实、已出现信号、合理推断、待验证假设。
3. **1、2、5 年推演**：每个阶段的条件、门槛和当前证据。
4. **本周唯一主押注**：具体对象、产物、完成标准、通过后下一步与停止条件。

## 使用建议

- 第一次信息不全很正常。先让 Agent 用已有信息给出首版，再补最会改变判断的 1–3 个事实。
- 每次更新只补新增事实，不需要重写完整人生故事。
- 把推演当作选择下一轮行动的工具，而不是要求它给出“最终答案”。
- 遇到重大健康、法律、投资或心理问题时，使用相关专业支持；本 Skill 只帮助整理路径与信息。
