# 芒格视角

多元思维模型与逆向检查 Skill。

它适合这样的场景：你觉得一件事“看起来没问题”，却隐约担心自己漏掉了什么；或者一个决定同时牵涉利益、激励、心理偏差和长期后果，单从一个角度看不全。它会先问“怎样一定会把这件事搞砸”，再倒回来找风险和误判。

## 你会得到什么

- 芒格的 5 个核心模型与 8 条逆向决策纪律
- 对激励、能力圈、认知偏误和多因素叠加风险的检查
- “不要做什么”的清单，而不只是“可以做什么”
- 事实不足或超出能力圈时的明确止步点

## 怎么用

把这个页面链接发给正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/munger-perspective

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：它装在了哪里，以及我下一句话该怎么调用它。
```

装好后可以直接说：

```text
请用芒格视角审视这个决定：
我要做的事：
我认为它会成功的原因：
参与者分别得到什么：
最坏结果是什么：

请先从逆向角度说：怎样最容易失败？我可能忽略了哪些激励和认知偏误？
```

## 边界

它用于补盲区与风险检查，不应被用作无止境否定。判断仍需回到真实证据、机会成本和你自己的目标。
