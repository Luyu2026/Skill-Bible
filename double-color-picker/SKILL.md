# 双色球随机选号

## 一句话主餐

普通聊天容易把随机数包装成走势预测；本技能按已核验规则和用户给定注数生成合法、不重复、可逐行核查的随机组合。

## 输入

- 确认是双色球单式选号还是用户给定的其他玩法。
- 读取用户给定注数与预算上限，不从聊天中猜支付能力。
- 有自选偏好时明确它只限制候选集合，不改变中奖机会。
- 规则、单价与开奖信息优先核验官方入口；未联网不声称掌握最新公告。
- 没有注数时默认只给一注展示；不自动购买、追加或追投。

输入处理顺序：
1. 先读取已给材料，复述本轮目标。
2. 只补问会改变执行路线的信息。
3. 可以合理假设的内容单独标记，事实缺口不能伪造。
4. 用户只要演示时明确标“模拟”，不称真实案例脱敏。

## 核心判断

1. 合法组合与有预测力分开；历史冷热、生日和幸运数不构成预测依据。
2. 常规单式口径为红球 01—33 选六个不重复号码、蓝球 01—16 选一个；执行时核对官方规则。
3. 红蓝球属于不同集合，相同数值可以分别出现在红球与蓝球。
4. 注内红球不重复；同批只排除完整组合重复，不要求各注互不共享号码。
5. 用户要求按遗漏、生肖或命理提高中奖率时，说明无法据此提升概率，可提供随机替代。
6. 不设计回本策略；预算不明确不擅自加大注数。

决策落地要求：
- 每个判断都必须影响本轮的取舍、动作或交付。
- 解释只写到足以让用户理解当前选择，不堆砌理论。
- 用户更正输入时，撤回受影响结论并重做对应部分。

## 编号工作流

### 1. 锁定规则与边界

- 确认用户要的玩法名称。
- 读取中国福彩网规则页面并记录查询日期。
- 不能核验时标注采用的常规规则假设。
- 如发现公告变化，先调整生成规则。
- 交付：规则口径与本次注数。

### 2. 核对预算和限制

- 核对所需注数是否超用户上限。
- 费用只有在单价核验后才精确列出。
- 限制号码导致候选不足时明确拒绝生成该配置。
- 不建议借钱、加注或用下一期弥补。
- 交付：本批生成范围和限制条件。

### 3. 随机抽样组合

- 工具可用时用系统随机源抽六个不同红球。
- 蓝球从独立范围抽一个。
- 红球升序排列，统一显示两位数。
- 同批完整组合重复则重新抽样。
- 交付：号码候选表。

### 4. 逐行校验

- 检查每行红球数量恰为六个。
- 检查红球互异且在规则范围。
- 检查蓝球范围和整行组合重复。
- 任何一行失败都修正后重新校验整批。
- 交付：校验通过的最终号码。

### 5. 标明生成性质

- 说明是随机组合，不是中奖预测。
- 用户偏好筛选须标注为受限随机。
- 没有随机工具时可给示例但标“人工示例，非系统随机”。
- 不伪造种子、程序执行或开奖对比结果。
- 交付：一行生成方式说明。

### 6. 完成并收口

- 只输出约定注数，不追加“更稳”的方案。
- 附规则来源和查询状态。
- 下一轮可改注数或禁选范围，但不建议追损。
- 收到预算反馈先调整数量再重新生成。
- 交付：可核对号码表及生成说明。

## 直接交付与下一步

- 红球升序、蓝球独立列出的号码表与校验状态。
- 完成标准：数量符合要求、每注合法、整批没有相同组合。
- 只生成文本，不购票，不声称已下注。
- 工具不可用时标注人工示例，允许用户复制校验脚本自行运行。
- 用户要求保证中奖时停止该承诺，仍可交付合法随机组合。

交付前验收：
- 对照用户原始输入，检查关键事实和目标没有被替换。
- 逐项检查本技能承诺的产物已实际给出，而非只说将会生成。
- 把未确认项写在相应结论附近，不藏在笼统说明里。
- 用户能直接采取下一动作，无需再把输出加工成另一个任务。
- 不宣称访问过未访问的材料，也不宣称运行了未运行的工具。

### 外部参考与延展

- 触发：用户询问规则更新、费用、玩法差异，或生成结果被指出不合法。
- 规则优先查中国福彩网 https://www.cwl.gov.cn/ 的双色球游戏规则与公告，避免用营销选号站作依据。
- 随机实现可查 Python 官方 random.SystemRandom 或 secrets 文档，重点确认无放回抽样和取值边界。
- 比较程序是否红蓝分池、注内无重复、批内去重；历史开奖不用于拟合中奖保证。
- 将核实规则写入校验条件，用边界号码、注内重复和红蓝同值案例验证；规则页不可用则标假设。

研究后的采用规则：
1. 先记录本轮具体缺口，再选互补机制，不以项目热度决定。
2. 优先复用用户已验证有效的方法；材料已足够时直接交付。
3. 外部机制只能改变执行方法，不能替代用户事实。
4. 新机制先用于当前产物，按上面的验收标准核对。
5. 找不到可靠改进时保留现有可用路径，并如实说明局限。

实际调用不复用其中的个人事实或把模拟结果当成用户结果。
