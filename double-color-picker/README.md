# 双色球随机选号

## 适合什么场景

想随机生成双色球号码、需要检查号码是否合法、想避免同批重复组合。

你可以直接交来已有材料，不用先整理成标准表。
只需要处理眼前卡点时，不必同时规划所有后续阶段。

## 解决什么

普通聊天容易把随机数包装成走势预测；本技能按已核验规则和用户给定注数生成合法、不重复、可逐行核查的随机组合。

优先处理：确认用户要的玩法名称。
本轮范围：红球升序、蓝球独立列出的号码表与校验状态。

## 一个重要机制

合法组合与有预测力分开；历史冷热、生日和幸运数不构成预测依据。

常规单式口径为红球 01—33 选六个不重复号码、蓝球 01—16 选一个；执行时核对官方规则。
执行中会把依据、假设与缺口分清，再决定如何交付。

## 你会拿到什么

- 红球升序、蓝球独立列出的号码表与校验状态。
- 完成标准：数量符合要求、每注合法、整批没有相同组合。
- 只生成文本，不购票，不声称已下注。

可以查看 [模拟成品](demo.md)，了解实际返回的样子。

## 怎么开始

1. 发来你手上的材料，或直接描述现在卡在哪里。
2. 说明这次最想完成的结果。
3. 有截止时间、口吻、篇幅或不可改内容时一并告诉我。
4. 收到初稿后，反馈一处具体问题即可继续。

建议提供：
- 确认是双色球单式选号还是用户给定的其他玩法。
- 读取用户给定注数与预算上限，不从聊天中猜支付能力。
- 有自选偏好时明确它只限制候选集合，不改变中奖机会。
