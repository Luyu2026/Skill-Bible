# 双色球随机选号

## 适合什么场景

要生成合法号码，或检查已有号码、同批整注是否重复。

可以直接交已有材料，不需要先整理成标准表。

## 解决什么

按明确规则生成并逐行校验号码，如实标注随机或人工示例。

每轮聚焦当前成果，缺口写在受影响的结果旁。

## 一个重要机制

注内红球无重复，注间只排除整注重复。红蓝分池抽取，两池同值合法。

必选或禁选先查候选容量，数量不够先说明冲突。

## 你会拿到什么

- 红球升序、蓝球独立列出的号码表。
- 注内合法性与整批去重校验。
- 生成方式、规则来源及核验状态。
- 可运行标准库脚本；无工具时标人工示例。

查看 [完整模拟成品](references/example.md)，了解实际返回内容。

## 怎么开始

1. 说明生成还是检查已有号码。
2. 给注数；仅有预算时先核对单价。
3. 有必选、禁选或需排除的整注时一并提供。
4. 未核验当前规则时会标常规假设，不伪造查验。

只需反馈具体卡点，就能继续当前成果。

## 可直接复制的调用模板

```text
使用 double-color-picker。
任务：生成三注双色球单式号码。
偏好：无，不参考历史走势。
要求：红球升序，两位数，同批整注不重复。
实际随机并校验，不能运行则标人工示例。
附规则核验状态，不做中奖预测或购票。
```
