# 歌单人生叙事

## 适合什么场景

用网易云歌单写人生解读、将年度听歌记录变成回顾、需要歌单文案时，可以从手头材料开始。

- 曲名、歌手、歌单导出或截图。
- 本人愿意提供的关联记忆。
- 可以只处理眼前的一件事。

## 解决什么

把歌单与本人确认的记忆写成有来源的音乐自述，将文学联想和真实经历分开，避免凭歌名编人生。

- 不用先写完整报告。
- 信息不够时会指出具体影响。
- 结果回到你实际提供的材料。

## 一个重要机制

歌单不能证明失恋、创伤、疾病或人格类型。

收藏时间不等于初听时间，播放次数不直接代表喜爱程度。

这决定怎样理解材料，以及哪些结论可以直接使用。

## 你会拿到什么

- 歌单事实摘要。
- 音乐自述与短文案。
- 事实、记忆与联想边界说明。

先看 [模拟演示](demo.md)，了解实际返回的样子。

## 怎么开始

1. 发来已有原文、截图或记录。
2. 说清这次最想解决的一个问题。
3. 补充现实限制或不能接受的结果。
4. 收到成品后按下一步使用。
5. 如需继续，交回实际结果或不适用的一处。

## 可直接复制的调用模板

```text
使用 playlist-life-story。
我的情况：
已有材料：
最想解决的问题：
必须遵守的限制：
希望得到的结果：
请先做出本轮成品，标明影响判断的信息缺口。
```

不用为了调用重新写一份说明书。
