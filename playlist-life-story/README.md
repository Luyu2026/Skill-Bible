# 歌单人生叙事

## 适合什么场景

把歌单与本人确认的记忆写成有来源的音乐自述，将文学联想和真实经历分开，避免凭歌名编人生。

发曲名与歌手或歌单截图，说明公开还是私密；愿意的话补一首歌关联的真实记忆。

可以只处理眼前的一件事，不要求先整理完整档案。

## 解决什么

把已有材料推进为本轮能使用的结果，并说明哪些判断还缺证据。

例如：模拟输入：歌单含朴树《平凡之路》，无次数或年份。本人说“毕业后搬家那天坐公交听的”，公开版不提城市。

本轮会完成一个明确目标，后续问题按实际反馈继续。

## 一个重要机制

只有歌曲列表：交歌单观察与音乐意象，不写人生阶段和事件。

输入不足会改变交付范围，缺失事实不会用猜测补齐。

关键步骤会解释依据，方便你发现哪里不符合实际。

## 你会拿到什么

- 歌单事实摘要。
- 音乐自述与短文案。
- 事实、记忆与联想边界说明。
- 同时说明关键缺口与结论适用范围。

可看 [完整模拟成品](references/review-validation.md)，输入与输出一一对应。

## 怎么开始

1. 发曲名与歌手或歌单截图，说明公开还是私密；愿意的话补一首歌关联的真实记忆。
2. 写明本轮最想拿到的结果和不能接受的做法。
3. 先使用返回的本轮成品，注意其中标明的执行前提。
4. 如果要继续，交回真实结果或指出最不适用的一处。

无法打开链接或截图时，直接粘贴关键文字也能开始。
