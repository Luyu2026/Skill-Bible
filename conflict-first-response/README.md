# 冲突当下回复急救

## 它适合什么场景

刚吵架收到一句气话，想知道怎么回；或者冷战、分手后犹豫这条消息该不该发。

只需最新原话、时间与必要前后文，不必交整段私密聊天。

## 它解决什么

先判断是否适合接触，再写一条短回复或明确建议不发。

同时说明发完或决定不发之后，下一步做什么、何时停止。

## 一个重要机制

接触边界优先。

“今晚别再发”意味着连确认也不再发送；普通暂停且未禁止回复才可能适合一句确认。

沉默和已读都不能证明可以继续追发。

## 你会拿到什么

- 发送或不发送的明确判断。
- 允许接触时的一条可用回复。
- 紧接着的一个行动与停止条件。
- 新回应出现时的简短处理分支。

## 怎么开始

1. 发对方最新原话与消息时间。
2. 写你已经回过什么，尤其是否反复追发。
3. 说明对方有无要求停止联系，以及是否有必要交接。
4. 收到建议后按边界行动；有新消息再带回。

[看“今晚别发”的完整模拟返回](references/delivery-example.md)。

## 可直接复制的调用模板

```text
请使用 conflict-first-response。

最新原话：“我现在不想吵，今晚别再发了。”
消息时间：今晚刚收到。
我还没回复，想发长文解释。
没有紧急事务或物品交接。
请先判断该不该发，再给下一动作与停止条件。
不要替我发送，也不要设计换渠道联系。
```
