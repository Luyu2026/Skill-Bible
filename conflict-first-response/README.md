# 冲突当下回复急救

## 它适合什么场景

根据刚收到的气话、冷战经过或分手信息，写一条符合当前边界的回复和紧接着的行动；适用于“吵架了怎么回”“对方不理我”“分手后这句该不该发”等当下场景。

从一份已经有的材料开始即可，不需要先学一套方法。

## 它解决什么

普通聊天可能把回复写成辩论长文；这里先判断当前是否适合接触，再交付一条能发送的回复和明确停止条件。

它会先处理你当前卡住的一件事，再给能直接使用的结果。

## 一个重要机制

先判断安全和接触边界，再优化措辞。

明确拒绝联系时不设计换号、找朋友传话或堵门等绕过方式。

这个区分会影响先做什么，以及最后交付哪一种结果。

## 你会拿到什么

- 一条可直接发送的回复，或明确不发送的判断。
- 对应理由、紧接着的一个行动和停止条件。
- 针对愿意谈、继续攻击、无回应的简短分支。
- 验收看是否尊重边界、没有升级矛盾、下一步可执行，不看是否成功复合。

## 怎么开始

1. 发来你已有的原文、记录或草稿。
2. 说明现在希望解决的卡点和本轮目标。
3. 写出会影响处理的时间、渠道或方法限制。
4. 收到结果后直接使用；有新反馈时带回原话或实际产物。

不必补齐所有背景；会先使用已有材料，只有关键缺口才追问。

## 可直接复制的调用模板

```text
请使用 conflict-first-response 帮我完成这次任务。
我已有的材料：
（在这里粘贴原文、草稿或提供可访问文件）

我现在最卡的是：
（描述具体问题）

本轮希望拿到：
（说明成品形式和长度）

需要遵守的限制：
（时间、渠道、边界或可用方法）

请先使用现有材料，区分事实与待确认信息，给可直接用的结果和下一步。
```
