# 时间与输出规则

## 校正参数

| 参数 | 含义 |
|---|---|
| `--offset-ms N` | 有符号整数毫秒；正数让字幕更晚，负数让字幕更早 |
| `--anchor S=T` | 当前字幕时刻 S 对应目标视频时刻 T；必须给两组，且 S 和 T 都严格递增 |
| `--negative error` | 默认；任何负开始时间导致整个转换失败 |
| `--negative clip` | 经用户明确接受后启用；结束时间 ≤ 0 的条目丢弃，跨零条目的开始时间设为 0 |
| `--encoding NAME` | 输入编码，默认 utf-8-sig，解码错误不会被替换或忽略 |
| `--out-dir PATH` | 新目录，包含 corrected.srt 与 report.json；拒绝覆盖已存在目录 |

线性变换是 `目标毫秒 = a × 原毫秒 + b`，其中 `a = (T2 − T1) / (S2 − S1)`，`b = T1 − a × S1`。使用有理数计算，最后四舍五入到毫秒，恰好半毫秒时远离零舍入。比例必须大于零。变速会同比缩放每条字幕持续时间。两锚点区间外也应用同一公式，在报告中标明外推条目数；不要把外推当作另行观察到的同步证据。

示例：10 秒→12 秒、610 秒→618 秒，比例是 101/100，截距 1900 毫秒；310 秒→315 秒。不能用简单加 2 秒代替这一变换。

## SRT 范围与保留内容

每个块为十进制编号、严格时间行、至少一行非空文字；块间以空行分隔。保留正文中的逐行空格、标签和编号，不重新编号、不重排。输入允许 CRLF/CR/LF，输出统一 LF；BOM 移除。重复编号、结束早于或等于开始、非法分秒、缺少空行或不支持的时间扩展均报错。输出任何条目的时长舍入成零也报错。

输入、结果都整体载入内存，适合通常的字幕文件，不能宣称支持无限大文件。原文件只读。输出目录独占创建，写入失败时清理本次生成的文件；错误消息不会打印字幕正文。

## 报告字段

`input_cues = output_cues + dropped_cues`，`clipped_cues` 是保留下来但开始时间截到零的条目数。`changes` 每条包含原编号、原时间、新时间（丢弃时为空）和处理动作。`scale` 与 `offset_ms` 是精确分数字符串。

`warnings` 提醒：输入/输出存在时间重叠或开始时间乱序、两锚点外推、片头裁剪。重叠检测按时间排序后比较覆盖区间；这仅用于诊断，不改变输出顺序。相邻结束与开始相等不算重叠。

退出码 0 表示文件按规则转换成功，不等于经过视听验证；退出码 2 表示参数、输入或输出失败。报告不记录正文、账户、设备或调用历史，无网络请求。
