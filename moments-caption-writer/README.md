# 朋友圈文案写手

## 适合什么场景

照片不知道配什么字、草稿太像广告，或希望更像自己的口吻。

可以直接交已有材料，不需要先整理成标准表。

## 解决什么

根据已发生的事写三种可复制文案，并选一条主推。

每轮聚焦当前成果，缺口写在受影响的结果旁。

## 一个重要机制

改变观察角度，保持同一事实底稿。三版应来自同一场景，不补编三段经历。

严肃场景会改用克制表达；不想互动时不强加问题。

## 你会拿到什么

- 三种角度的完整文案，主推其中一条。
- 主推理由一句，放在发布文本外。
- 符合表情、长度、隐私和口吻要求的最终稿。
- 按更短、口语或别像广告修订选定版本。

查看 [完整模拟成品](references/example.md)，了解实际返回内容。

## 怎么开始

1. 发照片描述或草稿，说明实际发生的事。
2. 告诉我谁会看，想记录还是邀请。
3. 给禁用词、表情和长度要求，可贴一条旧文。
4. 照片读不到时用文字描述，不需要补编故事。

只需反馈具体卡点，就能继续当前成果。

## 可直接复制的调用模板

```text
使用 moments-caption-writer。
事实：周六独自去公园走半小时，拍到长椅上的猫。
受众：熟人；目的：日常记录。
口吻：自然，不鸡汤，不加表情。
不要补写我坐下、绕路等未发生动作。
请给三版可复制文字和一条主推。
```
