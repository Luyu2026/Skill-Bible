# 朋友圈文案写手

## 适合什么场景

有照片不会配文、想写自然的朋友圈、已有文案太像广告需要改写。

你可以直接交来已有材料，不用先整理成标准表。
只需要处理眼前卡点时，不必同时规划所有后续阶段。

## 解决什么

普通聊天容易给万能金句；本技能根据真实场景、受众和表达边界，交付可直接发布且风格有区别的朋友圈文案。

优先处理：从材料中摘出可公开的事实。
本轮范围：三种差异文案和一条主推，用户可直接复制。

## 一个重要机制

日常记录与商业招募分开；前者保留生活感，后者明确事实与行动入口。

用户提供的真实细节优先于夸张形容词。
执行中会把依据、假设与缺口分清，再决定如何交付。

## 你会拿到什么

- 三种差异文案和一条主推，用户可直接复制。
- 不把解释、引号或“版本一”混入要发布的文字。
- 事实有缺口时优先给不依赖缺口的完整版本。

可以查看 [模拟成品](demo.md)，了解实际返回的样子。

## 怎么开始

1. 发来你手上的材料，或直接描述现在卡在哪里。
2. 说明这次最想完成的结果。
3. 有截止时间、口吻、篇幅或不可改内容时一并告诉我。
4. 收到初稿后，反馈一处具体问题即可继续。

建议提供：
- 优先读取照片说明、用户草稿、发生的事和想表达的心情。
- 图片不可读时依据用户描述，不编造地名、人物关系和品牌。
- 确认面向熟人、同事还是客户，以及是否希望互动。
