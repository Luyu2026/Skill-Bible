# 奥德赛三路人生规划

## 它适合什么场景

人生选择卡住、希望比较三种不同未来路线。

可以从一段已有材料开始，不必先写完整报告。

## 它解决什么

围绕当前卡点，完成三路人生卡、共同约束表、关键假设、一次体验计划。

先完成当前最能推进的一件事，再依据反馈决定是否继续。

## 一个重要机制

三路必须改变生活组织方式。

结论回到具体输入，缺失信息保留为未知，不用看起来完整的内容填空。

## 你会拿到什么

- 三路人生卡。
- 共同约束表。
- 关键假设。
- 一次体验计划。

交付会说明已完成内容及仍需补齐的部分。

## 怎么开始

直接发已有材料，并说明这次最想解决的一件事。

建议提供：当前生活与经历；选择困境；收入底线；家庭责任；可用时间；规划时间窗。

不方便分享的部分可以删去；影响判断的缺口会单独指出。

工具不足时先拿到可复制文本或制作包，未生成的文件会明确标注。

### 模拟输入

在职设计师需照顾家人，不能失去收入，想探索教学。

### 对应的模拟成品

一路保留设计并带新人；二路探索企业培训设计；三路保留主业试做周末教学。先整理一节已有技能小课并试讲，记录准备耗时与感受，不建议立即辞职。

使用后可交回实际结果或新材料，围绕同一个卡点继续修订。
