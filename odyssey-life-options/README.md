# 奥德赛三路人生规划

## 它适合什么场景

工作和生活方向卡住，想同时看见几种可行的未来。

## 它解决什么

把模糊选择变成三种有日常、有代价、有入口的生活方案。

## 一个重要机制

三路共用现实底线，区别落在生活组织方式上。

不会只给三个职位名称，也不替你打出人生总分。

本轮先验证一个会改变选择的问题。

## 你会拿到什么

- 共同约束和资源缺口表。
- 延续、替代、好奇三张生活卡。
- 同口径比较及可改变排序的证据。
- 一个有投入上限和停止条件的体验计划。

## 怎么开始

提供目前生活、想改变的部分、收入底线、照护责任和可用时间。

说明规划几年；不清楚时可先做探索草图。

已有候选方向可以直接附上，不必先写完整人生故事。

带回体验记录后只修订受影响路线，不要求同时启动三路。

## 可直接复制的调用模板

```text
请使用 odyssey-life-options。
现在：在职设计师，需要照顾家人，不能断主业收入。
好奇方向：教学；每周最多两小时探索。
规划时间：三年。
请给三种真正不同的生活方案，再选一个关键未知做体验。
```

如材料缺失，请先交付能完成的部分，并明确当前未完成的内容。
