# 小说开场创作

## 一句话主餐

普通聊天容易只扩写世界观；本技能把现有设定收束成角色必须当场作出选择的开场正文。

## 输入

- 已有一句设定、人物卡、片段或大纲，保留作者已确定的关系和世界规则。
- 询问本轮要开场正文还是改写已有开头；默认只完成一个场景。
- 可选信息：视角、题材、目标读者、篇幅、希望保留的句子。
- 材料不足时默认第三人称有限视角、单地点、约 600—1000 字，并先列创作假设。
- 可以补虚构角色和动作，不能把作者真实经历或他人作品内容当作自由素材。

输入处理顺序：
1. 已有正文优先于一句新设定：先圈出作者要求保留的句子和世界规则。
2. 缺主角目标时可拟“登记这本来历不明的书”，新增项在约束卡中注明。
3. 作者要求改稿时先保留原稿，定位第一处读者无法理解行动的段落。
4. 只有题材没有故事时先用单地点场景开写，不追问完整世界史。

## 核心判断

1. 设定新奇与戏剧冲突分开判断：先找谁想得到什么、谁或什么阻挡。
2. 无主角目标时先设本场景可见目标，如取回信件；不直接规划整个系列。
3. 已有正文先诊断卡在信息、动作还是选择，只重写影响开场的一处结构。
4. 视角信息只能来自当前叙述者可感知内容；不得靠突然全知揭谜。
5. 读者疑问必须由异常细节产生，不能只靠“更大的阴谋”一句话。
6. 结尾推进人物处境，留下具体待解决动作，而非突然切断。

判断落地检查：
- 用“目标—尝试—阻力—选择—后果”逐项检查，缺选择就重写主角行动。
- 悬疑可保留书的来历，但不能同时隐去人物此刻为何开门的理由。
- 新增奇观若不能改变主角下一动作，删去或移到下一场。

## 编号工作流

### 1. 锁定场景契约

- 提取原设定中不可改的事实。
- 写一句“主角要在某个限制内完成什么”。
- 标明新增的虚构设定。
- 选定一个场景地点和视角。
- 交付：不超过五行的场景约束卡。

### 2. 设计阻力与代价

- 为目标选择可被动作体现的阻力。
- 说明失败会失去什么。
- 让主角拥有一种有缺陷的应对方式。
- 检查阻力是否直接来自用户设定。
- 交付：目标、阻力、代价、选择四项表。

### 3. 排出动作节拍

- 依次写触发事件、尝试、反作用、选择、后果。
- 每个节拍必须改变人物能做的事。
- 设定解释只保留理解动作所需内容。
- 删去与本场景目标无关的历史年表。
- 交付：五个可转成正文的节拍。

### 4. 写出完整开场

- 第一段让人物正在做事。
- 用动作和物件承载冲突信息。
- 对话双方应有不同意图。
- 把心理解释转成可感知细节，但保留必要内心判断。
- 交付：有起止和转折的连续正文。

### 5. 做一次定点修订

- 逐段检查是否推进目标或改变判断。
- 检查物件位置、时间和视角一致。
- 找出最弱的一段并直接重写。
- 将新增设定回填约束卡，避免下轮矛盾。
- 交付：修订正文及两条实质修改理由。

### 6. 交接续写动作

- 给出结尾之后最直接的一个行动。
- 列两条不同代价的续写方向。
- 让用户只选择更符合主角的一条。
- 收到反馈后沿原约束续写，不重启世界观。
- 交付：下一场景起点和一个选择问题。

## 直接交付与下一步

- 连续开场正文是主交付，节拍和约束卡作为简短附件。
- 完成标准：主角有目标、受到阻力、作出选择，结尾处境已经改变。
- 下一轮只接收读者困惑点、希望保留的句子或续写选择。
- 不默认要求作者填写全部人物传记；能开写就先交稿。
- 文件工具不可用时在对话中交付正文和约束卡。

交付前验收：
- 正文默认 600—1000 非空白字符；明确要求短片段时按用户长度。
- 逐项比对约束卡：姓名、规则、叙述人称、物件位置不得悄然变化。
- 主角最后一项选择应造成可指出的处境变化，单纯“感到害怕”不通过。
- 冷静悬疑不等于无动作；至少有一次尝试失败与一次主动选择。
- 检查收尾之后能接的第一动作；不能只说“故事继续”。

## 外部参考与延展

- 先比较相邻 serial-chapter-draft 的章节账本：采用状态更新，单场开头不机械沿用单章长度。
- 写作课程入口：[OpenLearn Start writing fiction](https://www.open.edu/openlearn/history-the-arts/creative-writing/start-writing-fiction/content-section-0)。观察人物如何经行动显形，不搬用范文。
- 若目标不清，先研究 character objective scene conflict；若视角跳动，研究 limited viewpoint。每轮只解决一个缺口。
- 把采用机制用于同一原稿，逐项对照选择是否成立、信息是否越界；保留作者原风格有效部分。

### 场景分支与改稿边界

- 新写开场：允许拟角色名、场景物件；列入新增虚构设定。
- 已有开头：先保留作者原设定，只改变阻碍理解的因果或信息顺序。
- 只有世界观：选一项规则，让它妨碍主角今天必须做的小事。
- 目标含糊：把“寻找真相”改为眼前可完成的取证动作。
- 冲突过大：缩成一次登记、交接或开门，不在开头解决整座城市。
- 读者看不懂：补一个可观察的线索，避免追加整段历史。
- 读者猜到了：更换选择的代价，避免仅把谜底藏得更深。
- 要续写：复用上次状态卡，从上一场后果开始。
- 对照案例见 [完整开场与续接卡](references/example.md)。
