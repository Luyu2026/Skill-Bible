# 小说开场创作

## 一句话主餐

普通聊天容易只扩写世界观；本技能把现有设定收束成角色必须当场作出选择的开场正文。

## 输入

- 已有一句设定、人物卡、片段或大纲，保留作者已确定的关系和世界规则。
- 询问本轮要开场正文还是改写已有开头；默认只完成一个场景。
- 可选信息：视角、题材、目标读者、篇幅、希望保留的句子。
- 材料不足时默认第三人称有限视角、单地点、约 600—1000 字，并先列创作假设。
- 可以补虚构角色和动作，不能把作者真实经历或他人作品内容当作自由素材。

输入处理顺序：
1. 先读取已给材料，复述本轮目标。
2. 只补问会改变执行路线的信息。
3. 可以合理假设的内容单独标记，事实缺口不能伪造。
4. 用户只要演示时明确标“模拟”，不称真实案例脱敏。

## 核心判断

1. 设定新奇与戏剧冲突分开判断：先找谁想得到什么、谁或什么阻挡。
2. 无主角目标时先设本场景可见目标，如取回信件；不直接规划整个系列。
3. 已有正文先诊断卡在信息、动作还是选择，只重写影响开场的一处结构。
4. 视角信息只能来自当前叙述者可感知内容；不得靠突然全知揭谜。
5. 读者疑问必须由异常细节产生，不能只靠“更大的阴谋”一句话。
6. 结尾推进人物处境，留下具体待解决动作，而非突然切断。

决策落地要求：
- 每个判断都必须影响本轮的取舍、动作或交付。
- 解释只写到足以让用户理解当前选择，不堆砌理论。
- 用户更正输入时，撤回受影响结论并重做对应部分。

## 编号工作流

### 1. 锁定场景契约

- 提取原设定中不可改的事实。
- 写一句“主角要在某个限制内完成什么”。
- 标明新增的虚构设定。
- 选定一个场景地点和视角。
- 交付：不超过五行的场景约束卡。

### 2. 设计阻力与代价

- 为目标选择可被动作体现的阻力。
- 说明失败会失去什么。
- 让主角拥有一种有缺陷的应对方式。
- 检查阻力是否直接来自用户设定。
- 交付：目标、阻力、代价、选择四项表。

### 3. 排出动作节拍

- 依次写触发事件、尝试、反作用、选择、后果。
- 每个节拍必须改变人物能做的事。
- 设定解释只保留理解动作所需内容。
- 删去与本场景目标无关的历史年表。
- 交付：五个可转成正文的节拍。

### 4. 写出完整开场

- 第一段让人物正在做事。
- 用动作和物件承载冲突信息。
- 对话双方应有不同意图。
- 把心理解释转成可感知细节，但保留必要内心判断。
- 交付：有起止和转折的连续正文。

### 5. 做一次定点修订

- 逐段检查是否推进目标或改变判断。
- 检查物件位置、时间和视角一致。
- 找出最弱的一段并直接重写。
- 将新增设定回填约束卡，避免下轮矛盾。
- 交付：修订正文及两条实质修改理由。

### 6. 交接续写动作

- 给出结尾之后最直接的一个行动。
- 列两条不同代价的续写方向。
- 让用户只选择更符合主角的一条。
- 收到反馈后沿原约束续写，不重启世界观。
- 交付：下一场景起点和一个选择问题。

## 直接交付与下一步

- 连续开场正文是主交付，节拍和约束卡作为简短附件。
- 完成标准：主角有目标、受到阻力、作出选择，结尾处境已经改变。
- 下一轮只接收读者困惑点、希望保留的句子或续写选择。
- 不默认要求作者填写全部人物传记；能开写就先交稿。
- 文件工具不可用时在对话中交付正文和约束卡。

交付前验收：
- 对照用户原始输入，检查关键事实和目标没有被替换。
- 逐项检查本技能承诺的产物已实际给出，而非只说将会生成。
- 把未确认项写在相应结论附近，不藏在笼统说明里。
- 用户能直接采取下一动作，无需再把输出加工成另一个任务。
- 不宣称访问过未访问的材料，也不宣称运行了未运行的工具。

### 外部参考与延展

- 触发：开场只有解释、人物没有主动选择，或用户反馈故事虽顺却不想继续读。
- 优先比较仓库已有叙事技能、作者提供的范文与公开写作课程；可查 OpenLearn creative writing、Purdue OWL fiction writing。
- 重点观察目标如何落到动作、阻力如何升级、视角如何控制信息；不摘抄范文情节。
- 对照“场景目标—冲突—结果”和用户现有写法，选择能修复当前断点的一项机制。
- 将机制只应用到最弱段，以修订前后人物是否更可行动作验证。

研究后的采用规则：
1. 先记录本轮具体缺口，再选互补机制，不以项目热度决定。
2. 优先复用用户已验证有效的方法；材料已足够时直接交付。
3. 外部机制只能改变执行方法，不能替代用户事实。
4. 新机制先用于当前产物，按上面的验收标准核对。
5. 找不到可靠改进时保留现有可用路径，并如实说明局限。

随附 `demo.md` 是明确模拟的输入与成品，用于理解交付尺度。
实际调用不复用其中的个人事实或把模拟结果当成用户结果。
