# 模拟运行成品

## 输入

模拟输入：城市里每个人死后会变成一本书，年轻图书管理员收到一本写着自己名字的书。希望冷静、悬疑的第三人称开场。

## 成品

林澈给归还的书贴上封条时，收书口又响了一声。

他抬头看钟。闭馆已经十分钟，门外的卷帘也落了。收书口里是一册灰布封面的薄书，书脊没有死亡日期。

“日期没填，明天再送。”他朝铜管喊。铜管另一头传来纸张摩擦声，没有回答。

他把书拖到灯下。封面只有两个烫银的小字：林澈。

名字很常见，他想。同名的人每天都有。他翻到扉页，准备登记出生地。第一行却是他母亲的小字：下雨记得把右边的窗关上。那个“雨”字漏了最后一点，和家里冰箱上的便条一样。

右边的窗忽然响了。雨水正顺着窗沿流进来，浸湿了待登记的死者名单。林澈起身去关，走到一半又停下。

翻开的书页上，第二行墨迹还没有干：他走到一半，停住了。

他用手压住下一页。地下书库的门锁咔哒一声。有人在下面用他的声音说：“别读出最后一行。”

林澈抽出登记刀，没有翻页。他先把自己的名字从值夜名单上划掉，再走向那扇一直不准他打开的门。
