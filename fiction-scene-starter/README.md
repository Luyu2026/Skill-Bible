# 小说开场创作

## 适合什么场景

有世界设定却写不出开头；或已有开篇，人物一直解释而没有行动。

可以直接交已有材料，不需要先整理成标准表。

## 解决什么

把设定变成一个有人物目标、受阻和选择的完整场景。

每轮聚焦当前成果，缺口写在受影响的结果旁。

## 一个重要机制

用当场目标承载世界规则。死人会变成书的设定，先落到管理员必须登记一本不该出现的书。

读者可暂不知道谜底，但应理解人物为何做下一动作。

## 你会拿到什么

- 约600—1000字的连续开场正文。
- 原设定与新增虚构设定的简短约束卡。
- 目标、阻力、代价和结尾状态。
- 下一场动作及两条不同代价的续写方向。

查看 [完整模拟成品](references/example.md)，了解实际返回内容。

## 怎么开始

1. 贴一句设定或需要保留的开头。
2. 告诉我视角、口吻和不可改的规则。
3. 要改稿时指出一处读不下去的位置。
4. 读完后反馈保留哪句、哪里困惑或选哪个续写方向。

只需反馈具体卡点，就能继续当前成果。

## 可直接复制的调用模板

```text
使用 fiction-scene-starter。
设定：每个人死后会变成书，管理员收到自己的书。
本轮：第三人称，冷静悬疑，600—1000字完整开场。
不可改：主角此时仍活着。
请给正文、简短约束卡和下一场起点。
```
