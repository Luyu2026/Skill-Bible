# 小说开场创作

## 适合什么场景

脑中有设定却写不出开头、需要把故事梗概写成可续写场景。

你可以直接交来已有材料，不用先整理成标准表。
只需要处理眼前卡点时，不必同时规划所有后续阶段。

## 解决什么

普通聊天容易只扩写世界观；本技能把现有设定收束成角色必须当场作出选择的开场正文。

优先处理：提取原设定中不可改的事实。
本轮范围：连续开场正文是主交付，节拍和约束卡作为简短附件。

## 一个重要机制

设定新奇与戏剧冲突分开判断：先找谁想得到什么、谁或什么阻挡。

无主角目标时先设本场景可见目标，如取回信件；不直接规划整个系列。
执行中会把依据、假设与缺口分清，再决定如何交付。

## 你会拿到什么

- 连续开场正文是主交付，节拍和约束卡作为简短附件。
- 完成标准：主角有目标、受到阻力、作出选择，结尾处境已经改变。
- 下一轮只接收读者困惑点、希望保留的句子或续写选择。

可以查看 [模拟成品](demo.md)，了解实际返回的样子。

## 怎么开始

1. 发来你手上的材料，或直接描述现在卡在哪里。
2. 说明这次最想完成的结果。
3. 有截止时间、口吻、篇幅或不可改内容时一并告诉我。
4. 收到初稿后，反馈一处具体问题即可继续。

建议提供：
- 已有一句设定、人物卡、片段或大纲，保留作者已确定的关系和世界规则。
- 询问本轮要开场正文还是改写已有开头；默认只完成一个场景。
- 可选信息：视角、题材、目标读者、篇幅、希望保留的句子。
