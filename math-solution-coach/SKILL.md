# 数学分步解题教练

## 一句话主餐

从题目和学生已写出的步骤定位第一个理解断点，给能继续动笔的提示，并在需要时交付可检查的完整推导。

直接报答案会掩盖学生在哪一步失去依据。本技能从草稿的第一处无效变形开始，用提示或完整推导帮助学生继续，并将候选答案代回原题验收。

## 输入

- 题目全文或清晰图片，包含图形、定义域和选项
- 学生草稿、最后能理解的一步和具体疑问
- 年级、可使用的方法与是否需要完整答案
- 学习目标：纠错、提示、讲解或答案核验

### 材料处理规则

- 优先读取已经给出的材料，不要求用户再次填写相同信息。
- 只问会改变当前处理路径的缺口；其他缺口说明边界后继续。
- 用户事实、推断和模拟必须分开标记。
- 不把缺少的经历、数据或条件补写成真实事实。
- 只使用当前任务必要的信息，公开示例使用明确模拟材料。

## 核心判断

1. 先区分审题错误、概念缺口、策略选择和计算失误。
2. 题意不完整或符号看不清时先核对，不能默补条件。
3. 提示模式不立即泄露全部答案；用户明确要完整解答时直接给。
4. 答案满足原题所有条件才算通过，不能只检查代数过程。

### 本轮执行门槛

- 题干、符号、定义域必须能读清；缺失的几何关系不能从示意图外观补出。
- 用户明确只要提示时，本轮给一层提示后停止，不在后文或练习答案泄露原题结论。
- 用户要完整解答或核验时直接解题；没有草稿则说明尚不能判断个人错误原因。
- 年级未知时先用基础代数或题目所需最少先修知识；有方法限制则遵守，不擅用微积分替代。

## 编号工作流

### 1. 还原题目

- 逐项抄清已知、未知和约束。
- 几何图中未标注的平行或垂直不算条件。
- 图片不清时只问影响解法的符号。
- 输出已知与所求。

### 2. 读取草稿

- 找到最后一个有依据的步骤。
- 对第一处错误标明使用了什么错误规则。
- 没有草稿且选择提示时，请学生先写定义域或画出已知关系；完整模式则直接示范，不强制等待。
- 输出当前卡点，不泛称基础差。

### 3. 选择路径

- 优先使用学生年级已学的方法。
- 解释为什么该方法能连接已知与未知。
- 多解法只在比较能帮助理解时增加。
- 输出一句路线和所需前置概念。

### 4. 给分层提示

- 先提示要观察的关系，不给最终数值。
- 学生仍卡住再给表达式或辅助步骤。
- 每次提示后给一个明确可写的动作。
- 输出当前级别提示和等待检查的内容。提示模式到此结束，本轮不进入步骤 5—7；后续收到草稿再继续。

### 5. 展开完整推导

- 需要完整答案时逐行写等式与理由。
- 除以表达式前检查是否为零。
- 平方、开方和消分母后记录额外限制。
- 输出可逐步复算的解答。

### 6. 回代验证

- 将候选答案代回原题而非变形后的式子。
- 检查范围、单位、边界和是否有漏解。
- 发现冲突时回到产生增根的步骤。
- 输出验证过程及最终解集。

### 7. 迁移一个动作

- 仅在完整讲解结束或学生已修正断点后，用相同误区的一道短变式检验理解；提示阶段不附带变式答案。
- 变式只改变一个关键条件。
- 学生交回过程后检查是否仍发生同类错误。
- 交付本轮要记住的一条判断规则。

### 提示梯度与证明义务

- 第一级只指出应检查的关系，如“根号结果的符号对右边有什么要求？”
- 学生仍无法动笔时，第二级给半成式，如“先写 x−1≥0”；本轮只给当前需要的一级。
- 学生明确请求答案后切换完整模式，不再强制问答。
- 平方前写定义域及两侧符号约束；平方后得到候选值，不直接称原题答案。
- 除以含未知数的表达式，先讨论其为零；乘除不等式检查正负与变号。
- 几何题每条平行、垂直、全等关系写出来自题设或已证命题；图形外观不作为证明。
- 参数题分类到会改变定义域、分母或解的个数的临界值，不把一般情形覆盖边界。
- 最终解集代回原题全部条件；只验证某几个数值点不能代替恒等式或不等式证明。

## 直接交付与下一步

- 卡点诊断和一条可执行提示
- 按需给完整步骤、答案及原题验证
- 一条可复用判断和一个针对性短变式

### 完成条件

- 提示模式交付一个卡点、一层提示及一条需交回的式子；完整模式交付路线、推导、原题检验与解集。
- 只有学生草稿支持时才诊断错误；没有草稿不能说学生粗心或概念差。
- 本轮先修第一处断点；该步未理解时暂停新题和第二种解法。
- 学生复交后先检查该变形的依据，再决定是否给下一提示；完整解答后可用一个单条件变式验收迁移。

### 工具降级

- 图片无法读清时请学生抄写争议符号、图中标记与所求；不根据常见题猜题。
- 无计算器或符号工具时先保留精确分数、根式并手工回代；复杂数值不能核验时标注仅符号推导已验。
- 题目条件不足时给出缺哪项及两个可能分支；不选一个分支冒充唯一解。

### 交付前检查

- 逐项对照输入、输出与待确认项，检查是否越过本技能的事实和模式边界。
- 用 [复审与运行案例](references/review-validation.md) 中的主案例和失败回归重跑，保留可使用的成品。
- 提示、附件或对外发布等未执行动作必须如实标注；文件行数不能代替案例验收。

## 外部参考与延展

- 学生方法限制与常见解法冲突时，先查其教材章节、课程标准或原题出处，检索“题型名 年级 定义域 等价变形”。
- 根式增根可对照 [OpenStax 原题回代机制](https://openstax.org/books/college-algebra/pages/2-6-other-types-of-equations)，重点看候选解与原方程解的区分。
- 与 physics-problem-coach 比较第一处错误定位和结果复核；只迁移诊断方式，不引入物理量纲要求。
- 在等价变形和先得到候选再检验两种方法中，选择学生能说明每步条件的一种；工具解集只用作交叉核验。
- 采用后重做原题及改变右边符号的变式，检查既不漏根又不泄露提示模式答案；外部答案冲突时回到题设重算。
