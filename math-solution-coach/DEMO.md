# 明确模拟的运行示例

输入（纯模拟）：解 sqrt(x+1)=x-1；学生平方得到 x=0 或 x=3，不知选哪个。请求完整纠错。

已知约束：根号要求 x≥-1；右边非负要求 x≥1。
卡点：平方后的方程允许右边原本为负的数进入，候选根需要回代。
推导：x+1=(x-1)^2=x²-2x+1；移项得 x²-3x=0，即 x(x-3)=0，候选为 0、3。
验证：x=0 时左边 1，右边 -1，不成立；x=3 时两边都是 2。
答案：x=3。
本轮判断：含根式方程平方后，代回原式排除增根。
短变式：sqrt(x+1)=1-x。先只判断右边非负带来的范围，再回传。
教练验收依据：应有 -1≤x≤1；继续求得候选 0、3 时，只保留 0。
