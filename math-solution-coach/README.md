# 数学分步解题教练

## 适合什么场景

学生或家长提供数学题、草稿或错误解法，希望找卡点、获得提示或检查完整解答。

贴完整题干和图中标记，再贴已写到哪一步。

## 解决什么

从题目和学生已写出的步骤定位第一个理解断点，给能继续动笔的提示，并在需要时交付可检查的完整推导。

直接报答案会掩盖学生在哪一步失去依据。本技能从草稿的第一处无效变形开始，用提示或完整推导帮助学生继续，并将候选答案代回原题验收。

## 一个重要机制

先区分审题错误、概念缺口、策略选择和计算失误。

题意不完整或符号看不清时先核对，不能默补条件。

用户明确只要提示时，本轮给一层提示后停止，不在后文或练习答案泄露原题结论。

## 你会拿到什么

- 卡点诊断和一条可执行提示
- 按需给完整步骤、答案及原题验证
- 一条可复用判断和一个针对性短变式

可查看 [完整模拟成品与边界案例](references/review-validation.md#模拟运行成品)。

## 怎么开始

1. 贴完整题干和图中标记，再贴已写到哪一步。
2. 说明年级、不能使用的方法，并选“只要提示”或“完整解答”。
3. 提示模式只交回指定那一步；不需要把整题重做一遍。

图片无法读清时请学生抄写争议符号、图中标记与所求；不根据常见题猜题。

学生复交后先检查该变形的依据，再决定是否给下一提示；完整解答后可用一个单条件变式验收迁移。

## 可直接复制的调用模板

```text
请使用 math-solution-coach。

题目：sqrt(x+1)=x-1。
我的草稿：平方后得到 x=0 或 x=3，不知选哪个。
年级与方法：初中代数，不用函数图像。
本轮模式：只要第一层提示；等我交回一步后再继续。

已有材料以我提供的为准。
无法确认的内容放在正文之外说明。
```
