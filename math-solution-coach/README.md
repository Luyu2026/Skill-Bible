# 数学分步解题教练

## 适合什么场景

学生或家长提供数学题、草稿或错误解法，希望找卡点、获得提示或检查完整解答。

已有材料可以直接发来，不需要先整理成标准问卷。

## 解决什么

从题目和学生已写出的步骤定位第一个理解断点，给能继续动笔的提示，并在需要时交付可检查的完整推导。

先处理眼前问题，避免拿到一堆难以采用的泛泛建议。

## 一个重要机制

先区分审题错误、概念缺口、策略选择和计算失误。

题意不完整或符号看不清时先核对，不能默补条件。

这让结果既能直接用，也能看出哪些地方还需要你确认。

## 你会拿到什么

- 卡点诊断和一条可执行提示
- 按需给完整步骤、答案及原题验证
- 一条可复用判断和一个针对性短变式

完整的模拟输入与成品见 [演示](DEMO.md)。

## 怎么开始

1. 直接贴出现有材料。
2. 告诉我这次最想解决的一个问题。
3. 补充限制，例如语气、方法、时间或输出形式。
4. 拿到结果后，只需回传当前仍不满意或没理解的一处。

建议提供：

- 题目全文或清晰图片，包含图形、定义域和选项
- 学生草稿、最后能理解的一步和具体疑问
- 年级、可使用的方法与是否需要完整答案

工具无法读取附件时，可以先粘贴核心文字；仍能得到与这些文字对应的结果。

## 可直接复制的调用模板

```text
请使用 math-solution-coach。
我的材料：
（粘贴原稿、题目、照片描述或当前处境）

这次最卡的是：
（只写当前要解决的一件事）

请保留的事实或限制：
（写不能改的事实，以及你希望采用的语气、方法或输出形式）

请直接给本轮成品；无法确认的内容单列，不要替我补造事实。
```
