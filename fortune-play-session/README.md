# 玄学主题娱乐解读

## 适合什么场景

用户想体验八字、星座、风水、面相或每日一卦等文化娱乐解读时。

你可以直接贴现有材料、截图文字或原稿，不需要先整理成标准报告。

## 解决什么

先选一个娱乐主题并核对其所需材料，把传统象征转成有出处的轻量解读和自我观察问题，避免杂糅多个体系断言命运。

会区分已经能判断的部分和还需要核验的部分。
不会为了让答案显得完整而补造事实。

## 一个重要机制

传统文化象征、娱乐叙事与现实可验证事实分开。

本轮只选一个主题；切换主题应重设依据，不能跨体系相互背书。

这会直接影响哪些结论能写进本轮成品。

## 你会拿到什么

- 单主题娱乐解读卡和符号依据表。
- 一个可不同意的自我观察问题。
- 材料缺失时的文化介绍版及明确缺口。

可以先看 [明确模拟示范](demo.md)，了解输入不足时如何交付。

## 怎么开始

1. 说清当前想完成的一件事。
2. 贴上已有材料，保留来源和时间信息。
3. 说明不能改动的条件与希望的输出长度。
4. 收到成品后，只补影响关键判断的缺口。

优先给这些材料：

- 用户本轮选择的一个主题与希望获得的体验，如星座短卡或居室象征阅读。
- 已有星盘、四柱、卦象或房间草图；不要求一次交齐所有主题材料。
- 涉及日期时提供历法、时间精度与时区；涉及空间时标明门窗和实际用途。

```text
我本轮的目标：
我已有的材料（直接粘贴或附文件）：
材料来源、时间和已确认事实：

```

需要续接时，把上一轮成品和实际反馈一起贴回即可。
