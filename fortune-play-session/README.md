# 玄学主题娱乐解读

## 适合什么场景

你想读一张星座文化卡、聊一个已知卦象，或把房间草图当作民俗主题轻松体验。

可以直接贴现有材料，不必先写一份标准报告。
本轮聚焦你眼前的一件事；缺失信息会写清影响。

## 解决什么

先选一个娱乐主题并核对其所需材料，把传统象征转成有出处的轻量解读和自我观察问题，避免杂糅多个体系断言命运。

先处理足以判断的部分，再列真正影响结论的缺口。
不会把没有来源的数字、盘面、评价或人生事件写成你的事实。

## 一个重要机制

一次只解释一个体系。已有卦象就读卦象，没有排盘工具就交文化介绍，现代创作联想会标明。

你能看见结论来自哪项材料，以及哪些条件变了就要重做。
不需要为了开始，把不相关的私人信息也一起提交。

## 你会拿到什么

- 单主题娱乐解读卡和符号依据表。
- 一个可不同意的自我观察问题。
- 材料缺失时的文化介绍版及明确缺口。

[查看完整模拟成品](references/review-validation.md)。
示范标明了模拟设定、实际产物和未验证范围。

## 怎么开始

1. 选择本轮主题：八字、星座、风水、面相文化或每日一卦。
2. 贴已有盘面、卦名或匿名草图，写明来源。
3. 说一个想聊的话题和不想涉及的内容；不必提供真实姓名。

不确定的字段写“不详”即可，不必猜填。
结果标为待核验时，按对应缺口补来源或参数，再续接同一轮。

## 可直接复制的调用模板

```text
请使用 fortune-play-session。
本轮主题：
已有盘面／卦名／匿名草图及来源：
想聊的话题：
不想涉及的内容：
想要的语气和长度：
请交一张文化娱乐卡，区分原材料与创作，不补造个人盘面。
```

续接时贴上上一版成品与新材料，说明哪一项需要改。
只处理受新信息影响的部分，保留仍然成立的依据。
