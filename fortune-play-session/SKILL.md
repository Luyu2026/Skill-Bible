# 玄学主题娱乐解读

## 一句话主餐

先选一个娱乐主题并核对其所需材料，把传统象征转成有出处的轻量解读和自我观察问题，避免杂糅多个体系断言命运。

普通聊天常把八字、星座和卦象混成一套个人预言。本技能一次围绕一个明确文化主题，交付读得懂的象征短卡和可自选的观察问题。

## 输入

- 用户本轮选择的一个主题与希望获得的体验，如星座短卡或居室象征阅读
- 已有星盘、四柱、卦象或房间草图；不要求一次交齐所有主题材料
- 涉及日期时提供历法、时间精度与时区；涉及空间时标明门窗和实际用途
- 仅需代号；不要求身份证、地址或第三方私密照片
- 无可靠排盘工具时可用用户既有盘作条件阅读，不能编造盘面

### 材料处理

- 优先读取已给原稿、附件和记录，不要求重复填写。
- 只追问会改变当前路径的缺口，其他缺失放在相关判断旁。
- 来源无法打开时使用用户摘录，并写明尚未独立核验。
- 用户事实、工具结果、合理推断与纯模拟分别标记。
- 不把演示数据移植成真实用户材料。

## 核心判断

1. 传统文化象征、娱乐叙事与现实可验证事实分开。
2. 本轮只选一个主题；切换主题应重设依据，不能跨体系相互背书。
3. 星座不能证明人格；不能从面部照片推断能力、诚信、健康或命运。
4. 面相主题降级为历史术语介绍或用户自选角色创作，不做人脸命运鉴定。
5. 风水娱乐与居住安全分开，真实通风、动线与消防问题以实际规范为准。
6. 抽签只作叙事提示，用户给卦与随机生成必须标清来源。

### 本轮执行门槛

- 已给四柱、星盘或卦象：注明来自用户，按其明确体系阅读，不宣称已独立排盘。
- 只有生辰且无工具：不猜四柱，转为该体系文化介绍；要排盘时先取得可靠输出。
- 只想每日一卦：优先请用户给卦；没有随机工具则提供明确标为故事选题的主题，不能冒称随机起卦。
- 空间主题：草图方位不明时只描述已知摆设；面相主题只做文化术语或虚构人物创作。

## 编号工作流

### 1. 选定体验入口

- 读取用户已经说明的娱乐主题。
- 多主题请求先选其最想体验的一项作为主餐。
- 记录期望长度、语气和问题。
- 涉及现实重大决定时把象征阅读与事实分析拆开。
- 交付本轮主题卡。

### 2. 核对必要材料

- 星座材料先区分太阳星座和完整星盘。
- 八字阅读需要给定四柱及来源；只有生辰不能凭空推盘。
- 空间阅读只用匿名草图和已标方位。
- 卦象记录用户给出、工具生成或纯故事设定。
- 缺少材料则明确给文化介绍版，不冒称个人专属盘。

### 3. 确定一种解释口径

- 说明所用传统、术语版本或来源类型。
- 只挑与本次问题相关的两三个符号。
- 解释冲突时展示不同口径，不合成精确得分。
- 不把今天日期当成自动推演日运的算法。
- 交付符号、依据和解释边界表。

### 4. 写娱乐成品

- 开头注明传统文化娱乐解读。
- 每条先描述可见符号，再写条件化象征。
- 避免疾病、灾祸、财富或伴侣行为的确定预言。
- 提供一段完整可读短文而非堆满术语。
- 面部主题只给术语文化或虚构角色说明。

### 5. 转成自我观察

- 围绕用户当前话题给一个开放问题。
- 问题允许用户不同意解读。
- 现实建议只来自用户实际处境，例如整理桌面或安排对话。
- 不要求购买法器、付费化解或按吉日推迟必要就医。
- 交付一个可选的日常观察动作。

### 6. 收束与续接

- 明确哪些是材料、哪些是象征、哪些是创作。
- 本轮结束不默认要求更完整的私人信息。
- 用户想续玩时保留主题和口径。
- 新材料出现先修正对应符号，再重写受影响段落。
- 交付可复制主题卡与下轮入口。

## 直接交付与下一步

- 单主题娱乐解读卡和符号依据表。
- 一个可不同意的自我观察问题。
- 材料缺失时的文化介绍版及明确缺口。

### 按主题收取材料

| 主题 | 够用材料 | 缺材料时的可用成品 |
| --- | --- | --- |
| 八字 | 已有四柱、来源和解释口径 | 四柱结构介绍，不猜个人盘 |
| 星座 | 用户指定太阳星座；完整盘另需来源 | 单一星座象征卡，不猜上升星座 |
| 每日一卦 | 卦名或六爻、动爻与取得方式 | 用户自选主题的故事卡 |
| 风水 | 匿名平面草图、方位和空间用途 | 动线观察卡，不造罗盘读数 |
| 面相 | 用户指定文化术语或虚构角色 | 术语文化介绍，不评真人面部 |

有动爻才讨论变卦；只给卦名不自行补动爻。
用户未选主题时列两个简短入口供选，不要求提交所有出生和居住资料。
文化原义需要来源；现代联想明确标为本轮创作，不把自己写的解释署给古籍。

### 娱乐卡的交付格式

先写“传统文化娱乐阅读”，再写主题、材料来源、解释口径。
用一张表列可见符号、传统或创作依据、这一解释不能推出的结论。
正文围绕用户话题写成完整短文；不用一串术语代替阅读体验。
观察问题允许回答“不符合我”；不将否认解释为用户缺乏悟性。
现实动作如整理清单只能由用户实际目标推出，不能说做完即可转运。
不默认追问隐私，也不以“还有灾祸待解”诱导续聊。

### 本轮完成与续玩

完成条件是交付一张完整主题卡、一条观察问题和一个可选动作。
用户只要娱乐短文时交付即结束，不追加强制练习。
用户续玩时带回主题、口径和愿意继续的话题，不强收出生信息。
若用户纠正卦名或盘面，先撤回对应象征解释，再更新正文。
工具不可用仍可交文化介绍卡，但标题必须标“非个人排盘”。
空间安全、疾病或财产决策超出本轮娱乐材料的证明范围，不借象征给出结论。

## 外部参考与延展

- **何时研究**：主题混杂、符号来源不明或用户指出不同流派解释冲突时启动。
- **去哪找**：查博物馆、大学民俗研究、可标版本的传统典籍；历法问题查天文台，检索“民俗 占卜 文化史”。
- **看什么**：比较符号出处、解释范围与时代差异；不把流传广度当作预测有效性。
- **怎么用**：只将资料用于校准文化解释；用同一主题重写短卡，检查是否消除了混用或确定预言。
- 把已给卦象的条件阅读与从生辰生成盘面作对照：本技能采用前者；需要日期换算时查 [香港天文台](https://www.hko.gov.hk/tc/gts/time/conversion.htm)，日期来源不能证明象征预测有效。
- 来源热度只用于发现，不代表方法有效；原始规则优先于二手总结。
- 材料已经足够时直接交付，不机械追加联网研究。
- 外部方法只改变执行机制，不能创造用户经历、报价或个体事实。
- 若实际复用受许可约束内容，保留所需声明；独立改写不等于可以忽略许可。

### 交付前验收

1. 每个确定结论都能回到材料、计算或明确设定。
2. 关键数字、日期、资格和限制没有在改写中发生变化。
3. 交付与用户当前目标一致，没有串入无关阶段。
4. 复制正文即可使用，依赖工具的暂停部分有可操作恢复条件。
5. 不把模拟验证称为真实用户效果，不承诺未经测量的收益。

### 明确模拟的执行示范

用户自选乾卦且未给动爻，目标写毕业告别。成品给完整文化娱乐卡和写作动作，不补变卦；随机工具不可用时明确改为自选主题。
