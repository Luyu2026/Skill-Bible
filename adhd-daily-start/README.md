# ADHD 友好日计划

## 适合什么场景

任务很多却迟迟没开始、材料散乱，或中断后不知如何回来。

可以直接交已有材料，不需要先整理成标准表。

## 解决什么

依据今天的硬截止、可用时间与精力，拆出现在能动手的三步。

每轮聚焦当前成果，缺口写在受影响的结果旁。

## 一个重要机制

三步围绕同一个最低成果。先保护外部承诺，每步都写结束信号。

没开始时缩小第一动作；中断后读恢复句，不推倒已完成部分。

## 你会拿到什么

- 今天主目标与三步计划。
- 每步材料、时间盒及完成信号。
- 暂缓事项和必须协商的截止冲突。
- 包含保存位置与下一动作的恢复卡。

查看 [完整模拟成品](references/example.md)，了解实际返回内容。

## 怎么开始

1. 直接贴凌乱待办，标明真实截止。
2. 说明可用时段与当前精力；不需要提供诊断。
3. 告诉我最卡的是找材料、选任务还是下笔。
4. 先做第一步，再回一句完成、卡住或没开始。

只需反馈具体卡点，就能继续当前成果。

## 可直接复制的调用模板

```text
使用 adhd-daily-start。
截止：明早交五页汇报；今晚19:00—20:00有空。
状态：精力低，材料散在三个文件。
卡点：一直没打开演示文稿。
请给同一目标的三步、缓冲、停车区与恢复卡。
```
