# ADHD 友好日计划

## 适合什么场景

任务太大不知从哪开始、容易分心、想把今天的任务拆成可启动的三步。

你可以直接交来已有材料，不用先整理成标准表。
只需要处理眼前卡点时，不必同时规划所有后续阶段。

## 解决什么

普通聊天容易排满一天；本技能依据今天的精力、硬约束和卡点，交付能立即启动且允许中断恢复的三步计划。

优先处理：从原始材料列出任务和截止。
本轮范围：今天三步计划、停车区和一张中断恢复卡。

## 一个重要机制

硬截止与自我期待分开；先保护真实承诺，再安排可选推进。

启动动作必须包含动词、对象和结束标志；“研究项目”不能直接排入。
执行中会把依据、假设与缺口分清，再决定如何交付。

## 你会拿到什么

- 今天三步计划、停车区和一张中断恢复卡。
- 用户现在只执行第一步，不同时启动三个任务。
- 完成标准是得到约定的最低成果，允许后两步按真实反馈调整。

可以查看 [模拟成品](demo.md)，了解实际返回的样子。

## 怎么开始

1. 发来你手上的材料，或直接描述现在卡在哪里。
2. 说明这次最想完成的结果。
3. 有截止时间、口吻、篇幅或不可改内容时一并告诉我。
4. 收到初稿后，反馈一处具体问题即可继续。

建议提供：
- 读取现有待办、日历、未完草稿或用户随口描述，不要求先整理。
- 确认今天必须发生的事情、真实截止时间和可用时段。
- 请用户用低、中、高描述当前精力，可不提供诊断信息。

## 可直接复制的调用模板

```text
使用 adhd-daily-start。
我现在的场景：
已有材料：
这轮最想拿到：
必须遵守的限制：
请先读已有材料，只问会改变做法的缺口，直接给可用成品。
```

简短调用也可以：

> 明天上午要交五页项目汇报，今天 19:00—20:00 有空。资料散在三个文件，精力低，一直没开始。
