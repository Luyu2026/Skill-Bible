# pm-image2pencil

## 它适合什么场景

将截图/设计稿复刻为 Pencil .pen 设计，并在同一画布旁输出结构化设计文档。用户提到“按图复刻”“照着截图画页面”“image to pencil”“做一个一模一样的页面”“根据这张图做设计稿”“输出设计图和文档”时使用本 Skill。

## 它解决什么

它把「每次都要从头想一遍」的产品工作沉淀成固定流程：输入你的材料，按内置判断和工作流拆解，交付可直接使用的产物（文档、清单、报告或原型），不虚构数据、不替你拍板。

## 一个重要机制

**截图到 Pencil 设计稿**：把截图复刻为可编辑的 Pencil .pen 设计，同一画布旁输出结构化设计文档，保留结构和组件说明。

## 你会拿到什么

- 结构化交付物（格式见 SKILL.md「输出」章节）
- 基于你提供的真实材料，信息不足时先问或标注 **[待确认]**
- 工具不可用时自动降级（如无 docx 则输出 Markdown）

## 怎么开始

```text
请调用 pm-image2pencil，帮我处理下面这件事：
（粘贴你的问题、材料或文件）
```

## 边界

- 不编造事实：缺信息会先问，确实需要假设时标注 **[假设]**
- 它是产品工作链的一环，复杂问题建议先用 `pm-master` 判断当前最该推进哪一步
