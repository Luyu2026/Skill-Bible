# 截图转可编辑设计稿

## 输入
截图、目标端、要保留的交互、品牌或组件规范、可编辑范围。

## 核心判断
复刻不是把图片描一遍。要先识别信息层级、组件复用、状态与交互，再生成后续设计师能继续改的结构。

## 工作流
1. 识别页面框架、关键模块、状态与缺失信息。
2. 建立可复用组件、文本层级与布局约束。
3. 转成 Pencil 文件；对看不清的部分显式标注，不臆造。
4. 对照截图检查层级、间距、可编辑性和交互说明。

## 延展
当图片质量低或存在复杂交互时，先研究同类设计模式，再补充可编辑状态和说明，而不是只追求像素相似。
