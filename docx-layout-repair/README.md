# Word 文档结构与排版修复

## 适合什么场景

基于已有 DOCX 或文本稿修复标题层级、段落、列表和分页，交付可继续编辑的 Word 文档。用户要统一文档格式、修复目录、整理凌乱报告时使用。

你手里已有材料，希望直接得到可使用的结果。
只有方向而没有材料时，也可先明确缺什么和本轮能做的范围。

## 解决什么

普通聊天给排版建议却留下手工劳动；这里直接将现有报告修成有层级、可编辑、可核验的 DOCX。

保留来源与待确认项，避免为了看起来完整补造事实。
围绕当前卡点交付，不把多个无关任务捆在一起。

## 一个重要机制

先修文档语义结构，再应用样式；正文核对和版面检查分别验收。

结果可以回到原材料核验，而不只是看起来更漂亮。

## 你会拿到什么

- formatted.docx：可编辑的排版成品
- 标题树、样式映射和变更说明
- 内容核对结果与目录字段更新状态

另有一份[模拟演示](demo.md)，可先看实际交付长什么样。
真实任务的核验范围会随文件与工具环境说明。

## 怎么开始

1. 提供原始材料或可读取的文件路径。
2. 用一句话说明本轮最想完成什么。
3. 告诉我必须保留的内容、口径和输出格式。
4. 已经有模板或旧成品时一并提供，优先沿用。

材料不足时会先交能可靠完成的部分，并列出具体缺口。
有问题时回传问题所在页、行、段落或数据记录即可继续。

## 可直接复制的调用模板

```text
请使用 docx-layout-repair 处理我提供的材料。
材料：[附件、路径或正文]
本轮目标：[希望直接拿到的成品]
使用场景：[接收者、渠道或设备]
必须保留：[事实、格式、规则或原话]
已知问题：[目前最卡的一处]
输出要求：[格式和保存位置]
请直接制作成品，说明核验结果和仍需我确认的事项。
```
