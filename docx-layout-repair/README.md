# Word 文档结构与排版修复

## 适合什么场景

适合已有报告的标题不能导航、复制后列表编号混乱、长表分页失控，或目录无法更新。

含签章和修订的原件先保留；复杂对象是否完整保留会单独说明，目录页码需在排版软件中更新。

## 解决什么

普通聊天给排版建议却留下手工劳动；这里直接将现有报告修成有层级、可编辑、可核验的 DOCX。

先读取现有材料，直接处理你指定的这一轮任务。
需要确认的口径会和可用成品分开列出。

## 一个重要机制

标题会成为 Word 真正的标题样式；“看着像标题”和能在导航窗格跳转分开核验。

你能核对修改依据，并针对具体问题复交。

## 你会拿到什么

- formatted.docx：可编辑的排版成品
- 标题树、样式映射和变更说明
- 内容核对结果与目录字段更新状态

另有一份[模拟演示](demo.md)，可先看实际交付长什么样。
真实任务的核验范围会随文件与工具环境说明。

边界示例见[复审案例](references/review-cases.md)。

## 怎么开始

1. 提供原 DOCX；已有公司模板时一起上传。
2. 指出最困扰的页或段：标题、列表、宽表还是目录。
3. 说明只修格式，还是允许改正文。
4. 列出必须保留的修订、批注、签章和目标 Word/WPS 版本。

含签章和修订的原件先保留；复杂对象是否完整保留会单独说明，目录页码需在排版软件中更新。
收到成品后，如仍有问题，回传具体位置和希望调整的结果即可。

## 可直接复制的调用模板

```text
请使用 docx-layout-repair。
原始文档：[附件/路径]；模板：[附件/无]
用途与接收软件：[周报、Word/WPS 版本]
修复重点：[标题层级、长表分页、目录等]
允许改写正文：[否/允许范围]
必须保留：[修订、批注、签章、脚注等]
请另存 DOCX，核对正文数字并分别说明结构和分页验证状态。
```
