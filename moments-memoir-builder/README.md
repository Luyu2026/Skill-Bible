# 朋友圈个人回忆录生成

## 适合什么场景

你有过去一年的朋友圈文字、截图或照片，想留下一章能读的回忆。

你希望保留自己的说话方式，又不想按时间简单堆截图。

适合私人留存或准备分享的章节；不会自动登录抓取你的朋友圈。

## 解决什么

将已有片段串成有时间线、保留原话的回忆章节。

把配图位置、事件日期和来源对应好，方便以后继续写。

没有记录的时期留白，不为了好看补造经历、对话和心情。

## 一个重要机制

当年动态、现在补充的回忆和编辑连接语分别追溯。

发布日期不一定是事件日期，照片文件时间也不自动等于拍摄时间。

私人版转分享版时重新检查姓名、地址、儿童信息和图片背景。

## 你会拿到什么

- 可以直接阅读的一章回忆稿。

- 事件时间线及每段对应的素材索引。

- 图片编号、建议插入位置及必要遮盖项。

- 待确认的日期、记忆冲突和分享边界。

## 怎么开始

1. 先提供一段时间或一个主题的朋友圈文字、截图和照片。

2. 说明私人留存还是准备分享，哪些人或地点需要隐去。

3. 有喜欢的原话就指出来；没有人称偏好会沿用原文声音。

4. 返回不像自己的句子或记错的事件，先修这一章再继续下一章。
