# 朋友圈个人回忆录生成

## 适合什么场景

你需要把已有朋友圈文字、截图和照片整理成有时间线的个人回忆录。
已有零散材料也可以开始，不必先整理成标准格式。
如果只想处理一小段，请明确本轮范围。

## 解决什么

从用户交来的朋友圈碎片整理出保留本人声音、时间可追溯的回忆章节，不为故事好看补造人生情节。

以已有材料为起点，区分确认事实和仍需核对的内容。
先完成一版可以使用的结果，再按反馈修改。

## 一个重要机制

公开动态不等于完整人生，空白时期留白而不补编。

当时原文、现在回忆与编辑连接语分别标记来源。
遇到无法确认的地方会留下具体位置，不会悄悄补写。

## 你会拿到什么

- 可阅读回忆录章节及配图位置建议
- 事件时间线和段落来源索引
- 日期、身份与分享隐私的确认清单

交付会说明处理范围，以及哪些材料还没有覆盖。
工具无法生成目标文件时，会提供可复制的文字版本并说明差异。

## 怎么开始

1. 直接提供现有材料，附上你最想解决的问题。
2. 说明本次处理范围、使用对象和希望的输出形式。
3. 如果已有旧稿或参考风格，一并提供。
4. 收到结果后，指出需要修改的具体位置和原因。

不确定格式时，可以先要求一个小范围成品。
请只提供你有权使用的材料；分享范围也可以一起说明。

## 可直接复制的调用模板

```text
请使用 moments-memoir-builder。
我的任务：把已有朋友圈文字、截图和照片整理成有时间线的个人回忆录。
现有材料：粘贴文字或附上文件。
本轮范围：填写页面、时间段、主题或章节。
使用对象与目标：填写给谁看、希望完成什么。
输出形式：可复制文稿；如工具支持，再生成可编辑文件。
必须保留：填写事实、表达或格式要求。
请标明无法确认的内容，先交付本轮成品和必要下一步。
```

### 看一个小例子

模拟输入：2023-05-01 动态“今天终于搬进自己的小屋”；2023-05-03 动态“窗边放了一盆薄荷”；没有照片与其他经历。私人留存。

可以先按这个范围试用，再决定是否处理其余材料。
