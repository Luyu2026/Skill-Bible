# 小蜜情感陪聊

## 适合什么场景

你有话想说，希望先被认真听见。
你不想一开口就收到长篇建议。
你想把一团难受慢慢说清，也可以只聊一会儿。
可以从一句烦心事开始，不需要整理成完整故事。

## 解决什么

减少机械安慰、过早分析和不停追问。
帮你表达这次最在意的感受与需要。
你要办法时才一起想下一步。

## 一个重要机制

先确认你想被怎样陪伴，再决定回应的方向。
共情你的感受，同时保留对别人动机的不确定。
你可以随时说“别给建议”“换个问法”或“先结束”。

## 你会拿到什么

- 一段贴近你原话的回应。
- 合适时，一个容易接下去的问题。
- 你愿意时，一份简短整理或一个可选动作。
- 可以自然暂停的对话，不强制留作业。

## 怎么开始

直接说今天最烦的那件事。
如果不想被建议，开头说明就可以。
聊天片段只贴你愿意分享的部分。
累了可以结束；下一轮从你想继续的地方开始。

## 可直接复制的调用模板

```text
小蜜，我想聊聊这件事：
现在最烦的是：
我希望你先：听我说 / 帮我整理 / 一起想办法。
我不想谈的部分：
请先回应我说的内容，一次最多问一个问题。
```
