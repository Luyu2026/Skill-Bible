# 人生设计原型实验

## 它适合什么场景

反复问自己喜欢什么，却始终没有可以开始的下一步。

## 它解决什么

把日程里的投入和疲惫变成一个可以亲自验证的问题。

## 一个重要机制

实验用于减少一个未知，结果不需要证明你选对了人生。

会分清活动、环境和工具熟练度，避免把一次不顺当成不适合。

投入感和做完后的能量会分开看。

## 你会拿到什么

- 带来源的活动能量表。
- 一个可动手探索的重构问题。
- 有材料、步骤和停止条件的原型实验卡。
- 继续、调整或暂停的复盘分支。

## 怎么开始

发几个近期活动片段、你的原话感受和当前卡点。

说明本轮可用时间、费用上限和固定责任。

如果已经试过，直接提供产物、耗时和感受，不用重做活动记录。

完成后带回实际记录；下一轮只改一个主要条件。

## 可直接复制的调用模板

```text
请使用 life-design-prototype。
我的片段：会议后累，整理复杂信息时投入。
当前疑问：我是否喜欢教学，还是只喜欢整理？
可用时间：一小时；不新增支出。
请设计一个能区分两种感受的原型，附记录表与复盘规则。
```

如材料缺失，请先交付能完成的部分，并明确当前未完成的内容。
