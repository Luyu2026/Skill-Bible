# 人生设计原型实验

## 它适合什么场景

不知道自己喜欢什么、反复规划不行动、想用生活体验找下一步。

可以从一段已有材料开始，不必先写完整报告。

## 它解决什么

围绕当前卡点，完成活动能量表、重构后的问题、原型实验卡、复盘规则。

先完成当前最能推进的一件事，再依据反馈决定是否继续。

## 一个重要机制

具体活动不同于自我评价。

结论回到具体输入，缺失信息保留为未知，不用看起来完整的内容填空。

## 你会拿到什么

- 活动能量表。
- 重构后的问题。
- 原型实验卡。
- 复盘规则。

交付会说明已完成内容及仍需补齐的部分。

## 怎么开始

直接发已有材料，并说明这次最想解决的一件事。

建议提供：近期日程或活动记录；投入和疲惫片段；当前卡点；可用时间；固定责任；尝试反馈。

不方便分享的部分可以删去；影响判断的缺口会单独指出。

工具不足时先拿到可复制文本或制作包，未生成的文件会明确标注。

### 模拟输入

会议后很累，整理复杂信息时投入，每周只有一小时探索。

### 对应的模拟成品

问题改为怎样增加整理信息并帮助理解的活动。用一小时把已有非敏感资料做成一页说明，分别记录整理和讲解的能量变化；先分清喜欢哪个环节，不直接建议转行。

使用后可交回实际结果或新材料，围绕同一个卡点继续修订。
