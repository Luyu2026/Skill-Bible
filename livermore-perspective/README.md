# 利弗莫尔视角

趋势交易与交易纪律思维 Skill。

它适合用在这样的场景：你盯着行情想买、想卖，或者一笔交易已经开始亏损，却分不清自己是在按规则交易，还是在追涨、摊平和听消息。把你的市场判断、持仓计划或交易复盘交给它，它会先判断趋势是否已经确认，再把进场条件、仓位和止损条件说清楚。

## 你会得到什么

- 对大势、个股时机或交易心态的分类判断
- 利弗莫尔的 5 个核心模型：最小阻力路线、大势为王、历史重演、只有正确的一面、试探-确认-加码
- 8 条可执行的交易纪律，以及不确定时应当等待的原因
- 每次分析中明确的失效条件与风险边界

## 怎么用

把这个页面链接发给正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/livermore-perspective

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：它装在了哪里，以及我下一句话该怎么调用它。
```

装好后可以直接说：

```text
请用利弗莫尔视角复盘这笔交易：
标的：
我的入场理由：
买入价格和仓位：
当前市场环境：
原计划止损：
现在最犹豫的事：
```

## 边界

它用于研究、复盘和风险检查，不预测涨跌，也不构成投资建议。尤其不要把它的输出当作买卖指令；任何交易都应先明确可承受损失和止损条件。
