# 陆羽Skill · 元 Skill 工厂（luyu-skill）

## 它适合什么场景

你有一个职业/职能/行业，想给这个职业的人配一套能解决日常工作的 Agent Skill 库——但不知道从哪开始、该收哪些能力、怎么保证体系化。

陆羽Skill 输入一个职业，自动完成：**行业基本概念调研 → 遴选专家与经典书籍 → 并行蒸馏 → 生成一套体系化的职业 Skill 链**，交付即可安装使用。

## 它解决什么

普通方式造 Skill 库，容易变成「挑几个觉得有用的功能拼一拼」——覆盖不全、判断不深、没有总控。

陆羽Skill 替你把三件事做深：
1. **先调研再 Skill 化**：不凭训练语料猜，先调研该职业的核心工作流、高频决策场景、能力地图，再决定收哪些能力
2. **体系化生成**：一套职业 Skill 链 = 总控（career-master）+ 执行链（高频工作场景）+ 顾问团（3 专家视角 + 3 书方法论），覆盖完整工作链
3. **蒸馏的是 HOW 不是 WHAT**：提取专家怎么想、怎么判断（心智模型/决策启发式/表达DNA），提炼书的可执行框架（步骤/规则/清单），不是复读语录和读书笔记

## 一个重要机制

**总控分诊 + 链路编排**：生成的 career-master 会判断你是「判断类」（该不该做、怎么选）还是「产出类」（写文档、出方案），分别路由到顾问团或执行链；任务横跨多步时编排链路，保证上一步产出是下一步的合法输入。

**每个执行 Skill 自带参考模板**（模仿 pm-prd-writer 最佳实践）：SKILL.md 只写判断与工作流，完整输出模板（含写作指引）放 `references/output-template.md`——模板不复制进最终文档，可独立复用/迭代。

## 你会拿到什么

一套完整的职业 Skill 套件目录：

```
[职业]-skill-suite/
├── career-master/          # 总控：分诊 → 路由 → 编排
├── career-xxx/             # 执行链：3-6 个高频工作场景 Skill（各带 references/ 输出模板）
├── career-advisor-*/       # 3 位专家视角（心智模型+决策启发式+表达DNA）
├── career-method-*/        # 3 本书方法论（框架+规则+清单）
├── career-advisory-board/  # 顾问团子总控（路由+评审会+分歧地图）
└── README.md               # 套件使用说明
```

每个 Skill 都是完整目录（SKILL.md + README + SOURCES，执行型另加 references/ 模板），可直接安装到任何 skills-compatible 的 Agent。

## 怎么开始

把下面这段话发给你的 Agent：

```text
请调用陆羽Skill，为「[职业/行业]」生成一套体系化的职业 Skill 链。
（可选补充：侧重方向 / 中文语境 / 一段 JD）
```

或指定模式：

```text
请调用陆羽Skill，为「数据分析师」造一套 Skill 库，侧重做决策和产出质量。
```

```text
请调用陆羽Skill，快速模式，先给我看看「跨境电商运营」的候选专家和书籍清单。
```

## 边界

- 它生成 Skill 链，不直接替你做具体业务（那是生成出来的 skill 链的事）
- 蒸馏的是公开信息，输出是"某专家/某书的视角快照"，不是真人代言
- 调研信息截止到生成时间点；信息不足处会写进诚实边界，绝不编造
- 生成的套件不满意？哪个专家/哪本书/哪个执行场景不符合预期，可单独重做那一个
