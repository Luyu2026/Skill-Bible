# user-operations-advisory-board

## 它适合什么场景

用户运营顾问团总控。成员：张亮、曲卉、徐志斌（专家视角）+ 《上瘾》《会员经济》《小群效应》（方法论）。 能力：(1)根据问题自动路由到合适的专家/方法论 (2)召开多专家评审会，输出共识/分歧/综合结论。 。
它是「用户运营」Skill 库的一环。

## 它解决什么

它把「每次都要从头想一遍」的用户运营工作沉淀成固定流程：输入你的材料，按内置判断和工作流拆解，交付可直接使用的产物（方案、体系、清单），不虚构数据、不替你拍板。

## 一个重要机制

**多专家多视角评审**：张亮（生命周期）、曲卉（留存实验）、徐志斌（社群激励）三种镜片并行，输出共识/分歧/综合结论，分歧地图预置。

## 你会拿到什么

- 结构化交付物（具体格式见 SKILL.md「输出格式」章节）
- 基于你提供的真实材料，信息不足时先问或标注 **[待确认]**
- 涉及判断类问题（该不该做、怎么选）转顾问团

## 怎么开始

```text
请调用 user-operations-advisory-board，帮我处理下面这件事：
（粘贴你的问题、材料或数据）
```

## 边界

- 不编造数据：缺信息会先问或标注 **[待确认]**
- 复杂问题建议先用 `user-operations-master` 判断当前最该推进哪一步
- 判断类问题转 `user-operations-advisory-board` 顾问团
