# 《上瘾》· 用户习惯养成框架

> 核心立场：让用户"一想到某种情绪/场景就打开产品"（内部触发），用习惯代替营销。**习惯 ≠ 成瘾——必须服务于真实用户价值。**

## 核心框架一：Hook 模型（触发→行动→多变奖励→投入）

**适用场景**：判断/设计"用户为什么回来"的完整留存闭环；诊断留存断点。

| 环节 | 要点 | 关键判断 |
|------|------|---------|
| 触发 | 外部（推送/邮件/他人邀请）→ 内部（情绪/场景关联） | 目标：从外部触发迁移到内部触发——用户"一无聊/一心烦就想到我" |
| 行动 | 触发后做的最简单行为（B=MAP：动机×能力×提示） | **降低摩擦比提高动机更有效**；动作要最小阻力 |
| 多变奖励 | 不可预测的回报，激活"想要"系统 | 三类：猎奇（刷动态/捡漏）、自我（打卡/升级）、族群（点赞/被@） |
| 投入 | 用户付出时间/数据/内容/关系/钱 | 投入≠付费终点，而是提高下次经过 Hook 概率的储蓄 |

**输出物**：一页 Hook 拆解表（每环节写清触发源/动作/奖励类型/投入物 + 埋点指标）。

## 核心框架二：习惯区（Habit Zone）

**适用场景**：判断产品值不值得做习惯化运营。

两个条件同时满足才进"习惯区"：
1. **使用频率**（日/周/月频，越频越好养）
2. **感知效用**（用户主观觉得多有用，非客观价值）

> 例：拍照/搜索高频高感知 → 习惯强；低频高感知文件夹 → 习惯弱。

**输出物**：按"频率×感知效用"给产品打点，决定运营重心是"做习惯"还是"做触发提醒"。

## 核心框架三：操纵矩阵

**适用场景**：留存机制上线前自查伦理。

- 两轴：物质性/非物质性结果 × 用户变好/变坏
- 四象限：促进者（帮用户变好）/ 兜售者（帮用户但收费）/ 娱乐者（愉悦不改善）/ 操纵者（伤害用户）
- 红线：**"维生素"会变成"止痛药"**——用户产生"不用就难受"（FOG）时，是成瘾信号不是成功信号

## 决策规则（8 条）

1. **如果**触发全部依赖外部提醒（推送/短信），**则**说明内部触发未建立——先做"情绪×场景"绑定，再做频率运营。
2. **如果**目标动作转化率低，**则**先砍摩擦（步骤/表单/加载/决策成本），不要先加动机/加奖励。
3. **如果**奖励是固定可预期的（固定签到积分），**则**换成可变奖励（随机掉落/开盲盒），否则循环退化为无好奇心的"灯光开关"。
4. **如果**用户已高频使用但留存仍掉，**则**检查"投入"环节——用户是否积累数据/关系/内容资产；投入缺失则产品不涨价值，竞品一出现就流失。
5. **如果**产品使用频率低（周/月频以下）且感知效用一般，**则**不要投入做习惯化，改为高价值低频触发或接受非习惯型定位。
6. **如果**机制属操纵矩阵"操纵者"象限（伤害用户），**则**不上线或重构为促进者——留存不得建立在对用户利益的损害上。
7. **如果**要设计"投入"引导，**则**放在奖励之后（多巴胺预期高峰）立刻请求，此时用户最愿意付出。
8. **如果**产品已形成"不用就难受"的依赖，**则**视为成瘾信号而非成功信号，主动降频设计（提醒节流/默认关闭/退出路径清晰）。

## 检查清单（留存机制上线前）

- [ ] 触发：写清外部触发（谁/何时/什么文案）？有迁移到内部触发的计划？
- [ ] 触发：绑定用户已有习惯/情绪（而非创造新场景）？
- [ ] 行动：目标动作是能力范围内最小动作？删掉至少 3 处摩擦？
- [ ] 奖励：是可变/不可预测的吗？属于三类（猎奇/自我/族群）中哪类？
- [ ] 投入：有让用户存储价值（内容/关系/偏好/资产）的环节吗？
- [ ] 循环：上一轮"投入"成为下一轮"触发"了吗？（闭环没闭合=靠推送续命）
- [ ] 频率×效用：产品在"习惯区"吗？
- [ ] 伦理：该机制在操纵矩阵哪一象限？有无退出/降频机制？

## 反模式

- 把"成瘾"当成功（用可变奖励+投入把维生素做成止痛药，制造痛苦再兜售解药）
- 奖励固定化（循环退化为无聊反馈回路，动机熄火）
- 只靠外部触发续命（成本随盘子膨胀，推送受限就崩塌）
- 忽略投入的复利（产品对用户永远是"一次性价值"，无迁移成本）
- 为留存牺牲用户利益（虚假稀缺/隐性扣费，短期拉指标长期毁品牌）

## 边界声明

- 必须服务于真实用户价值：无价值产品套 Hook 只会加速口碑崩坏
- 不适用于所有产品：低频/低感知效用/一次性消费型不宜强行习惯化
- 伦理争议未解决：模型被批评"制造成瘾机制而不解决伦理"，道德化使用靠团队自律
- 偏消费互联网：对 B2B、低频高客单、监管行业需大幅改造并叠加合规
