# 用户分层方案模板

本文件是 user-operations-segmentation 的参考模板。生成用户分层方案时按此结构输出，每个章节的说明文字是写作指引（不要原样复制到最终文档里），根据实际需求填充内容。

---

## 文档头部

```markdown
# 用户分层方案

日期：（当天）
数据范围：（如有数据，注明口径）
```

## 一、分层目标与维度
**作用**：先写清楚分层为了什么（提升转化/留存/触达/增长），决定用哪个维度。

```markdown
- 分层目标：（提升转化？提升留存？精细化触达？）
- 分层维度：（RFM / 生命周期 / 价值 / 行为 / 渠道）
- 数据来源：（用户数据/交易数据/行为数据，口径）
```

## 二、分层体系

| 层级 | 定义（可量化） | 占比（如有数据） | 用户特征 | 价值判断 |
|------|---------------|-----------------|---------|---------|
| 重要价值 | 近30天消费≥2次且金额≥X | 5% | 重度用户 | 核心资产 |

> 数据不足时给分层标准框架 + 标注 [待补充数据]，不编造占比。

## 三、各层画像

每层回答：他们是谁？现在怎么用产品？核心诉求？

## 四、差异化策略

| 层级 | 目标 | 策略 | 成本水平 | 具体动作 |
|------|------|------|---------|---------|

**反模式**：对所有用户发同样内容；对高价值用低价值手段；分层粒度过粗等于没分。

## 五、落地与数据需求

- [ ] 所需数据清单（消费/行为/标签字段）
- [ ] 埋点补充项
- [ ] 分层更新周期（建议月度/季度）

## 六、效果闭环与迭代

- 2 周看：各层转化率变化
- 1 月看：整体留存/LTV 变化
- 迭代：按数据重跑分层


## 填写指引（增强版）

> 本节为逐项填写指引，实际交付文档时**不复制**本段，仅作为填写参考。

### 文档头部
- 先定义「要做成什么样（量化目标）」，再写「怎么做到（动作 + 负责人 + 时间）」，最后写「怎么知道做成了（验收指标）」
- 每个字段尽量给具体例子（数字 / 场景 / 文案），不要留空或只写形容词
- 写清依赖与协作：谁提供什么输入、谁验收什么输出

### 一、分层目标与维度
- 每个目标都要可量化：写清「数字 + 时间 + 责任人」，如「Q3 新增付费用户 5000 人（对比 Q2 提升 25%），数据组每周五出报表」
- 核心指标只选 1~2 个北极星指标，其余放辅助列；目标值必须注明依据（历史基线 / 行业基准 / 老板口径）
- 人群列要写具体是谁：新用户还是老用户、哪条渠道进来、哪个生命周期阶段

### 二、分层体系
> 通用填写指引同上：量化目标 → 动作+负责人+时间 → 验收指标；字段给具体示例；写明依赖协作。

### 四、差异化策略
- 策略回答三个问题：对谁（人群）、做什么（核心动作）、凭什么（差异化理由/资源）
- 每个策略项标注预期收益（可量化）与所需资源，方便排优先级
- 写明不做什么（放弃清单），防止策略漂移

### 五、落地与数据需求
- 数据表含「时间窗 + 维度 + 指标 + 环比/同比 + 口径说明」
- 异常先验证再下结论：排除埋点漏报、口径变更、节假日
- 每个结论指向一个动作
