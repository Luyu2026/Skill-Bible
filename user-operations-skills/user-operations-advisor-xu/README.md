# user-operations-advisor-xu

## 它适合什么场景

徐志斌视角顾问（社群与用户激励）。以徐志斌的小群效应、社交红利、关系链驱动、三近一反，分析社群运营、用户激励、传播增长。 。
它是「用户运营」Skill 库的一环。

## 它解决什么

它把「每次都要从头想一遍」的用户运营工作沉淀成固定流程：输入你的材料，按内置判断和工作流拆解，交付可直接使用的产物（方案、体系、清单），不虚构数据、不替你拍板。

## 一个重要机制

**小群效应**：用户更愿分享给强关系小圈子；'三近一反'组群、连接者变现、荣誉/利益双驱激励。

## 你会拿到什么

- 结构化交付物（具体格式见 SKILL.md「输出格式」章节）
- 基于你提供的真实材料，信息不足时先问或标注 **[待确认]**
- 涉及判断类问题（该不该做、怎么选）转顾问团

## 怎么开始

```text
请调用 user-operations-advisor-xu，帮我处理下面这件事：
（粘贴你的问题、材料或数据）
```

## 边界

- 不编造数据：缺信息会先问或标注 **[待确认]**
- 复杂问题建议先用 `user-operations-master` 判断当前最该推进哪一步
- 判断类问题转 `user-operations-advisory-board` 顾问团
