# 《会员经济》· 会员体系设计框架

> 核心立场：企业从"一次性交易"转向"持续会员关系"（forever transaction），以**客户使命**为中心而非产品，通过超级用户、免费增值、onboarding 获取忠诚与经常性收入。

## 核心框架一：会员模式 vs 交易模式

**适用场景**：评估"是否要做会员/订阅制"；交易型业务想转型。

| 维度 | 交易模式 | 会员模式 |
|------|---------|---------|
| 卖什么 | 所有权/单次交付 | 使用权/持续访问 |
| 客户 | 匿名 | 实名可识别关系 |
| 沟通 | 单向 | 双向 + 成员间互动 |
| 中心 | 产品 | 客户使命 |

**关键辨析**：订阅（Subscription）只是**定价机制**，会员是一种**心态/关系**——没有订阅也可以有会员（如 Costco 俱乐部）；有订阅 ≠ 有会员。

**步骤**：
1. 对照清单自评现状（一端交易、一端会员）
2. 定义"客户的核心使命"（客户真正想达成的事，而非你的产品）
3. 打造"唯一一笔 forever transaction"（注册到取消不重复输入支付信息、持续一致体验）
4. 选择组织形态

## 核心框架二：会员价值阶梯（获取→转化→留存漏斗）

**适用场景**：设计拉新、onboarding、续费全漏斗。

```
① 知名度/触达 → ② 试用（免费/低成本体验） → ③ 注册/订阅 → ④ 忠诚会员（留存/增购/传播）
```

**onboarding 是新会员成败关键**（像"新员工入职培训"一样投入）：
- 注册即开始：消除注册摩擦 → 立即交付价值（开放面板/即时反馈/赠礼）→ 鼓励期望行为
- 0-7-30 天节奏：知识 → 习惯 → 文化认同

**定价原则**：简单但灵活；"免费"是**战术**不是**战略**。

## 核心框架三：会员组织七策略

1. 建立优秀获取漏斗
2. 集成有效的 onboarding 引导
3. 建立正确组织
4. 提供简单而灵活的定价
5. 把"免费"当战术而非战略
6. 追踪会员数据并据其行动
7. 留存好会员、体面放走不适合的会员

**转型建议**：最好在重大转折点（新市场/新渠道/赛道变革）顺势切入会员模式，而非平稳期强推。

## 核心框架四：留住超级用户

- **20/80**：约 20% 多次访问客户贡献约 80% 收入
- 超级用户 = 高频 × 高价值 × 高传播行为
- **忠诚设计**：做"磁铁"（让价值把人吸住）不做"电围栏"（门槛高到走不了）——围栏式留人终将反噬

## 决策规则（9 条）

1. **如果**业务可标准化交付"持续访问/使用"，而客户不愿承担所有权成本，**则**转向会员/订阅模式。
2. **如果**想做订阅但只改价格不改与客户的关系与互动，**则**结果只是"自动扣款"，不是会员。
3. **如果**新用户刚注册（高流失窗口），**则**立即交付首个价值点并进入 onboarding 培育。
4. **如果**设计免费层，**则**让免费服务于"试用-升级"漏斗，而不是永久福利（"免费是战术不是战略"）。
5. **如果**价格结构复杂到需要解释，**则**简化定价："简单而灵活"。
6. **如果**会员不活跃/不匹配（低价值高成本），**则**体面地放走，把资源留给好会员。
7. **如果**设计忠诚度/留存机制，**则**用"磁铁式"价值吸引而非"电围栏式"设卡阻止离开。
8. **如果**要转型会员模式，**则**找重大转折点（新市场/新渠道/规则变化）顺势切入。
9. **如果**某客户群贡献 80% 收入且高频互动，**则**识别为超级用户，专项运营。

## 检查清单（会员体系上线/复盘）

**落地前**
- [ ] 已写下"客户的核心使命"一页纸（使命 > 产品 > 公司）
- [ ] 明确会员 vs 交易的定位自评结论
- [ ] 选定组织形态（社区/订阅/忠诚度/混合），列出优劣
- [ ] 定价简单可解释，含免费/付费边界表

**上线时**
- [ ] 注册零摩擦，注册后 15 分钟内交付首个价值
- [ ] onboarding 按 0/7/30 天节奏设计
- [ ] 免费层明确"升级钩子"，不构成永久白嫖
- [ ] 追踪三类指标：交易价值、交叉销售、规模经济

**运营中**
- [ ] 30%+ 运营资源投向超级用户识别与经营
- [ ] 忠诚机制是磁铁不是电围栏
- [ ] 有"体面送别"流程：取消顺畅、挽留真诚、离后回访
- [ ] 行为数据（增购/升级/传播）纳入会员看板

## 反模式

- **披着会员皮的订阅**：只改扣款方式，不建关系、不做 onboarding——会员感知为零
- **免费层做成永久福利（free-forever）**：用户永无付费动机，成本吞噬利润
- **onboarding 缺失/延迟**：注册后 30 天不交付价值，错失习惯养成窗口
- **电围栏式留存**：用高退出成本、复杂取消流程留人——短期好看，长期口碑崩塌

## 边界声明

- 适用优先：易标准化"访问权/使用权"的产品（内容订阅/SaaS/社区/健身）；实物低频高客单不必然适合
- 免费模式有前提：存在清晰升级路径且成本可承受；纯 C 端流量型平台需另行验证
- 20/80 为美国案例统计，中国语境需按自有数据重新验证
- 原书 2015 年出版，社交裂变/私域等中国本土打法需补充
