## 参考/保留的机制

## 优化了什么

本 Skill 由陆羽Skill 基于专项调研原创构建，心智模型/决策规则均标注来源证据与诚实边界，符合 Skill-Bible「不编造、可追溯」规范。

## 为什么这么改

「用户运营」职业 Skill 库聚焦用户全生命周期（分层→生命周期→留存→召回→会员→社群），与「通用运营」套件错位互补，由 `user-operations-master` 总控统一路由。
