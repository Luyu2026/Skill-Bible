# 社群运营方案模板

本文件是 user-operations-community 的参考模板。生成社群运营方案时按此结构输出，每个章节的说明文字是写作指引（不要原样复制到最终文档里），根据实际需求填充内容。

---

## 文档头部

```markdown
# 社群运营方案

日期：（当天）
数据范围：（如有数据，注明口径）
```

## 一、社群定位与目标

```markdown
- 定位：（服务型 / 内容型 / 转化型 / 关系型）
- 目标：（响应速度 / 讨论活跃 / 转化 / 粘性）
- 目标人群：
```

## 二、社群结构设计

**关键认知**：小群效应——小群活跃度远高于大群。

- 大群拆小群方案（按兴趣/地域/等级）
- 群角色：群主 / KOC / 氛围组
- 金字塔：核心 → 活跃 → 普通

## 三、拉新与入群机制

- 入群理由（价值承诺）
- 入群门槛（适度筛选）
- 新成员欢迎机制

## 四、活跃机制

| 机制 | 说明 | 频率 |
|------|------|------|
| 话题日历 | 固定主题讨论 | 每周 N |
| 价值日课 | 干货/案例分享 | 每天/每周 |
| 活动玩法 | 打卡/挑战/接龙 | 每周 |
| 关键人带动 | KOC 带动讨论 | 持续 |

**反模式**：群主自嗨刷屏、无主题闲聊、广告泛滥。

## 五、激励与转化策略

- 激励：积分/荣誉/小奖品
- 转化：先价值后转化、专属群优惠
- 克制：转化不破坏社群氛围

## 六、数据指标与复盘

- [ ] 群活跃指标（发言人数/条数、活动参与率）
- [ ] 转化指标（进群→转化）
- [ ] 月度社群复盘
