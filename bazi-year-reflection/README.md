# 八字流年文化报告

## 它适合什么场景

有生辰或已有排盘，想知道流年术语在传统文化里是什么意思。

## 它解决什么

把日期口径、文化叙事和现实年度计划分开，减少似是而非的断言。

## 一个重要机制

先查盘面从哪里来，再决定哪些内容可以解释。

缺日时或历法不明时不编盘，会给补充卡和无需命盘的反思表。

文化解读不作为现实事件必然发生的依据。

## 你会拿到什么

- 生辰与历法口径卡。
- 有出处的文化解读，或明确未排盘说明。
- 年度目标、动作、观察信号和回顾安排。
- 缺口及不同口径的影响范围。

## 怎么开始

提供出生日期、历法、出生城市、已知时间、目标年份和关注主题。

已有排盘请连同工具名称及时间设置一起提供。

不知道时辰可以直接说不知道；不需要身份证或详细地址。

补盘后只重做受影响解释；行动反馈则按现实进度更新。

## 可直接复制的调用模板

```text
请使用 bazi-year-reflection。
生日：1995年农历八月，具体日时暂不清楚。
目标年份：2027年；关注学习安排。
现实条件：每周可以练习两次。
请明确哪些无法推算，先给补充卡和年度反思表。
```

如材料缺失，请先交付能完成的部分，并明确当前未完成的内容。
