# 八字流年文化报告

## 它适合什么场景

提供生辰查看传统流年解读、整理年度反思。

可以从一段已有材料开始，不必先写完整报告。

## 它解决什么

围绕当前卡点，完成生辰口径卡、文化解读或待补说明、年度行动表、不确定性清单。

先完成当前最能推进的一件事，再依据反馈决定是否继续。

## 一个重要机制

传统符号不是现实事件预测。

结论回到具体输入，缺失信息保留为未知，不用看起来完整的内容填空。

## 你会拿到什么

- 生辰口径卡。
- 文化解读或待补说明。
- 年度行动表。
- 不确定性清单。

交付会说明已完成内容及仍需补齐的部分。

## 怎么开始

直接发已有材料，并说明这次最想解决的一件事。

建议提供：出生日期时间；公历农历；出生地与时区；目标年份；已有排盘及来源；关注主题。

不方便分享的部分可以删去；影响判断的缺口会单独指出。

工具不足时先拿到可复制文本或制作包，未生成的文件会明确标注。

## 可直接复制的调用模板

```text
请使用 bazi-year-reflection。
我现在的场景：
这次最想解决的问题：
我已有的材料：
必须保留的事实或限制：
希望拿到的输出：
如信息不足，请先完成可用部分，只问影响关键判断的问题。
```

### 模拟输入

只给1995年农历八月，想看2027年，无日时与地点。

### 对应的模拟成品

不排四柱。缺口卡列具体日期、是否闰月、出生时间地点及已有排盘。先给学习主题行动：选一项技能，安排每周练习，月底记录完成度；不生成命盘吉凶。

使用后可交回实际结果或新材料，围绕同一个卡点继续修订。
