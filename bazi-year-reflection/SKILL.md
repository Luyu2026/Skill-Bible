# 八字流年文化报告

## 一句话主餐

想读懂已有八字流年盘却被术语和相互矛盾的吉凶结论困住时，核对历法与排盘口径，交付有出处的文化解释和基于现实目标的年度反思表。

## 输入

优先使用已提供正文、截图、草稿与记录，不要求重复整理。

- 出生日期时间。
- 公历农历。
- 出生地与时区。
- 目标年份。
- 已有排盘及来源。
- 关注主题。

### 材料处理规则

- 明确区分材料事实、用户陈述、合理推断和未知信息。
- 只追问会改变当前做法的缺口，其他缺口写入交付边界。
- 附件读不到时说明具体缺失，允许粘贴相关片段继续。
- 不编造用户经历、外部访问状态或工具执行结果。
- 演示必须标为纯模拟，不称为真实材料脱敏。
- 私人材料留在当前任务，不混入通用安装包。

### 会改变本轮做法的缺口

只追问工作流中会切换分支的字段；其余未知保留，不用完整问卷阻止已有材料产出。
外部访问失败只说明实际失败，不将“没有读取”写成“已核实无权限”。

## 核心判断

1. 排盘是历法计算，命理解读是传统文化叙事；计算一致不能证明预测有效。
2. 生日历法、具体日期、出生地或时辰缺失时，不补造四柱；只有部分可靠柱时仅解释其可支持术语。
3. 公历元旦、农历新年和立春不是同一边界；换年及换日规则必须随来源明示。
4. 不从出生信息推断疾病、寿命、婚姻成败、职业能力或投资结果；相关现实决策回到现实证据。
5. 用户只要文化阅读时保留传统术语层；年度行动必须明确来自用户目标，而非把象征解释成因果。

## 编号工作流

### 1. 建立生辰口径卡

逐项记录原始日期、公历或农历、是否闰月、出生钟表时间、出生地、目标年份。

时辰来自回忆还是证件要注明；“大概午夜”按不确定区间处理。

不为排大运默认性别或使用未确认身份规则；本轮不需要大运就不额外收集。

只有年月时，列出缺失日期与时辰，转入年度反思分支。

产出已知／未知／是否影响排盘三栏卡。

### 2. 确定唯一计算依据

优先读取用户现成排盘、来源与参数；把四柱逐字转录，不凭记忆重算。

标记该工具使用的时区、立春换年、子时换日及是否采用真太阳时。

边界出生或两个盘冲突时保留两个口径，不选听起来更准确的命运描述。

需要新计算时仅用可核验历法工具；无工具就交付待核验，不声称排盘完成。

产出盘面来源、所用规则、尚待确认的参数。

### 3. 核验文化解释的输入

将每个要解释的术语映射到盘面字段，字段不存在就不写该段。

时辰未知时不分析时柱；涉及全盘强弱、格局或组合的结论同步搁置。

目标年核对用户所指公历年度还是传统干支年度；跨界月份单独标注。

外部排盘结果冲突时先查历法规则，不用用户往事反推哪个盘“灵”。

产出可以说明的概念和本轮不作的解读范围。

### 4. 写分层文化阅读

每个主题按“来源字段→传统术语释义→体系内常见说法→现实边界”写。

流派差异写成不同解释，不把一种说法写成确定事实。

术语用通俗语复述；禁止“必离婚”“注定破财”等断言。

没有可靠盘面时可解释用户询问的术语，但注明这是通用词义而非个人流年。

产出篇幅与已知材料相称的文化报告；不堆砌无来源的神煞。

### 5. 制作年度行动表

从用户现实关注点选一个主题，询问可控目标和可用时间。

按“现实目标／当前依据／可控动作／观察信号／回顾日期”成表。

用户尚无目标时给可选择主题，不把模型提议写成用户已决定。

财务、健康等重大决定不由盘面触发；需要专业判断时回到相应事实和专业渠道。

产出能在当周开始的动作，同时写明与命理预测无因果关系。

### 6. 交付与纠错

逐项核对原始生辰是否被改写，盘面来源和时间口径是否可追溯。

报告首段写完成级别：个人文化阅读、部分术语说明或未排盘反思包。

将缺失字段整理为一张补充卡，不重复索要已给的信息。

用户补时辰或更换排盘后，重做受影响段落并保留差异，不能只改标题年份。

产出一份准确标注范围的报告和下次需要的材料。

## 直接交付与下一步

完整交付包括生辰卡、计算口径、可解释范围、文化阅读、年度行动和不确定性。

验收要求每个个人化术语能回到盘面；没有盘面时不得出现虚构的四柱和个人吉凶。

下一步只补真正影响盘面的字段，或按现实目标记录一次行动；两条路径明确分开。

无联网或排盘工具时完成反思包，写明“未排盘，未做个人流年推算”。

不收集无关身份证号、详细住址；出生地通常只需城市或当时适用时区。

输出为可复制 Markdown 或用户指定且当前可生成的文件；只有真实写出文件后才报告路径。

模拟执行及本轮缺陷回归见 [references/review-validation.md](references/review-validation.md)；不得把模拟结果当成真实用户反馈。

## 外部参考与延展

触发：农历转换冲突、闰月不明、出生接近节气或午夜、两工具四柱不同；先列出产生差异的时间区间。

历法入口：香港天文台公历与农历对照资料（hko.gov.hk）；历史时区查 IANA tz database 原始资料；传统词义查可追溯版本的原典。

比较历法换算与排盘工具的换年换日规则：天文历书只能验证日期和节气，不能验证命理预测。

采用提供历法范围、时区和边界说明的来源；不以营销文章的事后命中案例作为可靠性证据。

将核验结果写回口径卡，使用同一边界时间检查差异是否消除；未消除则保留双版本且搁置依赖它的解释。

研究前先读已有材料；已有依据能解决当前问题时直接交付，不重复检索。

运行时若采用新机制，说明它改动哪一步和如何验证；不能仅附链接充当研究。

保存通用改进时同步说明与受影响示例；个人偏好留在个人任务，不默认推广。
