# 番茄小说单章写作

## 适合什么场景

卡在网文第一章、需要按已有大纲生成 2200—2800 字单章、需要续接上一章。

你可以直接交来已有材料，不用先整理成标准表。
只需要处理眼前卡点时，不必同时规划所有后续阶段。

## 解决什么

普通聊天常把片段当章节；本技能把现有设定或上一章接成具有事件闭环和章末牵引的 2200—2800 字正文。

优先处理：提取上一章未兑现的问题。
本轮范围：完整单章正文为主交付，必须与计数范围一致。

## 一个重要机制

首章优先让读者看见主角处境与异常；续章优先兑现上一章悬念。

本章只推进一个主事件，支线用于增加阻力而非抢占主题。
执行中会把依据、假设与缺口分清，再决定如何交付。

## 你会拿到什么

- 完整单章正文为主交付，必须与计数范围一致。
- 附篇幅口径、人物状态更新和下一章起点。
- 完成标准：长度合格、事件结果清晰、上一章关键事实无矛盾。

可以查看 [模拟成品](demo.md)，了解实际返回的样子。

## 怎么开始

1. 发来你手上的材料，或直接描述现在卡在哪里。
2. 说明这次最想完成的结果。
3. 有截止时间、口吻、篇幅或不可改内容时一并告诉我。
4. 收到初稿后，反馈一处具体问题即可继续。

建议提供：
- 先读作者设定、分章大纲、上一章末尾和已确定的人物关系。
- 确认本章是首章、承接章还是改稿，不能用同一开头模板处理。
- 确认叙述人称、题材和本章必须发生的事件。

## 可直接复制的调用模板

```text
使用 serial-chapter-draft。
我现在的场景：
已有材料：
这轮最想拿到：
必须遵守的限制：
请先读已有材料，只问会改变做法的缺口，直接给可用成品。
```

简短调用也可以：

> 城市停电后，修表匠发现所有钟停在同一秒。写悬疑首章，第三人称。正文 2200—2800 非空白字符。
