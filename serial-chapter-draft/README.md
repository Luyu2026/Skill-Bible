# 番茄小说单章写作

## 适合什么场景

需要网文首章、续接上一章，或把梗概改成完整章节。

可以直接交已有材料，不需要先整理成标准表。

## 解决什么

交付有主事件闭环与章末牵引的2200—2800字单章。

每轮聚焦当前成果，缺口写在受影响的结果旁。

## 一个重要机制

先兑现上一章，再制造下一章问题。首章建立处境，续章承接悬念，改稿保留确定事实。

只数正文非空白字符，含标点；标题和账本不计。这是技能交付长度，平台规则另核对。

## 你会拿到什么

- 完整单章正文与可见事件结果。
- 实际字数及口径；无法计数会标待验证。
- 人物、物件、已知信息与新增规则账本。
- 下一章第一场景的具体起点。

查看 [完整模拟成品](references/example.md)，了解实际返回内容。

## 怎么开始

1. 首章给设定及必须发生的事件。
2. 续章贴上章末尾、大纲与不可改关系。
3. 改稿贴原章及节奏或人设问题。
4. 反馈具体因果断点，或带更新账本续写。

只需反馈具体卡点，就能继续当前成果。

## 可直接复制的调用模板

```text
使用 serial-chapter-draft。
类型：悬疑首章，第三人称。
设定：城市停电后，修表匠发现所有钟停在同一秒。
本章结果：找到通往北站的入口。
正文2200—2800非空白字符，含标点。
请交正文、实测计数、状态账本与续章起点。
```
