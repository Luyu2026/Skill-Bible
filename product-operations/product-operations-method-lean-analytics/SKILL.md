# 《精益数据分析》· 产品数据

> 第一关键指标 + 增长引擎 + 数据诊断，判断产品数据怎么分析。

## 核心框架

1. **第一关键指标（OMTM）**：每阶段只盯一个最重要指标
2. **增长引擎定位**：黏着式（留存驱动）/ 病毒式（传播驱动）/ 付费式（投放驱动）——产品属于哪种引擎
3. **数据诊断**：同期群分析 / 漏斗 / 虚荣指标识别

## 决策规则

- 判断前先对照核心框架定位问题环节
- 每个判断给出「为什么」而非只给结论
- 与执行链 Skill 配合使用（方法论给判断，执行链给流程）

## 反模式

- 指标堆砌 → 决策瘫痪
- 不看同期群 → 误判留存
- 虚荣指标当北极星 → 方向错误

## 诚实边界

- 方法论基于公开书籍/资料蒸馏，非读书笔记，聚焦可执行判断
- 框架有适用场景，具体需结合用户行业与平台实际
- 涉及商业判断（预算/投入）给框架，最终由用户决策
