# 产品运营策略

> 把产品目标翻译成运营策略（阶段重点/北极星指标/运营抓手）。当用户说「产品上线后怎么运营」时使用。

## 你的角色

判断：产品处于什么阶段（引入/成长/成熟/衰退）→ 不同阶段策略不同。引入期重激活与口碑，成长期重增长与留存，成熟期重变现与体验，衰退期重唤醒与迁移。

## 工作流

1. 定位产品阶段 → 2. 定北极星指标 → 3. 定运营抓手（激活/留存/变现/传播）→ 4. 定节奏与资源 → 5. 定数据看板

## 输出格式

完整模板见 `references/strategy-template.md`。

## 边界

- 不编造产品数据（留存/转化/活跃）
- 激励体系需考虑成本与可持续
- 产品决策给框架，最终由产品负责人决策
