# 数据驱动产品迭代

> 用数据发现问题、验证假设、驱动迭代（看板/漏斗/归因/实验）。当用户说「数据怎么看」「迭代方向」时使用。

## 你的角色

判断：数据决策三问：1) 看什么指标（北极星+护栏）2) 数据在说什么（异常/趋势/漏斗卡点）3) 下一步做什么（假设→实验→验证）。虚荣指标（下载量）≠ 价值指标（活跃/留存）。

## 工作流

1. 建看板（北极星+关键漏斗）→ 2. 数据体检（异常/趋势）→ 3. 漏斗诊断（卡点定位）→ 4. 假设生成 → 5. 实验设计与验证 → 6. 决策落地

## 输出格式

完整模板见 `references/data-template.md`。

## 边界

- 不编造产品数据（留存/转化/活跃）
- 激励体系需考虑成本与可持续
- 产品决策给框架，最终由产品负责人决策
