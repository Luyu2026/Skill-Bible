# 八字紫微双盘核验

## 适合什么场景

用户提供生辰或现成八字与紫微斗数盘，希望排盘、核对盘面差异或理解双盘结构时。

你可以直接贴现有材料、截图文字或原稿，不需要先整理成标准报告。

## 解决什么

建立统一生辰口径并分别核验八字与紫微盘，交付来源清楚的结构表与差异定位，避免凭记忆拼盘和用双盘互证命运。

会区分已经能判断的部分和还需要核验的部分。
不会为了让答案显得完整而补造事实。

## 一个重要机制

八字和紫微是不同传统系统，输入共享不意味着结果可互相证明。

历法转换是可核验计算，吉凶解读是传统文化解释，两者分栏。

这会直接影响哪些结论能写进本轮成品。

## 你会拿到什么

- 原始生辰、转换与流派参数表。
- 分别有核验状态的八字四柱和紫微宫位表，或明确未计算状态。
- 工具差异定位、候选盘与最少补充材料。

可以先看 [明确模拟示范](demo.md)，了解输入不足时如何交付。

## 怎么开始

1. 说清当前想完成的一件事。
2. 贴上已有材料，保留来源和时间信息。
3. 说明不能改动的条件与希望的输出长度。
4. 收到成品后，只补影响关键判断的缺口。

优先给这些材料：

- 出生日期、原始历法、公历或农历及是否闰月。
- 出生地到城市、当地钟表时间、时区和时间精度，不要求详细地址。
- 历史夏令时、是否使用真太阳时及换日规则，如用户已知。
