# 八字紫微双盘核验

## 适合什么场景

同一生辰在两个工具里排出不同结果，或你想同时取得八字与紫微结构，先弄清盘面和参数有没有对齐。

可以直接贴现有材料，不必先写一份标准报告。
本轮聚焦你眼前的一件事；缺失信息会写清影响。

## 解决什么

建立统一生辰口径并分别核验八字与紫微盘，交付来源清楚的结构表与差异定位，避免凭记忆拼盘和用双盘互证命运。

先处理足以判断的部分，再列真正影响结论的缺口。
不会把没有来源的数字、盘面、评价或人生事件写成你的事实。

## 一个重要机制

原始生辰、转换日期、排盘算法分开记录。历法已核验不代表星曜已核验；没有执行工具就明确写未计算。

你能看见结论来自哪项材料，以及哪些条件变了就要重做。
不需要为了开始，把不相关的私人信息也一起提交。

## 你会拿到什么

- 原始生辰、转换与流派参数表。
- 分别有核验状态的八字四柱和紫微宫位表，或明确未计算状态。
- 工具差异定位、候选盘与最少补充材料。

[查看完整模拟成品](references/review-validation.md)。
示范标明了模拟设定、实际产物和未验证范围。

## 怎么开始

1. 出生日期及原始历法；农历请写是否闰月。
2. 出生城市、当地钟表时间及精度；不详可以直接说明。
3. 已有两盘截图、工具名和参数；只排盘或也要文化术语解释请说明。

不确定的字段写“不详”即可，不必猜填。
结果标为待核验时，按对应缺口补来源或参数，再续接同一轮。

## 可直接复制的调用模板

```text
请使用 bazi-ziwei-chart。
目标：排盘／对照差异／解释结构
原始日期、历法、是否闰月：
出生城市、当地钟表时间及精度：
已知时区和排盘规则：
已有盘面、工具名称与参数：
请分别交八字和紫微结构及核验状态，无可靠工具时交待执行参数卡。
```

续接时贴上上一版成品与新材料，说明哪一项需要改。
只处理受新信息影响的部分，保留仍然成立的依据。
