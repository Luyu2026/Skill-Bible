# 八字紫微双盘核验

## 一句话主餐

建立统一生辰口径并分别核验八字与紫微盘，交付来源清楚的结构表与差异定位，避免凭记忆拼盘和用双盘互证命运。

普通对话容易把缺材料的结论写得完整；本技能先限定可判断范围，再交付能够直接使用的成品。

## 输入

- 出生日期、原始历法、公历或农历及是否闰月
- 出生地到城市、当地钟表时间、时区和时间精度，不要求详细地址
- 历史夏令时、是否使用真太阳时及换日规则，如用户已知
- 已有排盘截图、工具名称、版本、参数和宫位或四柱文字
- 需要大运等功能时才收集该工具明确必需的规则参数，说明用途

### 材料处理

- 优先读取已给原稿、附件和记录，不要求重复填写。
- 只追问会改变当前路径的缺口，其他缺失放在相关判断旁。
- 来源无法打开时使用用户摘录，并写明尚未独立核验。
- 用户事实、工具结果、合理推断与纯模拟分别标记。
- 不把演示数据移植成真实用户材料。

## 核心判断

1. 八字和紫微是不同传统系统，输入共享不意味着结果可互相证明。
2. 历法转换是可核验计算，吉凶解读是传统文化解释，两者分栏。
3. 未配置可靠算法或工具时不能自称已算出四柱与星曜位置。
4. 子时、闰月、节气、历史时区与夏令时边界可能改变盘面。
5. 紫微流派在闰月、四化和起运规则可能不同，先对齐规则再比较。
6. 缺时辰时可核验日期，但不伪造时柱、命宫或完整十二宫。

### 路径选择

- 材料足以支持核心任务：直接执行，不为完整感增加问题。
- 关键字段缺失：完成不受影响部分，并指出哪项产物暂停。
- 同一事实有冲突：保留两种来源，不悄悄择一。
- 用户更正输入：撤回受影响判断，再更新对应交付。

## 编号工作流

### 1. 冻结原始生辰

- 逐项复述用户提供的日期、历法、地点和钟表时间。
- 不擅自把农历当公历。
- 保留原始记录与转换值两列。
- 记录时间为准确、约略或不详。
- 交付输入核对单。

### 2. 明确历法和时间规则

- 确定时区、夏令时与使用的时间尺度。
- 核实闰月标记。
- 说明八字换年换月及换日口径。
- 说明紫微闰月、四化和起运规则。
- 规则不明先列候选参数，不能悄悄采用默认值。

### 3. 取得工具输出

- 优先读取用户现成盘和能说明参数的排盘工具。
- 分别保存八字四柱与紫微十二宫输出。
- 记录工具名、版本、访问时间和参数。
- 没有工具时交付待填核验表，不手算补齐未知星曜。
- 不得把漂亮盘图当成已验证算法。

### 4. 核对确定部分

- 公农历转换用独立历法资料核验。
- 四柱与紫微分别按各自规则检查，不互相投票。
- 核查截图文字是否存在 OCR 错位。
- 缺宫位、星曜或时柱标记缺失。
- 交付确定、待核验与不适用清单。

### 5. 定位双盘或工具差异

- 先比较输入与时区，再比较换日、闰月与流派规则。
- 一次只改变一个参数，定位导致差异的条件。
- 出生时间跨边界时并列候选盘及需要的确认材料。
- 不通过编造过往灾祸来反推时辰。
- 交付差异矩阵和复现参数。

### 6. 解释与交付

- 八字表列年、月、日、时及核验状态。
- 紫微表列宫位、主星和来源，缺项保留空缺说明。
- 术语用传统象征语言解释，不推断健康、寿命或必然财富。
- 用户只要排盘则在核验表结束，不附加算命内容。
- 下轮补正确参数或来源后仅重算受影响部分。

## 直接交付与下一步

- 原始生辰、转换与流派参数表。
- 分别有核验状态的八字四柱和紫微宫位表，或明确未计算状态。
- 工具差异定位、候选盘与最少补充材料。

### 交付顺序

1. 先给本轮结论与其成立条件。
2. 随后给完整可用正文、底表或核验卡，不让用户自行拼装。
3. 最后列一个最有价值的补充输入，以及它将改变哪项判断。

### 完成与续接

- 完成意味着本轮承诺的成品已经出现，不能仅交方法介绍。
- 暂停项写清所缺字段与恢复条件，不把局限埋在结尾。
- 持续任务保留本轮版本、关键条件和未解决问题。
- 用户交回新信息时只处理相关变化，沿用仍成立的事实。

### 工具降级

- 文件无法生成时提供可复制 Markdown 正文。
- 外部来源不可访问时依赖用户快照，并明确时间与核验范围。
- 依赖算法或实时数据的结论不能靠叙事填补。
- 未执行查询、导出、发布或计算时如实标记，不能写成已经成功。

### 外部参考与延展

- **何时研究**：节气边界、子时换日、闰月或不同工具盘面不一致时启动。
- **去哪找**：公农历查香港天文台对照表 https://www.hko.gov.hk/tc/gts/time/conversion.htm；时区查 IANA tz database；星曜规则查所用工具文档及有版本的传统资料。
- **看什么**：重点比较历法、夏令时、真太阳时、日界、闰月和四化映射，不能只比解释文案。
- **怎么用**：同一输入按明确参数复现差异；日期换算验证不能冒称星曜算法已经验证，缺工具保留未计算。
- 采用前比较两种可行机制或与现有方法对照，判断是否真能补当前缺口。
- 来源热度只用于发现，不代表方法有效；原始规则优先于二手总结。
- 材料已经足够时直接交付，不机械追加联网研究。
- 外部方法只改变执行机制，不能创造用户经历、报价或个体事实。
- 若实际复用受许可约束内容，保留所需声明；独立改写不等于可以忽略许可。

### 交付前验收

1. 每个确定结论都能回到材料、计算或明确设定。
2. 关键数字、日期、资格和限制没有在改写中发生变化。
3. 交付与用户当前目标一致，没有串入无关阶段。
4. 复制正文即可使用，依赖工具的暂停部分有可操作恢复条件。
5. 不把模拟验证称为真实用户效果，不承诺未经测量的收益。

### 明确模拟的执行示范

- 模拟输入：用户只说“农历五月初五晚上，出生于上海”，无年份，也无现成盘。
- 输入表：年份缺失；农历闰月状态未知；“晚上”不能确定时辰；地点为上海。
- 执行结果：八字四柱未计算，紫微十二宫未计算；不能从模糊时间生成命宫或日柱。
- 可直接发出的补充请求：请补出生年份、是否闰五月、当地钟表时间或时间范围；有现成盘可直接附工具参数。
- 下一步：先核验公农历与时区，再分别排两套盘；不要求姓名和精确住址。
