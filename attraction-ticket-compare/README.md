# 景点门票同口径比价

## 适合什么场景

一家人已确定景点和日期，看到官网、平台套票和券后价各不相同，想知道这趟实际付多少、怎么买。

可以直接贴现有材料，不必先写一份标准报告。
本轮聚焦你眼前的一件事；缺失信息会写清影响。

## 解决什么

把用户已有报价按日期、人群、项目和退改条件对齐，算出实际应付金额并给可购买候选，解决低价标题掩盖不同票种的问题。

先处理足以判断的部分，再列真正影响结论的缺口。
不会把没有来源的数字、盘面、评价或人生事件写成你的事实。

## 一个重要机制

先对齐日期、人群和权益，再算整笔订单。订单券只扣一次；资格不明的儿童票和新客券不会被算成确定优惠。

你能看见结论来自哪项材料，以及哪些条件变了就要重做。
不需要为了开始，把不相关的私人信息也一起提交。

## 你会拿到什么

- 带观察时间的同口径比价表与排除项。
- 按人数和优惠条件展开的总价计算。
- 首选、备选及付款前核对卡。

[查看完整模拟成品](references/review-validation.md)。
示范标明了模拟设定、实际产物和未验证范围。

## 怎么开始

1. 景点正式名称、城市、游玩日和入园时段。
2. 各类游客人数，儿童适用年龄或身高；必含的索道、交通等项目。
3. 已有报价和结算页、优惠券及退改规则截图，保留截取时间。

不确定的字段写“不详”即可，不必猜填。
结果标为待核验时，按对应缺口补来源或参数，再续接同一轮。
