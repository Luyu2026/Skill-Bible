# 景点门票同口径比价

## 适合什么场景

用户想比较同一景点在官网和不同平台的门票、套票或优惠报价时。

你可以直接贴现有材料、截图文字或原稿，不需要先整理成标准报告。

## 解决什么

把用户已有报价按日期、人群、项目和退改条件对齐，算出实际应付金额并给可购买候选，解决低价标题掩盖不同票种的问题。

会区分已经能判断的部分和还需要核验的部分。
不会为了让答案显得完整而补造事实。

## 一个重要机制

同景点不等于同票种，同日期同人群同权益才进入直接价格排序。

展示价、券后价和提交订单应付价分开；无法验证的券不算已获得。

这会直接影响哪些结论能写进本轮成品。

## 你会拿到什么

- 带观察时间的同口径比价表与排除项。
- 按人数和优惠条件展开的总价计算。
- 首选、备选及付款前核对卡。

可以先看 [明确模拟示范](demo.md)，了解输入不足时如何交付。

## 怎么开始

1. 说清当前想完成的一件事。
2. 贴上已有材料，保留来源和时间信息。
3. 说明不能改动的条件与希望的输出长度。
4. 收到成品后，只补影响关键判断的缺口。

优先给这些材料：

- 景点正式名称、城市、游玩日期、入园时段与人数。
- 成人儿童长者等票种资格，儿童优先提供身高或年龄条件而非身份号码。
- 已有平台链接、订单确认页截图、优惠券条件或报价文字。
