# 朋友圈知识长图设计

## 适合什么场景

将已有长文收敛为手机可读分区长图，交付可编辑源稿和实际可用格式，避免只有配色建议没有成品。

发原文、必须保留的数字来源、目标读者和格式要求。无品牌素材也可以开始。

可以只处理眼前的一件事，不要求先整理完整档案。

## 解决什么

把已有材料推进为本轮能使用的结果，并说明哪些判断还缺证据。

例如：模拟输入：面向新手的三步提问法“说清目标、给已有材料、约定输出”；无品牌图，无渲染工具。

本轮会完成一个明确目标，后续问题按实际反馈继续。

## 一个重要机制

先确认用户要可发布位图还是可编辑源稿，分别记录实际交付状态。

输入不足会改变交付范围，缺失事实不会用猜测补齐。

关键步骤会解释依据，方便你发现哪里不符合实际。

## 你会拿到什么

- 整理后的长图文案。
- 可编辑源稿和实际生成的图稿。
- 手机阅读检查与修改入口。
- 同时说明关键缺口与结论适用范围。

可看 [完整模拟成品](references/review-validation.md)，输入与输出一一对应。

## 怎么开始

1. 发原文、必须保留的数字来源、目标读者和格式要求。无品牌素材也可以开始。
2. 写明本轮最想拿到的结果和不能接受的做法。
3. 先使用返回的本轮成品，注意其中标明的执行前提。
4. 如果要继续，交回真实结果或指出最不适用的一处。

无法打开链接或截图时，直接粘贴关键文字也能开始。

## 可直接复制的调用模板

```text
使用 social-longform-design。
原文：提问要说清目标、给已有材料、约定输出
读者：刚接触AI的新手
用途：朋友圈知识长图
格式：可编辑HTML及PNG；无法导出请标明状态
限制：手机能读，不增加未经核实的模型宣传
请先交付本轮能直接使用的成品，说明关键缺口和下一步。
```
