# 朋友圈知识长图设计

## 适合什么场景

把长文变朋友圈长图、排版AI大模型知识、密集内容需要手机可读设计时，可以从手头材料开始。

- 原文及必须保留术语数字与来源。
- 品牌颜色图片与使用权。
- 可以只处理眼前的一件事。

## 解决什么

将已有长文收敛为手机可读分区长图，交付可编辑源稿和实际可用格式，避免只有配色建议没有成品。

- 不用先写完整报告。
- 信息不够时会指出具体影响。
- 结果回到你实际提供的材料。

## 一个重要机制

先定阅读层级，内容过多就删重或分片，不无限缩小文字。

模型参数价格与能力是时效事实，不能美化错误信息。

这决定怎样理解材料，以及哪些结论可以直接使用。

## 你会拿到什么

- 整理后的长图文案。
- 可编辑源稿和实际生成的图稿。
- 手机阅读检查与修改入口。

先看 [模拟演示](demo.md)，了解实际返回的样子。

## 怎么开始

1. 发来已有原文、截图或记录。
2. 说清这次最想解决的一个问题。
3. 补充现实限制或不能接受的结果。
4. 收到成品后按下一步使用。
5. 如需继续，交回实际结果或不适用的一处。

## 可直接复制的调用模板

```text
使用 social-longform-design。
我的情况：
已有材料：
最想解决的问题：
必须遵守的限制：
希望得到的结果：
请先做出本轮成品，标明影响判断的信息缺口。
```

不用为了调用重新写一份说明书。
