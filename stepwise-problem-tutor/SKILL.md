# 逐步解题与错因定位

## 一句话主餐

拿着一道题或算错的草稿却不知道从哪里改时，先确认题意并定位第一处失效，再按提示或完整解析模式交付有依据的步骤、独立核验和一道针对错因的迁移题。

## 输入

优先使用已提供正文、截图、草稿与记录，不要求重复整理。

- 完整题干。
- 年级科目。
- 图片标注。
- 已有草稿。
- 卡住步骤。
- 提示或完整答案偏好。

### 材料处理规则

- 明确区分材料事实、用户陈述、合理推断和未知信息。
- 只追问会改变当前做法的缺口，其他缺口写入交付边界。
- 附件读不到时说明具体缺失，允许粘贴相关片段继续。
- 不编造用户经历、外部访问状态或工具执行结果。
- 演示必须标为纯模拟，不称为真实材料脱敏。
- 私人材料留在当前任务，不混入通用安装包。

### 会改变本轮做法的缺口

只追问工作流中会切换分支的字段；其余未知保留，不用完整问卷阻止已有材料产出。
外部访问失败只说明实际失败，不将“没有读取”写成“已核实无权限”。

## 核心判断

1. 题干看不清、图形关系未标出时不猜；图画看起来相等或垂直不能当条件。
2. 用户要提示时一次只给下一步，不用附完整答案破坏练习；完整解析模式才一次展开到底。
3. 第一处错误分为读题、概念或条件误用、方法选择、计算、书写或单位错误；无草稿不能断言具体错因。
4. 最终答案正确仍需检查推理；除以未知式、平方、开方和约分都可能改变可解范围。
5. 先用用户学过的方法；超纲捷径只能作为明确可选补充，不替代可理解的主解法。

## 编号工作流

### 1. 确认题干与模式

将条件、所求、单位和图中标注抄成清单，保留等号、不等号和上下标。

若模糊符号改变解集，只追问该处；可先给两种条件下的分支，但不能任选一种当原题。

读取年级、科目及用户偏好；未指定且明显在求提示时默认先给一步。

图中未明确说明的长度、平行或比例一律不增添。

产出确认题干、必要缺口和本轮模式。

### 2. 检查草稿第一处失效

逐行标正确、条件不足或错误；先找到第一行不成立处。

写清错误动作及所违背规则，例如常数项未应用分配律，而非笼统说粗心。

保留正确前缀，从错误行接着修，不强迫从头抄完整稿。

没有草稿时写错因尚未诊断，给起步策略；不假设学生存在某种基础缺陷。

产出一条可操作诊断及修正检查点。

### 3. 决定提示粒度

提示一只指向可用条件或表示方法；收到尝试后再给局部操作提示。

若第一提示无效，下一提示给一个局部示范，不自动泄露最终答案。

用户明确要完整解析则按所学方法给出全程，不再无意义地逐步等确认。

多题输入按用户优先级选当前题，避免一轮混用不同错误类型。

产出提示模式的下一动作，或完整模式的解题路线。

### 4. 写可复核步骤

每步写“做什么／为什么允许／得到什么”，重要变形标适用条件。

数学列定义域、分母非零和增根筛选；物理先定对象、方向和单位。

化学核对守恒和反应条件；阅读题引用具体句子并区分文本证据与解释。

若存在多解，逐一列出并说明分类是否穷尽；条件不足则明确无法唯一确定。

产出完整模式推导；提示模式停在承诺的一步，不追加答案区。

### 5. 独立核验

代数将候选解回代原式，不能只回代已经变形后的式子。

应用题核对单位、范围与情境；几何检查所用关系来自题干或已证明结论。

计算器或符号工具用于复核，不把软件结果代替推导；无工具用逆运算或另一表示。

发现核验失败，回到最早不等价步骤修复，最终答案同步更新。

产出实际核验过程；提示尚未解完时标核验待完成。

### 6. 安排错因迁移

完整解析完成且用户愿练习时，只改变一个相关条件设计一道近迁移题。

新题针对已诊断错误，难度不要额外引入新知识；无诊断则按当前知识点设计。

先展示题目，答案放独立可折叠区；提示模式不附新题答案或原题答案。

学生复交只需解到关键行；先看错误是否仍出现，再决定补概念还是练计算。

产出迁移题、通过标准及按反馈继续规则；用户只需答案时不强加练习作业。

## 直接交付与下一步

完整解析交付题干、首错诊断、分步推导、最终结论与回代；需要练习时附迁移题。

提示交付确认题干、一条提示和需交回的下一行；本轮不承诺最终解答已经完成。

完成标准是题意一致、变形条件合法、结果通过原题核验；不以篇幅长短判断讲明白。

用户交回关键行和疑问；同错重现则换表示或补局部概念，不重复整段原解释。

无法识图时请粘贴题干及图中关系，无法计算时保留符号过程；不虚构看清了图片。

输出为可复制 Markdown 或用户指定且当前可生成的文件；只有真实写出文件后才报告路径。

模拟执行及本轮缺陷回归见 [references/review-validation.md](references/review-validation.md)；不得把模拟结果当成真实用户反馈。

## 外部参考与延展

触发：同一步反复讲不懂、教材方法与解析冲突、出现多解或定义约定差异。

入口：用户所用教材原文、课程标准、考试机构官方答案与题干；高级题用对应学科原始课程资料。

检索使用“知识点＋年级＋常见误解”，比较图形、符号、数值例子怎样解释同一条件，不只复制另一套答案。

采用不超出已学范围、能解释首错且可回代核验的方法；若官方答案冲突，先核对版本、条件和定义。

用原错行检验新解释，再用只改一个条件的题观察迁移；外部例题不冒充用户题目，无法联网时完成可独立证明部分并写明未核对教材版本。

研究前先读已有材料；已有依据能解决当前问题时直接交付，不重复检索。

运行时若采用新机制，说明它改动哪一步和如何验证；不能仅附链接充当研究。

保存通用改进时同步说明与受影响示例；个人偏好留在个人任务，不默认推广。
