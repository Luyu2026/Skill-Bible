# 逐步解题与错因定位

## 它适合什么场景

发作业题目、截图或草稿，需要逐步提示、完整解析或错因定位。

可以从一段已有材料开始，不必先写完整报告。

## 它解决什么

围绕当前卡点，完成题干确认、错因诊断、分步提示或解析、核验过程、针对性迁移题。

先完成当前最能推进的一件事，再依据反馈决定是否继续。

## 一个重要机制

看不清不猜题。

结论回到具体输入，缺失信息保留为未知，不用看起来完整的内容填空。

## 你会拿到什么

- 题干确认。
- 错因诊断。
- 分步提示或解析。
- 核验过程。
- 针对性迁移题。

交付会说明已完成内容及仍需补齐的部分。

## 怎么开始

直接发已有材料，并说明这次最想解决的一件事。

建议提供：完整题干；年级科目；图片标注；已有草稿；卡住步骤；提示或完整答案偏好。

不方便分享的部分可以删去；影响判断的缺口会单独指出。

工具不足时先拿到可复制文本或制作包，未生成的文件会明确标注。

### 模拟输入

解2(x-3)=8，学生写成2x-3=8，要求完整解析。

### 对应的模拟成品

第一处错误为分配律漏乘常数。2x-6=8，2x=14，x=7；回代2(7-3)=8。迁移题3(x-2)=12，答案x=6，回代为12，检查是否仍漏乘常数。

使用后可交回实际结果或新材料，围绕同一个卡点继续修订。
