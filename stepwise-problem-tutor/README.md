# 逐步解题与错因定位

## 它适合什么场景

一道题卡住，或答案不对却看不出草稿从哪一行出错。

## 它解决什么

保留已经写对的部分，从第一处失效接着修。

## 一个重要机制

提示和完整解析分开：你要提示时不会顺带看到最终答案。

错误会落到具体规则，例如分配律漏乘，而非一句“粗心”。

算出的答案还会回到原题检查。

## 你会拿到什么

- 题干确认及必要的待补条件。
- 首个错误位置、错误类型及依据。
- 一条能推进的提示，或完整分步解析。
- 完整模式的独立核验；需要时附一道针对性迁移题。

## 怎么开始

发完整题干、图片中的标注和现有草稿。

说明年级科目，以及希望只给提示还是完整解析。

图片模糊时可补关键符号；不会根据图形外观补条件。

复交关键一行即可；看是否真正修正后再决定下一步。

## 可直接复制的调用模板

```text
请使用 stepwise-problem-tutor。
题目：2(x-3)=8。
我的草稿：2x-3=8。
年级：初中；模式：先只给提示。
请指出第一处错误，让我自己重写下一行，不要先给最终答案。
```

如材料缺失，请先交付能完成的部分，并明确当前未完成的内容。
