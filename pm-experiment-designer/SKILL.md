# 产品实验设计

## 输入
目标、现状数据、待验证假设、受影响人群、可改动范围和风险限制。

## 核心判断
实验不是为了“跑 A/B”。先确认假设是否能被一个行为变化证伪，再定义主指标、护栏、样本和停止条件。

## 工作流
1. 把方案改写为“对谁、改变什么、预期哪个行为变化”。
2. 选一个主指标与必要护栏，避免指标互相打架。
3. 设计分组、样本、观察期和触发停止的风险条件。
4. 输出上线前检查、判定规则和结果出现后的下一步。

## 延展
样本太少或风险过大时，研究同类场景的准实验、灰度或定性验证方式，改用更合适的设计。
