# pm-experiment-designer

## 它适合什么场景

A/B 实验设计 Skill。从实验目标出发，输出完整的实验方案（假设、分组、指标体系、样本量估算、止损规则、判定规则）。 触发条件：用户提到"A/B 测试"、"AB 实验"、"实验设计"、"对照实验"、"分流实验"、"灰度方案"、"实验方案"、"样本量计算"、"显著性检验"、"实验评估"、"p值"、"置信区间"、"MDE"、"统计功效"、"实验周期"、"止损规则"等关键词。

## 它解决什么

它把「每次都要从头想一遍」的产品工作沉淀成固定流程：输入你的材料，按内置判断和工作流拆解，交付可直接使用的产物（文档、清单、报告或原型），不虚构数据、不替你拍板。

## 一个重要机制

**从假设到判定的完整因果框架**：先写可证伪假设，再设计分组、算样本量、定止损规则和判定标准——所有决策在实验开始前就定好，避免“数据出来才想怎么判”。

## 你会拿到什么

- 结构化交付物（格式见 SKILL.md「输出」章节）
- 基于你提供的真实材料，信息不足时先问或标注 **[待确认]**
- 工具不可用时自动降级（如无 docx 则输出 Markdown）

## 怎么开始

```text
请调用 pm-experiment-designer，帮我处理下面这件事：
（粘贴你的问题、材料或文件）
```

## 边界

- 不编造事实：缺信息会先问，确实需要假设时标注 **[假设]**
- 它是产品工作链的一环，复杂问题建议先用 `pm-master` 判断当前最该推进哪一步
