# 真实需求访谈

## 输入
想验证的假设、目标用户、现有访谈提纲或聊天记录。

## 核心判断
“你会不会用”没有证据价值；真正该问的是用户上一次怎么做、付出了什么、什么时候最痛。

## 工作流
1. 标出提纲里的假设、诱导问法和空泛问题。
2. 改成过去时、具体场景和行为证据问题。
3. 为每题标注它要验证什么。
4. 输出追问树和访谈后信号判读规则。

## 延展机制
某类用户总给模糊回答时，研究该行业常见的行为数据或工作流证据，再补充追问。
