# 报告说明

`schema_version: 1`。所有大小均为整数 bytes；JSON 使用转义保证换行、引号、非 ASCII 文件名可安全解析，解析后是原始路径。

| 字段 | 解释 |
|---|---|
| roots | 去重并规范化后的扫描根目录 |
| complete | 没有观察到枚举、读取或候选文件变化错误；不表示文件系统快照 |
| regular_paths / independent_files | 枚举到的普通文件路径数量 / 按设备与 inode 合并后的对象数量，含后续读取失败项 |
| groups / duplicate_groups | 完全相同内容的组 / 组数；按理论冗余 bytes 降序 |
| groups[].files[].paths | 同一个文件对象的已扫描路径；多个路径可能是硬链接 |
| groups[].files[].link_count | 文件系统报告的硬链接数，可能大于扫描范围内的路径数 |
| logical_redundant_bytes | 每组 size × (独立对象数 − 1) 后求和；仅逻辑内容数量，不承诺可释放空间 |
| hardlink_sets | link_count 大于 1 的对象及已扫描路径；即使只有一个路径在范围内也提示 |
| skipped | 符号链接和特殊文件；不是扫描失败，不读取链接目标 |
| errors | 无法访问、读取失败或检测到文件变动；有任何错误即 complete=false |

只读取同大小候选文件的内容，无匹配大小的文件无需哈希。哈希匹配后再逐字节比较，发布分组前复核候选路径元数据。不会读取用户材料到网络，也不收集使用记录。读取可能由操作系统更新访问时间。

退出码 0 表示报告完整（在上述范围与限制内）；1 表示部分结果，需要优先处理 errors；2 表示失败。不要将任意失败解释为“零重复”。报告生成后文件仍可能变化，因此不能将其用作延迟删除的证据。文件名、排序、修改时间均不能证明哪份是原件。
