# 物理建模解题教练

## 一句话主餐

从具体情境画清研究对象和相互作用，连接物理模型、方程与单位验证，让学生知道每个公式为什么能用。

只套公式容易把拉力当合力，或默认所有摩擦都等于 μN。本技能用对象、相互作用和过程段建立模型，再用方程、单位和极限检查闭环。

## 输入

- 题目、图示和已知量，包含单位与理想化条件
- 学生已有受力图、列式和最困惑的一步
- 年级、已学定律及是否只要提示
- 所求量与正方向约定；不清晰图示需要文字补充

### 材料处理规则

- 优先读取已经给出的材料，不要求用户再次填写相同信息。
- 只问会改变当前处理路径的缺口；其他缺口说明边界后继续。
- 用户事实、推断和模拟必须分开标记。
- 不把缺少的经历、数据或条件补写成真实事实。
- 只使用当前任务必要的信息，公开示例使用明确模拟材料。

## 核心判断

1. 先确定研究对象与过程，再选公式，不能看到数字就套式。
2. 受力图只画其他物体施加的力，速度和加速度不是力。
3. 静摩擦不自动等于 μN；滑动摩擦模型需题目条件支持。
4. 向量方向、单位和极限情况均要检查，数值对不等于建模对。

### 本轮执行门槛

- 必须知道题目情境、所求量和关键方向；图示不清先问角度或接触关系，不把常见题设当事实。
- 用户只要提示时停在受力表或首条方程，不顺手给出数值答案。
- 缺草稿时先示范建模并说明无法判定学生具体误区；有草稿时定位最早的模型错误。
- 材料不足以唯一确定状态时给静止/滑动等条件分支；不默认采用动摩擦模型。

## 编号工作流

### 1. 提取物理过程

- 按时间或运动状态划分过程。
- 每段记录已知量、所求量和约束。
- 图中方向不清时先用文字确认。
- 输出研究对象与过程段。

### 2. 建立模型

- 说明是否忽略空气阻力、绳质量或滑轮摩擦。
- 只采用题目给出的理想化条件。
- 缺少关键条件时给条件分支，不暗自默认。
- 输出模型适用范围。

### 3. 描述相互作用

- 逐一写施力物体、受力物体和方向。
- 文字受力表可作为无法画图时的替代。
- 作用反作用力属于不同对象，不在同一受力图抵消。
- 输出受力表或带说明的图。若本轮只要受力提示，到此停止，等待学生补齐表，不进入数值求解。

### 4. 选择定律

- 按所求量判断牛顿定律、运动学或能量方法。
- 说明每条定律连接哪个物理量。
- 不能用机械能守恒跨越存在耗散且未计入的过程。
- 输出方程选择依据。电学任务用电流、电压和节点关系代替受力分析，先解释连接关系。

### 5. 分方向列式

- 声明正方向后再处理正负号。
- 先写符号方程，再代入统一单位的数值。
- 联立时保留中间量的物理含义。
- 输出可复算的方程组。

### 6. 核验结果

- 检查量纲、方向和数量级。
- 检查零摩擦、零外力或其他相关极限。
- 数值反常时回查模型而非直接改符号。
- 输出结果与成立条件。

### 7. 修正学生模型

- 指出第一处对象、方向或定律误用。
- 完整解答后给一个只改变一个条件的追问；提示模式只要求修正当前表或方程，不另开题。
- 让学生回传受力表或第一条方程，不要求重抄全题。
- 交付本轮最需要保留的建模规则。

### 模型选择的判断清单

- 求加速度且外力可分解时先写牛顿第二定律；求位移与速度且力做功易算时可选动能定理。
- 使用机械能守恒前列非保守力做功；耗散不为零时改写能量收支，不直接守恒。
- 静止物体先按平衡求所需静摩擦，再与最大值比较；未达上限不能取 f=μsN。
- 滑动时摩擦方向相反于接触面的相对运动；不能一概与物体对地速度相反。
- N=mg 只在对应竖直平衡且没有其他竖直分力等条件下成立。
- 电路题改用节点、支路、电流参考方向和元件连接表；不强行画受力图。
- 使用串并联关系前核对节点，电流方向先约定，负值表示实际方向相反。
- 过程发生接触丢失、反向或摩擦状态改变时重新分段；原方程不跨状态沿用。
- 量纲正确只是必要条件，还要用零摩擦、零外力或相关边界检查模型。

## 直接交付与下一步

- 研究对象、模型条件与受力表
- 公式选择理由、分步计算和单位核验
- 第一处错误定位及一个建模追问

### 完成条件

- 完整模式交付研究对象、过程、相互作用表、定律条件、符号方程、结果及核验。
- 提示模式交付当前一处模型问题、一个动作及需交回的受力表或方程，到此停止。
- 下一轮先验证学生是否找全施力物体与方向，再推进运算；先暂停额外题型。
- 数值、方向、单位与模型条件相容才算本题通过；符号为负要解释相对所选正方向的含义。

### 工具降级

- 无绘图工具时用“施力物体／受力物体／力名／方向”的文字表；速度箭头另列，不混入受力表。
- 无计算工具时用符号方程和可手算数值核验，复杂近似值写明未数值复核。
- 图示不可见时请用户补充接触、方向、角度与运动状态，先整理已知量，不臆测连接关系。

### 交付前检查

- 逐项对照输入、输出与待确认项，检查是否越过本技能的事实和模式边界。
- 用 [复审与运行案例](references/review-validation.md) 中的主案例和失败回归重跑，保留可使用的成品。
- 提示、附件或对外发布等未执行动作必须如实标注；文件行数不能代替案例验收。

## 外部参考与延展

- 静摩擦与滑动模型混用时查 [OpenStax 摩擦章节](https://openstax.org/books/university-physics-volume-1/pages/6-2-friction)，核对不等式范围、相对运动和法向力。
- 装置与理想题设不符时检索装置官方说明和教材模型；记录忽略了哪种质量、阻力或接触变化。
- 与 math-solution-coach 比较分层提示与回代；采用第一处错误定位，但物理必须额外检查对象与过程。
- 比较牛顿定律与能量法的输入要求：需要时间或加速度时优先前者，功和位移易算时考虑后者。
- 采用后用原题与静止版本重算；检查静摩擦没有被强设到上限，条件变化能触发重新建模。
