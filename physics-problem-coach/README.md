# 物理建模解题教练

## 适合什么场景

学生提供物理题、图示或计算草稿，希望弄懂受力、选定模型、检查公式与单位。

贴题目、图中方向和全部单位；说明物体静止还是滑动。

## 解决什么

从具体情境画清研究对象和相互作用，连接物理模型、方程与单位验证，让学生知道每个公式为什么能用。

只套公式容易把拉力当合力，或默认所有摩擦都等于 μN。本技能用对象、相互作用和过程段建立模型，再用方程、单位和极限检查闭环。

## 一个重要机制

先确定研究对象与过程，再选公式，不能看到数字就套式。

受力图只画其他物体施加的力，速度和加速度不是力。

用户只要提示时停在受力表或首条方程，不顺手给出数值答案。

## 你会拿到什么

- 研究对象、模型条件与受力表
- 公式选择理由、分步计算和单位核验
- 第一处错误定位及一个建模追问

可查看 [完整模拟成品与边界案例](references/review-validation.md#模拟运行成品)。

## 怎么开始

1. 贴题目、图中方向和全部单位；说明物体静止还是滑动。
2. 贴受力图或首条方程，告诉我只要提示还是完整讲解。
3. 先交回本轮指定的受力表或方程，模型正确后再算数值。

无绘图工具时用“施力物体／受力物体／力名／方向”的文字表；速度箭头另列，不混入受力表。

数值、方向、单位与模型条件相容才算本题通过；符号为负要解释相对所选正方向的含义。
