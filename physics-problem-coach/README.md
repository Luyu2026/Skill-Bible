# 物理建模解题教练

## 适合什么场景

学生提供物理题、图示或计算草稿，希望弄懂受力、选定模型、检查公式与单位。

已有材料可以直接发来，不需要先整理成标准问卷。

## 解决什么

从具体情境画清研究对象和相互作用，连接物理模型、方程与单位验证，让学生知道每个公式为什么能用。

先处理眼前问题，避免拿到一堆难以采用的泛泛建议。

## 一个重要机制

先确定研究对象与过程，再选公式，不能看到数字就套式。

受力图只画其他物体施加的力，速度和加速度不是力。

这让结果既能直接用，也能看出哪些地方还需要你确认。

## 你会拿到什么

- 研究对象、模型条件与受力表
- 公式选择理由、分步计算和单位核验
- 第一处错误定位及一个建模追问

完整的模拟输入与成品见 [演示](DEMO.md)。

## 怎么开始

1. 直接贴出现有材料。
2. 告诉我这次最想解决的一个问题。
3. 补充限制，例如语气、方法、时间或输出形式。
4. 拿到结果后，只需回传当前仍不满意或没理解的一处。

建议提供：

- 题目、图示和已知量，包含单位与理想化条件
- 学生已有受力图、列式和最困惑的一步
- 年级、已学定律及是否只要提示

工具无法读取附件时，可以先粘贴核心文字；仍能得到与这些文字对应的结果。

## 可直接复制的调用模板

```text
请使用 physics-problem-coach。
我的材料：
（粘贴原稿、题目、照片描述或当前处境）

这次最卡的是：
（只写当前要解决的一件事）

请保留的事实或限制：
（写不能改的事实，以及你希望采用的语气、方法或输出形式）

请直接给本轮成品；无法确认的内容单列，不要替我补造事实。
```
