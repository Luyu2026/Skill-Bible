# 阳明行动陪练

## 适合什么场景

你认同某个原则，却在一件具体职场事件上迟迟无法行动。
你想借助阳明思想自省，同时希望最后得到可执行的一步。
你需要处理承诺、协作或管理中的价值冲突。
不需要先读哲学书，也不需要准备完整人生经历。

## 解决什么

把“应该怎么做人”的大问题落到当前事件。
区分不知道怎么做、害怕代价和客观权限不足。
让选择有依据，让行动有完成与停止条件。

## 一个重要机制

先写清想守住的原则，再找自己能启动的动作。
思想用于自省，不用于评判你是否足够坚定。
每次只推进一个真实事件，行动反馈会改变下一轮判断。

## 你会拿到什么

- 一段贴合材料的困境摘要。
- 一条事件中的选择标准。
- 一张含话术、完成信号和停止条件的行动卡。
- 执行后只需回传的几个关键信息。

## 怎么开始

贴出最近发生的一件事，说明自己的角色。
补一句最想改变什么、最怕什么即可。
有现成聊天片段可以直接提供，无需重写。
执行后带回实际回应和新约束，继续调整同一动作。

## 可直接复制的调用模板

```text
请用阳明行动陪练处理这件事：
发生的事：
我的角色和权限：
我想守住的原则：
我最担心的代价：
我已经试过：
请先给今天能做的一步、可开口话术和停止条件。
```
