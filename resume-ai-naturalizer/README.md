# 简历去 AI 味

它适合这样的场景：你的简历看上去写得很“专业”，但满是“赋能、闭环、从 0 到 1、持续优化”；真的被问“你具体做了什么”“这个数据怎么算”“你本人贡献是什么”时，又很难讲清。

这个 Skill 不会只帮你删几个词。它会先保留并核对你的真实材料，再给你一段典型 AI 腔反例、2-3 个不同侧重的可投递版本、一段 60 秒面试说法和最容易被追问的问题。最终目标是：简历能投，面试也接得住。

## 你会拿到什么

- 一段“AI 直接写出来的简历”反例，以及它为什么不能直接投；
- 2-3 个不同侧重的经历版本，例如增长效率、用户服务、商业化或产品迭代；
- 每个版本对应的事实边界和待确认信息；
- 一段 60 秒能自然说出口的面试表达；
- 3 个最容易被追问的问题、回答思路和补证据清单；
- 一张“材料使用说明”，明确本次是否调用了 JD 和互联网求职知识库。

## 它和普通简历润色有什么不同

普通润色会把句子写得更漂亮。

这个 Skill 先判断：一句话里是抽象词多，还是用户真的做过的动作多。它会把“看起来厉害”的表达还原成可核实的问题、判断、动作和结果；没有证据的地方保留待确认，不替你编进正式简历。

## 怎么开始

把本页面链接发给你正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/resume-ai-naturalizer

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：装在了哪里，以及我下一句该怎么调用它。
```

装好后，直接说：

```text
请使用「简历去 AI 味 Skill」处理下面这段经历。

原始简历 / 项目材料：
目标岗位 JD（可选）：
我更想突出：增长效率 / 用户服务 / 商业化 / 产品迭代 / 你帮我判断
输出方式：飞书文档 / 本地 Markdown / 先预览

要求：
1. 先给一段典型 AI 腔反例，并指出哪里不能直接投；
2. 基于真实材料给我 2-3 个不同侧重、可直接复制的版本；
3. 不编造数字、职责或结果；没有依据的地方标成待确认；
4. 再给 60 秒面试说法和 3 个高概率追问；
5. 最后附上材料使用说明。
```

## 示例：不是“从 0 到 1”，而是把真实动作说清楚

原始信息：

> 负责求职服务平台的数据看板和产品迭代。内容生产原来约 2 小时一条，优化后约 15 分钟一条；设计小红书与闲鱼双渠道内容生产流程；梳理 300+ 用户辅导数据和真实服务流程；响应时间缩短 90%，满意度提升 18.7%，ARPU 提升 30%。

常见 AI 写法可能是：

> 从 0 到 1 搭建一站式求职服务平台，基于多 Agent 内容生产体系赋能线索增长；深度洞察用户需求，持续优化产品体验，实现业务价值最大化。

这句话没有说清流程到底怎么改、本人到底做了什么，也无法解释“价值最大化”怎么衡量。

Skill 会优先把它改成事实可追问的写法，例如：

> 负责求职服务平台的数据看板搭建与产品迭代。针对内容生产依赖人工、单条耗时约 2 小时的问题，设计小红书与闲鱼双渠道内容生产流程，将热点抓取、选题规划、内容生成和校验拆成标准化环节，使单条内容生产时间缩短至约 15 分钟。同步梳理 300+ 用户辅导数据和真实服务流程，围绕高频咨询与面试准备场景优化自助服务，用户问题平均响应时间缩短 90%，满意度提升 18.7%，ARPU 提升 30%。

这段仍必须以你的真实材料为准。没有提供的日均产能、合规率、转化率或营收，不会被补写进最终简历。

## 互联网求职知识库的作用

如果你拥有并授权 Agent 使用 [互联网求职知识库](https://gte09oerz5.feishu.cn/wiki/FLSXwArGOijrh6kp125cMjsNngf)，Skill 会用其中与目标行业、岗位能力和真实案例有关的规则，校准表达顺序、指标边界和追问风险。

知识库不替代你的经历，也不会把案例写成你的事实。没有权限时，Skill 仍可基于你提供的材料完成改写，并在文档底部清楚说明本次未调用。


先把简历变成真实可讲的版本，再把每个数字、动作和取舍练成能接追问的回答。
