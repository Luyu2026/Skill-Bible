# 人生难题推演

## 适合什么场景

纠结搬家或转向、人生难题不知怎么选、希望用思维模型拆解时，可以从手头材料开始。

- 决策问题、截止日期和默认选项。
- 预算、照护与地点硬约束。
- 可以只处理眼前的一件事。

## 解决什么

从硬约束与可选行动出发，用少量适用模型推演代价、反转条件和可逆试探，避免堆十种模型仍无下一步。

- 不用先写完整报告。
- 信息不够时会指出具体影响。
- 结果回到你实际提供的材料。

## 一个重要机制

先分信息不足、价值冲突和执行受阻。

十大模型是工具箱，不是每次必须完成的十份分析。

这决定怎样理解材料，以及哪些结论可以直接使用。

## 你会拿到什么

- 选项与硬约束表。
- 模型推演与反转条件。
- 信息收集或可逆试探动作。

先看 [模拟演示](demo.md)，了解实际返回的样子。

## 怎么开始

1. 发来已有原文、截图或记录。
2. 说清这次最想解决的一个问题。
3. 补充现实限制或不能接受的结果。
4. 收到成品后按下一步使用。
5. 如需继续，交回实际结果或不适用的一处。

## 可直接复制的调用模板

```text
使用 life-decision-lab。
我的情况：
已有材料：
最想解决的问题：
必须遵守的限制：
希望得到的结果：
请先做出本轮成品，标明影响判断的信息缺口。
```

不用为了调用重新写一份说明书。
