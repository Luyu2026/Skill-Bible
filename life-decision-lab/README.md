# 人生难题推演

## 适合什么场景

从硬约束与可选行动出发，用少量适用模型推演代价、反转条件和可逆试探，避免堆十种模型仍无下一步。

说明必须何时决定什么，发已有选项、预算与不能牺牲的条件；如果已经决定，请直接说执行卡点。

可以只处理眼前的一件事，不要求先整理完整档案。

## 解决什么

把已有材料推进为本轮能使用的结果，并说明哪些判断还缺证据。

例如：模拟输入：现租3500元，通勤单程70分钟；候选房4500元、20分钟；月租硬上限4000元，一周内决定。

本轮会完成一个明确目标，后续问题按实际反馈继续。

## 一个重要机制

信息不足：找一个可能改变选择且能核实的未知，先安排取证而非评分。

输入不足会改变交付范围，缺失事实不会用猜测补齐。

关键步骤会解释依据，方便你发现哪里不符合实际。

## 你会拿到什么

- 选项与硬约束表。
- 模型推演与反转条件。
- 信息收集或可逆试探动作。
- 同时说明关键缺口与结论适用范围。

可看 [完整模拟成品](references/review-validation.md)，输入与输出一一对应。

## 怎么开始

1. 说明必须何时决定什么，发已有选项、预算与不能牺牲的条件；如果已经决定，请直接说执行卡点。
2. 写明本轮最想拿到的结果和不能接受的做法。
3. 先使用返回的本轮成品，注意其中标明的执行前提。
4. 如果要继续，交回真实结果或指出最不适用的一处。

无法打开链接或截图时，直接粘贴关键文字也能开始。

## 可直接复制的调用模板

```text
使用 life-decision-lab。
决策：一周内是否搬家
现状：3500元，单程70分钟
候选：4500元，单程20分钟
硬约束：月租不能超过4000元
希望得到：可行选项、反转条件和下一步取证
请先交付本轮能直接使用的成品，说明关键缺口和下一步。
```
