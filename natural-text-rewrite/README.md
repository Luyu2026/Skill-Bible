# 自然文本改写与对照

## 适合什么场景

将机械、套话密集或语气不合场景的文本改成自然表达，并提供原文对照与事实核验。适用于去套话、保留个人风格、改邮件文章或口播稿；不判断作者是否用了 AI。

你已经有材料，却卡在把它变成可使用结果的这一步。
可以提交初稿、截图或片段，不必先重新整理。

## 解决什么

从原文和真实说话习惯出发改出可直接使用的文本，并解释关键改动，解决泛泛要求“去 AI 味”却越改越空的问题。

本轮围绕一个具体卡点完成交付。
事实不够的地方会标清，已能完成的部分先交付。

## 一个重要机制

自然度问题与事实问题分开处理，不能靠虚构细节增加人味

根据用途选择书面、口语或正式表达，不能一律改得随意

这样你能知道哪些结论有材料支持，哪些仍需确认。

## 你会拿到什么

- 可直接复制的完整改写稿
- 重点句子的原文改文对照
- 待确认事实或语义变化清单，无问题则明确写无
- 一项可调的语气方向及复交方式

结果以可复制文本或可编辑表格呈现。
若相关工具可用，再按你的要求生成文件。

## 怎么开始

1. 贴出现有材料或提供可读取的文件。
2. 说清当前卡点和本轮想拿走的结果。
3. 补充使用场景与不可改变的限制。
4. 收到成品后，按其中一个下一步复交即可。

优先提供：完整原文及不能改动的数字、引文、术语和立场。
可选补充：读者、用途、发布位置与希望对方采取的动作。
