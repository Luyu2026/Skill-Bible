# 自然文本改写与对照

## 适合什么场景

文章、邮件或口播稿有套话，读起来不像你想要的语气。

适合已有原稿的改写；也适合已审定稿只做保守润色。

## 解决什么

交付可直接复制的全文，同时保留原来的事实与立场。

本轮围绕你提交的材料完成一份可使用的结果。
缺失项会明确标出，已有材料不需要重新整理。

## 一个重要机制

先锁定数字、否定、承诺和时间状态，再调整信息顺序与措辞。

“计划”不会改成“已经”；没有个人样本就使用中性语气。

## 你会拿到什么

- 连续完整的改写稿
- 关键原句、改句及修改原因对照
- 语义风险和待确认信息
- 基于具体句子继续调语气的方法

结果优先给可复制正文或可编辑表格。
如需文件，会说明实际生成和验证到哪一步。

## 怎么开始

1. 贴原稿，不必先自己去套话。
2. 说明读者、用途和希望对方采取的动作。
3. 圈出不能改的事实与措辞。
4. 如有偏好，附一段你认可的本人写作样本。

没有样本也能改；你只需指出哪句话太正式或太随意。

可先查看 [完整模拟案例](references/review-example.md) 了解成品形式。

## 可直接复制的调用模板

```text
请使用 natural-text-rewrite。
用途：团队群通知，直接但礼貌。
原稿：[粘贴完整原文]
事实锁：[数字、时间、计划状态、术语]
个人样本：[可选]
请先给完整改稿，再列重点对照，不添加未经确认的经历或结果。
```
