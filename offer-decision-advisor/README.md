# Offer 选择顾问

比较两份及以上 Offer，帮你在兴趣、行业、岗位、薪资和城市之间做一个可解释、可核实的选择。

它适合这样的场景：你拿到了互联网和国企、创业公司和成熟平台、留在家乡和去一线城市等多个 Offer；你不想只看总包，也不想被“稳定”“大厂”“AI”“离家近”这些标签带着走，他会从兴趣、行业、岗位、薪资和城市五个维度帮助你做一个可解释、可核实的选择。

## 它怎么工作

1. 将截图、JD、HR 口述和合同信息整理成 Offer 事实卡，区分已确认与待核实。
2. 先检查底线：固定收入、城市与家庭安排、合同条款、健康与到岗时间。底线不通过，分数再高也不能忽略。
3. 按你的偏好为兴趣、行业、岗位、薪资、城市设置权重；默认各 1 分，真正更重要的项加 0.5。
4. 用事实给每项 1-5 分，并写出哪条不确定信息会改变评分。
5. 给出当前建议、结论会反转的条件、入职前要核实的问题，以及 24 小时内最该做的一件事。

## 第一次使用

直接把这段发给 Agent：

```text
请使用 offer-decision-advisor 帮我比较这几份 Offer。

Offer A：公司/行业、城市、岗位、薪资结构、福利、团队和我担心的事：
Offer B：公司/行业、城市、岗位、薪资结构、福利、团队和我担心的事：
我的现实限制（最低到手收入、家庭、城市、健康、签约截止日期）：
我未来 2-3 年最想积累的能力：
我最看重的维度（兴趣/行业/岗位/薪资/城市）：

请先找出硬约束和待核实信息，再按我的权重比较。不要只给总分；要告诉我当前建议、哪些事实会推翻它，以及我今天应该问谁、问什么。
```

## 它不会做什么

- 不把国企、互联网、大厂或创业公司本身当成高分或低分。
- 不把期权、口头奖金或未确认补贴当作确定收入。
- 不承诺哪份 Offer 一定带来更好的未来。
- 不替代劳动合同、税务或竞业协议的专业审查。
