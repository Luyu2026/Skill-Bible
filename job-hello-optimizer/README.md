# 投递打招呼语优化

## 它适合什么场景

你准备在 Boss 直聘等聊天平台投一个具体岗位，简历有了，却不知道第一句话怎么写，担心对方只看到“您好，我对岗位很感兴趣”就划过去。或者已经出现了已读、要简历、无回复等结果，想根据真实反馈只改一处再试。

## 它解决什么

它不把打招呼语写成一大段求职信，而是先判断目标岗位最在意什么，再用你真实经历中最能承接的一条证据，直接产出 10 条不同风格的可发话术：招聘方列表页先能读懂的第一句话、点开后的最少证明，以及一个容易索要简历的下一步。

## 一个重要机制

聊天投递不是从“完整介绍”开始，而是从首屏开始：

```text
首屏钩子 → 展开证明 → 索要简历动作
```

10 条不是同义词改写，而是 10 种点击理由：结果直给、岗位职责、问题解决、业务洞察、作品案例、领域专长、反差切入、克制直给、提问共创、轻剧情/角色。具体 JD 会驱动这些理由；只有“运营/市场/营销”这类宽方向时，Skill 会先分清可能的岗位分支，给出不冒充定制的保守版本，并告诉你还该补哪条岗位信息。

轻剧情/角色会成为高辨识度选项，但只在创意、内容、品牌或用户明确接受的场景优先使用；正式行业默认改为有轻微人味的故事式开场。

## 你会拿到什么

- 当前岗位最该承接的一项职责或结果，以及与本人事实的对应关系；
- 10 条完整可发的话术，每条都有风格、好处、适用条件和风险；
- 一条条招聘方只看第一句也能读懂的开场、点击后证明与索要简历动作；
- 优先该测试哪 3 条、同一招聘方为什么只能发一条；
- 可复制的回传格式，以及带回 `已读 / 要简历 / 无回复` 后下一轮只该改什么。

## 怎么开始

把本页面链接发给你正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/job-hello-optimizer

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：装在了哪里，以及我下一句该怎么调用它。
```

装好后，直接说：

```text
请使用「投递打招呼语优化 Skill」帮我写 Boss 直聘投递开场。

目标岗位 / JD / 链接：
我的相关经历与可确认数据：
当前平台与对方已知身份（如有）：
我现在的打招呼语和真实反馈（如有）：

要求：先判断这个岗位最该承接的点，再给我 10 条完整可发的话术，并按“话术、风格、这个话术的好处、适合什么情况/风险”做成表格。
每条都要有“首屏第一句、点击后展开、收尾动作”；首屏必须单独也读得懂；不编造经历、数据或匹配度。
最后告诉我优先测哪 3 条、怎么记录已读/要简历/无回复，以及我回传什么后你会怎么迭代。
```

## 不能替代什么

它不替你决定岗位值不值得投，也不替你重写整份简历。前者使用 `job-application-match`，后者使用 `resume-jd-tailor` 或 `resume-crafter`；当对方已索要简历却没有后续推进时，再回到岗位版简历与证据本身排查。
