# 投递打招呼语优化

## 它适合什么场景

你准备在 Boss 直聘等聊天平台投一个具体岗位，简历有了，却不知道第一句话怎么写，担心对方只看到“您好，我对岗位很感兴趣”就划过去。或者已经出现了已读、要简历、无回复等结果，想根据真实反馈只改一处再试。

## 它解决什么

它不把打招呼语写成一大段求职信，而是先判断目标岗位最在意什么，再用你真实经历中最能承接的一条证据，写出招聘方列表页先能读懂的第一句话；点开后再补最少的证明，并给对方一个容易索要简历的下一步。

## 一个重要机制

聊天投递不是从“完整介绍”开始，而是从首屏开始：

```text
首屏钩子 → 展开证明 → 索要简历动作
```

第一句只能说一个值得点开的理由。具体 JD 会驱动这条理由；只有“运营/市场/营销”这类宽方向时，Skill 会先分清可能的岗位分支，给出不冒充定制的保守版本，并告诉你还该补哪条岗位信息。

## 你会拿到什么

- 当前岗位最该承接的一项职责或结果，以及与本人事实的对应关系；
- 一条招聘方只看第一句也能读懂的开场；
- 点击后的短句证明与低摩擦索要简历动作；
- 一条可单独测试的备选首屏；
- 发送前核对项，以及带回 `已读 / 要简历 / 无回复` 后下一轮只该改什么。

## 怎么开始

把本页面链接发给你正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/job-hello-optimizer

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：装在了哪里，以及我下一句该怎么调用它。
```

装好后，直接说：

```text
请使用「投递打招呼语优化 Skill」帮我写一条 Boss 直聘投递开场。

目标岗位 / JD / 链接：
我的相关经历与可确认数据：
当前平台与对方已知身份（如有）：
我现在的打招呼语和真实反馈（如有）：

要求：先判断这个岗位最该承接的一个点，再输出“首屏第一句、点击后展开、收尾动作”。
首屏必须单独也读得懂；不编造经历、数据或匹配度；另给一条不同角度的备选首屏。
```

## 不能替代什么

它不替你决定岗位值不值得投，也不替你重写整份简历。前者使用 `job-application-match`，后者使用 `resume-jd-tailor` 或 `resume-crafter`；当对方已索要简历却没有后续推进时，再回到岗位版简历与证据本身排查。
