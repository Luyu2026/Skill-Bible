# 《超级IP》· 个人IP方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

## 核心框架

### 框架1：人格化IP（人设即资产）
- **适用场景**：小红书账号人设设计时
- **步骤**：
  1. 确认"人格化"的独特性（不是"内容机器"，是"有性格的人"）
  2. 人设三要素：身份（你是谁）+ 性格（你什么样）+ 价值观（你信什么）
  3. 人设贯穿所有内容与互动（一致性）
- **输出物**：人格化人设设计
- **来源**：人格化章节

### 框架2：内容场景（把内容放进生活场景）
  - **适用场景**：选题与内容设计
  - **步骤**：内容不是"知识点"，而是"某个生活场景里被需要的东西"（通勤/租房/带娃/加班），场景越具体越有共鸣
  - **输出物**：场景化选题库
  - **来源**：场景章节

### 框架3：粉丝资产（关注是信任的货币）
  - **适用场景**：涨粉与变现的底层逻辑
  - **步骤**：粉丝不是"流量数字"，是"信任资产"——用内容持续增值，用变现小心支取，避免透支
  - **输出物**：粉丝资产经营观
  - **来源**：IP 变现章节

## 决策规则（节选）

1. **如果**账号没人设感，**则**强化"人"的属性（性格/价值观/真实生活），而非只发内容。（人格化章节）
2. **如果**内容没共鸣，**则**把内容放进具体生活场景（谁、在哪、什么情况需要）。（场景章节）
3. **如果**要变现阶段，**则**把粉丝当"信任资产"经营——接广透支信任要克制。（粉丝资产章节）
4. **如果**内容同质化，**则**回到人设差异（同一个选题，你的人设视角有什么不同）。（差异化章节）

## 检查清单

- [ ] 人设是否有"人味"（性格/价值观/真实生活）
- [ ] 内容是否场景化（具体的人、地点、情境）
- [ ] 是否在积累粉丝信任资产（而非消耗）
- [ ] 内容是否体现人设一致性
- [ ] 变现行为是否克制（不透支信任）

## 反模式

- 内容机器（无性格无人味，关注无理由）。
- 脱离场景讲道理（抽象无共鸣）。
- 频繁接广透支信任（粉丝流失）。

## 边界声明

- 超级IP理论源自互联网商业观察，小红书个人IP语境适配度高但非原书场景。
- IP 建设是慢功夫，与快速涨粉的诉求有张力。
