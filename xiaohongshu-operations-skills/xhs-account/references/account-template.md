> 使用说明：以下是完整输出结构。Agent 生成时**参考本模板但不复制进最终文档**；每节说明是"这节干嘛的、怎么写"。

# [账号] 小红书账号定位卡

> 日期：YYYY-MM-DD · 账号名（拟）：[名称]

## 一、定位一句话

**我是 [身份]，为 [人群]，提供 [生活方式/信息价值]，风格 [记忆点]。**

> 写作指引：一句话让用户懂你是谁。例："我是 3 年北漂设计师，为想改造出租屋的打工人，分享 300 元出租屋改造，风格真实不滤镜。"

## 二、目标定义

- 主目标：[涨粉/变现/个人IP/引流]
- 定位侧重：[泛人群强视觉 / 垂直信任 / 人设鲜明 / 转化路径清晰]

## 三、自身优势（兴趣/能力/资源 交集）

| 类型 | 内容 | 可持续性 |
|------|------|---------|
| 兴趣 | | 能长期做吗 |
| 能力 | | 擅长什么 |
| 资源 | | 有什么特别素材/圈子 |

> 写作指引：小红书是"生活方式内容"平台——真实生活经验比专业教程更受欢迎，从真实生活找内容。

## 四、人群画像

- 人口特征：[年龄/性别/地域/职业]
- 场景特征：[什么时间看/什么情绪看]
- 需求特征：[想获得什么：种草/攻略/共鸣]

## 五、赛道分析

- 赛道热度：[搜索/笔记量观察]
- 头部账号：[3 个对标 + 做得好在哪]
- 细分空位：[哪些没人做/做得差]

## 六、差异化设计（三问）

- 用户凭什么记住我（记忆点）：
- 用户凭什么关注我（独特价值）：
- 用户凭什么持续看我（可连续性）：

## 七、人设设定

| 元素 | 设计 |
|------|------|
| 昵称+简介 | 一句话+🏷️标签 |
| 视觉风格 | 主色/字体/封面模板 |
| 内容栏目 | 固定 2-3 个栏目（如"百元改造""红黑榜"） |
| 口吻 | 亲切/真实/有分享欲 |
