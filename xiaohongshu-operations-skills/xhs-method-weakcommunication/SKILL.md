# 《弱传播》· 内容传播方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

## 核心框架

### 框架1：弱传播规律（弱者优势）
- **适用场景**：设计小红书内容的人设与叙事角度时
- **步骤**：
  1. 理解"弱传播"核心：现实中强势的，舆论中常处弱势；现实中弱势的，舆论中常占优势
  2. 内容设计站"弱者视角"（普通人/打工人/踩坑者/过来人），不站"强者视角"（专家/大厂/优越感）
  3. 用"真实的小"（具体的人/小事/细节）引发共鸣，不用"抽象的大"（宏大的道理）
- **输出物**：内容的叙事视角选择
- **来源**：全书核心理论

### 框架2：情感优先（情绪是传播的第一推动力）
  - **适用场景**：选题与标题设计
  - **步骤**：先判断内容能否引发情感（共鸣/好奇/愤怒/治愈），情感优先于信息罗列
  - **输出物**：选题情绪检查
  - **来源**：情感传播章节

### 框架3：生活叙事（把道理放进故事）
  - **适用场景**：笔记正文结构
  - **步骤**：用"自己的生活体验/故事"承载信息（我踩过的坑/我的变化），比讲道理更能传播
  - **输出物**：笔记叙事结构
  - **来源**：叙事章节

## 决策规则（节选）

1. **如果**内容没人共鸣，**则**检查是否站在"强者视角"说教——换成"普通人/过来人"视角重写。（弱传播章节）
2. **如果**要设计标题，**则**先问"能引发什么情绪"，无情绪不发布。（情感章节）
3. **如果**正文干巴巴，**则**把道理换成自己的真实故事/体验。（叙事章节）
4. **如果**要涨粉，**则**用"小人物真实感"建立亲近，不用"权威专家感"拉开距离。（弱者优势章节）

## 检查清单

- [ ] 内容视角是否"弱"（普通人/过来人）而非"强"（说教/优越）
- [ ] 是否能引发明确情绪（共鸣/好奇/治愈）
- [ ] 是否用了生活化叙事（我的经历）而非讲道理
- [ ] 是否有具体的小细节（真实感）
- [ ] 是否避免"抽象宏大"的表达

## 反模式

- 专家式说教（居高临下，社区反感）。
- 宏大叙事（大而空，没人共鸣）。
- 无情绪内容（平铺直叙，不传播）。

## 边界声明

- 弱传播理论源自舆论学与传播学，小红书社区语境适配度高但非原书场景。
- 理论是视角工具：内容价值仍需要干货支撑，不能只靠"弱"与"情绪"。
