# 《文案创作完全手册》· 文案创作方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

## 核心框架

### 框架1：标题公式（4U 法则）
- **适用场景**：设计小红书标题、封面大字
- **步骤**：
  1. **Urgent 紧迫感**：时间/限量相关（"旺季前必存"）
  2. **Unique 独特性**：新角度/新信息（"99% 人都不知道"）
  3. **Ultra-specific 明确具体**：具体数字/细节（"30 元出租屋改造"）
  4. **Useful 有用**：用户能获得什么（"收藏这份清单"）
  标题至少满足 2U，最好 3U
- **输出物**：标题方案（按 4U 检查）
- **来源**：标题章节

### 框架2：卖点翻译（把功能翻译成利益）
  - **适用场景**：笔记正文、种草文案
  - **步骤**：每一步功能 → 问"所以呢？" → 直到翻译成用户能感知的利益（"保温 6 小时" → "冬天随时有热水喝"）
  - **输出物**：卖点→利益翻译表
  - **来源**：卖点章节

### 框架3：文案结构（AIDA 通道）
  - **适用场景**：笔记正文结构
  - **步骤**：Attention 注意（标题封面）→ Interest 兴趣（开头痛点/场景）→ Desire 渴望（卖点利益）→ Action 行动（收藏/关注/购买引导）
  - **输出物**：正文结构稿
  - **来源**：结构章节

## 决策规则（节选）

1. **如果**标题没点击，**则**按 4U 逐项检查，至少补足 2U。（标题章节）
2. **如果**正文不种草，**则**把功能参数翻译成用户利益（"所以呢？"追问法）。（卖点章节）
3. **如果**正文散乱，**则**套 AIDA 结构：注意→兴趣→渴望→行动。（结构章节）
4. **如果**文案平庸，**则**重写：改开头、加细节、删形容词。（改写章节）

## 检查清单

- [ ] 标题是否满足 2U+（紧迫/独特/具体/有用）
- [ ] 卖点是否翻译成用户利益（非参数）
- [ ] 正文是否 AIDA 结构完整
- [ ] 是否有具体细节（数字/场景/对比）
- [ ] 是否删掉了空洞形容词

## 反模式

- 标题只有"有用"（无紧迫无独特，不点）。
- 参数堆砌无利益翻译（说明书式）。
- 无行动引导（看完就划走）。

## 边界声明

- 方法源自传统广告文案，小红书语境需适配（更口语、更真实）。
- 文案技巧是放大器：产品/内容本身不行，文案救不了。
