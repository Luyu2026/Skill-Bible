# 项目找赛与参赛执行

## 它适合什么场景

你已经有一个项目，想找到适合、仍在报名的比赛，并让 Agent 帮你把报名和作品提交实际做完。可以给仓库、网站、现有材料，也可以续接此前中断的参赛任务。

## 它解决什么

它把赛事发现、资格核验、作品选择、材料准备、真实运行、报名组队与最终提交连起来。报名、发布和提交分别记录，不会只给一串比赛链接就结束。

## 一个重要机制

每个赛事维护一份可续接的档案。用户自己报完名、换 Agent 或页面中断后，先核对已完成状态，再继续尚未完成的部分。

## 你会拿到什么

- 有官方来源、截止时间和适配理由的候选赛事。
- 一份针对真实赛题的报名与作品材料。
- 报名、组队、平台验证和正式提交的实际状态及证据。
- 遇到阻塞时可直接交给另一个 Agent 的交接记录。

## 怎么开始

安装本文件夹到当前 Agent 的技能目录，再说：

```text
使用「项目找赛与参赛执行」Skill。
我的项目：[仓库、网址或文件夹]
帮我搜索当前适合的比赛，核对官方资格和提交要求，优先免费线上赛事。
直接推进最匹配的一场：准备材料、报名组队、完成必要适配和实际验证，再正式提交并保存回执。
只有涉及缺失身份信息、费用或必须本人处理的事项时再问我；进度保存到项目专属档案。
```

继续上一次任务时：

```text
继续使用「项目找赛与参赛执行」Skill。
先读取这份任务档案：[路径或链接]，核对已完成的报名、团队与作品状态，直接续办，不重复创建。
```

本 Skill 需要宿主提供联网检索，以及相应平台的浏览器或官方工具能力。跨设备无法访问原文件时，使用已交接材料或重新读取公开项目；不能假装读取了另一台电脑的路径。
