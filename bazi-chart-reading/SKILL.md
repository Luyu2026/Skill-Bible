# 八字四柱核验与解读

## 一句话主餐

普通聊天容易把不确定生辰算成确定命运；本技能先核验排盘输入与来源，再把传统术语解释成有边界的文化阅读。

## 输入

- 优先读取用户已有排盘及其来源、出生日期、出生地与记录时间。
- 明确公历或农历；农历须确认是否闰月。
- 时间跨时区、夏令时或接近换日与节气时，记录待核验边界。
- 只收集核验所需地点与时间，不要求姓名或证件。
- 缺可验证排盘工具时请求用户提供四柱截图，不凭记忆计算日柱。

输入处理顺序：
1. 有四柱无日期时仅做给定盘术语说明，不要求用户为解释术语披露隐私。
2. 生日必须保留原始历法、是否闰月、当地记录时刻和出生城市。
3. 近换日或节气时刻要保留原始分钟精度；只知道上午不能擅定时柱。
4. 不能取得排盘规则与工具结果时停止计算，仍可交付缺口表和术语说明。

## 核心判断

1. 输入核验、历法换算、传统解释三层分开，不能用解释流畅掩盖排盘未核验。
2. 采用立春换年、节令换月等规则时注明口径，不把农历初一直接当节令月界。
3. 午夜换日与子初换日、当地钟表时与真太阳时等差异分别列出，不能暗中切换。
4. 单一五行数量不能直接推出喜忌；缺完整论证时只说明结构，不下喜用神定论。
5. 传统文化解释不是可证实的个人未来预测，不据此安排医疗、投资或婚姻决策。
6. 生时不明时只解读确定部分，必要时并列候选时柱，不反推灾祸来定时。

判断落地检查：
- 先核查每柱是合法干支字符、位置是否抄反；格式成立不表示出生盘已核验。
- 历法转换只能核对日期，不能据此声称四柱、喜忌和人生预测都已证实。
- 两盘有差异先比较输入与换日口径，无法消除差异就并列候选。

## 编号工作流

### 1. 核对生辰记录

- 逐项复述日期历法、时间和地点。
- 标记用户确认、工具换算与待核验。
- 只问影响四柱的缺口。
- 不要求为排盘补充无关隐私。
- 交付：输入核验表。

### 2. 确定排盘口径

- 列所用历法与换年换月规则。
- 说明时间是否含夏令时修正。
- 接近边界时保留两种候选。
- 不能读取工具时暂停四柱计算。
- 交付：口径与不确定性清单。

### 3. 取得可追溯四柱

- 使用可用且能说明规则的历法或排盘工具。
- 记录工具名、输入与输出。
- 对关键日期用独立历法来源交叉核验。
- 截图来源未知时标“用户提供，尚未独立核验”。
- 交付：年、月、日、时四柱表或明确缺口。

### 4. 解释结构术语

- 以日干为解释中心，先说干支基本关系。
- 五行数量只作描述，说明藏干等口径。
- 十神关系给出相对日干的推导，不直接贴人格标签。
- 若规则或资料不足，省略无法核验的细分判断。
- 交付：术语、依据、文化含义对照。

### 5. 转成可讨论问题

- 将传统解释表述为象征阅读。
- 避免“必定”“某年必出事”等确定断言。
- 用户问现实选择时回到其真实约束与证据。
- 不提供致病、寿命或灾祸推断。
- 交付：可自我观察的问题，而非命运指令。

### 6. 交付边界与续接

- 明确哪些部分已核验、哪些仅按给定盘解释。
- 给出解决缺口所需的最少信息。
- 用户更正时重新排盘，再重做受影响解释。
- 未核验盘不包装成完整算命结果。
- 交付：结构解读和可执行核验下一步。

## 直接交付与下一步

- 输入与口径表、可追溯四柱或待核验项、术语解释。
- 完成状态分为已核验排盘解读、仅按用户盘解释、资料不足暂停计算。
- 下一步只补足会改变排盘的信息。
- 无排盘工具时仍可解释用户给定术语，但不补造出生四柱。
- 不承诺准确预测，不把灾祸或付费化解当作交付。

交付前验收：
- 交付开头标明已核验、给定盘解释或暂停计算，三种状态不能混写。
- 逐柱分别写来源；日柱未核验时不可推导为已确定的出生信息。
- 只有日期对照来源时不声称核验分钟级节气边界。
- 术语与象征解释分栏；不由五行个数推出疾病、寿命或必须从事的职业。
- 用户改生时后撤回受影响的时柱关系，不沿用旧盘结论。

## 外部参考与延展

- 历法冲突先查 [香港天文台公农历对照](https://www.hko.gov.hk/tc/gts/time/conversion.htm)，对分钟级边界另找带时区的节气时刻资料；日期对照不能替代完整排盘。
- 传统解释如需深化，检索可标明版本与章节的子平原典或学术文化研究；分别记录术语定义和流派条件。
- 比较工具公开的输入字段、时区、换年换月及日界规则；不按多数工具结果投票。
- 只采用能追溯并解释差异的规则；重做受影响柱与术语，未解决部分保持候选，不以文化资料为未来预测背书。

### 不确定输入的处理分支

- 仅抄录四柱：保留原字，先讲年、月、日、时的阅读顺序。
- 字符不清：标出该字待确认，不把相似字自动补齐。
- 日期无历法：只问公历还是农历，不进入排盘。
- 农历闰月不明：暂停转换，说明同名月份可能对应不同日期。
- 生时范围跨两段：保留候选，不按生活遭遇倒推出时刻。
- 已有两个排盘：列表比较输入、时区、换日与节令口径。
- 历法工具不通：交付用户可拿去核验的输入卡，不生成日柱。
- [香港天文台对照表](https://www.hko.gov.hk/tc/gts/time/conversion.htm)提供公农历对照；不能当作传统解释验证。
- 用户问升职或婚姻：将象征阅读与现实条件分开，不给命定结论。
