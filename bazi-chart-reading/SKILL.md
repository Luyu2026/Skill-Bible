# 八字四柱核验与解读

## 一句话主餐

普通聊天容易把不确定生辰算成确定命运；本技能先核验排盘输入与来源，再把传统术语解释成有边界的文化阅读。

## 输入

- 优先读取用户已有排盘及其来源、出生日期、出生地与记录时间。
- 明确公历或农历；农历须确认是否闰月。
- 时间跨时区、夏令时或接近换日与节气时，记录待核验边界。
- 只收集核验所需地点与时间，不要求姓名或证件。
- 缺可验证排盘工具时请求用户提供四柱截图，不凭记忆计算日柱。

输入处理顺序：
1. 先读取已给材料，复述本轮目标。
2. 只补问会改变执行路线的信息。
3. 可以合理假设的内容单独标记，事实缺口不能伪造。
4. 用户只要演示时明确标“模拟”，不称真实案例脱敏。

## 核心判断

1. 输入核验、历法换算、传统解释三层分开，不能用解释流畅掩盖排盘未核验。
2. 采用立春换年、节令换月等规则时注明口径，不把农历初一直接当节令月界。
3. 午夜换日与子初换日、当地钟表时与真太阳时等差异分别列出，不能暗中切换。
4. 单一五行数量不能直接推出喜忌；缺完整论证时只说明结构，不下喜用神定论。
5. 传统文化解释不是可证实的个人未来预测，不据此安排医疗、投资或婚姻决策。
6. 生时不明时只解读确定部分，必要时并列候选时柱，不反推灾祸来定时。

决策落地要求：
- 每个判断都必须影响本轮的取舍、动作或交付。
- 解释只写到足以让用户理解当前选择，不堆砌理论。
- 用户更正输入时，撤回受影响结论并重做对应部分。

## 编号工作流

### 1. 核对生辰记录

- 逐项复述日期历法、时间和地点。
- 标记用户确认、工具换算与待核验。
- 只问影响四柱的缺口。
- 不要求为排盘补充无关隐私。
- 交付：输入核验表。

### 2. 确定排盘口径

- 列所用历法与换年换月规则。
- 说明时间是否含夏令时修正。
- 接近边界时保留两种候选。
- 不能读取工具时暂停四柱计算。
- 交付：口径与不确定性清单。

### 3. 取得可追溯四柱

- 使用可用且能说明规则的历法或排盘工具。
- 记录工具名、输入与输出。
- 对关键日期用独立历法来源交叉核验。
- 截图来源未知时标“用户提供，尚未独立核验”。
- 交付：年、月、日、时四柱表或明确缺口。

### 4. 解释结构术语

- 以日干为解释中心，先说干支基本关系。
- 五行数量只作描述，说明藏干等口径。
- 十神关系给出相对日干的推导，不直接贴人格标签。
- 若规则或资料不足，省略无法核验的细分判断。
- 交付：术语、依据、文化含义对照。

### 5. 转成可讨论问题

- 将传统解释表述为象征阅读。
- 避免“必定”“某年必出事”等确定断言。
- 用户问现实选择时回到其真实约束与证据。
- 不提供致病、寿命或灾祸推断。
- 交付：可自我观察的问题，而非命运指令。

### 6. 交付边界与续接

- 明确哪些部分已核验、哪些仅按给定盘解释。
- 给出解决缺口所需的最少信息。
- 用户更正时重新排盘，再重做受影响解释。
- 未核验盘不包装成完整算命结果。
- 交付：结构解读和可执行核验下一步。

## 直接交付与下一步

- 输入与口径表、可追溯四柱或待核验项、术语解释。
- 完成状态分为已核验排盘解读、仅按用户盘解释、资料不足暂停计算。
- 下一步只补足会改变排盘的信息。
- 无排盘工具时仍可解释用户给定术语，但不补造出生四柱。
- 不承诺准确预测，不把灾祸或付费化解当作交付。

交付前验收：
- 对照用户原始输入，检查关键事实和目标没有被替换。
- 逐项检查本技能承诺的产物已实际给出，而非只说将会生成。
- 把未确认项写在相应结论附近，不藏在笼统说明里。
- 用户能直接采取下一动作，无需再把输出加工成另一个任务。
- 不宣称访问过未访问的材料，也不宣称运行了未运行的工具。

### 外部参考与延展

- 触发：节气附近出生、日界有争议、工具输出不同，或用户要求细化喜忌。
- 历法与日期换算优先查香港天文台公历农历对照表 https://www.hko.gov.hk/tc/gts/time/conversion.htm 。
- 传统术语用可标明版本的子平类原典或学术文化研究，记录流派与适用规则。
- 比较来源的换年、节令月、时区和换日口径，先解释差异而非投票选盘。
- 将可核验历法事实与传统解释分栏；有冲突保留候选，不用检索结果制造预测可信度。

研究后的采用规则：
1. 先记录本轮具体缺口，再选互补机制，不以项目热度决定。
2. 优先复用用户已验证有效的方法；材料已足够时直接交付。
3. 外部机制只能改变执行方法，不能替代用户事实。
4. 新机制先用于当前产物，按上面的验收标准核对。
5. 找不到可靠改进时保留现有可用路径，并如实说明局限。

实际调用不复用其中的个人事实或把模拟结果当成用户结果。
