# 八字四柱核验与解读

## 适合什么场景

提供生辰希望理解八字四柱、已有排盘想逐项解释、出生时刻不确定需要比较。

你可以直接交来已有材料，不用先整理成标准表。
只需要处理眼前卡点时，不必同时规划所有后续阶段。

## 解决什么

普通聊天容易把不确定生辰算成确定命运；本技能先核验排盘输入与来源，再把传统术语解释成有边界的文化阅读。

优先处理：逐项复述日期历法、时间和地点。
本轮范围：输入与口径表、可追溯四柱或待核验项、术语解释。

## 一个重要机制

输入核验、历法换算、传统解释三层分开，不能用解释流畅掩盖排盘未核验。

采用立春换年、节令换月等规则时注明口径，不把农历初一直接当节令月界。
执行中会把依据、假设与缺口分清，再决定如何交付。

## 你会拿到什么

- 输入与口径表、可追溯四柱或待核验项、术语解释。
- 完成状态分为已核验排盘解读、仅按用户盘解释、资料不足暂停计算。
- 下一步只补足会改变排盘的信息。

可以查看 [模拟成品](demo.md)，了解实际返回的样子。

## 怎么开始

1. 发来你手上的材料，或直接描述现在卡在哪里。
2. 说明这次最想完成的结果。
3. 有截止时间、口吻、篇幅或不可改内容时一并告诉我。
4. 收到初稿后，反馈一处具体问题即可继续。

建议提供：
- 优先读取用户已有排盘及其来源、出生日期、出生地与记录时间。
- 明确公历或农历；农历须确认是否闰月。
- 时间跨时区、夏令时或接近换日与节气时，记录待核验边界。
