# 八字四柱核验与解读

## 适合什么场景

想核对出生四柱，或只有排盘截图想看懂术语。

可以直接交已有材料，不需要先整理成标准表。

## 解决什么

区分输入、历法换算与传统解释，交付有来源状态的文化阅读。

每轮聚焦当前成果，缺口写在受影响的结果旁。

## 一个重要机制

每一柱都有来源与确定程度。没有出生日期也可解释给定盘，但明确未独立核验。

工具不通或生时跨界时保留缺口与候选，不凭记忆补日柱。

## 你会拿到什么

- 输入历法、时间、地点与口径表。
- 可追溯四柱或待核验项。
- 日主等术语的逐项白话解释。
- 补哪条信息能推进核验的具体下一步。

查看 [完整模拟成品](references/example.md)，了解实际返回内容。

## 怎么开始

1. 已有盘直接贴四柱或截图，附来源。
2. 要核验则说明公历或农历、是否闰月。
3. 提供出生城市、记录时间和误差，不需姓名证件。
4. 不想提供生辰也可只问术语，不做命定预测。

只需反馈具体卡点，就能继续当前成果。

## 可直接复制的调用模板

```text
使用 bazi-chart-reading。
给定盘：甲子、丙寅、戊辰、壬子。
来源：截图抄录，暂不提供出生日期。
目标：看懂四柱顺序和日主。
请明确未核验状态，只解释有依据的部分。
列出继续核验所需的最少信息。
```
