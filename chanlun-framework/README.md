# 缠论框架

用走势结构而不是一句“看涨 / 看跌”来分析行情的技术研究 Skill。

它适合用在这样的场景：你看着一段上涨、下跌或横盘行情，听到“背驰”“中枢”“三买”却不知道它们分别意味着什么；或者你已经持仓，却分不清这里是趋势延续、盘整震荡，还是一个需要等确认的转折。把 K 线周期、当前走势、持仓与计划交给它，它会先做结构分解，再给出条件化的应对和失效位置。

## 你会得到什么

- 走势类型、中枢、背驰、三类买卖点和级别的结构化解释
- 从“大级别定方向，小级别找位置”开始的分析顺序
- 7 个核心概念、5 个思维模型、8 条交易纪律
- 不确定时该等待什么确认、发生什么才说明原判断失效

装好后可以直接说：

```text

标的：

我看到的结构或 K 线截图：

```

## 边界

缠论不是预测工具，也不是“必赚公式”。它用于结构化研究、复盘与风险检查，不构成买卖建议。不同人对走势分解可能不同，尤其在多级别联立、背驰确认和实时行情上，应把不确定性、仓位与风险承受能力放在结论之前。
