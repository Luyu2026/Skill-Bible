## 填写指引（增强版）

> 本节为逐项填写指引，实际交付文档时**不复制**本段，仅作为填写参考。

### 一、渠道全景盘点
- 渠道列写「渠道名 + 触达量级 + 单位成本 + 历史转化」
- 按 ROI 从高到低排序，注明主渠道（放量）与测试渠道（小额验证）
- 写明渠道组合逻辑：信息流拉新 → 私域承接 → 社群促活

### 二、渠道效率评估
- 渠道列写「渠道名 + 触达量级 + 单位成本 + 历史转化」
- 按 ROI 从高到低排序，注明主渠道（放量）与测试渠道（小额验证）
- 写明渠道组合逻辑：信息流拉新 → 私域承接 → 社群促活

### 三、预算分配建议
- 预算按「项 × 金额 × 依据」列
- 预留 10~20% 机动预算并注明触发条件
- 写清 ROI 口径与回本周期

### 四、素材与投放优化
- 投放计划写「人群包 / 素材组 / 出价 / 预算 / 时段 / 落地页」
- 每组写 A/B 对照设计：变量只有一个
- 预设止损线：指标到什么值就关停/换素材

### 五、归因与数据口径
- 数据表含「时间窗 + 维度 + 指标 + 环比/同比 + 口径说明」
- 异常先验证再下结论：排除埋点漏报、口径变更、节假日
- 每个结论指向一个动作

### 六、风险
- 风险写「场景 + 概率 + 影响 + 预案」，预案必须可执行
- 至少覆盖：内容/合规、成本超支、关键人/供应商、数据口径分歧
- 标出谁负责监控、多久检查一次
