# 《上瘾》（Hooked: How to Build Habit-Forming Products）方法论提炼

## 一、核心框架

### 1.1 Hook 模型（触发 → 行动 → 多变奖励 → 投入）
- **适用场景**：设计/诊断留存机制、习惯养成类功能的留存优化
- **步骤**：
  1. **触发 Trigger**：外部触发（推送/短信/邮件/图标红点）引导用户进入，内部触发（情绪/场景/习惯）让用户自发想起
  2. **行动 Action**：让用户做出最简行为——降低行为门槛（时间/金钱/体力/脑力/社会偏差五要素）
  3. **多变的奖励 Variable Reward**：奖励要有随机性/变化（社交奖赏/猎物奖赏/自我奖赏三类），让用户"期待未知"而持续回来
  4. **投入 Investment**：让用户在产品里沉淀资产（内容/关系/数据/声誉），投入越多越不愿离开（沉没成本 + 为下次触发埋点）
- **输出物**：Hook 四步设计表（每步的具体设计 + 触发时机）

### 1.2 习惯区判断（Habit Zone：频率 × 感知效用）
- **适用场景**：判断产品是否值得做习惯养成机制
- **步骤**：
  1. 评估使用频率：高频（>1 次/天）或低频
  2. 评估感知效用：用户是否强烈感知到价值
  3. 落入"习惯区"（高频+高感知效用）才值得设计 Hook；否则换留存思路
- **输出物**：产品在频率×效用矩阵中的位置 + 是否走习惯化路径

### 1.3 诚实反馈环（Honest Feedback Loop）
- **适用场景**：设计奖励时的伦理检查
- **步骤**：问三个问题——
  1. 用户会因为这个机制变得更好吗（真实受益）
  2. 我自己会推荐/使用这个机制吗
  3. 这个机制是否在利用用户弱点（成瘾设计）
- **输出物**：机制伦理评估结论

## 二、决策规则（8条，标注章节）

1. **如果**使用频率低且感知效用低，**则**不做习惯养成机制，先提升核心价值（第1章 习惯区）
2. **如果**用户离开后没有触发物，**则**设计外部触发（推送/提醒），但注意频率合规（第2章 触发）
3. **如果**行为门槛高，**则**简化行动（减少步骤/预填/默认选项）（第3章 行动）
4. **如果**奖励固定不变，**则**用户会习惯化失效，改为多变奖励（第4章 多变奖励）
5. **如果**奖励与核心价值无关，**则**只是短期刺激，无法形成习惯（第4章 多变奖励）
6. **如果**用户没有在产品中投入，**则**设计投入机制（内容沉淀/社交关系/等级资产）（第5章 投入）
7. **如果**机制会让用户"更糟"，**则**重设计（诚实反馈环：用户受益才可持续）（第6章 什么不是习惯）
8. **如果**多变的奖励设计不当（赌博式），**则**有伦理风险，需克制（第6章 成瘾边界）

## 三、检查清单

- [ ] 触发是否明确（外部/内部触发分别是什么）
- [ ] 行动门槛是否最低（时间/金钱/体力/脑力/社会偏差五要素检查）
- [ ] 奖励是否多变（不是固定积分，有随机/惊喜成分）
- [ ] 投入是否沉淀（用户资产：内容/关系/等级/数据）
- [ ] 是否在"习惯区"（频率 × 感知效用）
- [ ] 诚实反馈环三问是否通过

## 四、反模式

- 固定奖励（每天签到给固定积分）——用户习惯化后失效
- 只为"让用户多来"而设计奖励，与核心价值脱钩
- 用恐惧/焦虑驱动（FOMO 滥用）形成负习惯
- 投入设计变成"绑架"（无法离开的沉没成本陷阱）
- 把 Hook 当万能：低频/低感知效用产品硬套习惯机制

## 五、边界声明（≥3条）

- Hook 模型适用于高频、有行为重复空间的产品（社交/内容/工具）；B2B/低频交易型产品（房产/保险）不适用
- 书中案例以美国消费互联网为主，中国语境（微信生态、推送规范）需适配
- 习惯养成≠成瘾：多变的奖励有操纵性风险，需伦理克制
- 作者立场：Nir Eyal 后续转向"不可分心"主题，对技术成瘾有反思，方法论本身有伦理张力
