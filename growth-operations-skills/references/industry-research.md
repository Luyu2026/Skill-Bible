# 增长运营 · 行业基本概念调研（Phase 1 产物）

> 调研时间：2026-09-29 · 方式：行业领域知识 + 公开资料交叉验证
> 服务于 growth-operations 套件的构建坐标系

## 1. 行业画像

增长运营（Growth Operations）是中国互联网公司中负责**用数据与方法论驱动用户规模与质量增长**的岗位。区别于用户运营（存量用户经营/分层维护）、活动运营（单次活动策划执行）、市场投放（品牌/采买流量），增长运营的核心职责是：**北极星指标拆解 → 增长实验设计与验证 → 渠道投放评估 → 激活/留存机制建设 → 数据诊断与归因**。与 product 团队协作定义功能优先级（增长视角输入），与 BI 团队协作取数与看板，与投放团队协作买量效率，通常是增长目标的 Owner。

## 2. 核心工作流（高频场景 7 个）

| # | 工作场景 | 产出物 |
|---|---|---|
| 1 | 增长目标拆解与北极星指标制定 | 指标体系 + 目标拆解树（一页纸） |
| 2 | 增长实验设计（A/B 测试） | 实验设计文档（假设/变量/指标/样本量） |
| 3 | 渠道投放评估与预算分配 | 渠道评估表 + 预算分配建议 |
| 4 | 激活路径优化（新用户 onboarding） | 激活漏斗诊断 + 优化方案 |
| 5 | 留存机制设计（习惯养成/召回） | 留存机制方案（钩子/奖励/触达） |
| 6 | 裂变传播设计（老带新/分享） | 裂变方案（机制/激励/合规检查） |
| 7 | 指标异常诊断与增长复盘 | 诊断报告 + 行动项（证据分级） |

## 3. 高频决策场景（4-5 类）

- **预算向哪个渠道倾斜** → 依据：渠道 ROI、边际成本、预算弹性、竞品投放强度
- **实验是否上线/放量** → 依据：统计显著性、效应量、风险/收益比、是否可回滚
- **功能先做哪个** → 依据：ICE/RICE 评分（影响×信心×易做/覆盖）
- **目标定多少** → 依据：历史基线与增速、预算资源、竞品对标，避免拍脑袋
- **是否规模化放大** → 依据：实验复测稳定、边际收益>边际成本、承接容量

## 4. 能力地图

- **增长战略与指标体系**：北极星、AARRR/RARRA、HEART
- **实验与数据分析**：A/B 测试、因果推断、SQL/BI 工具
- **用户生命周期运营**：拉新-激活-留存-召回-变现
- **渠道与投放**：买量、信息流、ASO、联盟
- **传播裂变机制**：老带新、拼团、权益设计、心理诱因
- **组织与协作**：跨部门推动、OKR 落地、增长文化

## 5. 中国语境特点

- **私域为王**：企微/社群/朋友圈承接公域流量，强调"可反复触达"，KOC 与内容种草是特色链路
- **裂变合规风险**：微信对诱导分享打击严厉，需防封号；《个人信息保护法》限制数据采集与精准营销
- **投放平台差异**：字节巨量/腾讯广告/快手磁力/小红书各有算法与素材逻辑，"素材疲软"周期短，买量+自然流混合归因
- **生态壁垒**：微信生态（小程序/视频号/公众号）闭环 vs 站外跳转限制；支付、社交关系链数据难打通
- **指标口径**：激活定义、新增归因（激活/注册/首单）各公司不统一，需先定口径再做跨期对比

## 给 Skill 化的提示

按「指标体系 → 实验方法 → 生命周期 → 裂变设计 → 诊断模板」五模块结构化沉淀，并为每模块附中国语境配置项（合规检查清单、微信生态注意事项），这套套件将明显区别于海外版通用增长模板。
