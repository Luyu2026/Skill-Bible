# Growth Operations Master

> 增长运营总控：分诊 → 路由 → 编排链路

## 适合什么场景

增长运营总控：判断用户此刻卡在增长运营的哪一环，路由到对应执行 Skill 或顾问团，编排跨步骤链路。

## 它解决什么

增长运营总控：分诊（判断类/产出类/链路类）→ 路由（单点路由表）→ 编排（预置链路），保证上一步产出是下一步合法输入。

## 一个重要机制

北极星先行 + 留存第一 + 实验验证 + 数据闭环。

## 怎么开始

直接说你的增长问题（目标/实验/激活/留存/渠道/诊断），我会路由到最合适的 Skill。

## 调用模板

```
增长没效果，帮我看看卡在哪
我要做一个增长实验
```
