# 《上瘾》· 留存习惯方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

> Hook 模型（触发→行动→多变奖励→投入）+ 习惯区判断，设计/诊断留存机制与习惯养成功能。

## 核心框架

### 1. Hook 模型（触发 → 行动 → 多变奖励 → 投入）
- **适用场景**：设计/诊断留存机制、习惯养成类功能
- **步骤**：
  1. 触发：外部触发（推送/短信/红点）引导进入；内部触发（情绪/场景）让用户自发想起
  2. 行动：降低行为门槛（时间/金钱/体力/脑力/社会偏差五要素）
  3. 多变奖励：奖励有随机性/变化（社交/猎物/自我三类奖赏），让用户期待未知
  4. 投入：让用户沉淀资产（内容/关系/数据/声誉），投入越多越不愿离开
- **输出物**：Hook 四步设计表

### 2. 习惯区判断（频率 × 感知效用）
- **适用场景**：判断产品是否值得做习惯养成机制
- **步骤**：评估使用频率与感知效用 → 高频+高感知效用才值得设计 Hook，否则换留存思路
- **输出物**：产品在频率×效用矩阵的位置 + 是否走习惯化路径

### 3. 诚实反馈环
- **适用场景**：奖励机制伦理检查
- **步骤**：三问——用户会变得更好吗 / 我会推荐吗 / 是否在利用用户弱点
- **输出物**：机制伦理评估结论

## 决策规则（8条）

1. 频率低且感知效用低 → 不做习惯机制，先提升核心价值
2. 用户离开后没有触发物 → 设计外部触发，注意频率合规
3. 行为门槛高 → 简化行动（减少步骤/预填/默认）
4. 奖励固定不变 → 用户习惯化失效，改多变奖励
5. 奖励与核心价值无关 → 只是短期刺激，无法形成习惯
6. 用户没有投入 → 设计投入机制（内容沉淀/关系/等级）
7. 机制让用户"更糟" → 重设计（用户受益才可持续）
8. 多变奖励设计不当（赌博式）→ 有伦理风险，需克制

## 检查清单

- [ ] 触发明确（外部/内部分别是什么）
- [ ] 行动门槛最低（五要素检查）
- [ ] 奖励多变（非固定积分，有随机/惊喜）
- [ ] 投入沉淀（内容/关系/等级/数据）
- [ ] 在"习惯区"（频率 × 感知效用）
- [ ] 诚实反馈环三问通过

## 反模式

- 固定奖励（每天签到固定积分）——习惯化后失效
- 只为"让用户多来"设计奖励，与核心价值脱钩
- 用恐惧/焦虑驱动（FOMO 滥用）形成负习惯
- 投入设计变"绑架"（沉没成本陷阱）
- 低频/低感知效用产品硬套习惯机制

## 边界声明（≥3条）

- 适用于高频、有行为重复空间的产品；B2B/低频交易型产品不适用
- 案例以美国消费互联网为主，中国语境（微信生态/推送规范）需适配
- 习惯养成≠成瘾：多变奖励有操纵性风险，需伦理克制
- 作者后续转向"不可分心"主题，方法论本身有伦理张力
