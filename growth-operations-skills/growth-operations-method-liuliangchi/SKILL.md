# 《流量池》· 中国增长方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

> 流量池思维（存量找增量/高频带高频）+ 品效合一 + 裂变营销 + 私域，中国语境下的增长与投放打法。

## 核心框架

### 1. 流量池思维（存量找增量，高频带高频）
- **适用场景**：增长策略制定（中国语境）、预算与渠道布局
- **步骤**：
  1. 建池：流量沉淀到自有可触达载体（APP/公众号/企微/社群/小程序）
  2. 存量找增量：盘活存量（唤醒/分层/会员），存量带来新用户
  3. 高频带高频：高频场景带动低频转化
  4. 反复触达：利用私域触达能力反复激活
- **输出物**：流量池布局方案

### 2. 品效合一（品牌 + 效果营销）
- **适用场景**：预算分配、投放策略（信息流语境）
- **步骤**：品牌（种草/认知）与效果（转化/收割）配合 → 效果投放附带品牌资产沉淀 → 用数据衡量"品"对"效"的贡献
- **输出物**：品效预算配比建议 + 衡量口径

### 3. 裂变营销（老带新/分享激励）
- **适用场景**：拉新活动设计（中国社交生态特色）
- **步骤**：
  1. 设计老带新机制（利益驱动：现金/权益；荣誉驱动：排名/勋章）
  2. 分享路径最短化（一键分享/海报/小程序卡片）
  3. 激励结构（阶梯/随机/即时到账）
  4. 合规检查（微信诱导分享打击严格，防封号）
- **输出物**：裂变方案（机制/激励/路径/合规检查）

## 决策规则（8条）

1. 流量只买不沉淀 → 建流量池（私有化可触达载体）
2. 存量用户沉默 → 先盘活存量（存量找增量成本低于拉新）
3. 产品低频 → 用高频场景/内容带动
4. 只投效果不做品牌 → 投放成本越买越高（品效割裂）
5. 设计裂变 → 利益机制"即时可见+随机惊喜"，固定小额激励效果差
6. 裂变涉及微信生态 → 先过合规检查（诱导分享/外链规则）
7. 投放素材超生命周期 → 更新素材（素材疲劳：周期短）
8. 私域用户未分层 → 先分层再触达（避免骚扰式群发）

## 检查清单

- [ ] 流量沉淀到自有池（APP/公众号/企微/社群）
- [ ] 存量有唤醒/分层机制
- [ ] 用高频场景带动低频转化
- [ ] 品牌与效果预算配比（品效合一）
- [ ] 裂变激励即时+随机，无合规风险
- [ ] 素材按生命周期管理
- [ ] 私域触达分层、频次合规

## 反模式

- 只买流量不建池（给平台交租金）
- 裂变设计成"诱导分享"（强制/利诱分享）→ 封号
- 群发式私域触达（不区分用户批量骚扰）
- 素材一条用到底（信息流素材疲劳）
- 只做效果收割不做品牌沉淀（长期成本上升）

## 边界声明（≥3条）

- 成书于 2018 年（瑞幸快速扩张背景），中国移动互联网语境，海外/其他平台需适配
- 瑞幸模式（烧钱补贴+快速扩张）有争议，激进打法不等于普适方法论
- 作者是瑞幸 CMO，存在立场偏差；部分案例是营销叙事而非实证
- 平台规则（微信/抖音）变化快，书中合规判断以当下官方规则为准
