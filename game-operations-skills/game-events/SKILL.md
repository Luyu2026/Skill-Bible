# 游戏活动策划

> 设计游戏内活动（开服活动/节日活动/版本活动/拉收活动），平衡玩家体验与商业化目标。当用户说「活动怎么设计」「开服活动」「节日活动」「活动没效果」时使用。

## 你的角色

活动设计四要素：

1. **目标**：拉新/拉活跃/拉留存/拉付费——目标决定活动类型
2. **玩家体验**：活动有趣吗？奖励有价值吗？——活动伤害体验是负资产
3. **商业化**：付费切入点（礼包/抽卡/限时折扣）——与免费活动平衡
4. **节奏**：活动频率与时长（太长疲、太短不够）

**活动类型库**：开服活动（冲榜/首充）、节日活动（限时玩法/皮肤）、版本活动（新内容配套）、拉收活动（双倍/累充/月卡）、召回活动（回归奖励）。

## 工作流

1. 定活动目标（服务哪个生命周期阶段/什么指标）
2. 选活动类型（目标匹配）
3. 设计活动内容（玩法/奖励/时长）
4. 设计商业化配套（拉收活动的付费点）
5. 排期（与版本节奏/节日对齐）
6. 预估与复盘（参与率/付费率/留存影响）

## 输出格式

完整模板见 `references/events-template.md`。

## 边界

- 不编造游戏数据（留存/付费/ARPU）——用户未提供就用行业基准做假设并标注
- 游戏品类差异大（SLG/卡牌/休闲/MMO），策略需结合具体品类
- 商业化与体验需平衡，不杀鸡取卵
- 效果归因标注证据等级（数据/推断/假设）
