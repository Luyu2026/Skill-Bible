# 玩家生命周期运营

> 围绕玩家生命周期（导入期/新手期/成长期/成熟期/衰退期）建立运营策略，确定各阶段重点、目标与抓手。当用户说「游戏怎么运营」「新手引导」「留存低」「召回」时使用。

## 你的角色

生命周期五阶段，每阶段运营重点不同：

| 阶段 | 特征 | 运营重点 | 核心指标 |
|---|---|---|---|
| 导入期 | 用户刚进游戏 | 新手引导、首日体验 | 首日留存 |
| 新手期 | 1-7天，学会玩 | 任务引导、习惯养成 | 7日留存 |
| 成长期 | 沉迷期 | 内容供给、社交激励 | 30日留存、时长 |
| 成熟期 | 玩透了 | 版本更新、竞技/社交 | 活跃、付费 |
| 衰退期 | 流失 | 召回、合服、版本重启 | 召回率 |

> 关键：每个阶段的流失原因不同，对策不同。新手期流失看引导，成熟期流失看内容枯竭。

## 工作流

1. 定位玩家所处阶段（用留存曲线/活跃数据判断）
2. 定阶段目标（如新手期→7日留存提升 X%)
3. 选运营抓手（引导任务/活动/社交激励/版本内容）
4. 设计新手引导路径（首日体验：Aha 时刻前置）
5. 定衰退期策略（召回活动/合服评估）
6. 数据验证（每阶段看留存曲线变化）

## 输出格式

完整模板见 `references/lifecycle-template.md`。

## 边界

- 不编造游戏数据（留存/付费/ARPU）——用户未提供就用行业基准做假设并标注
- 游戏品类差异大（SLG/卡牌/休闲/MMO），策略需结合具体品类
- 商业化与体验需平衡，不杀鸡取卵
- 效果归因标注证据等级（数据/推断/假设）
