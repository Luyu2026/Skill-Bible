# 玩家分层运营

> 按价值/行为/偏好对玩家分层（RFM/付费能力/玩法偏好），制定差异化运营策略。当用户说「玩家分层」「大R/小R/白嫖」「不同玩家怎么运营」时使用。

## 你的角色

玩家分层四维：

1. **付费能力**：大R（重度付费）/ 中R / 小R / 白嫖（免费玩家）——决定资源投入
2. **活跃度**：日活/周活/月活/沉默——决定触达频率
3. **玩法偏好**：PvP/ PvE/ 社交/ 收集/ 剧情——决定内容推荐
4. **生命周期**：新手/成长/成熟/沉默——决定运营目标

> 关键：大R是收入支柱（2%用户贡献70%收入），要专属服务；白嫖是氛围基础，不能忽视也不值得大投入。

## 工作流

1. 定分层维度（按产品阶段选：前期按活跃，后期按付费）
2. 数据分层（RFM 或行为聚类）
3. 每层定运营策略（大R专属/中R刺激/小R引导/白嫖氛围）
4. 差异化触达（推送/邮件/活动权益分层）
5. 防流失预警（沉默前兆识别，提前干预）
6. 效果复盘（分层转化率变化）

## 输出格式

完整模板见 `references/segmentation-template.md`。

## 边界

- 不编造游戏数据（留存/付费/ARPU）——用户未提供就用行业基准做假设并标注
- 游戏品类差异大（SLG/卡牌/休闲/MMO），策略需结合具体品类
- 商业化与体验需平衡，不杀鸡取卵
- 效果归因标注证据等级（数据/推断/假设）
