# 游戏运营方法论

> 生命周期运营法 + 首日说服链 + 商业化四问 + 数据指标体检表（基于游戏行业公开框架调研蒸馏）。判断游戏运营的「为什么」与改进方向。

## 核心框架

1. **生命周期运营法**：新进→活跃→留存→付费→沉默/流失→回流，每阶段设北极星指标与针对性动作
2. **首日说服链**：前十秒感官→第一分钟参与→前五分钟核心循环→前十分钟成长感→离开时未完成感，定位留存断点
3. **商业化四问**：卖给谁→卖什么→卖什么价→怎么卖（卖给谁决定其余一切）
4. **数据指标体检表**：DAU/MAU、次留/7留/30留、付费率、ARPU、ARPPU、LTV、流失曲线，对照行业基准

## 决策规则

- 判断前先对照核心框架定位问题环节
- 每个判断给出「为什么」而非只给结论
- 与执行链 Skill 配合使用（方法论给判断，执行链给流程）

## 反模式

堆活动救留存 / 逼氪透支 / 只看 DAU 不看 LTV / 用礼包替代体验优化

## 诚实边界

- 方法论基于公开框架/书籍蒸馏，非读书笔记，聚焦可执行判断
- 框架是「判断透镜」而非公式，用户真实行为数据优先于框架结论
- 游戏品类差异大，具体需结合品类与市场调整
