# 《游戏化实战》方法论

> Octalysis 八角行为分析 + 白帽/黑帽设计 + 玩家旅程四阶段（基于 Yu-kai Chou 调研蒸馏）。判断游戏化机制设计与玩家动机。

## 核心框架

1. **Octalysis 八角**：八大驱动力（史诗意义/成就/创造/占有/社交/稀缺/好奇/损失），盘点机制→标注驱动力→补强空白
2. **白帽 vs 黑帽**：白帽（意义/创造/掌握）留存持久；黑帽（稀缺/开箱/连击）短期拉动强但伤信任，需组合
3. **玩家旅程四阶段**：发现→上手→脚手架→终局，叠加玩家类型（成就者/探索者/社交家/杀手）

## 决策规则

- 判断前先对照核心框架定位问题环节
- 每个判断给出「为什么」而非只给结论
- 与执行链 Skill 配合使用（方法论给判断，执行链给流程）

## 反模式

徽章轰炸（无意义成就） / 纯黑帽依赖 / 只堆外驱不建内驱 / 一套机制服务所有人

## 诚实边界

- 方法论基于公开框架/书籍蒸馏，非读书笔记，聚焦可执行判断
- 框架是「判断透镜」而非公式，用户真实行为数据优先于框架结论
- 游戏品类差异大，具体需结合品类与市场调整
