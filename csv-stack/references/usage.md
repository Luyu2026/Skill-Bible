# 参数与数据语义

在 Skill 目录运行示例；输入和输出可以使用绝对路径。至少两个输入，输出父目录需存在。

| 参数 | 行为 |
|---|---|
| `--output` | 必填的新 CSV 路径；已有文件、软链接均不覆盖 |
| `--mode strict` | 默认；列集合相同，输出列序采用首文件 |
| `--mode union` | 按文件顺序扩展列集合，新列追加到末尾；缺列填空 |
| `--encoding gb18030` | 所有输入使用同一编码；默认 `utf-8-sig` |
| `--delimiter ';'` | 所有输入使用同一单字符分隔符；输出仍是逗号 CSV |
| `--source-column 来源文件` | 新增来源列名，必须不与任何输入列名重合 |

混合编码或分隔符应先按用户认可的方式转成独立副本，再合并；不要用错误替换字符进行有损转码。制表符分隔时通过参数数组传入实际 tab 字符。

JSON 统计打印到标准输出，包含 `total_rows`、`columns`、每个文件的 `rows`、`missing_columns` 和 `blank_lines_skipped`。错误写入标准错误，退出码 2；成功退出码 0。统计只用于本次交付，不自动存档或上传。

空物理记录会跳过并计数；`""` 或逗号组成的空值记录是数据，按列宽验证后保留。数字、日期、科学计数法、公式样文本、重复行都原样保留为字符串；引号和换行的 CSV 序列化形式可能变化。

脚本按行处理数据，内存主要取决于表头和单条记录。沿用 Python CSV 单字段大小上限，超限会报错；不宣称支持无限大小单元格。输出先暂存于目标文件系统，全部输入验证通过后使用硬链接排他发布，避免截断旧文件；不支持硬链接的目标文件系统会失败，可改用本地磁盘目录。普通失败会清理暂存文件；进程被强制终止可能留下 `.csv-stack-` 临时文件，不能把它作为结果。

只读取用户提供的静态导出；处理过程中会检查文件大小、修改时间和文件标识是否变化，这不是对恶意并发修改的安全保证。
