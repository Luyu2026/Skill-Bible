# 人生奥德赛计划

基于斯坦福奥德赛计划，帮你在职业迷茫、转行冲动、想创业或不知道下一步该往哪里走时，设计三条可信的人生路径，并把选择落成一个可逆的 90 天实验。

它适合这样的场景：你不是缺一句“勇敢一点”的鼓励，而是需要在工作、兴趣、收入、家庭、城市和风险之间，真正看清自己有哪些选择；也适合“如果我不改变现状会怎样”“如果现在的工作没了，我还能做什么”“钱不是问题时我会怎么安排人生”这些问题。

## 它怎么工作

1. 先把你已经拥有的资源、正在承受的限制和仍不确定的事实分开。
2. 生成三条真正不同的路线：深耕已有方向、保留跑道建设长期资产，或重构身份与能力用途。
3. 对每条路线同时写出收益、代价、失败方式、退出条件与必须成立的假设。
4. 额外推演“把当前路径做到极致”和“当前职位消失后还能带走什么”。
5. 最后只选择一个能产生新信息、成本可控的 90 天实验，而不是催你立刻裸辞或全押。

## 第一次使用

直接把这段发给 Agent：

```text
请使用 life-odyssey-planner 帮我做一次人生奥德赛计划。

我现在的工作和生活：
我喜欢 / 厌倦的部分：
我已有的能力、作品或关系：
我的现实约束（收入、家庭、城市、健康、时间）：
我想增加 / 减少的东西：
未来一年最不能承受的风险：

请不要预测我的人生，也不要建议我冲动辞职。
请基于真实信息给出三条明显不同但现实可行的路径，写清每条的代价、失败方式和反转条件；最后只设计一个可逆的 90 天实验。
```

## 它不会做什么

- 不把五年后的收入、职位、粉丝或幸福感伪装成准确预测。
- 不把稳定工作、创业、转行写成高低之分。
- 不把情绪高峰时的冲动，直接翻译成辞职、借贷或不可逆承诺。
- 不替代心理、医疗、法律或高杠杆财务决策的专业意见。
