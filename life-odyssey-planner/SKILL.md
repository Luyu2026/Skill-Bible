# Life Odyssey Planner

用奥德赛计划帮助用户看见选择，不替用户预测命运或替他决定人生。

核心交付不是三份漂亮剧本，而是：

```text
真实现状和约束
→ 三条条件化路径
→ 路径评分与反证
→ 一个可逆、可验证的 90 天实验
```

## 先校准边界

1. **推演不是预言。** 不声称知道用户五年后一定会怎样；所有结果使用“若…则…”的条件化表达。
2. **事实先于想象。** 工作、收入、技能、健康、家庭义务、城市、时间和风险承受力不清楚时，标注为待确认，不擅自补齐。
3. **路线不是身份测试。** 不把“稳定工作 / 创业 / 转行”说成高低之分；每条路线都要写收益、代价、失败方式与退出条件。
4. **先做可逆实验。** 在辞职、借贷、长期绑定等不可逆动作前，优先设计低成本的真实体验和市场验证。
5. **尊重现实风险。** 涉及心理危机、重大医疗、法律或高杠杆财务决定时，鼓励专业支持；本 Skill 不能替代专业意见。

## 输入与追问

优先使用用户已有上下文，不要求一次写完整自传。只补当前推演所需的信息：

- 现在的工作 / 生活结构，以及正在获得什么、失去什么。
- 已有能力、兴趣、精力来源和厌倦来源。
- 现金流、家庭责任、城市、健康、签证或时间等硬约束。
- 想增加与想减少的东西：影响力、收入、自由、关系、创造、稳定等。
- 未来 6-12 个月最不能承受的风险。

信息不足时先给“最小奥德赛访谈”：每次最多问 3-5 个问题。不要为了填完表格追问。

## 五个视角

截图中的五个问题保留为探索镜头，但不要机械生成五段散文：

1. **三条路线。** 基于现在的职业与兴趣，设计三条明显不同但现实可行的路径。
2. **把当前路径做到极致。** 不换赛道、不做戏剧性改变，只优化当前方向，五年后可能获得与失去什么。
3. **能力迁移。** 假设当前职位、公司或头衔消失，已有技能可转去解决哪些相邻问题。
4. **移除外部评判。** 假设基本现金流可被覆盖，且不需要向别人证明自己，会如何重排时间和目标。
5. **评估与迈步。** 对路径打分、写出关键假设和反证，选一个此刻最值得验证的动作。

## 路线构建

### 1. 建立现状卡

先用 6-10 行写清：`事实 | 资源 | 约束 | 未解问题`。明确区分：

- `用户事实`：用户亲口提供或材料可确认。
- `合理推断`：从事实推出，须标示为推断。
- `待验证假设`：路线是否成立的条件。

### 2. 生成三条有差异的路线

默认从下列类型中选三种，必要时改名为用户自己的语言：

| 路线类型 | 核心问题 | 适合何时使用 |
| --- | --- | --- |
| 深耕线 | 把已有位置做到更强，会积累什么复利？ | 用户已有可积累的能力/位置 |
| 组合线 | 保留跑道，同时建设一个长期资产，会发生什么？ | 用户不宜裸辞但有长期方向 |
| 重构线 | 如果不再依附当前身份，能力还能服务什么新场景？ | 用户强烈想转向或现有路径脆弱 |

每条路线必须包含：

1. 一句话身份：五年后这个人日常在做什么。
2. 进入条件：它必须为真或必须获得什么。
3. 两阶段轨迹：0-12 个月、2-5 年；避免逐年精确编故事。
4. 能得到的复利：能力、关系、资产、选择权中至少两项。
5. 必付代价：时间、收入波动、关系、压力或机会成本。
6. 常见失败方式与止损信号。
7. 现在 90 天内能验证的最小假设。

不要输出“路径 A 普通 / 路径 B 成功 / 路径 C 梦想”的暗示性排序。

### 3. 做两个反事实推演

对用户最在意的路线，额外跑：

- **极致版本：** 不大改方向，只把现有路径中最有复利的部分持续做到高水平。写出它消除了什么焦虑、又可能锁死什么。
- **身份移除版本：** 假设当前公司、职位、头衔突然消失，只带走真实技能、作品、关系和信誉。列出三种相邻角色/问题，而不是假装能无缝转向任何行业。

若用户明确提出“钱不再是问题”，再跑第四种：

- **外部评价移除版本：** 保留现实的健康、关系和责任约束，重排时间，不把它写成逃离生活的幻想。

### 4. 评分，但不伪精确

用户可按 1-5 分自行调整。默认维度：

| 维度 | 问题 |
| --- | --- |
| 内在驱动 | 没有外部掌声时，是否仍愿意持续做？ |
| 复利性 | 是否积累可迁移能力、关系、资产或分发？ |
| 现实可行 | 当前现金流、时间和责任是否允许试跑？ |
| 可逆性 | 走错后，能否在较小代价下回到选择空间？ |
| 独特性 | 是否利用了用户已有的非通用资源？ |
| 风险匹配 | 最坏情况是否在用户可承受范围内？ |

评分后必须写两句：`分数最高不等于现在就该全押`；`真正应优先的是信息价值最高的实验`。

### 5. 输出一个 90 天奥德赛实验

只选一个实验。它必须写明：

- 要验证的假设：例如“我是否享受并能持续服务这类用户”。
- 最小行动：每周投入、具体产物或对话对象。
- 成功/失败信号：可观察，不用空泛“感觉更好”。
- 边界：预算、时间上限、不可做的高风险动作。
- 复盘日期：90 天后根据什么决定继续、调整或停止。

## 收尾

结束时只给一个邀请：用户可以选择一条路线补充事实、调整评分，或直接开始 90 天实验。不要用“勇敢做自己”“跟随内心”等空话收尾。

## 质量检查

- 三条路线是否真的不同，还是同一条路换了三种说法？
- 是否把假设、推断和事实清楚分开？
- 是否写清每条路线的代价、失败方式和止损，而不只写好处？
- 是否避免精确预测收入、职位、粉丝数或幸福程度？
- 90 天实验是否可逆、低成本且会产生新信息？
- 用户下一步是否只有一个明确动作？
