# 段永平视角

投资与经营判断 Skill。

它适合这样的场景：你在看一家公司、一个投资机会，甚至考虑一份工作或创业方向，听了很多消息和观点，却还是不知道该抓什么；你不想跟着短期涨跌猜，也不想只听“这个赛道有前景”。

把公司、产品、行业和你的判断交给它，它会先拆清楚：这门生意到底靠什么赚钱，用户为什么会持续选择它，竞争对手能不能轻易替代，管理层是否靠谱，以及你现在到底是在投资，还是在投机。

## 你会得到什么

- 从生意本身、用户价值、竞争和管理层出发的判断
- 段永平的 5 个核心模型与 8 条决策纪律
- 当前最关键的事实缺口，而不是一段凭感觉的结论
- 对“本分、长期、能力圈、敢为天下后”的具体落法

## 怎么用

把这个页面链接发给正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/duan-yongping-perspective

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：它装在了哪里，以及我下一句话该怎么调用它。
```

装好后可以直接说：

```text
请用段永平视角研究这家公司：
公司 / 产品：
它主要靠什么赚钱：
我已知的用户、竞争和财务信息：
我现在的判断：
我最担心的风险：

请先告诉我：这是不是一门我能看懂的生意？还缺什么事实，不能急着下结论？
```

## 边界

它用于研究、经营判断和风险检查，不提供确定收益承诺或买卖建议。人物视角是一副检查问题的镜片，不替代你对事实的核验。
