# 一天行动重整

## 它适合什么场景

把混乱目标、积压事项和当天时间约束变成一份能开始执行的当天行动表；适用于“想一天重塑人生”“事情太多不知道先做什么”“今天想重新开始”的场景。

从一份已经有的材料开始即可，不需要先学一套方法。

## 它解决什么

普通聊天容易给宏大自律清单；这里把用户现有事项收敛为当天可以启动、完成并复盘的一次改变。

它会先处理你当前卡住的一件事，再给能直接使用的结果。

## 一个重要机制

区分当天能改变的行动与需要长期积累的结果，不承诺一天改变人生。

先保住刚性责任，再安排能解除主要阻塞的一件事。

这个区分会影响先做什么，以及最后交付哪一种结果。

## 你会拿到什么

- 一个当天主目标及明确完成物。
- 覆盖剩余时间的行动表、必要维护和暂缓清单。
- 一个缩小版本及被打断后的重启动作。
- 当天结束交回完成物与实际阻碍，才据此安排后续。

## 怎么开始

1. 发来你已有的原文、记录或草稿。
2. 说明现在希望解决的卡点和本轮目标。
3. 写出会影响处理的时间、渠道或方法限制。
4. 收到结果后直接使用；有新反馈时带回原话或实际产物。

不必补齐所有背景；会先使用已有材料，只有关键缺口才追问。

## 可直接复制的调用模板

```text
请使用 one-day-reset-plan 帮我完成这次任务。
我已有的材料：
（在这里粘贴原文、草稿或提供可访问文件）

我现在最卡的是：
（描述具体问题）

本轮希望拿到：
（说明成品形式和长度）

需要遵守的限制：
（时间、渠道、边界或可用方法）

请先使用现有材料，区分事实与待确认信息，给可直接用的结果和下一步。
```
