# 一天行动重整

## 它适合什么场景

今天事情很多，想重新开始，却不知道剩下几个小时先做哪一件。

适合已有待办、固定安排和现实截止时间，希望今天能有一个可见结果。

## 它解决什么

把混乱清单收成当天行动表，保住刚性责任，再推动一个主要卡点。

“重整”落实为今天能交出的东西，不承诺一天改完人生。

## 一个重要机制

先算时间，再定范围。

会议、照护、休息与转换都会占用真实时间；装不下时缩减任务。

同时准备一个被打断后仍有用的最低版本。

## 你会拿到什么

- 一个主目标与可检查完成物。
- 剩余时间内的任务安排。
- 必要维护和明确暂缓的事项。
- 最低版本、重启动作与收工检查。

## 怎么开始

1. 发杂乱待办即可，无需先分类。
2. 写当前时间、收工时间与不能挪动的安排。
3. 说明真实截止及今天的精力。
4. 做第一个动作，收工交回产物与阻碍。

[查看模拟下午计划及被打断后的重排](references/delivery-example.md)。

## 可直接复制的调用模板

```text
请使用 one-day-reset-plan。

现在14:00，18:00收工，16:00—17:00开会。
待办：会上要讨论的一页提案、清理桌面、学英语。
精力：一般；资料已有，但没起草。
今天必须交：会议前的可讨论提案。
请给能装进时间的安排、暂缓项和被打断后的最低版。
不要替我创建提醒，先给现在能做的第一动作。
```
