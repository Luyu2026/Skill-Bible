# 内容计划模板

本文件是 operations-content-strategy 的参考模板。生成内容计划时按此结构输出，每个章节的说明文字是写作指引（不要原样复制到最终文档里），根据实际需求填充内容。

---

## 文档头部

```markdown
# [账号名] 内容计划（[周期]）

日期：（当天）
```

---

## 一、定位概述

**作用**：写清楚账号是干什么的，后续所有选题围绕它。

```markdown
## 一、定位概述
- **服务人群**：（给谁看）
- **解决什么**：（用户为什么关注）
- **差异化**：（和同类账号的区别）
- **内容形态**：（图文/短视频/直播/社群 + 频次 + 风格）
```

## 二、用户需求清单

**作用**：选题依据，避免自嗨。每条附来源。

```markdown
## 二、用户需求清单
| # | 用户需求 | 来源 | 证据强度 |
|---|---------|------|---------|
| 1 | 如何快速上手 XX | 评论/私信高频问题 | 一手 |
| 2 | XX 的坑与避雷 | 搜索热词 | 二手 |
| 3 | ... | 行业热点 | 通用 |
```

## 三、选题清单（按矩阵分类）

**作用**：主体产出。四类选题占比约 干货40% / 观点25% / 故事20% / 互动15%。

```markdown
## 三、选题清单
| 类型 | 选题 | 核心观点 | 素材 | 形式 | 状态 |
|------|------|---------|------|------|------|
| 干货 | ... | ... | ... | 图文 | 待写 |
| 观点 | ... | ... | ... | 短视频 | 待写 |
| 故事 | ... | ... | ... | 图文 | 撰写中 |
| 互动 | ... | ... | ... | 投票 | 待发 |
```

**选题四问**（每条候选过四问才收录）：
1. 用户在乎吗？
2. 我讲得了吗？（有素材/能力/独到观点）
3. 现在发合适吗？（时效/节点）
4. 能落地吗？（有明确产出形式和时间）

## 四、发布排期

**作用**：把选题落到日历，可协作。

```markdown
## 四、发布排期
| 日期 | 选题 | 渠道 | 形式 | 备注（节点/联动） |
|------|------|------|------|------------------|
| 7/1 | ... | 公众号 | 图文 | 配合月度活动 |
| 7/3 | ... | 视频号 | 短视频 | ... |
```

## 五、数据反馈闭环

**作用**：发布后看什么、怎么迭代。让内容不是发完就完。

```markdown
## 五、数据反馈闭环
**发布后 1-2 周看**：
- 打开率/完播率 / 互动（赞藏评转）/ 涨粉 / 引流转化

**迭代规则**：
- 哪类选题数据好 → 加量同类
- 哪类差 → 换方向或调整形式
- 每月复盘一次，按数据更新选题矩阵
```

## 六、风险与假设

```markdown
## 六、风险与假设
- [ ] 假设1：（如"目标用户活跃在晚上"）验证方式：（发布时间 A/B）
- [ ] 资源约束：（设计/拍摄/审核排期）
```
