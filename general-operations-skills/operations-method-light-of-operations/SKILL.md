# 《运营之光》· 运营判断框架

> 核心立场：运营是帮助产品与用户建立并维系关系的一切干预手段。**先创造价值，再谈回报。**

## 核心框架一：做局与破局（第 2 章 2.4）

**适用场景**：设计一场活动、一个增长机制、一个社区冷启动，或任何"让多方角色互相受益"的复杂目标。

**步骤**：
1. 界定目标：明确这个"局"要达成的核心结果
2. 画要素：识别局中的人（角色）、事、场景、价值交换关系
3. 设计价值链：让每个角色都"各取所需"，形成正向循环
4. 找破局点：局太大时不追求一步到位，找出一个最小可撬动的"破局点"
5. 先做足一件事：把破局点做到极致，撬动其他元素连锁运转
6. 滚动放大：局运转后持续补位、扩容

**输出物**：局的要素/价值关系图、破局点清单、分步行动计划。

## 核心框架二：4 个关键性运营思维（第 2 章 2.6）

**适用场景**：拿到任何运营问题/指标时的思考起点，四者递进。

| 思维 | 核心动作 | 输出 |
|------|---------|------|
| 流程化思维 | 界定目标 → 梳理全流程与环节 → 找干预点 | 流程拆解图 |
| 精细化思维 | 把大问题拆成可执行细节，用 SOP/清单建立掌控 | SOP 表 |
| 杠杆化思维 | 先做好做足一件事，以此为杠杆撬动更多 | 杠杆点清单 |
| 生态化思维 | 梳理各角色价值关系，让所有角色互为价值、自生长 | 生态价值关系图 |

## 核心框架三：运营第一公式——流量-变现闭环（3.0 第 4 章）

**适用场景**：建立或诊断一款产品的运营主轴。

**步骤**：
1. 明确商业逻辑（直接售卖 / 免费+增值 / 免费+流量变现）
2. 判断用户行为频次（一次性 / 中低频 / 高频）
3. 选流量渠道获取流量 → 承接转化 → 私域蓄水 → 复购/传播
4. 找到并守护"最关键用户行为"的发生几率
5. 开源节流固定化 + 核心用户维系 + 阶段性活动拉动

## 决策规则（10 条，标注来源章节）

1. 产品处于早期（探索期）**不应追求增长甚至爆红**——那会加速死亡；应围绕口碑运营。（第 4 章 4.1 规律二、三）
2. 用户使用频次**一次性** → 重获客渠道+销售转化+高客单；**中低频** → 占搜索/商店入口+品牌认知；**高频** → 培养习惯+打通分享做病毒增长。（第 4 章 4.3）
3. 投放任何内容/请求转发前，**先自问"这东西对对方有没有价值"**，没有就先把它变得有价值再发。（第 2 章 2.2）
4. 拿到运营指标，按"拆解目标→盘点来源构成→识别高转化渠道→聚焦投入"推进，让 70% 以上可知可控。（第 3 章 3.1）
5. 做内容**必须先定定位与调性**，否则建立用户认知的成本越来越高；选题决定一篇内容 60% 命运。（第 3 章 3.3）
6. PGC 内容体系**常规保底 + 爆款突破**：平时 60-70 分，每 1-2 周放出一篇 90 分以上。（第 3 章 3.3.3）
7. 撬动用户互动，从 8 个原则组合：物质激励、概率事件、稀缺感、竞争意识、炫耀/猎奇、强烈情绪、尊崇感、对比超值感。（第 3 章 3.8）
8. 成熟产品运营体系依次保证：基础业务顺畅 → 开源节流固定化 → 关键用户行为几率 → 核心用户维系 → 活动拉动。（第 4 章 4.4）
9. 社区从 0 到 1 按：创建初始化 → 信任与价值确立 → 去中心化 → 自生长（划边界定规则）。（第 4 章 4.5）
10. 用户运营核心覆盖：开源（拉新）、节流（减流失）、维持（活跃留存）、转付费；大规模靠成长路径+分级+激励+激活。（第 3 章 3.6）

## 检查清单 A：成熟产品运营体系自检

- [ ] 主业务流程已梳理，基础业务顺畅运转？
- [ ] "开源"有稳定增长来源，"节流"有流失节点梳理+干预手段？
- [ ] 已界定"最关键用户行为"，有新手引导保障其发生几率？
- [ ] 核心用户已界定，有专属维系机制？
- [ ] 有阶段性活动/事件/营销计划？

## 检查清单 B：内容运营自检

- [ ] 定位与调性明确且有差异化？
- [ ] 内容生产通路顺畅（UGC 激励 或 PGC 任务分解）？
- [ ] 内容组织四层到位：单篇标准/相关聚合/导览索引/拳头内容？
- [ ] 内容已"流通"起来，能被用户发现消费？
- [ ] 常规保底 + 每 1-2 周一篇爆款，持续执行？

## 反模式

- 只打杂不思考（80% 运营停留在执行层，从不复盘哪些产出高）
- 短视线性思维（只盯单一结果指标，不关注层次感）
- 早期追爆红/盲目增长（未验证就疯狂拉新，加速死亡）
- "标题党"与"段子手"式内容（无可持续价值与体系）
- 只消费用户价值不创造价值（透支信任破坏长期关系）

## 边界声明

- 1.0/2.0（2016-2017）方法论建立在公众号红利、应用商店语境上，具体渠道打法已过时；**引用优先标注 3.0 版本**（2022 已更新短视频/直播/私域）
- 主干面向 2C 互联网产品（内容/社区/电商/工具/平台）；2B、传统行业需自行迁移
- 作者是三节课联合创始人，案例隐含个人经验与公司立场
- 多数规则是启发式判断（"70% 可控""60 分保底"），非精确算法
- 反模式"早期勿爆红"不普适：纯流量生意、快消品、短期 campaign 快速起量可能是正确策略
