# operations-user-segmentation

## 它适合什么场景

用户分层与触达策略：分层差异化运营，资源向高价值用户倾斜。
它是「运营」Skill 库执行链的一环。

## 它解决什么

它把「每次都要从头想一遍」的运营工作沉淀成固定流程：输入你的材料，按内置判断和工作流拆解，交付可直接使用的产物（报告、方案、清单），不虚构数据、不替你拍板。

## 一个重要机制

本 Skill 遵循运营 Skill 库规范：默认使用你提供的材料与数据；信息不足时先问或标注 **[待确认]**，不编造。产出物可直接用于实际工作（汇报、评审、执行）。

## 你会拿到什么

- 结构化交付物（具体格式见 SKILL.md「输出格式」章节）
- 基于你提供的真实材料，证据分级标注（A 数据支持 / B 强推断 / C 推测）
- 信息不足时降级输出框架 + 待补清单，不硬凑结论

## 怎么开始

```text
请调用 operations-user-segmentation，帮我处理下面这件事：
（粘贴你的问题、材料或数据）
```

## 边界

- 不编造数据：缺信息会先问或标注 **[待确认]**
- 复杂问题建议先用 `operations-master` 判断当前最该推进哪一步
- 判断类问题（该不该做、怎么选）转 `operations-advisory-board` 顾问团
