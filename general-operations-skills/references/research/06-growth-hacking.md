# 《增长黑客》（Hacking Growth）——综合/通用运营实操方法论

> 提炼对象：Sean Ellis & Morgan Brown《Hacking Growth》(2017)；中文参考范冰《增长黑客》。定位：判断框架，非读书笔记。

## 1. 书籍概述
Sean Ellis/Morgan Brown《Hacking Growth》（范冰中文版同名）：主张增长不是单点爆款技巧，而是制度化的数据驱动体系——组增长团队、定北极星指标、跑"分析→想法→排优→测试→复盘"高频实验循环，在用户生命周期各环节持续系统性优化。

## 2. 核心框架（3 个）

### 框架 A：增长黑客实验循环（Growth Hacking Loop）
- **适用场景**：产品已过 PMF 验证、留存达竞品基线后追求可持续增长；也适用于任何运营环节的持续优化。
- **步骤**：① 分析（定量漏斗/群组/留存分析 + 定性用户调研，定位薄弱环节）→ ② 提想法（跨职能头脑风暴，多多益善并存库）→ ③ 排优（ICE：影响 Impact × 信心 Confidence × 易做 Ease 打分排序）→ ④ 快节奏测试（A/B，一次只改一个变量）→ ⑤ 度量复盘（记录假设、结果、干扰因素、结论）→ 回到 ①，形成闭环。"缓慢起步，逐渐提速"。
- **输出物**：实验想法库、ICE 评分表、实验记录模板（名称/描述/类型/受影响特征/关键指标/时间/假设与结果/干扰因素/结论）。

### 框架 B：北极星指标（North Star Metric）
- **适用场景**：团队目标分散、指标打架、跨职能协同时；确立唯一增长方向的锚点。
- **步骤**：① 选一个能代表"用户获得核心价值"的单一指标（如付费订阅数、周活跃用户）→ ② 拆成增长等式/增长模型（如 DAU = 新增活跃 + 老用户活跃 + 流失召回）→ ③ 配套关键指标看板（定量）+ 用户心理决策地图（定性）→ ④ 定期复核是否仍代表价值。
- **输出物**：增长等式、指标看板、北极星指标说明书（含选择理由与排除项）。

### 框架 C：AARRR 用户生命周期漏斗（海盗模型，Dave McClure 2008）
- **适用场景**：定位增长瓶颈在哪个环节；按阶段分配资源；获客-激活-留存-变现-推荐全链路。
- **步骤**：① 各环节建立漏斗与基线 → ② 与同类最高/竞品基线对比 → ③ 群组分析下钻找差异原因 → ④ 定位杠杆点 → ⑤ 用框架 A 实验优化。
- **关键要点**：获客 = 语言-市场匹配 + 渠道-产品匹配，且 LTV > CAC 才放量；激活 = 引导"啊哈时刻（Aha moment）"，公式 转化 = 触发物 + 欲望 − 摩擦；留存分初期（激活延伸）/中期（养成习惯）/长期（重新认识价值）三阶段策略；变现 = 绘制用户旅程盈利点与阻碍点、优化定价与套餐；推荐 = 病毒系数 K = 邀请数 × 受邀接受率。
- **输出物**：分环节漏斗基线表、留存曲线、群组分析报告、K 因子测算、盈利点旅程图。

## 3. 决策规则（8 条）
1. **如果**产品尚未验证"不可或缺性"（PMF）——**则**不烧钱获客，先做用户调研（"明天不能用有多失望"问卷 + 访谈）并与竞品留存对比，改进产品至留存达竞争基线（来源：《Hacking Growth》第2章 产品-市场契合）。
2. **如果**团队对增长目标各说各话、指标打架——**则**先定单一北极星指标并拆成增长等式、上线看板，再谈任何实验（来源：第4章 北极星指标）。
3. **如果**实验想法过多——**则**用 ICE（影响×信心×易做）打分排序，优先执行"高影响+高信心+易实现"批次，每轮只做 1-3 个（来源：第5章 排优机制）。
4. **如果**新用户激活率低——**则**优先减摩擦（精简注册字段、修 bug、简化 on-boarding）而非加功能，并设计直通"啊哈时刻"的引导路径（来源：第7章 激活；转化 = 欲望 − 摩擦）。
5. **如果**某获客渠道 ROI 不明——**则**不加大投放，先小预算多渠道路测做渠道-产品匹配，确认 LTV > CAC 再放量（来源：第6章 获客）。
6. **如果**中期/长期留存下滑——**则**从"养成习惯"入手：调优触发物频率与奖励设计（借鉴上瘾模型），并周期性推出新功能让用户重新体验价值（来源：第8章 留存，P222-231）。
7. **如果**实验结果无法沉淀复用——**则**强制按固定模板记录假设/结果/干扰因素/结论，回写想法库作为下一轮输入（来源：第5章 度量环节）。
8. **如果**要做推荐/裂变——**则**先确认产品价值体验到位，算出病毒系数 K，再以实验调优邀请话术与数量（参考 LinkedIn 邀请数测试：2→4 条最优、6 条起用户冷淡）（来源：第6/9章，P137-154）。

## 4. 检查清单

**启动前**
- [ ] 不可或缺性已验证（问卷 + 竞品留存对比）？
- [ ] 有单一北极星指标并拆成增长等式？
- [ ] 有跨职能增长小组与固定实验节奏（如每周一轮）？
- [ ] 埋点/看板能支撑分环节漏斗与群组分析？

**每轮实验**
- [ ] 基于数据分析定位环节，而非拍脑袋？
- [ ] 假设清晰："改变 X → 影响 Y 指标"？
- [ ] ICE 排序后只做优先级最高的 1-3 个？
- [ ] 控制变量：一次一变量、样本量与时长足够？
- [ ] 按模板记录名称/类型/关键指标/假设/结果/干扰因素/结论？
- [ ] 结果回写想法库或更新基线，形成下一轮输入？

**按漏斗逐环节**
- [ ] 获客：LTV > CAC？语言-市场、渠道-产品匹配做过实验？
- [ ] 激活：几分钟内到达"啊哈时刻"？摩擦清单（注册、验证码、引导步骤）过一遍？
- [ ] 留存：留存曲线对比竞品基线，按群组下钻找流失原因？
- [ ] 变现：用户旅程盈利点与阻碍点图完成？定价/套餐/页面做过实验？
- [ ] 推荐：K 值算过？邀请刺激是否已过边际（邀请量递增后转化回落）？

## 5. 反模式
1. **无 PMF 硬砸钱获客**：留不住人的产品加大投放，漏斗漏得比进的快，钱打水漂。
2. **把增长黑客当一次性"爆点技巧"**而非制度化实验体系，做完一个活动就停，无法积累能力——正确姿势是"缓慢起步、逐渐提速"的持续循环。
3. **虚荣指标当北极星**：以注册量、下载量、曝光代替激活与留存，团队被错误指标带偏，做出"假增长"。
4. **实验无沉淀 + 触发物骚扰**：每轮实验不记录不复盘，同样的坑反复踩；推送/红包过度，触发物从助推变成摩擦，反噬留存。

## 6. 边界声明
1. **语境差异**：原书是美国 SaaS/科技公司语境（2017），默认具备工程/数据团队与 A/B 测试基础设施、容忍较高试错成本；中国运营语境更依赖渠道投放、补贴、社群与平台规则（微信生态），**循环方法论适用、案例不直接照搬**。
2. **前提假设**：方法论默认产品已过 PMF 验证；处于需求验证期的产品应先走精益/访谈路线，增长循环不是万能药。
3. **小团队/低频业务适用性**：单人可跑简化版（自己列想法 + ICE + 最小实验）；但高客单 B2B、低频场景样本量小、周期长，A/B 不现实，应以群组分析 + 定性调研替代。
4. **时效与合规**：裂变、K 因子等技巧依赖特定渠道红利窗口，用前需验证当前环境；欧美 GDPR / 中国个保法下数据实验须合规，埋点与用户数据使用受限。
