# operations-advisory-board

## 它适合什么场景

运营顾问团总控：路由到专家/方法论，或召开多专家评审会输出共识/分歧/综合结论。
它是「运营」Skill 库顾问团的一环。

## 它解决什么

运营里很多问题不是"怎么做"，而是"怎么判断"——这个动作值不值得做、该看什么指标、增长实验怎么设计。本 Skill 把一位专家/一本书的认知框架沉淀成可调用的判断工具，让资深视角随时可用。

## 一个重要机制

它蒸馏的是 HOW（怎么想、怎么判断），不是 WHAT（说了什么）。每个判断都带来源证据和局限说明，只给"视角快照"，不冒充真人。

## 你会拿到什么

- 基于该视角的分析与判断（含心智模型应用、决策启发式）
- 条件化结论——告诉你在什么条件下该怎么做，不替你拍板
- 诚实边界——这个视角做不到什么，明确标注

## 怎么开始

```text
请调用 operations-advisory-board，用这个视角看看：
（粘贴你的问题、方案或数据）
```

## 边界

- 蒸馏自公开信息，是"视角快照"不是真人代言
- 信息截止到调研时间点（见 SKILL.md 调研时间戳）
- 复杂问题建议先用 `operations-master` 或 `operations-advisory-board` 判断该找谁
