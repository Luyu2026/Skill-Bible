# 口播配音制作

## 它适合什么场景

短视频、课程或产品介绍已有文案，想做成自然口播。

## 它解决什么

把容易错读的文字变成可试音、可核对、可交接的制作包。

## 一个重要机制

先试最容易出错的一小段，再生成全稿。

脚本、估时、实测和音频状态分别标明。

没有语音工具时仍能拿到可导入稿，但不会显示虚构下载链接。

## 你会拿到什么

- 可粘贴到语音工具的口播纯文本。
- 独立的发音表和段落导演表。
- 短段试音方案与两版参数差异。
- 工具可用时的真实音频及检查记录；否则为明确未渲染制作包。

## 怎么开始

发原文案、用途、语言、希望的情绪和目标时长。

有工具时说明名称及导出规格；专名请提供确认读法。

需要真人音色时说明相应授权与允许用途，也可选择普通合成声音。

修改反馈写段号、原词和期望读法，便于只重做问题段。

## 可直接复制的调用模板

```text
请使用 voiceover-production-kit。
原稿：今天教你用AI整理3条笔记。
用途：短视频；普通话，轻快自然，10秒以内。
当前无音频工具，AI按英文字母读。
请给纯文本、发音表、两版试音指令，并区分估时和实测。
```

如材料缺失，请先交付能完成的部分，并明确当前未完成的内容。
