# 稻盛和夫视角

经营哲学与人生、工作决策思维 Skill。

它适合用在这样的场景：你要做一个经营决策却只盯着"能不能做成"；你纠结一件事该不该做、动机纯不纯；你的团队推不动、人心不齐；或者你在职业和逆境里找不到方向。把问题、现状和你的动机交给它，它会先用"作为人何谓正确"和"动机至善、私心了无"这两问逼你回到根本，再从方向、现场、数字和人心四个维度帮你理清判断。

## 你会得到什么

- 对经营决策、人生工作或组织管理问题的分类判断
- 稻盛和夫的 5 个核心模型：人生方程式、作为人何谓正确、动机审讯法、以心为本、现场主义
- 8 条以"正确"为基准的决策纪律
- 动机不纯时，该先停下来审视什么

## 边界

它用于经营与人生决策参考，不提供确定的结果承诺。稻盛和夫的"作为人何谓正确"是长期修行内化的直觉，无法被公式化；阿米巴经营在"哲学共有"前提缺失时会失效，不能机械套用。
