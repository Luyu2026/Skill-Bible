# 面试逐字稿去 AI 味

它适合这样的场景：你已经有一份面试稿，但读起来全是“我认为”“赋能”“闭环”“提升体验”；看似完整，真让你开口时却不像自己，一被追问就接不下去。

这个 Skill 不会只帮你删几个书面词。它会先核对你的简历和项目事实，再把回答改成一条你能说清的主线：当时发现了什么、为什么这样判断、你做了什么、结果如何证明。最后还会补上最容易被追问的地方。

## 你会拿到什么

- 原稿里哪些句子太空、太像模板、最容易被追问；
- 一份 60-90 秒能直接开口的版本；
- 一份需要展开时可用的 2-3 分钟版本；
- 每个答案的事实边界和待确认信息；
- 2-3 个高概率追问与短回答；
- 一轮当天就能完成的录音练习。

## 它和普通“润色”有什么不同

普通润色会把一句话写得更漂亮。

面试里真正的问题通常是：你没说清自己当时为什么这么做，或者数字、个人贡献和取舍接不住追问。

这个 Skill 会先把这些问题找出来，再改表达。所以目标不是让回答“更像 AI”，而是让它更像你真的做过。

## 怎么开始

把本页面链接发给你正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/interview-script-naturalizer

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：装在了哪里，以及我下一句该怎么调用它。
```

装好后，直接说：

```text
请使用「面试逐字稿去 AI 味 Skill」修改下面这段回答。

面试题：
目标岗位 / JD：
我的简历或项目事实：
原始回答：

要求：不要编造数字、职责或结果。先指出这段话哪些地方太像模板；
再给我 60-90 秒能直接开口的版本、2-3 分钟展开版，以及 3 个最可能的追问和短回答。
```

## 示例：把“社群运营”从汇报稿改成能说出口的回答

原始回答可能会写成：

> 我认为社群运营的核心是以用户为中心，通过精细化运营和内容供给提升用户活跃与留存。首先，我完成了用户画像分析；其次，我通过内容运营和线下活动构建社群生态；最终，社群 7 日留存达到 90%，长期活跃社群占比提升 30%。

问题不在于词不够口语，而在于：听不出当时到底发现了什么、你做了什么，也不知道 90% 是怎么来的。

Skill 会先确认事实，再改成类似：

> 我当时发现，问题不在于新生不愿意进群，而是很多人进群以后不知道留下来能得到什么。我们先访谈了一批新生，再结合问卷把大家分成想学拍摄、想找活动和单纯想认识同学几类。基于这个判断，我一边固定推 Vlog 和影像创作攻略，一边每周做狼人杀、谁是卧底这类线下活动，把线上内容和线下参与连起来。最后，社群 7 日留存做到约 90%，长期活跃社群占比提升了 30%，平均活动参与率是 35%。我觉得最关键的不是多发内容，而是让不同需求的人都能在群里找到下一步能参与的事。

这段仍然必须以你的真实项目材料为准。这个示例中的数据来自已提供的校媒体部经历，用来展示“事实 → 判断 → 动作 → 结果”的表达方式。

## 和其他求职 Skill 怎么配合

先用“面试简历深挖准备”把项目事实和追问挖清，再用“面试准备 / 多轮面试准备”选出要练的问题，最后用这个 Skill 把答案练成自己的话。面试结束后，再把真实问题交给“面试复盘”继续补强。

更多 Skill 使用案例和更新：抖音 / 小红书 / 公众号搜索“陆羽”。
