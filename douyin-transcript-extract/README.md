# 抖音视频文案提取

## 适合什么场景

你要把抖音视频、已录好的屏幕视频或字幕转成可复制文字。

你需要逐段回查，而不是只要一段内容总结。

可以只提取一段；链接无法读取时可改用已获授权的视频、音频或字幕。

## 解决什么

分开还原口播、画面文字和发布配文，不混成一篇所谓原文。

保留时间位置，听不清的地方留回听点。

只有截图就提取截图文字，只有字幕就整理字幕，不推测没听过的音轨。

## 一个重要机制

每段文字都对应一个来源轨道与时间范围。

字幕写“3 个方法”、口播说“三种办法”时，两轨分别保留。

截图、字幕文件与回听结果会注明核验状态；缺失区间不会被自动补齐。

## 你会拿到什么

- 可复制逐字稿或字幕来源稿，按时间分段。

- 画面文字、口播和发布配文的来源说明。

- 音画差异、听不清片段与未覆盖区间。

- 如另要编辑版，会与原始提取稿分开保留。

## 怎么开始

1. 优先上传能读取的视频、音频或字幕，也可给公开视频链接。

2. 说明只要口播、画面文字、发布配文还是全部。

3. 指定起止时间，以及是否保留语气词与说话人。

4. 补交模糊片段时保留原片时间，便于只修对应区间。

## 可直接复制的调用模板

```text

请使用 douyin-transcript-extract。

材料：附上的字幕文件和已授权录屏。

范围：原片 00:00–00:30。

需要：口播逐字稿与画面文字分开，保留时间戳。

对字幕与口播差异逐项标出；听不清不要补猜。

如果读不了音频，只整理可读取的字幕，并明确未回听。

```
