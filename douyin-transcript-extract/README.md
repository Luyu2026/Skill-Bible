# 抖音视频文案提取

## 适合什么场景

你需要从抖音视频、用户上传的录屏或字幕中提取可复制文案。
已有零散材料也可以开始，不必先整理成标准格式。
如果只想处理一小段，请明确本轮范围。

## 解决什么

把用户可访问的视频材料还原为带时间定位的口播与字幕，清楚标出听不清和画面差异，不把摘要冒充原文。

以已有材料为起点，区分确认事实和仍需核对的内容。
先完成一版可以使用的结果，再按反馈修改。

## 一个重要机制

视频口播、画面字幕、发布配文是不同来源，不混成一篇原文。

链接可见不代表可以下载，无法读取就明确未提取。
遇到无法确认的地方会留下具体位置，不会悄悄补写。

## 你会拿到什么

- 可复制口播逐字稿或画面文字稿
- 时间戳与来源索引，含口播和字幕差异
- 提取覆盖范围及待核片段列表

交付会说明处理范围，以及哪些材料还没有覆盖。
工具无法生成目标文件时，会提供可复制的文字版本并说明差异。

## 怎么开始

1. 直接提供现有材料，附上你最想解决的问题。
2. 说明本次处理范围、使用对象和希望的输出形式。
3. 如果已有旧稿或参考风格，一并提供。
4. 收到结果后，指出需要修改的具体位置和原因。

不确定格式时，可以先要求一个小范围成品。
请只提供你有权使用的材料；分享范围也可以一起说明。

## 可直接复制的调用模板

```text
请使用 douyin-transcript-extract。
我的任务：从抖音视频、用户上传的录屏或字幕中提取可复制文案。
现有材料：粘贴文字或附上文件。
本轮范围：填写页面、时间段、主题或章节。
使用对象与目标：填写给谁看、希望完成什么。
输出形式：可复制文稿；如工具支持，再生成可编辑文件。
必须保留：填写事实、表达或格式要求。
请标明无法确认的内容，先交付本轮成品和必要下一步。
```

### 看一个小例子

模拟输入：用户提供转写片段，00:00–00:03“今天讲三个整理方法”；同段画面字幕为“3个整理方法”；00:03–00:05 音频模糊。

可以先按这个范围试用，再决定是否处理其余材料。
