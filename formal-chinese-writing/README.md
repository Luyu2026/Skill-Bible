# 中文公文材料写作

## 适合什么场景

你要发一份通知、写一份请示或报告，手头只有零散要点或旧稿。

你不确定应该请对方批准，还是只向对方汇报情况。

支持单位内部正式材料；严格机关版式需要相应模板和规则依据。

## 解决什么

先定行文目的，再写成有对象、有事项、有办理要求的完整文稿。

检查谁来做、何时前完成、通过哪里提交，避免只把口语换成套话。

未批准的方案保留“拟”，不写成已作出的决定。

## 一个重要机制

用“希望收文者采取什么动作”区分文种。

请求上级批准用请示，汇报事实用报告，部署已确认事项用通知。

报告里夹了审批请求时会拆开；文号、印章和签发日期不会被编造。

## 你会拿到什么

- 标题、称谓、正文和落款齐备的文稿或明确标注的送审稿。

- 责任、期限、渠道、附件的办理要素核对表。

- 阻碍定稿的具体缺口及位置。

- 可复制正文；是否有 Word 文件、是否核验版式会如实说明。

## 怎么开始

1. 提供原始要点、旧稿或会议纪要。

2. 说明发文单位、收文对象，以及想让对方执行还是批准。

3. 给出具体日期、地点、办理期限、回复渠道和单位模板。

4. 核实待补项及审批状态；返回批注时指出要改的事实或语气。
