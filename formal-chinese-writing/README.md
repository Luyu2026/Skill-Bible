# 中文公文材料写作

## 适合什么场景

你需要把零散要点、旧稿或会议记录整理成通知、请示、报告等正式材料。
已有零散材料也可以开始，不必先整理成标准格式。
如果只想处理一小段，请明确本轮范围。

## 解决什么

根据行文目的和现有事实写出对象明确、事项可执行的正式文稿，避免只把口语改成套话。

以已有材料为起点，区分确认事实和仍需核对的内容。
先完成一版可以使用的结果，再按反馈修改。

## 一个重要机制

请求批准用请示，告知执行事项用通知，汇报情况用报告；混合需求先拆目的。

单位内部材料不自动套用党政机关红头格式。
遇到无法确认的地方会留下具体位置，不会悄悄补写。

## 你会拿到什么

- 完整正式文稿：标题、称谓、正文、落款或待确认项
- 办理要素核对表：责任、期限、渠道、附件
- 送审状态与需要确认的事项

交付会说明处理范围，以及哪些材料还没有覆盖。
工具无法生成目标文件时，会提供可复制的文字版本并说明差异。

## 怎么开始

1. 直接提供现有材料，附上你最想解决的问题。
2. 说明本次处理范围、使用对象和希望的输出形式。
3. 如果已有旧稿或参考风格，一并提供。
4. 收到结果后，指出需要修改的具体位置和原因。

不确定格式时，可以先要求一个小范围成品。
请只提供你有权使用的材料；分享范围也可以一起说明。

## 可直接复制的调用模板

```text
请使用 formal-chinese-writing。
我的任务：把零散要点、旧稿或会议记录整理成通知、请示、报告等正式材料。
现有材料：粘贴文字或附上文件。
本轮范围：填写页面、时间段、主题或章节。
使用对象与目标：填写给谁看、希望完成什么。
输出形式：可复制文稿；如工具支持，再生成可编辑文件。
必须保留：填写事实、表达或格式要求。
请标明无法确认的内容，先交付本轮成品和必要下一步。
```

### 看一个小例子

模拟输入：内部培训通知；产品组周三 15:00 在 A 会议室培训 40 分钟；周二 18:00 前回复是否参加；发出日期未给。

可以先按这个范围试用，再决定是否处理其余材料。
