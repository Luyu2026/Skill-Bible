# 股票多流派研究团

## 适合什么场景

你已经有某只股票的财报或研究笔记，想知道不同投资方法会追问什么，而不是收集二十句看多或看空的话。

可以直接贴现有材料，不必先写一份标准报告。
本轮聚焦你眼前的一件事；缺失信息会写清影响。

## 解决什么

把已有财报与估值材料拆成二十个可追溯的流派观察卡，再收敛成关键分歧和待验证清单，避免用名人语气替代研究。

先处理足以判断的部分，再列真正影响结论的缺口。
不会把没有来源的数字、盘面、评价或人生事件写成你的事实。

## 一个重要机制

二十席使用同一证据编号，每席给独有问题和反证。缺价格的席位会明确暂停估值，不能参加“多数票买入”。

你能看见结论来自哪项材料，以及哪些条件变了就要重做。
不需要为了开始，把不相关的私人信息也一起提交。

## 你会拿到什么

- 共用财务证据底表与来源索引。
- 二十席方法研究卡，包含无法判断的席位及原因。
- 关键分歧对照、反证和下一份资料的核对清单。

[查看完整模拟成品](references/review-validation.md)。
示范标明了模拟设定、实际产物和未验证范围。

## 怎么开始

1. 股票名称、代码、交易所、研究截止日。
2. 年报或季报、估值资料；只有截图也可以，保留日期与单位。
3. 这轮要理解经营、核对估值，还是找原研究的盲点。

不确定的字段写“不详”即可，不必猜填。
结果标为待核验时，按对应缺口补来源或参数，再续接同一轮。

## 可直接复制的调用模板

```text
请使用 stock-master-panel。
标的与交易所：
研究截止日：
财报或已有笔记：
同期价格／市值（没有可留空）：
我最想核对的投资假设：
请交证据底表、二十席方法卡和关键分歧；无依据的估值暂停。
```

续接时贴上上一版成品与新材料，说明哪一项需要改。
只处理受新信息影响的部分，保留仍然成立的依据。
