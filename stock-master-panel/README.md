# 股票多流派研究团

## 适合什么场景

用户输入股票代码，希望看二十位投资大师视角、比较投资流派或检查股票分析盲点时。

你可以直接贴现有材料、截图文字或原稿，不需要先整理成标准报告。

## 解决什么

把已有财报与估值材料拆成二十个可追溯的流派观察卡，再收敛成关键分歧和待验证清单，避免用名人语气替代研究。

会区分已经能判断的部分和还需要核验的部分。
不会为了让答案显得完整而补造事实。

## 一个重要机制

二十个视角是方法模拟，不是大师本人发言、推荐或持仓披露。

定量筛选、企业质量、估值与交易纪律不能混合成一个神秘评分。

这会直接影响哪些结论能写进本轮成品。

## 你会拿到什么

- 共用财务证据底表与来源索引。
- 二十席方法研究卡，包含无法判断的席位及原因。
- 关键分歧对照、反证和下一份资料的核对清单。

可以先看 [明确模拟示范](demo.md)，了解输入不足时如何交付。

## 怎么开始

1. 说清当前想完成的一件事。
2. 贴上已有材料，保留来源和时间信息。
3. 说明不能改动的条件与希望的输出长度。
4. 收到成品后，只补影响关键判断的缺口。

优先给这些材料：

- 股票全称、代码、交易市场及分析截止日，避免同名标的混淆。
- 用户已有年报、季报、估值表、持仓问题与研究笔记。
- 希望理解企业、比较估值还是检查投资假设；不默认代用户买卖。
