# 股票多流派研究团

## 一句话主餐

把已有财报与估值材料拆成二十个可追溯的流派观察卡，再收敛成关键分歧和待验证清单，避免用名人语气替代研究。

普通聊天容易让二十种名人口吻重复同一结论。本技能让二十席共用一份证据底表，各自提出可被证伪的问题，最后指出真正分歧和最值得补的材料。

## 输入

- 股票全称、代码、交易市场及分析截止日，避免同名标的混淆
- 用户已有年报、季报、估值表、持仓问题与研究笔记
- 希望理解企业、比较估值还是检查投资假设；不默认代用户买卖
- 财务报表币种、单位、会计期间，价格数据必须带时间戳
- 缺少财报时可先按用户摘录研究，但不能生成当下估值结论

### 材料处理

- 优先读取已给原稿、附件和记录，不要求重复填写。
- 只追问会改变当前路径的缺口，其他缺失放在相关判断旁。
- 来源无法打开时使用用户摘录，并写明尚未独立核验。
- 用户事实、工具结果、合理推断与纯模拟分别标记。
- 不把演示数据移植成真实用户材料。

## 核心判断

1. 二十个视角是方法模拟，不是大师本人发言、推荐或持仓披露。
2. 定量筛选、企业质量、估值与交易纪律不能混合成一个神秘评分。
3. 同一事实可支持不同策略，分歧必须追溯到期限、假设或风险偏好。
4. 现金流为负与利润为负分开判断；P/E 是否适用取决于利润和口径，不把增长当盈利证据。
5. 财务事实、模型假设、情景估值和缺失项分栏，不给无依据目标价。
6. 研究输出不代替个性化适当性评估，不承诺回报。

### 本轮执行门槛

- 只给代码：先确认交易所和公司，再查公司公告；不能取得财报时交研究入口和缺数卡，不生成当前估值。
- 有财报无价格：完成经营、杠杆与方法卡；暂停价格便宜与否和收益空间。
- 有同期价格与财报：先核对总股本、币种和时间，再计算适用倍数；用户未给组合信息时不写仓位比例。
- 追求二十票买卖结论：改交证据覆盖矩阵，明确无法判断席位不能算赞成票。

## 编号工作流

### 1. 锁定对象与截止日

- 核对公司、证券种类与上市地。
- 将用户问题改写成一个研究命题。
- 记录资料发布日期与分析日，禁止使用截止日之后的材料冒充事前判断。
- 只有简称时先消除歧义，再做公司结论。
- 交付一张研究边界卡。

### 2. 建立共用证据底表

- 抽取收入、经营现金流、资本开支、债务和现金。
- 每个数字附期间、单位、来源页码或链接。
- 自由现金流明确采用经营现金流减资本开支的简化口径。
- 金融企业等不适用该口径时另列行业指标，不强行横比。
- 缺数标未知，不用模型猜测填满表格。

### 3. 配置二十个方法席位

- 价值组设 Graham、Buffett、Munger、Klarman、Greenblatt。
- 成长与质量组设 Fisher、Lynch、T. Rowe Price、Terry Smith、Nick Sleep。
- 逆向与周期组设 Templeton、Marks、Dreman、Zell、Rogers。
- 组合与纪律组设 Bogle、Dalio、Soros、Druckenmiller、O’Neil。
- 以上仅作方法索引；每席核对其公开原始方法，资料不足则标“方法归属待核验”，不可编造名言。

### 4. 生成独立研究卡

- 每席写关注问题、用到的证据、条件判断和一个反证。
- 缺少数据的席位也保留编号并明确暂无法判断。
- 不写虚构访谈、第一人称名言或模拟大师最新表态。
- 组合策略只解释该股票在组合中的角色，不假定知道用户总资产。
- 每席判断必须回到共用底表，避免二十遍改写同一句话。

### 5. 收敛真实分歧

- 按企业质量、价格、周期与持有条件合并重复判断。
- 展示至少一对有材料支持的相反解释。
- 解释分歧究竟来自事实、参数还是投资期限。
- 不以二十席多数票形成买入信号。
- 若证据不足，结论是补数优先级而非强行选边。

### 6. 计算可复核情景

- 只有数据充分才列保守、基准和乐观情景。
- 列公式、输入、适用范围及对关键参数的敏感性。
- 历史股价与当前报价不同步时暂停收益空间计算。
- 将最重要反证转为下一次财报需观察的指标。
- 交付研究摘要、观察触发点与不确定性。

## 直接交付与下一步

- 共用财务证据底表与来源索引。
- 二十席方法研究卡，包含无法判断的席位及原因。
- 关键分歧对照、反证和下一份资料的核对清单。

### 二十席卡与计算口径

每席固定输出：编号／方法索引／本席独有问题／证据编号／条件判断／反证或待查项／核验状态。
方法没有原始出处时保留名字但标“方法归属待核验”，不输出仿真引语。
所有席位均须出现；无数据时写出恢复判断所需的最少字段。
不得把“现金流依赖一次性回款”写成已发生事实；无附注时它只是待查反证。

| 运算 | 使用门槛 | 不满足时 |
| --- | --- | --- |
| 简化自由现金流 = 经营现金流 − 资本开支 | 同期间同币种，资本开支以正支出额记录 | 保留原值并暂停计算 |
| 简化净债务 = 有息债务 − 现金 | 说明受限现金、租赁负债是否包含 | 标口径待核验 |
| P/E = 同期市值 ÷ 归属普通股股东利润 | 利润为正且期间明确 | 亏损时标不适用，不生成负倍数排名 |
| EV = 市值 + 净债务 | 另核优先股、少数股东权益等调整 | 只能标简化 EV，不冒称完整值 |
| 永续现金流现值 = C ÷ r | 明示恒定现金流、无增长的教学假设 | 不作真实目标价 |

负自由现金流不等于亏损，也不自动使 P/E 失效；分别检查分母与行业适用性。
经营现金流与企业自由现金流、股权自由现金流不能互换，折现率要匹配现金流归属。
对真实公司使用模型时说明预测期、终值、净债务调整和股数；任何一项缺失都不产出每股目标价。

### 本轮完成与下一次财报

交付顺序为结论边界、证据底表、二十席卡、分歧矩阵、观察触发点。
没有材料支持的相反观点时写“尚无可证实分歧”，不强造多空对抗。
观察触发点写指标、当前来源、将推翻哪一假设；不随意设置买卖阈值。
用户交回新财报后对照旧证据编号，更新受影响卡和计算，保留截止日期差异。
不能联网时可用用户快照做历史研究；当前行情与公告仍须查询，查询失败标未核验。
不能生成文件时交付可复制 Markdown 表格；不声称建立了后台监控。

## 外部参考与延展

- **何时研究**：财务口径冲突、流派归属不明、行业特殊或估值结论对参数高度敏感时启动。
- **去哪找**：公司投资者关系年报、交易所公告、SEC EDGAR；方法查作者书籍、股东信和公开访谈原文。
- **看什么**：比较现金流定义、资本结构、持有期限、估值条件；检索“shareholder letter valuation margin of safety”。
- **怎么用**：把原始方法改成一个能被当前财报检验的问题，与原分析并排重跑，不新增虚构权威背书。
- 参考 [伯克希尔 1994 年股东信](https://berkshirehathaway.com/letters/1994.html) 对估值依赖假设的说明，与简单倍数法比较；采用假设表与敏感性机制，不把单一现金流折现值当精确真值。
- 来源热度只用于发现，不代表方法有效；原始规则优先于二手总结。
- 材料已经足够时直接交付，不机械追加联网研究。
- 外部方法只改变执行机制，不能创造用户经历、报价或个体事实。
- 若实际复用受许可约束内容，保留所需声明；独立改写不等于可以忽略许可。

### 交付前验收

1. 每个确定结论都能回到材料、计算或明确设定。
2. 关键数字、日期、资格和限制没有在改写中发生变化。
3. 交付与用户当前目标一致，没有串入无关阶段。
4. 复制正文即可使用，依赖工具的暂停部分有可操作恢复条件。
5. 不把模拟验证称为真实用户效果，不承诺未经测量的收益。
