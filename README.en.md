Skill Bible is not a prompt pile or an archive of unrelated files. Every Skill should solve a recurring problem worth standardizing: it makes the judgment, required material, workflow, deliverable, and boundary explicit so an agent can move work forward reliably.

There are two kinds of capabilities here: **single-purpose Skills** for a specific task, and **professional Skill chains** for a connected workflow. You do not need to install the whole repository or understand all 94 Skills first.

## Start here

Describe the blocker you have now. These are the recommended entry points:

| What you are doing | Start with | Where it leads |
|---|---|---|
| Unsure what to apply for, change, or prepare in a job search | [job-search-pilot](./job-search-pilot/) | Diagnosis → resume / interview / review / offer next step |
| Requirements are unclear or a product project is stuck | [pm-master](./pm-master/) | Judgment → PRD / review / prioritization / roadmap / data / postmortem |
| Operations goals, data, campaigns, and content are tangled | [operations-master](./general-operations-skills/operations-master/) | Strategy → data / content / campaigns / users / review |
| Improving retention, recall, membership, or community | [user-operations-master](./user-operations-skills/user-operations-master/) | Segmentation → lifecycle / retention / recall / membership / community |
| Planning overseas marketing, SEO, ads, or email | [overseas-marketing-master](./overseas-marketing-skills/overseas-marketing-master/) | Research → positioning / content SEO / ads / email / analytics |
| Expanding a content idea or adding useful article visuals | [daily-idea-expander](./daily-idea-expander/) / [wechat-visual-narrative](./wechat-visual-narrative/) | Spoken script / visual narrative for a finished WeChat article |
| Reframing a decision through a person's mental model | [Perspectives](#perspectives) | 13 bounded thinking frameworks |

**Use a specialist Skill when the task is clear.** Start with a `*-master` only when you do not know the next step or the work genuinely spans several stages.

## Professional Skill chains

These are not loose bundles. Each chain has a controller, execution Skills, and advisory or methodological Skills with clear handoffs.

| Chain | For | Entry point | Full directory |
|---|---|---|---|
| 📦 Product management · 21 Skills | Requirements, research, prototypes, experiments, data, and review | [pm-master](./pm-master/) | [Product workflow](./pm-master/README.md) |
| 📣 General operations · 14 Skills | Strategy, campaigns, content, data, and review | [operations-master](./general-operations-skills/operations-master/) | [Operations suite](./general-operations-skills/README.md) |
| 👥 User operations · 14 Skills | Segmentation, lifecycle, retention, recall, membership, and community | [user-operations-master](./user-operations-skills/user-operations-master/) | [User operations suite](./user-operations-skills/README.md) |
| 🌍 Overseas marketing · 14 Skills | Market research, positioning, SEO, paid ads, email, and analysis | [overseas-marketing-master](./overseas-marketing-skills/overseas-marketing-master/) | [Overseas marketing suite](./overseas-marketing-skills/README.md) |

- **Controller**: identifies the problem and routes the necessary work.
- **Execution Skills**: produce a usable plan, report, document, or analysis.
- **Advisory / methods**: handle trade-offs and judgment; they do not make the final decision for the user.

## Install one Skill

Open the Skill you need, copy its URL, and send this to your agent:

```text
Please install this Skill:
[paste the Skill page URL here]

Install only this Skill, not the entire repository.
Identify the right installation directory and method for my current agent, then complete the installation.
When finished, tell me where it was installed and the next sentence I can use to invoke it.
```

If a document-oriented Skill needs Feishu but Feishu CLI is not configured, it should deliver local Markdown rather than stall on permissions.

## Curation and sources

- Original or redesigned Skills maintain this repository's standards for inputs, workflow, deliverables, boundaries, and validation.
- A Skill that preserves external mechanisms or source material declares its source, author, license, and the changes actually made in its own `SOURCES.md`.
- Inclusion does not mean a Skill is right for everyone. Capabilities should not be installed or invoked simply to inflate the collection.

Submit an original Skill or recommend a project worth studying: [submit / recommend a Skill](https://github.com/Luyu2026/Skill-Bible/issues/new?template=submit-skill.yml). Search for "陆羽" on Douyin, Xiaohongshu, or WeChat Official Accounts for Skill usage notes.
