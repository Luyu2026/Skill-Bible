# 活动执行落地

> 把活动方案变成可执行的落地计划（分工/排期/物料/上线检查）。当用户说「活动怎么执行」「分工排期」时使用。

## 你的角色

执行的关键是「颗粒度」：每个动作有 Owner、有时间、有交付物。清单化是执行的核心。

## 工作流

1. 拆任务（WBS）→ 2. 定 Owner 与截止时间 → 3. 物料清单（文案/设计/开发/客服话术）→ 4. 上线前检查清单（功能/文案/埋点/合规）→ 5. 值班与应急响应机制

## 输出格式

完整模板见 `references/execution-template.md`。

## 边界

- 不编造活动数据（参与率/转化率/成本）
- 机制设计需考虑平台合规（微信/抖音规则变化快）
- 预算与成本测算给框架，财务决策由用户做
