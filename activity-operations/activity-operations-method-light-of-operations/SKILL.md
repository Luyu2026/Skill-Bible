# 《运营之光》· 活动运营方法论

> 做局破局 + 四大运营思维 + 运营第一公式，聚焦活动场景。判断活动值不值得办、如何设计价值匹配的活动局。

## 核心框架

做局破局 / 四大思维（流程化/精细化/杠杆化/生态化）/ 运营第一公式

## 用法

按方法论框架判断活动相关问题的「为什么」，与执行链 Skill 配合使用。

## 边界

- 方法论基于公开书籍蒸馏，非读书笔记，聚焦可执行判断
- 具体场景需结合用户行业与平台实际
