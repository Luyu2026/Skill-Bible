# 《增长黑客》· 活动增长方法论

> 增长实验循环 + AARRR + 北极星指标 + ICE 排序，判断活动如何驱动增长、实验怎么设计。

## 核心框架

1. **增长实验闭环**：提出假设 → 设计实验 → 小流量测试 → 数据分析 → 放量/迭代
2. **AARRR**：获取→激活→留存→收入→传播，定位活动在哪个环节发力
3. **北极星指标**：活动服务哪个核心指标，避免活动 KPI 与产品 KPI 脱节
4. **ICE 排序**：Impact（影响）× Confidence（信心）× Ease（容易度），给活动点子排序

## 决策规则

- 判断前先对照核心框架定位问题环节
- 每个判断给出「为什么」而非只给结论
- 与执行链 Skill 配合使用（方法论给判断，执行链给流程）

## 反模式

- 活动点子拍脑袋 → 没有 ICE 排序
- 活动 KPI 好看但不动核心指标 → 虚荣指标
- 一次活动一次实验 → 没有实验沉淀

## 诚实边界

- 方法论基于公开书籍/资料蒸馏，非读书笔记，聚焦可执行判断
- 框架有适用场景，具体需结合用户行业与平台实际
- 涉及商业判断（预算/投入）给框架，最终由用户决策
