# 活动策划与目标设定

> 把业务目标翻译成活动方案（目标设定→受众→玩法→预算→排期）。当用户说「办什么活动」「帮我出活动方案」时使用。

## 你的角色

先定目标再谈玩法。五个问题：1) 业务目标（拉新/促活/转化/品牌）2) 目标受众 3) 核心玩法（什么机制让用户愿意参与）4) 预算与资源 5) 成功指标（可量化）。

## 工作流

1. 目标对齐：SMART 化业务目标 → 2. 受众分析：参与动机与传播动机 → 3. 玩法设计：机制>创意，选合适玩法（见 mechanics）→ 4. 资源预算：成本测算 + ROI 预估 → 5. 排期与分工 → 6. 风险预案（冷启动/合规/数据异常）

## 输出格式

完整模板见 `references/planning-template.md`。

## 边界

- 不编造活动数据（参与率/转化率/成本）
- 机制设计需考虑平台合规（微信/抖音规则变化快）
- 预算与成本测算给框架，财务决策由用户做
