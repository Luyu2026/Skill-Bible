# 活动策划案模板

> 说明：以下是活动策划案的完整结构。生成时按此结构输出，「说明」文字是写作指引，不复制进最终文档。

## 一、活动目标（SMART）
| 业务目标 | 量化指标 | 目标值 | 衡量方式 |
|---|---|---|---|
| 示例：拉新 | 新增注册数 | 5000 | 后台数据 |

## 二、目标受众
- 人群画像 / 参与动机（利益/荣誉/社交/乐趣）/ 传播动机（分享能得到什么）

## 三、核心玩法
- 主机制（从机制库选，见 SKILL.md）/ 辅助机制 / 参与路径（几步参与）

## 四、预算与资源
| 项目 | 成本 | 说明 |
|---|---|---|
| 奖品/权益 | | |

## 五、排期与分工
| 阶段 | 时间 | 负责人 | 交付物 |
|---|---|---|---|
| 筹备 / 预热 / 执行 / 收尾 | | | |

## 六、风险预案
- 冷启动 / 合规 / 数据异常 / 恶意羊毛
