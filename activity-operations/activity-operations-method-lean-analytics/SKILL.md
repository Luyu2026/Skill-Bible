# 《精益数据分析》· 活动数据方法论

> 第一关键指标 + 增长引擎定位 + 数据诊断框架，判断活动指标怎么定、数据异常怎么归因。

## 核心框架

1. **第一关键指标（OMTM）**：每个阶段只盯一个最重要指标，避免指标互相打架
2. **增长引擎**：黏着式（靠留存）/ 病毒式（靠传播）/ 付费式（靠投放）——活动按增长引擎选指标
3. **数据诊断**：同期群分析（按时间看活动效果）/ 漏斗对比 / 虚荣指标识别（下载量≠价值）

## 决策规则

- 判断前先对照核心框架定位问题环节
- 每个判断给出「为什么」而非只给结论
- 与执行链 Skill 配合使用（方法论给判断，执行链给流程）

## 反模式

- 指标堆砌 → 不知道该优化什么
- 只看总量不看同期群 → 误判活动效果
- 把虚荣指标当北极星 → 决策失效

## 诚实边界

- 方法论基于公开书籍/资料蒸馏，非读书笔记，聚焦可执行判断
- 框架有适用场景，具体需结合用户行业与平台实际
- 涉及商业判断（预算/投入）给框架，最终由用户决策
