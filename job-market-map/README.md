# 招聘情报地图

把公司的公开招聘信息，读成一份可验证的业务与人才情报。

你可以给它一家公司招聘官网、一条 JD、一个岗位名称，甚至一个很宽泛的方向。它会先做招聘信息分析，再在你提供个人经历时，附加定向匹配和提升建议。

## 你会拿到什么

- **公司招聘页**：招聘盘面、能力链路、重点业务信号、人才画像，以及哪些判断仍需验证；
- **具体 JD**：岗位真正负责的结果、工作链路、需要证明的能力、进入门槛与职责边界；
- **具体岗位名**：岗位的主要子分支、各分支的工作差异、公开招聘信号与能力证据；
- **宽泛方向**：先拆出不能混为一谈的岗位族，再比较哪些分支值得继续看；
- **可选的个人建议**：只有你给出简历或经历时，才会做市场/公司要求与你的真实证据、待补事实和能力缺口的映射。

它不会把一个招聘标题或一条 JD 放大成市场结论，也不会用招聘词汇替你虚构经历。

## 适合什么时候用

- 想知道一家公司最近到底在为哪些业务和能力招人；
- 想读懂一个职位，不止看“岗位职责”四个字；
- 想了解“产品运营”“AI 产品经理”等职位在不同公司究竟差在哪；
- 只知道自己想做“运营/市场/营销”，但还没有拆出真实岗位方向；
- 看完招聘信息后，才想判断自己的经历应如何准备。

## 怎么开始

把本页面链接发给正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/job-market-map

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：装在了哪里，以及我下一句该怎么调用它。
```

装好后，任选一种方式开始：

```text
请使用「招聘情报地图 Skill」分析字节跳动的公开招聘页面：
https://jobs.bytedance.com/

请先告诉我数据范围与可见边界，再从招聘盘面、能力链路、战略信号和人才画像分析。区分事实、推断与仍需验证的地方。
```

```text
请使用「招聘情报地图 Skill」分析“产品运营”这个岗位。
我关注的城市 / 行业 / 经验阶段是：
如无特别限制，请先给一份明确标注范围的市场快照，区分它的主要子分支，不要只给通用能力词。
```
