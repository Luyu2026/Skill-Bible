# 岗位需求地图

写简历之前，先弄清公司到底在招什么人。

很多学生一上来就改简历、背面试题，但连“运营、市场、营销”几个方向实际分别做什么都没看清。这个 Skill 会带你从 BOSS 直聘等公开 JD 中抽取真正重复出现的业务结果、工作链路和证据要求，再回到你的经历判断主投方向。

它不会把 JD 变成一串待堆进简历的关键词，也不会让你因为缺少一项偏好就放弃一个方向。

## 你会拿到什么

- 一份可直接填写的 JD 采样表；
- 一句清晰的岗位定义：这个岗位入职后要把什么结果做成；
- 核心共性要求：业务结果、常见工作链路、公司希望看到的证明能力；
- 主投与备选方向，以及为什么；
- 一张“市场要求—本人证据”地图，明确哪些经历能写、哪些数据待补、哪些是真实能力缺口；
- 下一步该改简历、补事实，还是收窄投递范围。

## 它怎样推进

```text
JD 采样 → 岗位需求地图 → 主投方向与证据地图 → 简历改写 / 单岗投递 / 面试准备
```

方向还宽时，先对用户/增长运营、内容/社区运营、市场/品牌/整合营销各做少量探索性采样；已经有主投方向时，直接精读 8-12 条同一岗位族 JD。结论通过后，才改简历。

## 适合什么时候用

- 想投运营、市场或营销，但分不清不同岗位真实在做什么；
- 准备写第一版简历，希望先建立市场坐标；
- 看了很多 JD，却只记住“沟通能力、数据分析、执行力”；
- 有一批 BOSS 直聘 JD，想知道其中真正重复出现的要求；
- 想判断自己的经历应该主打用户增长、内容运营、市场活动还是其他方向。

它不用于单个 JD 的简历改写，也不替你决定某一个岗位要不要投。已经锁定具体岗位时，请使用 `resume-jd-tailor` 或 `job-application-match`。

## 怎么开始

把本页面链接发给正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/job-market-map

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：装在了哪里，以及我下一句该怎么调用它。
```

装好后，直接说：

```text
请使用「岗位需求地图 Skill」带我先研究目标岗位，再决定怎么写简历。

我目前想投：
城市 / 可接受地点：
经验阶段：实习 / 校招 / 1-3 年 / 其他
我的简历或已有经历：
我已经收集的 JD 链接、截图或文本（如有）：

要求：如果我的方向还很宽，先只布置探索性 JD 采样；如果我已经给了同类 JD，就先验收样本再分析。不要把不同岗位混成词云，不要虚构我的经历，也不要在方向明确前直接改简历。
```
