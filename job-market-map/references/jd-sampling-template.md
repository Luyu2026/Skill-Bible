# JD 采样与结论模板

学生在第一轮采样时使用。不要先把每条 JD 改写成简历语言。

## 一、JD 采样表

| 编号 | 公司/行业 | 岗位与城市/经验 | 是否计入核心样本 / 原因 | 采样日期与链接/截图 | 这个岗位对什么结果负责 | 它通常怎么推进工作 | 公司想看到什么证据 | 进入条件 | 一句原文依据 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| JD-01 |  |  |  |  |  |  |  |  |  |

填写要求：

- “对什么结果负责”不能只填“运营”，要写拉新、留存、付费转化、订单、内容供给、品牌认知、线索等具体结果；
- “怎么推进工作”写判断—动作—复盘的顺序，例如“分层找问题 → 设计触达/活动 → 看留存和转化”；
- “公司想看到什么证据”写项目、指标、工具、行业经验或协同，不要只抄“沟通能力强”；
- 保留一句能证明自己判断的原文，避免事后凭印象总结；
- 每条都先写“计入”或“不计入”及原因。不可比样本单独标记原因，例如经验年限差距过大、明显偏销售/客服、城市不同、岗位实际属于另一条线、职责不清或同公司重复发布；
- 同一公司同一岗位族最多 1 条计入核心统计，其他重复 JD 留作背景材料，不增加频次；
- “进入条件”单独记录学历、年限、语言、城市、到岗等筛选门槛。它们用于判断能不能投，不用于替代项目成果、指标或作品等能力证据。

## 二、学生的初步结论

交表时用自己的话回答：

1. 有效样本一共几条、来自几家公司？哪些 JD 被剔除，为什么？
2. 这批岗位共同对什么结果负责？请标注支持它的 JD 编号和数量。
3. 它们最常见的工作链路是什么？请标注支持它的 JD 编号和数量。
4. 招聘方不是只要“会做什么”，而是希望我拿什么证明自己？
5. 哪些是进入条件，哪些才是我需要用经历证明的能力？
6. 我已有的哪两段经历最能证明这些要求？各自缺什么事实或数据？
7. 因此我主投什么方向、备选什么方向；暂时不投什么方向，为什么？

## 三、验收表

| 检查项 | 通过标准 |
| --- | --- |
| 样本可比 | 同一城市/经验段为主，岗位族没有混杂 |
| 样本质量 | 每条标注是否计入；核心样本尽量来自不同公司，同公司重复不重复计数 |
| 原文依据 | 每条都有链接、截图或关键原文 |
| 结果意识 | 能说清每条 JD 对什么结果负责 |
| 共性判断 | 至少引用 3 条有效 JD、标明 JD 编号和数量，不把形容词当结论 |
| 门槛分离 | 学历、年限、语言等进入条件没有被误写成能力证据 |
| 个人映射 | 区分“我做过但没写”“待补事实”“确实不会” |

未通过时，只补样本或重写结论，不进入简历改写。
