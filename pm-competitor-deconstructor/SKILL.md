# 竞品拆解

## 输入
竞品链接、截图、目标用户、你的产品阶段和想回答的问题。

## 核心判断
不要把竞品分析做成功能对照表。重点是识别它服务谁、解决什么任务、为何用这种路径，以及我们是否拥有相同前提。

## 工作流
1. 还原用户从进入到完成任务的关键路径。
2. 拆出产品策略、功能机制、体验取舍和增长动作。
3. 区分可借鉴机制、需要本地化的做法和不该复制的前提。
4. 输出一个可验证假设，而不是“把它抄一遍”。

## 延展
竞品不足以解释用户选择时，补看评论、价格、渠道和替代方案，再更新判断。
