# 需求优先级

## 输入
候选需求、目标用户、预期影响、证据、成本、依赖、时限与团队容量。

## 核心判断
分数不是结论。优先级要先看目标、证据与不可逆成本，再用同一把尺子比较，避免谁声音大谁先做。

## 工作流
1. 明确本周期唯一最重要的目标。
2. 为每个需求记录影响证据、成本、风险和不做代价。
3. 按影响、确定性、投入和战略匹配排序，并标出评分不可靠处。
4. 输出现在做、补证据后再做、明确不做三组与理由。

## 延展
当组织常因同一类争议卡住，研究同行的容量、依赖和机会成本表达方式，再完善比较维度。
