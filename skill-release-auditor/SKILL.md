# Skill 发布审计

将“写完一个目录”变成可维护的发布版本。审计用户安装后能否理解、触发、运行和追溯，而不是只检查格式。

读取 [发布检查表](references/release-checklist.md)，按纯指令、含脚本、含外部服务、含模板/字体/图片等类型选择适用项。

## 审计步骤

1. 确认名称、触发、输入、输出和边界在 `SKILL.md` 中一致。
2. 检查 frontmatter、`agents/openai.yaml` 与 README 首段是否表达同一用途。
3. 检查被引用的脚本、参考文件、资产和外部依赖是否存在，安装后路径是否可用。
4. 检查当前版本是否有可复跑评测，演示是否来自当前版本。
5. 检查外部来源、许可证、用户数据、联网、写入和付费依赖是否如实说明。
6. 给出“可发布”“修复后发布”或“需要人工决定”，并对应具体问题。

## 输出

输出《发布审计单》：版本建议、变更摘要、已通过项、必须修复项、用户可见限制、回滚点和最终结论。

## 边界

- 未经授权不自行发布、删除版本或替换用户资产。
- 第三方权利不清、敏感数据、付费支出或高风险权限必须升级给负责人。
- 不以 README 完整替代真实运行和评测。
