# 《爆款文案》· 卖点话术方法论

## 核心框架

### 框架1：卖点四步法（把产品翻译成用户语言）
- **适用场景**：设计单品话术、详情页卖点、引流视频文案时
- **步骤**：
  1. **挖卖点**：功能 → 利益 → 感受（"保温6小时" → "冬天随时喝热水" → "被照顾的感觉"）
  2. **找痛点**：用户现在怎么难受，你的产品怎么解决
  3. **给证据**：数据/对比/资质/好评，把"我说好"变成"有证明"
  4. **做号召**：明确的下一步动作（"拍1号链接，领券下单"）
- **输出物**：单品话术的卖点结构
- **来源**：卖点章节

### 框架2：痛点场景化（让用户对号入座）
  - **适用场景**：话术开场钩子
  - **步骤**：把痛点写成用户熟悉的场景（"你是不是也……"），让用户代入
  - **输出物**：开场钩子话术
  - **来源**：痛点章节

## 决策规则（节选）

1. **如果**要讲卖点，**则**按"功能→利益→感受"讲，不讲参数讲好处。
2. **如果**转化犹豫，**则**补证据（对比/数据/好评），而非加形容词。
3. **如果**要开场，**则**用痛点场景让用户对号入座。
4. **如果**要收尾，**则**给明确行动号召，不给开放式结尾。
5. **如果**卖点超过 3 个，**则**砍到 3 个以内，讲透不讲全。

## 检查清单

- [ ] 卖点是否讲"好处"而非"参数"
- [ ] 痛点是否场景化（用户能代入）
- [ ] 是否有证据支撑（对比/数据/好评）
- [ ] 是否有明确行动号召
- [ ] 卖点是否 ≤3 个

## 反模式

- 堆参数不翻译成好处（用户无感）。
- 形容词轰炸（"超级好用"）没有证据。
- 卖点贪多（一个都记不住）。

## 边界声明

- 方法源自文案领域，直播语境需配合口头表达节奏。
- 证据必须真实：编造数据/好评是翻车源头。
- 平台违禁词（极限词）限制部分表达，需替换。
