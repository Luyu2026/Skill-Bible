# 《影响力》· 直播转化方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

## 核心框架

### 框架1：六大影响力原则（直播转化底层）
- **适用场景**：设计直播话术、逼单、福利机制时
- **步骤**：
  1. **互惠**：先给（福利/知识/试吃试用），用户有回报心理
  2. **承诺一致**：引导扣屏"要"、预约，让用户先承诺再履约
  3. **社会认同**：展示销量/好评/在线人数，用户跟随大众
  4. **喜好**：主播人设/共情，用户喜欢才买
  5. **权威**：专家身份/资质/对比实验背书
  6. **稀缺**：限量/限时，怕错过驱动下单
- **输出物**：一场直播的转化机制设计（每条原则对应哪个环节）
- **来源**：全书六大章节

### 框架2：稀缺的实操（怕错过 > 想得到）
  - **适用场景**：逼单环节设计
  - **步骤**：限量 + 限时 + 竞争（"只剩 X 单"），把"想要"变成"怕失去"
  - **输出物**：逼单话术与库存/时间锚点
  - **来源**：稀缺章节

## 决策规则（节选）

1. **如果**要设计开场，**则**先给福利/价值（互惠），再谈产品。
2. **如果**转化犹豫，**则**展示社会认同（销量/好评/大家都在买）。
3. **如果**要逼单，**则**用稀缺（限量/限时），但前提是产品价值真实。
4. **如果**要建立信任，**则**调用权威（资质/实验/专家身份）。
5. **如果**用户已扣屏承诺，**则**用承诺一致跟进（"你都说要了，拍吧"）。

## 检查清单

- [ ] 开场是否给了互惠钩子
- [ ] 是否有引导承诺的互动（扣屏/预约）
- [ ] 是否展示社会认同证据（销量/好评）
- [ ] 逼单是否用了稀缺（限量/限时/竞争）
- [ ] 信任背书是否调用权威

## 反模式

- 虚假稀缺（编造限量）——信任反噬，监管风险。
- 只稀缺不讲价值——用户觉得被套路。
- 滥用权威（资质造假）——翻车代价大。

## 边界声明

- 原则来自社会心理学实验，个别案例年代较早，需结合当下语境。
- 原则是增强器：产品/价格不行时，任何原则都救不了。
- 平台监管（虚假宣传）趋严，稀缺话术需真实。
