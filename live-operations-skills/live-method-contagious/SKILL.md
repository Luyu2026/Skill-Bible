# 《疯传》· 直播传播方法论

> 本 Skill 由 [陆羽Skill](https://github.com/Luyu2026/Skill-Bible/tree/main/luyu-skill) 生成。

## 核心框架

### 框架1：STEPPS 六原则（直播/切片传播底层）
- **适用场景**：设计直播引流短视频、切片传播、裂变机制时
- **步骤**：
  1. **社交货币**：给用户"分享后显得我懂/我值"的内容（谈资、优惠情报）
  2. **诱因**：把内容与高频场景绑定（"每天 8 点抢""通勤路上看"）
  3. **情绪**：高唤醒情绪驱动分享（惊喜/愤怒/感动），低唤醒（满足）不传播
  4. **公开性**：让行为可见（"直播间 N 万人正在抢"），模仿跟随
  5. **实用价值**：给用户用得上的信息（省钱攻略/避坑清单）
  6. **故事**：把产品放进故事里，让信息搭便车传播
- **输出物**：引流视频/切片的传播设计（每条内容对应哪条原则）
- **来源**：全书六章

### 框架2：高唤醒情绪（分享的燃料）
  - **适用场景**：选择切片内容时
  - **步骤**：优先剪"高唤醒瞬间"（超低价、逼单高潮、翻车、感动），低唤醒内容不剪
  - **输出物**：切片内容挑选标准
  - **来源**：情绪章节

## 决策规则（节选）

1. **如果**要设计引流视频，**则**先想"用户为什么愿意转发"（社交货币/情绪/实用价值）。
2. **如果**要剪切片，**则**只剪高唤醒瞬间，平淡内容不剪。
3. **如果**想让直播被讨论，**则**制造可公开的谈资（价格/玩法/事件）。
4. **如果**要设计裂变，**则**给分享者"显得聪明/省钱"的内容，而非干巴巴的链接。

## 检查清单

- [ ] 内容是否给用户社交货币（分享有面子/有价值）
- [ ] 是否有高唤醒情绪点
- [ ] 是否绑定高频诱因
- [ ] 分享行为是否可见/可模仿
- [ ] 是否有实用价值或故事外壳

## 反模式

- 硬广式内容（没有分享动机）。
- 平淡切片（低唤醒不传播）。
- 虚假事件炒作（信任反噬）。

## 边界声明

- 方法源自社交媒体研究，平台算法变化快，需结合当下。
- 传播是放大器：内容本身不行，再会传播也留不住。
- 情绪炒作需守住真实性底线。
