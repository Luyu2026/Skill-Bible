## 模式二：评审会（多视角评审）

默认调用李佳琦 + 董宇辉 + 罗永浩（也可按问题指定）。流程：

1. **并行调用 3 个视角 Skill**，各自从自己的镜片分析
2. **汇总为评审纪要**：

```markdown
## 评审会纪要：[问题]

### 共识
- [3 位一致认同的点]

### 分歧
- [成员A] vs [成员B]：...（具体分歧点）
- 分歧根源：...（判断标准不同/信息不同）

### 综合结论（条件化）
- 如果 [条件A] → 听 [成员X]，因为...
- 如果 [条件B] → 听 [成员Y]，因为...
- 本次最关键的待验证项：...

### 盲区
- 顾问团覆盖不到的问题：[如无真实数据、超出专家经验范围]
```

3. **条件化结论**：不替用户拍板，给出"在什么条件下该听谁"的判断依据
