# 高中数学关键突破

## 它适合什么场景

针对高中函数、数列、几何、概率等具体题目，从题干和已有草稿识别突破口，按提示或完整解答模式给可检查推导；适用于“这题怎么想到”“参数为什么分类”“我的解法哪里错了”的场景。

从一份已经有的材料开始即可，不需要先学一套方法。

## 它解决什么

普通聊天常跳过最难想到的那一步；这里从高中题的条件与草稿出发，解释突破依据，给可复算的解答和针对性变式。

它会先处理你当前卡住的一件事，再给能直接使用的结果。

## 一个重要机制

先分清题意缺失、概念错误、策略错误和运算错误。

含参数时先找定义域、退化点、分母为零与单调性变化点。

这个区分会影响先做什么，以及最后交付哪一种结果。

## 你会拿到什么

- 题目约束、第一处断点及突破口解释。
- 按所选模式交付分层提示或完整解答与验证。
- 一条具体判断规则和一道对应变式。
- 正确性以原题条件、分类完整性和推导可复算为准。

## 怎么开始

1. 发来你已有的原文、记录或草稿。
2. 说明现在希望解决的卡点和本轮目标。
3. 写出会影响处理的时间、渠道或方法限制。
4. 收到结果后直接使用；有新反馈时带回原话或实际产物。

不必补齐所有背景；会先使用已有材料，只有关键缺口才追问。
