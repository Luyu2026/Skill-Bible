# 高中数学关键突破

## 它适合什么场景

高中题干看得懂，却不知道为什么要配方、分类或作辅助线。

也适合拿已有解法来问：第一步哪里不成立，边界有没有漏。

## 它解决什么

从完整题干和草稿找突破口，解释为什么这样想到，给可检查的推导。

可以只要一层提示，也可以直接要完整解答。

## 一个重要机制

先找第一处断点，再选解法。

含参数时先查定义域、零值和符号；算出答案还要检查必要性、充分性和边界。

只要提示时会停在当前一步，不在后文偷放答案。

## 你会拿到什么

- 已知、所求与变量范围。
- 草稿第一处缺口，或没有草稿时的突破口。
- 一层提示或完整解答与回代检查。
- 完整讲解后的一条规则和对应变式。

## 怎么开始

1. 发完整题干，带图时包含全部标记。
2. 发草稿与最后能理解的一行；没有也可开始。
3. 说明已学方法，以及要提示、纠错还是完整解答。
4. 提示后交下一行推理，变式后交实际过程。

## 可直接复制的调用模板

```text
请使用 high-school-math-breakthrough。

题目：对所有实数x，a x²−2x+1≥0，求a范围。
草稿：判别式4−4a≤0，所以a≥1。
疑问：这样是否漏了分类？
已学方法：配方、判别式，尚未学导数。
本轮模式：完整纠错。
请指出第一处论证缺口，给必要充分推导和边界核验。
```
