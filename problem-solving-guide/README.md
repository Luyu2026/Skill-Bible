# 怎样解题：思路还原

## 适合什么场景

根据完整题目、年级和学生草稿还原解题思路，提供分层提示、推导与检验。适用于家长想看懂难题、学生卡住、想把答案拆成可解释步骤的场景。

你已经有材料，却卡在把它变成可使用结果的这一步。
可以提交初稿、截图或片段，不必先重新整理。

## 解决什么

从题目与学生草稿定位卡住的思维动作，交付能讲明白且可验算的解题过程，解决只抄答案却不知道为什么的问题。

本轮围绕一个具体卡点完成交付。
事实不够的地方会标清，已能完成的部分先交付。

## 一个重要机制

不会读条件、不会建模、计算错误和验证遗漏分别处理

提示模式逐层透露，完整解答模式一次给足，不强迫问答

这样你能知道哪些结论有材料支持，哪些仍需确认。

## 你会拿到什么

- 卡点诊断与适合年级的主方法
- 分层提示或完整解答，遵循用户选择
- 回代、单位或逻辑完备性检验
- 家长可直接问的一句话和一个迁移问题

结果以可复制文本或可编辑表格呈现。
若相关工具可用，再按你的要求生成文件。

## 怎么开始

1. 贴出现有材料或提供可读取的文件。
2. 说清当前卡点和本轮想拿走的结果。
3. 补充使用场景与不可改变的限制。
4. 收到成品后，按其中一个下一步复交即可。

优先提供：题目原文或清晰图片，保留图形标记和选项。
可选补充：学生年级、学过的方法及老师的限制。
