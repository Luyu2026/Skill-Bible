# 怎样解题：思路还原

## 适合什么场景

孩子或你自己已经做了几步，却不知道接下来怎么走。

适合家长看懂讲解、学生逐层提示，或直接需要完整推导。

## 解决什么

从已有草稿最后一个有效步骤接着解释，给出有依据且能验算的解答。

本轮围绕你提交的材料完成一份可使用的结果。
缺失项会明确标出，已有材料不需要重新整理。

## 一个重要机制

读题、建模、运算和检验分别诊断，避免把所有卡点叫作粗心。

只要提示时逐层给，不提前抖出答案；要完整解答时则一次给足。

## 你会拿到什么

- 草稿断点与适合已学知识的主方法
- 按你选择的模式给提示或完整讲解
- 回代、单位、取值或证明覆盖检查
- 一个同构问题及复交关键关系式

结果优先给可复制正文或可编辑表格。
如需文件，会说明实际生成和验证到哪一步。

## 怎么开始

1. 给完整题目，保留图形标记和选项。
2. 补充年级、已学方法与老师限制。
3. 贴草稿，哪怕只有一行。
4. 说明本轮要提示、完整答案还是家长讲解稿。

没有草稿也能开始；题图看不清时先核对条件，不猜图形关系。

可先查看 [完整模拟案例](references/review-example.md) 了解成品形式。

## 可直接复制的调用模板

```text
请使用 problem-solving-guide。
题目：[原文或清晰图片]
年级与限制：[已学方法、禁用方法]
我的草稿：[已有步骤]
本轮模式：[逐层提示/完整解答/家长讲解]
请定位第一个断点，解释关键关系并检验；提示模式先不要给最终答案。
```
