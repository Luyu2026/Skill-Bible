# 怎样解题：思路还原

## 一句话主餐

从题目与学生草稿定位卡住的思维动作，交付能讲明白且可验算的解题过程，解决只抄答案却不知道为什么的问题。

## 输入

- 题目原文或清晰图片，保留图形标记和选项
- 学生年级、学过的方法及老师的限制
- 已有草稿、答案和具体卡点优先于重新做题
- 用户要提示、完整解答还是家长讲解稿
- 图片关键条件不清时先核对，不能补出不存在的条件

材料优先级：用户现有原稿与记录优先；补充信息只追问会改变本轮判断的部分。
真实材料、合理推断与明确模拟内容分别标记。
不能读取附件时，请用户粘贴关键片段；先完成不依赖附件的部分。

## 核心判断

1. 不会读条件、不会建模、计算错误和验证遗漏分别处理
2. 提示模式逐层透露，完整解答模式一次给足，不强迫问答
3. 多解法只选适合已学知识的一条主线
4. 题目条件不足、矛盾或有多个答案时应明确指出
5. 证明题检验推理完备，应用题检验单位与实际意义
6. 家长稿用引导问题帮助孩子推进，不替孩子制造“粗心”诊断

## 编号工作流

### 1. 复原题意

- 列已知、所求、约束和必要图形关系
- 把文字条件翻译为变量或数量关系
- 区分题面明确给出与图上看起来像的关系
- 输出一句话题意并标记不清处

### 2. 定位草稿断点

- 沿学生现有路径找到最后一个有效步骤
- 指出第一个失效转换，而非重写整份答案
- 没有草稿时提出一个区分读题与建模的问题
- 在能合理解释的范围内给出卡点判断

### 3. 选择桥梁关系

- 从所求倒推需要什么中间量
- 比较列式、画图、枚举或反推中的合适方法
- 解释为什么这个关系连接已知和所求
- 只在主方法受阻时增加备选方法

### 4. 执行并解释

- 每个关键式子紧跟依据
- 提示模式先给方向，再给关系，最后才给运算
- 完整模式列清必要中间步骤与结果单位
- 不能跳过除零、取值范围或增根检查

### 5. 独立检验

- 把结果带回原始条件而非只重算同一个式子
- 检查数量级、边界和题目所问对象
- 证明题检查是否覆盖所有情况
- 发现原题不成立时给反例或矛盾位置

### 6. 迁移与复交

- 提炼本题最有用的一个思维动作
- 仅改变一个条件生成一题同构练习
- 本轮完成主问题，再让学生交回关键关系式
- 按关系是否正确决定补提示或转下一类题

## 直接交付与下一步

- 卡点诊断与适合年级的主方法
- 分层提示或完整解答，遵循用户选择
- 回代、单位或逻辑完备性检验
- 家长可直接问的一句话和一个迁移问题

### 完成条件

- 交付物逐项回到输入来源，关键判断有依据或明确的未知边界。
- 用户能直接使用本轮成品，而不是再把方法说明自行转成成品。
- 待确认项只阻塞相关结论，不阻塞已可完成的部分。
- 本轮结束时指出一个最值得交回的材料和它会改变的判断。

### 工具与数据降级

- 工具不可用时说明已执行到哪一步，交付可编辑文本或底表。
- 依赖外部事实的部分没有核验就保留待确认，不写成已经完成。
- 文件交付失败时直接提供可复制正文，并保留建议文件名。

### 外部参考与延展

- 何时研究：常规解释学生仍不懂、教材限制不清或证明路径存疑时启动。
- 去哪找：查对应教材、课程标准和大学教学资源；检索“Polya understand plan carry out look back”。
- 看什么：观察如何表征条件、选择中间量和设计渐进提示。
- 怎么用：用原草稿重新执行，验证学生能补上断点，不以答案相同代替理解。
- 采用前比较至少两个可行机制或与当前方法对照，说明材料成本及适用边界。
- 用触发问题的同一输入验证改动，保留有效方法，丢弃不能改善交付的装饰功能。
- 外部资料帮助调整方法，不能替代用户事实；实际复用受许可约束的内容时保留必要声明。

### 交付前逐项复核

1. 对照原始材料，检查是否改变数字、条件、角色或时间。
2. 检查推荐路径是否符合用户现有工具和材料条件。
3. 把仍需核验的结论与已经完成的内容分开。
4. 用下方模拟案例执行主流程，核对输出是否能落地。
5. 遇到模拟案例未覆盖的真实限制，缩小承诺后再交付。
6. 对后续反馈只改影响本轮目标的判断，避免无关扩展。
7. 输出文件与对话结论保持一致，不把计划称为执行结果。

### 明确模拟的执行示范

- 模拟题：鸡兔共 8 只，共 22 条腿，鸡兔各几只？小学，尚未学二元方程。
- 模拟草稿：8×2=16，然后不知道怎么用 22。
- 卡点：已经得到全按鸡计算的腿数，缺少每换一只兔增加 2 条腿的关系。
- 提示：实际比 16 多几条？每只鸡换成兔增加几条？
- 解答：(22−16)÷(4−2)=3 只兔；8−3=5 只鸡。
- 检验：3+5=8，3×4+5×2=22；迁移只把腿数改为 24，让学生写差额关系。

方法入口：[多伦多大学 Pólya 解题步骤](https://www.utsc.utoronto.ca/learningstrategies/polyas-problem-solving)。采用理解、计划、执行、回顾的阶段区分；本 Skill 进一步以草稿断点控制提示深度。
