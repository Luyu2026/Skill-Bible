# 朋友圈场景文案

## 适合什么场景

用户提供照片、生活片段或活动信息，想写朋友圈、同图三种文案或不知道怎样配字。

已有材料可以直接发来，不需要先整理成标准问卷。

## 解决什么

把用户眼前的一张照片或一件小事，写成三条风格清楚、事实一致、可以直接发布的朋友圈文案。

先处理眼前问题，避免拿到一堆难以采用的泛泛建议。

## 一个重要机制

先区分生活记录和商业邀请；生活记录不能擅加购买引导。

照片中可见的物体不等于用户的经历；不能由海边照片推断旅行地点。

这让结果既能直接用，也能看出哪些地方还需要你确认。

## 你会拿到什么

- 三条可直接发的文案，清晰标明风格
- 一条推荐及理由；必要事实缺口单列
- 用户回传喜欢哪版和哪个词不像自己，即可继续精修

完整的模拟输入与成品见 [演示](DEMO.md)。

## 怎么开始

1. 直接贴出现有材料。
2. 告诉我这次最想解决的一个问题。
3. 补充限制，例如语气、方法、时间或输出形式。
4. 拿到结果后，只需回传当前仍不满意或没理解的一处。

建议提供：

- 照片或照片内容描述；识别不到的细节先确认
- 事情的时间、地点、人物关系和用户愿意公开的事实
- 本次目的：记录生活、表达心情、分享活动或邀请参与

工具无法读取附件时，可以先粘贴核心文字；仍能得到与这些文字对应的结果。

## 可直接复制的调用模板

```text
请使用 moments-caption-studio。
我的材料：
（粘贴原稿、题目、照片描述或当前处境）

这次最卡的是：
（只写当前要解决的一件事）

请保留的事实或限制：
（写不能改的事实，以及你希望采用的语气、方法或输出形式）

请直接给本轮成品；无法确认的内容单列，不要替我补造事实。
```
