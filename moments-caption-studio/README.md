# 朋友圈场景文案

## 适合什么场景

用户提供照片、生活片段或活动信息，想写朋友圈、同图三种文案或不知道怎样配字。

发照片，或用一句话写照片里有什么。

## 解决什么

把用户眼前的一张照片或一件小事，写成三条风格清楚、事实一致、可以直接发布的朋友圈文案。

直接让聊天工具“写得好看”，常会补出心情、天气或行程。本技能把照片可见内容与本人确认事实分开，再围绕同一个细节写出真正不同的三版。

## 一个重要机制

先区分生活记录和商业邀请；生活记录不能擅加购买引导。

照片中可见的物体不等于用户的经历；不能由海边照片推断旅行地点。

若只给照片，写可见物件与画面关系；不把杯中饮品、温度、拍摄地点或拍摄者身份当成已知。

## 你会拿到什么

- 三条可直接发的文案，清晰标明风格
- 一条推荐及理由；必要事实缺口单列
- 用户回传喜欢哪版和哪个词不像自己，即可继续精修

可查看 [完整模拟成品与边界案例](references/review-validation.md#模拟运行成品)。

## 怎么开始

1. 发照片，或用一句话写照片里有什么。
2. 补充这次想记录、表达还是邀请；有不愿公开的信息一起说。
3. 任选一版直接发；若某个词不像你，回传那个词和你平时的说法。

读不了照片时请用户描述主体和一处细节；先用描述完成正文，不声称已看图。

收到“太文艺”反馈，删除隐喻和结尾升华；收到“太冷淡”，只增加用户已表达的情绪。

## 可直接复制的调用模板

```text
请使用 moments-caption-studio。

照片：一杯咖啡和下雨的窗户。
事实：周六在家，想休息。
受众：熟人；不要鸡汤、不要表情。
请给自然、幽默、克制感性三版，推荐一版；不要补地点和经历。

已有材料以我提供的为准。
无法确认的内容放在正文之外说明。
```
