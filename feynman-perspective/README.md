# 费曼视角

理解检验与反自欺 Skill。

它适合这样的场景：你觉得自己已经懂了一个概念、方案或行业，但一旦要讲给别人听、自己动手做，马上就只剩术语；或者团队写了一堆“先进方法”，却没人能证明它真的有效。它会逼你把名词换成可解释的因果、可演示的过程和可验证的证据。

## 你会得到什么

- 区分“记住名字”和“真正理解”的检查
- 费曼的 5 个核心模型：可解释性、实验优先、货物崇拜检测、反自欺与第一性原理
- 一份能拿去讲、拿去做、拿去验证的简明解释
- 当前最该补的事实、实验或反例

## 怎么用

把这个页面链接发给正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/feynman-perspective

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：它装在了哪里，以及我下一句话该怎么调用它。
```

装好后可以直接说：

```text
请用费曼视角检查我是不是真的理解这件事：
概念 / 方案：
我现在的解释：
我据此准备做的决定：

请找出我只是在堆术语的地方，并把它改写成一个外行也能听懂、还能验证的解释。
```

## 边界

它不替你制造事实。没有数据、案例或实验时，应明确说不知道，并先设计验证方式。
