# 长文证据摘要

## 它适合什么场景

长报告没空读，需要三条重点；或手里多份材料，想看结论哪里一致、哪里冲突。

适合要求数字、条件和出处都能回到原文的工作摘要。

## 它解决什么

只从已读取的内容压缩重点，保留会改变结论的前提。

不会凭标题补内容，也不会把作者建议写成已经证实的效果。

## 一个重要机制

每条重点都能回查。

数字保留分母、时间和单位；材料冲突时并列说明来源与口径。

自算比例会标注，外部核验和原文摘要分开。

## 你会拿到什么

- 指定篇幅的重点摘要。
- 页码、标题或本轮段落编号定位。
- 核心限制与来源分歧。
- 读取不完整时的具体范围提示。

## 怎么开始

1. 发原文、附件或可访问链接。
2. 说明读给谁看，想了解、决策还是转述。
3. 指定三条、字数或必须保留的数据。
4. 链接不可读时补正文；追问时指出对应条目即可。

[查看三条重点与缺页处理的模拟示例](references/delivery-example.md)。

## 可直接复制的调用模板

```text
请使用 source-grounded-summary。

原文：试点40人，24人完成。完成者18人满意。
报告建议扩大，但无对照组，不能判断课程造成效果。
目标读者：负责人。
输出：三条重点，每条带出处，保留分母和限制。
原文没有页码，可用本轮段落编号。
只做原文摘要，不要另编预算和行动负责人。
```
