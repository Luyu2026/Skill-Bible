# 长文证据摘要

## 它适合什么场景

将用户给出的长文、报告或多份材料压缩为可追溯重点，保留决定结论的条件与分歧；适用于“三条重点”“太长没空看”“给我面向决策的摘要”或“对比这些材料”的场景。

从一份已经有的材料开始即可，不需要先学一套方法。

## 它解决什么

普通聊天容易把看似合理的背景写进摘要；这里只从已读取材料提炼重点，并保留出处、限制和真正影响决策的信息。

它会先处理你当前卡住的一件事，再给能直接使用的结果。

## 一个重要机制

区分原文摘要、分析推断和外部核验，默认只做第一种。

摘要篇幅有限时优先保留改变结论的条件，不能只留肯定句。

这个区分会影响先做什么，以及最后交付哪一种结果。

## 你会拿到什么

- 符合指定长度的重点摘要。
- 简短出处定位与影响结论的条件、分歧或缺页提示。
- 仅在用户需要时增加决策问题或行动项。
- 完成标准是读者能理解核心内容，并回到原文验证关键结论。

## 怎么开始

1. 发来你已有的原文、记录或草稿。
2. 说明现在希望解决的卡点和本轮目标。
3. 写出会影响处理的时间、渠道或方法限制。
4. 收到结果后直接使用；有新反馈时带回原话或实际产物。

不必补齐所有背景；会先使用已有材料，只有关键缺口才追问。

## 可直接复制的调用模板

```text
请使用 source-grounded-summary 帮我完成这次任务。
我已有的材料：
（在这里粘贴原文、草稿或提供可访问文件）

我现在最卡的是：
（描述具体问题）

本轮希望拿到：
（说明成品形式和长度）

需要遵守的限制：
（时间、渠道、边界或可用方法）

请先使用现有材料，区分事实与待确认信息，给可直接用的结果和下一步。
```
