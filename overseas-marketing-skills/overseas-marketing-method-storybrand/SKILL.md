# 《Building a StoryBrand》· 品牌叙事框架

> 核心立场：客户是英雄、品牌是向导；用 SB7 七要素写清"你卖什么、如何改善客户生活、如何购买"，消除噪音提升转化。

## 核心框架一：SB7 七要素故事框架

**适用场景**：官网首页/落地页/广告/邮件的整体叙事结构；新品牌定位时的消息架构。

| # | 要素 | 要点 | 关键判断 |
|---|------|------|---------|
| 1 | 角色 Character | 客户即英雄，定义他想要什么 | 触发"故事缺口"，不是公司自我介绍 |
| 2 | 问题 Problem | 反派（单一/可感/真实/根源性）+ 三层：外部/内部/哲学 | 客户为**内部问题**（焦虑挫败）买单 |
| 3 | 向导 Guide | 品牌 = 向导：共情 + 权威 | 共情句 + 权威四件套（见证/数据/奖项/logo） |
| 4 | 方案 Plan | ≤4 步过程计划 + 协议计划 | 给计划起名提升感知价值 |
| 5 | 召唤行动 CTA | 直接 CTA + 过渡 CTA | 直接=购买/预约；过渡=免费资料/试用 |
| 6 | 避免失败 | 不买的代价 | 亏钱/浪费时间/错过机会/生活质量下降 |
| 7 | 成功结局 | 买了之后的人生 | 权力地位/圆满合一/自我实现；"从 X 变成 Y" |

**输出物**：一页 BrandScript；官网首页结构；one-liner（角色+问题+方案+成功）。

## 核心框架二：用户是英雄，品牌是向导

**适用场景**：品牌语气校准；判断文案是否"自嗨"；写 about/首页标题。

**步骤**：
1. 找出客户的生存驱动型渴望（省钱/省时/建立社交/地位/资源/意义）
2. 把品牌从"英雄位"撤下（品牌当英雄=和客户抢主角）
3. 用共情句 + 权威证明"我能帮你赢"

**核心转变**：文案主语是客户（"你将得到…"）而不是公司（"我们是…"）。

## 核心框架三：BrandScript 品牌脚本

**适用场景**：公司→产品线→产品→细分客群逐级统一消息。

**步骤**：按 7 要素逐格填写 + 两行补充：
- 客户身份转变 "from ___ to ___"（如"从被动狗主人 → 每只狗的救星"）
- 先定 to（理想身份），from 即其反面

**输出物**：一页品牌脚本，作为官网/落地页/邮件/销售话术的单一事实源。

## 决策规则（8 条，标注章节）

1. **如果**访客 5 秒内答不出"你卖什么/如何让生活更好/我该怎么做"，**则**重写首屏——信息的敌人是噪音。（Ch2）
2. **如果**文案主语是公司而非客户，**则**改为以客户渴望开头并显式说出"你将得到什么"。（Ch4）
3. **如果**只讲外部问题（如"更省电"），**则**补充并主推内部问题（焦虑/挫败感）。（Ch5）
4. **如果**品牌在文案里当英雄，**则**降为向导：删掉自夸，换共情+权威。（Ch6）
5. **如果**客户行动流程超 4 步，**则**压成 3 步并命名。（Ch7）
6. **如果**页面上没有"唯一醒目"的按钮，**则**设一个直接 CTA 并随滚动重复；再配过渡 CTA。（Ch8/Ch12）
7. **如果**文案未回答"不买会失去什么"，**则**补"避免失败"段落定义风险。（Ch9）
8. **如果**成功画面模糊，**则**显式写出客户"从 X 变成 Y"的结局。（Ch10/Ch11）

## 检查清单（官网文案自查）

- [ ] 首屏 5 秒可答三问：卖什么？如何改善生活？怎么买？
- [ ] 有 1 句 one-liner（角色+问题+方案+成功）
- [ ] 反派单一、可感、真实，且非竞争对手
- [ ] 三层问题齐备：外部、内部、哲学
- [ ] 共情句 + 权威四件套至少 2 项
- [ ] 计划 ≤4 步且有命名
- [ ] 唯一醒目直接 CTA（整页重复）
- [ ] 至少 1 个过渡 CTA
- [ ] 明确写出"不买的代价"
- [ ] 明确写出"买了之后的人生"+"从X到Y"转变
- [ ] 全页字极少（参考：整页 ≤10 句）

## 反模式

- **英雄型品牌**：首页全是"我们是行业领先者"——客户在找向导，直接流失
- **噪音式官网**：功能清单+内部黑话堆砌，让客户"燃烧太多卡路里"去理解
- **无反派、无风险**：只讲好处不讲"不买的代价"，故事无张力
- **CTA 缺席或泛滥**：无按钮或满屏同权重按钮

## 边界声明

- SB7 是**信息架构与叙事框架**，不是完整营销策略：不覆盖定价/渠道/产品/竞品差异化（4P）
- 书中数据多属轶事与断言，转化提升案例不可直接外推
- 偏向 B2C/服务型/中小 B2B 的情绪购买路径；纯功能型/开发者产品、强监管行业需调适
- 情感叙事跨文化效力不同；高语境/低信任市场需本地证据与 KOL 背书
