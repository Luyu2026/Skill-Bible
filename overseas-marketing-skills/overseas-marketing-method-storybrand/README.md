# overseas-marketing-method-storybrand

## 它适合什么场景

《Building a StoryBrand》方法论。把 SB7 故事框架（角色/问题/向导/方案/CTA/避免失败/成功结局）转化为品牌叙事与官网文案的可执行框架。 。
它是「海外市场营销」Skill 库的一环。

## 它解决什么

它把「每次都要从头想一遍」的海外营销工作沉淀成固定流程：输入你的材料，按内置判断和工作流拆解，交付可直接使用的产物（报告、方案、策略），不虚构数据、不替你拍板。

## 一个重要机制

**SB7 七要素叙事框架**：客户是英雄、品牌是向导；用七要素写清'卖什么/如何改善生活/怎么买'，消除噪音提升转化。

## 你会拿到什么

- 结构化交付物（具体格式见 SKILL.md「输出格式」章节）
- 基于你提供的真实材料，信息不足时先问或标注 **[待确认]**
- 涉及判断类问题（该不该做、怎么选）转顾问团

## 怎么开始

```text
请调用 overseas-marketing-method-storybrand，帮我处理下面这件事：
（粘贴你的问题、材料或数据）
```

## 边界

- 不编造数据：缺信息会先问或标注 **[待确认]**
- 复杂问题建议先用 `overseas-marketing-master` 判断当前最该推进哪一步
- 判断类问题转 `overseas-marketing-advisory-board` 顾问团
