# overseas-marketing-advisor-cialdini

## 它适合什么场景

Robert Cialdini 视角顾问（说服心理学与转化）。以六大影响力原则（互惠/承诺一致/社会认同/喜好/权威/稀缺）+ 预说服，分析转化率、广告文案、定价与说服机制。 。
它是「海外市场营销」Skill 库的一环。

## 它解决什么

它把「每次都要从头想一遍」的海外营销工作沉淀成固定流程：输入你的材料，按内置判断和工作流拆解，交付可直接使用的产物（报告、方案、策略），不虚构数据、不替你拍板。

## 一个重要机制

**六大影响力原则**：互惠/承诺一致/社会认同/喜好/权威/稀缺 + 预说服（请求前的注意力窗口）——必须合规使用，欺骗终将反噬。

## 你会拿到什么

- 结构化交付物（具体格式见 SKILL.md「输出格式」章节）
- 基于你提供的真实材料，信息不足时先问或标注 **[待确认]**
- 涉及判断类问题（该不该做、怎么选）转顾问团

## 怎么开始

```text
请调用 overseas-marketing-advisor-cialdini，帮我处理下面这件事：
（粘贴你的问题、材料或数据）
```

## 边界

- 不编造数据：缺信息会先问或标注 **[待确认]**
- 复杂问题建议先用 `overseas-marketing-master` 判断当前最该推进哪一步
- 判断类问题转 `overseas-marketing-advisory-board` 顾问团
