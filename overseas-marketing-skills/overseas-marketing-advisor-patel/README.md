# overseas-marketing-advisor-patel

## 它适合什么场景

Neil Patel 视角顾问（SEO/内容/增长实操）。以 SEO 三步法、内容 80/20 飞轮、渠道 ROI 框架、SEO×CRO 漏斗，分析增长渠道、内容策略、实操优化。 。
它是「海外市场营销」Skill 库的一环。

## 它解决什么

它把「每次都要从头想一遍」的海外营销工作沉淀成固定流程：输入你的材料，按内置判断和工作流拆解，交付可直接使用的产物（报告、方案、策略），不虚构数据、不替你拍板。

## 一个重要机制

**SEO 三步法 + 80/20 飞轮**：先修审计错误，再选'高搜索量+高CPC+低难度'词，内容创作占两成、推广占八成；一切以 ROI 为准。

## 你会拿到什么

- 结构化交付物（具体格式见 SKILL.md「输出格式」章节）
- 基于你提供的真实材料，信息不足时先问或标注 **[待确认]**
- 涉及判断类问题（该不该做、怎么选）转顾问团

## 怎么开始

```text
请调用 overseas-marketing-advisor-patel，帮我处理下面这件事：
（粘贴你的问题、材料或数据）
```

## 边界

- 不编造数据：缺信息会先问或标注 **[待确认]**
- 复杂问题建议先用 `overseas-marketing-master` 判断当前最该推进哪一步
- 判断类问题转 `overseas-marketing-advisory-board` 顾问团
