# 品牌定位文档模板

本文件是 overseas-marketing-branding 的参考模板。生成品牌定位文档时按此结构输出，每个章节的说明文字是写作指引（不要原样复制到最终文档里），根据实际需求填充内容。

---

## 文档头部

```markdown
# 品牌定位文档

日期：（当天）
数据范围：（如有数据，注明口径）
```

## 一、目标客群
**作用**：定位的地基——先明确为谁服务。

- 核心客群画像（人口/行为/痛点/渴望）
- 替代方案（他们现在用什么）
- 最小可行受众（MVA）

## 二、竞品定位地图
**作用**：找到空位。

- 两轴定位地图（价格×品质 或 功能×情感）
- 主要竞品位置标注
- 空位分析

## 三、差异化定位
**作用**：核心交付——一句话说清"为什么选我们"。

> 对于 [目标客群]，他们 [痛点]，我们的 [产品] 是 [品类]，能 [核心价值]，不同于 [竞品] 的 [做法]，因为我们 [差异化证据]。

**检验三问**：真实吗？独特吗？用户在乎吗？

## 四、品牌故事
- 使命（为什么存在）
- 为谁战斗（客群）
- 价值观（相信什么）

## 五、品牌调性与关键词
- 语气（专业/亲民/先锋...）
- 视觉方向（配色/风格）
- 品牌关键词（3-5 个）

## 六、风险与假设
- [ ] 客群洞察数据依据
- [ ] 差异化可持续性
- [ ] 假设：...（验证方式）


## 填写指引（增强版）

> 本节为逐项填写指引，实际交付文档时**不复制**本段，仅作为填写参考。

### 文档头部
- 先定义「要做成什么样（量化目标）」，再写「怎么做到（动作 + 负责人 + 时间）」，最后写「怎么知道做成了（验收指标）」
- 每个字段尽量给具体例子（数字 / 场景 / 文案），不要留空或只写形容词
- 写清依赖与协作：谁提供什么输入、谁验收什么输出

### 一、目标客群
- 每个目标都要可量化：写清「数字 + 时间 + 责任人」，如「Q3 新增付费用户 5000 人（对比 Q2 提升 25%），数据组每周五出报表」
- 核心指标只选 1~2 个北极星指标，其余放辅助列；目标值必须注明依据（历史基线 / 行业基准 / 老板口径）
- 人群列要写具体是谁：新用户还是老用户、哪条渠道进来、哪个生命周期阶段

### 二、竞品定位地图
> 通用填写指引同上：量化目标 → 动作+负责人+时间 → 验收指标；字段给具体示例；写明依赖协作。

### 六、风险与假设
- 风险写「场景 + 概率 + 影响 + 预案」，预案必须可执行
- 至少覆盖：内容/合规、成本超支、关键人/供应商、数据口径分歧
- 标出谁负责监控、多久检查一次
