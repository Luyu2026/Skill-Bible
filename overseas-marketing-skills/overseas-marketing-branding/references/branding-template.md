# 品牌定位文档模板

本文件是 overseas-marketing-branding 的参考模板。生成品牌定位文档时按此结构输出，每个章节的说明文字是写作指引（不要原样复制到最终文档里），根据实际需求填充内容。

---

## 文档头部

```markdown
# 品牌定位文档

日期：（当天）
数据范围：（如有数据，注明口径）
```

## 一、目标客群
**作用**：定位的地基——先明确为谁服务。

- 核心客群画像（人口/行为/痛点/渴望）
- 替代方案（他们现在用什么）
- 最小可行受众（MVA）

## 二、竞品定位地图
**作用**：找到空位。

- 两轴定位地图（价格×品质 或 功能×情感）
- 主要竞品位置标注
- 空位分析

## 三、差异化定位
**作用**：核心交付——一句话说清"为什么选我们"。

> 对于 [目标客群]，他们 [痛点]，我们的 [产品] 是 [品类]，能 [核心价值]，不同于 [竞品] 的 [做法]，因为我们 [差异化证据]。

**检验三问**：真实吗？独特吗？用户在乎吗？

## 四、品牌故事
- 使命（为什么存在）
- 为谁战斗（客群）
- 价值观（相信什么）

## 五、品牌调性与关键词
- 语气（专业/亲民/先锋...）
- 视觉方向（配色/风格）
- 品牌关键词（3-5 个）

## 六、风险与假设
- [ ] 客群洞察数据依据
- [ ] 差异化可持续性
- [ ] 假设：...（验证方式）
