# 邮件营销策略模板

本文件是 overseas-marketing-email 的参考模板。生成邮件营销策略时按此结构输出，每个章节的说明文字是写作指引（不要原样复制到最终文档里），根据实际需求填充内容。

---

## 文档头部

```markdown
# 邮件营销策略

日期：（当天）
数据范围：（如有数据，注明口径）
```

## 一、目标与指标
- 核心目标：（转化/培育/留存）
- 关键指标：打开率/点击率/转化率/退订率
- 行业基准参考（打开 15-25%、点击 2-5%）

## 二、列表健康与分层
- 送达率/退订率/垃圾箱率
- 分层方案（活跃/沉睡/按行为）
- 清理计划（不活跃用户处理）

## 三、邮件类型与频率
| 类型 | 目的 | 频率 | 触发 |
|------|------|------|------|
| 欢迎序列 | 激活 | 一次性3-5封 | 订阅 |
| 培育 | 教育 | 每周 | 定期 |

## 四、自动化流程
**欢迎流**：
```
订阅 → 欢迎邮件（立送价值）
    → 品牌故事
    → 产品亮点+社会认同
    → 转化 CTA
```

**弃购流**：1h/24h/72h 三封

**培育流（B2B）**：内容下载 → 教育序列 → 销售触达

## 五、文案与设计方向
- 主题行策略（个性化+好奇心+价值）
- 正文：单一 CTA
- 移动端优先

## 六、测试计划
| 测试 | 变量 | 指标 |
|------|------|------|
| 主题行 | A/B | 打开率 |
| CTA | A/B | 点击率 |
| 发送时间 | A/B | 打开率 |

## 七、合规清单
- [ ] 退订链接
- [ ] 发件人真实
- [ ] 许可来源（CAN-SPAM/GDPR）
