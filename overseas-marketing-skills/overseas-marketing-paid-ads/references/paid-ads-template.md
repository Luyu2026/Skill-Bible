# 广告投放计划模板

本文件是 overseas-marketing-paid-ads 的参考模板。生成广告投放计划时按此结构输出，每个章节的说明文字是写作指引（不要原样复制到最终文档里），根据实际需求填充内容。

---

## 文档头部

```markdown
# 广告投放计划

日期：（当天）
数据范围：（如有数据，注明口径）
```

## 一、目标与盈亏线
**作用**：先定"多少算赢、多少算亏"再谈投放。

- 核心目标：（销售/线索/流量/安装）
- KPI：（ROAS/CPA/CPL/CPI）
- 盈亏线：ROAS ≥ X / CPA ≤ Y（红线）
- 测试预算：总预算的 10-20%

## 填写指引（增强版）

> 本节为逐项填写指引，实际交付文档时**不复制**本段，仅作为填写参考。

### 文档头部
- 先定义「要做成什么样（量化目标）」，再写「怎么做到（动作 + 负责人 + 时间）」，最后写「怎么知道做成了（验收指标）」
- 每个字段尽量给具体例子（数字 / 场景 / 文案），不要留空或只写形容词
- 写清依赖与协作：谁提供什么输入、谁验收什么输出

### 一、目标与盈亏线
- 每个目标都要可量化：写清「数字 + 时间 + 责任人」，如「Q3 新增付费用户 5000 人（对比 Q2 提升 25%），数据组每周五出报表」
- 核心指标只选 1~2 个北极星指标，其余放辅助列；目标值必须注明依据（历史基线 / 行业基准 / 老板口径）
- 人群列要写具体是谁：新用户还是老用户、哪条渠道进来、哪个生命周期阶段

### 二、渠道与预算分配
- 渠道列写「渠道名 + 触达量级 + 单位成本 + 历史转化」
- 按 ROI 从高到低排序，注明主渠道（放量）与测试渠道（小额验证）
- 写明渠道组合逻辑：信息流拉新 → 私域承接 → 社群促活

### 三、受众与定位策略
- 策略回答三个问题：对谁（人群）、做什么（核心动作）、凭什么（差异化理由/资源）
- 每个策略项标注预期收益（可量化）与所需资源，方便排优先级
- 写明不做什么（放弃清单），防止策略漂移

### 四、素材与文案方向
> 通用填写指引同上：量化目标 → 动作+负责人+时间 → 验收指标；字段给具体示例；写明依赖协作。

### 五、出价策略与学习期
- 策略回答三个问题：对谁（人群）、做什么（核心动作）、凭什么（差异化理由/资源）
- 每个策略项标注预期收益（可量化）与所需资源，方便排优先级
- 写明不做什么（放弃清单），防止策略漂移

### 六、测试计划
- 计划拆到「周 × 动作 × 负责人 × 产出物」
- 每个动作标注优先级（P0 必做 / P1 应做 / P2 可做）
- 写明检查方式：每周几、由谁、看哪几个指标验收

### 七、复盘节奏
- 先摆事实再下结论：目标值 vs 实际值逐项对比
- 结论分三类：有效（继续）/ 无效（停止）/ 待验证（再试）
- 每条行动项写「负责人 + 截止时间 + 验收口径」
