# 专家蒸馏方法论

供专家蒸馏 Agent 阅读。目标：提取一个人的认知操作系统（HOW they think），不是复制语录（WHAT they said）。

## 一、提取五层

| 层次 | 内容 | 提取方式 |
|------|------|---------|
| 怎么想 | 心智模型（看世界的镜片） | 三重验证（见下） |
| 怎么判断 | 决策启发式（快速规则） | 从决策记录和访谈中归纳 |
| 怎么说话 | 表达 DNA | 从原文统计句式/词汇/节奏 |
| 什么不做 | 反模式、价值观底线 | 明确反对过的行为 |
| 知道局限 | 诚实边界 | 信息不足处、公开≠真实处 |

## 二、心智模型三重验证

候选论点（此人反复表达的观点、自创术语、核心主张）逐个执行：

1. **跨域复现**：在 ≥2 个不同领域/话题中出现过？（排除随口一说）
2. **生成力**：能据此推断他对一个新问题的立场？（有预测力）
3. **排他性**：不是所有聪明人都这么想？（有辨识度）

三重都过 → 心智模型；过 1-2 重 → 降级为决策启发式；0 重 → 丢弃。
按排他性排序取 top 3-5。宁少勿多：3 个深刻的模型远好于 10 条浅薄原则。

每个模型记录：名称 / 一句话描述 / 来源证据（≥2 个场景，附 URL）/ 应用方式 / 局限性（失效条件）。

## 三、决策启发式

从决策记录和访谈中归纳，格式：**"如果 X，则 Y"**，每条有案例支撑。5-8 条。

## 四、表达 DNA

从原文统计：高频用词、句式节奏、确定性程度、幽默方式、比喻习惯。转成角色扮演时的 3-5 条风格规则。

## 五、反模式

此人明确反对的行为、价值观底线、警告过的错误。3-5 条。

## 六、诚实边界（≥3 条）

- 不能预测面对全新问题的反应
- 不能替代此人的创造力和直觉
- 公开表达 vs 真实想法可能有差距
- 信息截止到调研时间点

## 七、回答工作流（Agentic Protocol）

专家 Skill 必须有「回答工作流」：收到问题先分类——
- **需要事实的问题**（具体公司/人物/事件/市场现状）→ 先 WebSearch 研究再回答，不凭训练语料编造
- **纯框架问题**（思维方式/价值观）→ 直接用心智模型回答
- **混合问题** → 先获取案例事实，再用框架分析

研究维度必须**从心智模型反推**（不是通用"搜索相关信息"）。例：芒格 → 看护城河/管理层激励/最大风险（逆向）；费曼 → 看基本约束/官方说法漏洞/实验数据。

## 八、信息源规则

| 来源类型 | 权重 |
|---------|------|
| 用户提供的一手素材 | 最高+ |
| 本人著作 / 长对话 / 决策记录 | 最高 |
| 社交媒体 | 中等 |
| 他人评价 / 二手转述 | 低（需验证） |

**黑名单（永远排除）**：知乎、微信公众号、百度百科。
中文人物优先：36氪、晚点LatePost、财新、第一财经、虎嗅、少数派、机器之心等权威媒体；访谈用播客（小宇宙/喜马拉雅原始音频）和 B 站原始视频。
