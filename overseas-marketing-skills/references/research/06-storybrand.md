# 《Building a StoryBrand》（故事品牌）— 海外市场营销方法论提炼

## 1. 书籍概述（<80字）
Donald Miller 著（2017，2025 出 2.0 版）。核心主张：客户是英雄、品牌是向导；用 SB7 七要素写清"你卖什么、如何改善客户生活、如何购买"，消除噪音提升转化。全球销量超 100 万册，TREK、TOMS、The Economist 采用。

## 2. 核心框架（3 个）

### 框架一：SB7 七要素故事框架（全书主线）
- **适用场景**：官网首页/落地页/广告/邮件的整体叙事结构；新品牌定位时的消息架构。
- **步骤**（按序走完 7 格）：
  1. 角色 Character——客户即英雄，定义他想要什么（触发"故事缺口"）
  2. 问题 Problem——反派（单一、可感、真实、根源性）+ 三层问题：外部/内部（挫败、焦虑、困惑）/哲学（"不该如此"）
  3. 向导 Guide——品牌 = 向导，只需展示共情（"我们懂你的感受"）+ 权威（客户见证/数据/奖项/logo）
  4. 方案 Plan——≤4 步的过程计划（购买前/后/混合）+ 协议计划（消除顾虑），并给计划起名提升感知价值
  5. 召唤行动 CTA——直接 CTA（购买/预约）+ 过渡 CTA（免费资料、试用、白皮书）
  6. 避免失败——明确"不买的代价"（亏钱、浪费时间、错过机会、生活质量下降）
  7. 成功结局——明确"买了之后人生变成什么样"（权力地位/圆满合一/自我实现）
- **输出物**：一页 BrandScript；官网首页结构；one-liner（角色+问题+方案+成功）。

### 框架二：用户是英雄，品牌是向导（叙事角色原则）
- **适用场景**：品牌语气与定位校准；判断文案是否"自嗨"；写 about/首页标题。
- **步骤**：1) 找出客户的生存驱动型渴望（省钱/省时/建立社交/地位/资源/意义）2) 把品牌从"英雄位"撤下（品牌当英雄=和客户抢主角，客户在找向导）3) 用共情句+权威四件套证明"我能帮你赢"。
- **输出物**：英雄画像（他想要什么、反派是谁）+ 向导证明清单（4 种权威素材）。

### 框架三：BrandScript 品牌脚本（落地工具）
- **适用场景**：公司整体 → 各产品线 → 各产品 → 各细分客群，逐级生成统一消息。
- **步骤**：按 7 要素逐格填写（可在线工具 mystorybrand.com），特别补两行：客户身份转变 "from ____ to ____"（如"从被动狗主人 → 每只狗的救星"）；先定 to（理想身份），from 即其反面。
- **输出物**：一页品牌脚本，作为官网/落地页/邮件/销售话术的单一事实源。

## 3. 决策规则（8 条，标注章节）
1. 若访客 5 秒内答不出"你卖什么 / 如何让生活更好 / 我该怎么做"，则重写首屏——信息的敌人是噪音（Ch2）。
2. 若文案主语是公司而非客户，则改为以客户渴望开头并显式说出"你将得到什么"（Ch4，原则一）。
3. 若只讲外部问题（如"更省电"），则补充并主推内部问题（焦虑/挫败感）——客户为内部问题的解决买单（Ch5，原则二）。
4. 若品牌在文案里当英雄，则降为向导：删掉自夸，换共情+权威（Ch6，原则三）。
5. 若客户行动流程超 4 步，则压成 3 步并命名——多一步多一分困惑（Ch7，原则四）。
6. 若页面上没有"唯一醒目"的按钮，则设一个直接 CTA（颜色/大小突出）并随滚动重复；再配过渡 CTA 承接未决策者（Ch8/Ch12，原则五）。
7. 若文案未回答"不买会失去什么"，则补"避免失败"段落定义风险——没风险故事就不成立（Ch9，原则六）。
8. 若成功画面模糊，则显式写出客户"从 X 变成 Y"的结局——永远不要假设客户懂你的价值（Ch10/Ch11，原则七）。

## 4. 官网文案自查清单（落地页逐项打勾）
- [ ] 首屏 5 秒可答三问：卖什么？如何改善生活？怎么买？
- [ ] 有 1 句 one-liner（角色+问题+方案+成功），并重复于签名/社媒/包装
- [ ] 反派单一、可感、真实，且非竞争对手
- [ ] 三层问题齐备：外部、内部、哲学
- [ ] 有共情句（"我们理解……/你不该经历……"）+ 权威四件套至少 2 项
- [ ] 计划 ≤4 步且有命名（如"极简上线计划"）
- [ ] 唯一醒目直接 CTA（整页重复出现）
- [ ] 至少 1 个过渡 CTA（白皮书/试用/免费资料）
- [ ] 明确写出"不买的代价"（Ch9）
- [ ] 明确写出"买了之后的人生"+"从X到Y"转变（Ch10/11）
- [ ] 成功画面/微笑客户图出现（Ch12）
- [ ] 收入流分块展示（Ch12：每种收入一屏简述）
- [ ] 全页字极少（参考：整页 ≤10 句）

## 5. 反模式（4 条）
1. **英雄型品牌**：首页全是"我们是行业领先者"，客户被迫看另一英雄的故事 → 客户在找向导，直接流失（Ch6，Tidal 反例）。
2. **噪音式官网**：功能清单+内部黑话堆砌，让客户"燃烧太多卡路里"去理解 → 换简单故事结构（Ch1/Ch2）。
3. **无反派、无风险**：只讲好处不讲"不买的代价"，故事无冲突无张力 → 答不出"so what"（Ch9）。
4. **CTA 缺席或泛滥**：无按钮或满屏同权重按钮/软性请求 → 必设唯一醒目按钮并重复（Ch8/Ch12）。

## 6. 边界声明（4 条）
1. SB7 是**信息架构与叙事框架**，不是完整营销策略：不覆盖定价、渠道、产品、竞品差异化（4P），须与 SEO、AB 测试、市场调研并用。
2. 书中数据多属**轶事与断言**（如"70% 营收来自少数客户"），缺乏同行评审实证；转化提升案例不可直接外推。
3. 框架偏向 B2C/服务型/中小 B2B 的**情绪购买路径**；对纯功能型/开发者产品、强监管行业（金融医疗合规文案）需本地化调适。
4. 情感叙事在不同文化市场效力不同；高语境/低信任市场（部分海外新兴市场）需配合本地证据与 KOL 背书，避免恐惧营销引起反感。
