# 私域朋友圈产品文案

## 一句话主餐

从产品证据与客户疑问中选一个发布目标，写出符合本人语气的可发文案和反馈改稿路径，解决空泛卖点与虚构口碑。

普通聊天常把没有证明的卖点写成口碑。本技能从真实产品资料里选一个读者问题，交付两版有风格差异、无待替换符号的朋友圈正文和咨询回复。

## 输入

- 产品资料、价格、规格、适用对象和真实使用限制
- 已有朋友圈原稿、本人常用表达与客户真实问题
- 已授权使用的评价、案例、图片和可公开范围
- 本条目标是解释、互动、咨询还是活动报名；不一条兼做所有目标
- 优惠起止、库存和售后规则；缺证据不能补造稀缺感

### 材料处理

- 优先读取已给原稿、附件和记录，不要求重复填写。
- 只追问会改变当前路径的缺口，其他缺失放在相关判断旁。
- 来源无法打开时使用用户摘录，并写明尚未独立核验。
- 用户事实、工具结果、合理推断与纯模拟分别标记。
- 不把演示数据移植成真实用户材料。

## 核心判断

1. 卖点必须对应证据和受众问题，形容词不能替代事实。
2. 个人体验、客户评价与品牌资料应清楚区分，不伪装亲历。
3. 一条只保留一个主要行动，避免评论、转发和付款同时争抢。
4. 风格差异要体现在开场、视角和节奏，而不只是替换表情。
5. 健康、金融等受监管产品的功效与承诺须核对允许表述。
6. 无真实案例时写产品使用情境，不编造客户、销量或好评。

### 本轮执行门槛

- 资料已有价格规格：可以写解释或咨询稿；活动期限、库存未确认就不写限时限量。
- 只有品牌口号：提取可核对功能；关键功能未确认时先交事实补充卡，不能编功效写发布稿。
- 有本人样稿：只学习句长、称呼和语气，不挪用他人的亲历。
- 客户询问尺寸但规格缺失：行动目标改为领取已知产品信息，不能承诺立即答复未知尺寸。

## 编号工作流

### 1. 读材料与定目标

- 抽取本轮产品、目标人群和发布时间。
- 复用现有原稿与真实客户提问。
- 区分已确认事实与品牌尚待证明的说法。
- 确定一项最希望读者完成的动作。
- 交付发布任务卡。

### 2. 建立卖点证据配对

- 每个卖点附规格、实拍、测试或授权评价来源。
- 指出它解决哪个具体困扰。
- 无证据的绝对化效果降为功能描述。
- 列不适用人群和影响购买的限制。
- 交付可以说与待确认表。

### 3. 选择切入机制

- 解释型从一个反复被问的问题起笔。
- 场景型从用户能识别的使用瞬间起笔。
- 活动型先说明谁适用、截止时间与真实规则。
- 只选择适合当前材料的两种写法。
- 不靠虚构聊天记录或焦虑恐吓制造吸引力。

### 4. 写完整可发稿

- 每版包含开头、证据、适用场景和一个行动入口。
- 使用本人样稿中的句长与称呼，保留自然停顿。
- 若无样稿，采用平实短句并标明语气假设。
- 价格与活动规则按资料原样核对。
- 不给发布稿留下待替换符号；缺项则省略或先确认。

### 5. 配图与回复衔接

- 仅建议用户已有图片的排序和裁切重点。
- 缺实拍时建议使用规格图，不生成假用户反馈。
- 给一个与主行动一致的咨询回复。
- 涉及报价时直接列已确认价格和包含项。
- 不主动向客户发送或发布，交付复制文本即可。

### 6. 按反馈修一轮

- 先给推荐版并说明适合当前目标的原因。
- 记录发布时间、咨询问题与可获得的浏览数据。
- 没有曝光分母时不计算转化率。
- 读者质疑证据先补事实，不先增加夸张。
- 下一轮只改开场、证明或行动中的一个主要变量。

## 直接交付与下一步

- 两版完整朋友圈正文和一版推荐理由。
- 卖点证据核对表与已有图片使用建议。
- 一个可复制咨询回复及下轮反馈入口。

### 卖点进入正文的门槛

| 材料 | 可用方式 | 禁止升级 |
| --- | --- | --- |
| 官方规格 | 准确写功能、尺寸、材质 | 从材质直接推出治病或绝对耐用 |
| 本人实际体验 | 保留时间、条件和个人范围 | 推成人人有效 |
| 已授权评价 | 标明是客户反馈并保留原意 | 编造截图、销量或改成本人体验 |
| 没有案例 | 写假设使用场景并用提问开场 | 虚构客户名字和成交过程 |

价格规格相互冲突时，发布稿删去冲突点，另列需确认字段。
缺活动规则可先交常规款介绍稿，不能用“今晚最后”补气氛。
没有本人样稿时默认平实口语，不写“我用了多年”或“老客都知道”。

### 两版正文与回复的交付规格

两版共享相同事实、同一个主行动；风格分别采用问题解释和场景展示。
每版都直接写完整正文，不把证据核对表夹进可发段落。
常规短帖可按 80—180 字起草；用户指定更短时优先保留事实和单一行动。
选推荐版时说明它如何匹配现有受众疑问，不说已验证更高转化。
图片建议仅对应已有图片：首图展示主要功能，后图补规格；没有图片则交纯文字版。
回复应能兑现正文承诺；缺尺寸时不说“马上发尺寸”，而是如实说明待核对。
只交复制稿；未经用户明确要求不发布、不向客户发消息。

### 发布后的反馈与降级

用户只需带回原发文、读者实际问句和发布时间，不要求收集第三方隐私。
有人问价格说明价格可见性不足；有人误解功能先查证据和表述，不归咎流量。
没有浏览人数时只报咨询条数，不计算咨询率或推断改稿提升幅度。
续改只动一个主要变量，并记录旧句、新句及希望减少的误解。
没有检索工具可用用户已确认的普通产品规格写稿；监管功效未核验则删去相关承诺。
涉及受监管品类时先核验所在地现行要求，失败时交不含功效与收益承诺的事实介绍稿。
完成条件是两版可发稿、一版推荐、证据表、图片建议和一个真实可执行的回复。

## 外部参考与延展

- **何时研究**：用户反馈像广告、风格无差异、产品合规范围不清或咨询集中误解时启动。
- **去哪找**：优先本人历史有效文案、真实客户问句、品牌官方规格；监管要求查产品所在地主管机关。
- **看什么**：比较开场问题、证据位置、信息密度和行动成本；检索“产品类别 广告 宣称 规范”。
- **怎么用**：选一个机制重写同条正文，与原稿比较事实准确、语气与行动是否更清楚，不承诺咨询量提升。
- 比较产品问题开场与场景开场：保持事实和行动相同，仅改变开场视角，用读者是否仍问同一基础问题校验；优先复用用户本人过往稿，不能用热门广告当成效果证据。
- 来源热度只用于发现，不代表方法有效；原始规则优先于二手总结。
- 材料已经足够时直接交付，不机械追加联网研究。
- 外部方法只改变执行机制，不能创造用户经历、报价或个体事实。
- 若实际复用受许可约束内容，保留所需声明；独立改写不等于可以忽略许可。

### 交付前验收

1. 每个确定结论都能回到材料、计算或明确设定。
2. 关键数字、日期、资格和限制没有在改写中发生变化。
3. 交付与用户当前目标一致，没有串入无关阶段。
4. 复制正文即可使用，依赖工具的暂停部分有可操作恢复条件。
5. 不把模拟验证称为真实用户效果，不承诺未经测量的收益。

### 明确模拟的执行示范

39元帆布袋、有内袋、可机洗，但缺尺寸。两版稿均引导领取已确认资料，不承诺立即发尺寸；回复明确尺寸待核对，避免正文承诺无法兑现。
