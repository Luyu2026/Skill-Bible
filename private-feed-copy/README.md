# 私域朋友圈产品文案

## 适合什么场景

你要向熟客介绍产品、上新或活动，资料已有，但写出来总像广告，或客户总在追问同一个基础问题。

可以直接贴现有材料，不必先写一份标准报告。
本轮聚焦你眼前的一件事；缺失信息会写清影响。

## 解决什么

从产品证据与客户疑问中选一个发布目标，写出符合本人语气的可发文案和反馈改稿路径，解决空泛卖点与虚构口碑。

先处理足以判断的部分，再列真正影响结论的缺口。
不会把没有来源的数字、盘面、评价或人生事件写成你的事实。

## 一个重要机制

每个卖点先找证据，两版正文共享事实和一个行动。没有客户评价就写产品情境，不编“回购爆了”。

你能看见结论来自哪项材料，以及哪些条件变了就要重做。
不需要为了开始，把不相关的私人信息也一起提交。

## 你会拿到什么

- 两版完整朋友圈正文和一版推荐理由。
- 卖点证据核对表与已有图片使用建议。
- 一个可复制咨询回复及下轮反馈入口。

[查看完整模拟成品](references/review-validation.md)。
示范标明了模拟设定、实际产物和未验证范围。

## 怎么开始

1. 贴产品规格、价格和限制，活动稿另给真实期限与规则。
2. 说明希望读者做什么：了解、留言、咨询或报名，选一个。
3. 附自己的旧文案和可公开图片；没有旧稿也可先写平实版。

不确定的字段写“不详”即可，不必猜填。
结果标为待核验时，按对应缺口补来源或参数，再续接同一轮。

## 可直接复制的调用模板

```text
请使用 private-feed-copy。
产品与已确认规格、价格：
目标读者和他们常问的问题：
本条唯一目标：
我的旧稿／语气样本：
可用图片、评价授权与活动规则：
请交两版可发文案、推荐理由和咨询回复，不编口碑、体验或库存。
```

续接时贴上上一版成品与新材料，说明哪一项需要改。
只处理受新信息影响的部分，保留仍然成立的依据。
