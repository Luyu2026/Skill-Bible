# 私域朋友圈产品文案

## 适合什么场景

用户已有产品、活动或服务资料，希望写可直接发布的朋友圈种草、上新或成交引导文案时。

你可以直接贴现有材料、截图文字或原稿，不需要先整理成标准报告。

## 解决什么

从产品证据与客户疑问中选一个发布目标，写出符合本人语气的可发文案和反馈改稿路径，解决空泛卖点与虚构口碑。

会区分已经能判断的部分和还需要核验的部分。
不会为了让答案显得完整而补造事实。

## 一个重要机制

卖点必须对应证据和受众问题，形容词不能替代事实。

个人体验、客户评价与品牌资料应清楚区分，不伪装亲历。

这会直接影响哪些结论能写进本轮成品。

## 你会拿到什么

- 两版完整朋友圈正文和一版推荐理由。
- 卖点证据核对表与已有图片使用建议。
- 一个可复制咨询回复及下轮反馈入口。

可以先看 [明确模拟示范](demo.md)，了解输入不足时如何交付。

## 怎么开始

1. 说清当前想完成的一件事。
2. 贴上已有材料，保留来源和时间信息。
3. 说明不能改动的条件与希望的输出长度。
4. 收到成品后，只补影响关键判断的缺口。

优先给这些材料：

- 产品资料、价格、规格、适用对象和真实使用限制。
- 已有朋友圈原稿、本人常用表达与客户真实问题。
- 已授权使用的评价、案例、图片和可公开范围。

## 可直接复制的调用模板

```text
请使用 private-feed-copy。
我本轮的目标：
我已有的材料（直接粘贴或附文件）：
材料来源、时间和已确认事实：
必须保留的限制：
希望交付的形式和长度：
请先利用已有信息产出可用成品；缺失项写清影响，不要编造。
```

需要续接时，把上一轮成品和实际反馈一起贴回即可。
