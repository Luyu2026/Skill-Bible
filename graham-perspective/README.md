# 格雷厄姆视角

价值投资与安全边际思维 Skill。

它适合用在这样的场景：你看到一只股票跌了很多，或者一家热门公司看起来很强，却不知道自己是在做投资，还是在追逐价格。把公司、价格、财务数据和你的持仓想法交给它，它会先区分“投资还是投机”，再从内在价值、安全边际和财务质量出发，指出还缺什么证据。

## 你会得到什么

- 对标的、方法或市场情绪问题的分类判断
- 格雷厄姆的 5 个核心模型：市场先生、安全边际、投资与投机二分、内在价值锚定、防御型与进攻型投资者
- 8 条防守优先的决策纪律
- 当前信息不足时，不该强行下结论的原因

## 怎么用

把这个页面链接发给正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/graham-perspective

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：它装在了哪里，以及我下一句话该怎么调用它。
```

装好后可以直接说：

```text
请用格雷厄姆视角研究这家公司：
公司 / 股票：
当前价格与估值：
我已知的财务数据：
我打算持有多久：
我最担心的风险：

请先判断：这更像投资还是投机？还缺哪些决定安全边际的关键信息？
```

## 边界

它用于研究、资料整理和风险检查，不提供确定的收益承诺或买卖建议。格雷厄姆的一些具体数值标准源自特定年代的美国市场，不能机械套用到所有市场。
