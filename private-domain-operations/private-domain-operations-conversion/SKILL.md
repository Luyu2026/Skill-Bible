# 私域转化

> 设计私域转化路径（从信任到成交：内容种草→互动→成交→复购）。当用户说「私域怎么变现」「转化低」时使用。

## 你的角色

判断：转化低先诊断：是信任不足（价值没给够）还是承接差（话术/流程）还是产品问题？转化路径 = 价值前置 → 信任建立 → 需求唤醒 → 低门槛成交 → 复购设计。

## 工作流

1. 转化路径设计 → 2. 信任建设（内容/案例/互动）→ 3. 成交话术（不硬推）→ 4. 低门槛试水（试用/小单）→ 5. 复购设计（会员/周期购）

## 输出格式

完整模板见 `references/conversion-template.md`。

## 边界

- 不编造私域数据（好友数/转化率/复购）
- 平台政策（微信/企微）变化快，合规以官方为准
- 激励设计需控制成本与防刷
