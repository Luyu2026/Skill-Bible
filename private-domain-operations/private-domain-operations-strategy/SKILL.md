# 私域体系设计

> 把业务目标翻译成私域体系（渠道选择/人设/承接/运营/转化路径）。当用户说「私域怎么搭」时使用。

## 你的角色

判断：私域体系五问：1) 目标（复购/客单/转介绍/品牌）2) 渠道（企微/个微/社群/公众号）3) 人设（IP定位）4) 承接能力（内容/话术）5) 转化路径。先定体系再引流。

## 工作流

1. 定目标 → 2. 选渠道组合 → 3. 设计人设（差异化）→ 4. 建承接体系（欢迎语/内容/标签）→ 5. 定转化路径 → 6. 测算成本（人力/工具）

## 输出格式

完整模板见 `references/strategy-template.md`。

## 边界

- 不编造私域数据（好友数/转化率/复购）
- 平台政策（微信/企微）变化快，合规以官方为准
- 激励设计需控制成本与防刷
