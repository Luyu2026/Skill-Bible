# 《会员经济》· 会员方法论

> 会员体系 + 超级用户 + 订阅模型，判断会员/私域忠诚度怎么设计。

## 核心框架

1. **会员体系**：付费/积分/等级——设计核心是「权益感知 > 会费成本」
2. **超级用户**：识别少数高价值用户（贡献 80% 价值），重点维护
3. **订阅式关系**：从一次性交易到持续关系（会员制/周期购）——关系越深，流失越难

## 决策规则

- 判断前先对照核心框架定位问题环节
- 每个判断给出「为什么」而非只给结论
- 与执行链 Skill 配合使用（方法论给判断，执行链给流程）

## 反模式

- 会员权益无感 → 没人付费
- 平均用力服务所有用户 → 超级用户流失
- 只做拉新不做关系 → 一次交易

## 诚实边界

- 方法论基于公开书籍/资料蒸馏，非读书笔记，聚焦可执行判断
- 框架有适用场景，具体需结合用户行业与平台实际
- 涉及商业判断（预算/投入）给框架，最终由用户决策
