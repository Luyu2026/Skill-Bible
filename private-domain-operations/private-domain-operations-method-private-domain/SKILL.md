# 私域运营方法论

> 私域链路（引流-承接-运营-转化-裂变）+ SCRM，判断私域体系怎么搭。

## 核心框架

1. **私域五环**：引流（钩子）→ 承接（人设/欢迎语）→ 运营（价值内容）→ 转化（信任成交）→ 裂变（老带新）
2. **标签分层**：静态+动态标签，RFM 分层，差异化运营
3. **SCRM 数据**：工具自动化（标签/触达）+ 数据看板（健康度）

## 决策规则

- 判断前先对照核心框架定位问题环节
- 每个判断给出「为什么」而非只给结论
- 与执行链 Skill 配合使用（方法论给判断，执行链给流程）

## 反模式

- 只引流不承接 → 加了好友就流失
- 一上来就卖 → 信任崩塌
- 无分层一刀切 → 效率低下

## 诚实边界

- 方法论基于公开书籍/资料蒸馏，非读书笔记，聚焦可执行判断
- 框架有适用场景，具体需结合用户行业与平台实际
- 涉及商业判断（预算/投入）给框架，最终由用户决策
