# 私域运营核心方法论（调研成果）

> 用途：为「私域运营」Skill 提供方法论底座。核心事实来源见文末。

## 一、核心框架（4 个）

**1. 五步链路：引流→承接→运营→转化→裂变**
全链路闭环是私域运营的骨架。引流：从公域（门店物料扫码、小程序/公众号/视频号、投放、包裹卡）把用户导入私域，用"扫码领券"等即时利益降低动作门槛；承接：过渡到企业微信个人号/社群，添加后自动回复入群链接，做首次触达和信任铺垫；运营：通过社群内容、朋友圈、私聊持续培育；转化：用福利、限时权益促单；裂变：老带新、分享返利驱动自传播。瑞幸走的是"门店/小程序→公众号→企业微信→社群"路径，180 万私域用户、3 个月起量、入群用户月消费频次提升 30%，验证了此链路的可复制性。

**2. 社群 SOP 框架：人设 + 内容节奏 + 互动 + 转化位**
社群不是"拉个群发广告"。核心四件套：①人设统一（如瑞幸"首席福利官 Lucky"、完美日记"小完子"，统一头像昵称强化 IP）；②固定内容节奏（瑞幸每天 5–7 条消息、早晚高峰定点推送，朋友圈每天 1 条推单品）；③互动机制（问答、接龙、红包）；④转化位（群公告置顶小程序/商品入口）。SOP 要写清"时间轴 + 内容类型 + 话术模板 + 责任人"，并提前排期一周。

**3. 标签分层框架：静态标签 + 动态标签 + RFM 分层**
分层是精细化运营的前提，核心是"差异对待"。标签分两层：静态标签（地域、渠道来源、性别等不变属性）和动态标签（近期购买、活跃度、偏好、生命周期阶段）。用 RFM（最近购买间隔 R / 频次 F / 客单价 M）做价值分层，把用户分成高价值、潜价值、成长、流失等层级，分别配置不同运营动作——高价值给专属权益和人工私聊，低价值/流失做召回和低门槛激活。分层的目的是资源投产最大化（20% 用户贡献 80% 价值），并能在 GMV 波动时快速定位是哪一层级出了问题，而非一刀切处理。

**4. 私域数据闭环（SCRM）**
以工具为抓手衡量整个链路：接入量、通过率、入群率（承接指标）；消息触达率、打开率、互动率（运营指标）；转化率、复购率、客单价（转化指标）；裂变率、K 因子、拉新成本（裂变指标）；以及 LTV、私域订单占比、MAU 这类全局指标。数据要反哺策略：哪个渠道引流质量差就调投放，哪个话术触达率低就换文案，形成"数据→洞察→动作"的迭代闭环。

## 二、决策规则（5 条）

1. **如果** 公域流量成本持续上升或投放 ROI 下滑，**则** 把资源向私域沉淀，用现有用户做复购与裂变摊薄获客成本。
2. **如果** 用户入群后 7 天内无互动或未首购，**则** 判定承接失败，检查加粉话术、欢迎语与首单利益点，而不是继续拉新。
3. **如果** 用户已完成首购，**则** 打上"已购+渠道来源+偏好"标签并纳入复购触达序列，因为首购后的 30 天是复购黄金窗口。
4. **如果** 用户 30–60 天未活跃且未流失预警，**则** 用低门槛权益（小额券、签到）激活，而非高折扣；折扣只给价格敏感层，避免伤害价格体系。
5. **如果** 社群转化率下降但新客正常，**则** 优先复盘内容节奏与群活跃度（是否变广告群），而非加推优惠券。

## 三、反模式（3 条）

1. **群发轰炸 + 纯广告群**：只发不养，不设人设和内容节奏，最终群死、用户屏蔽，封死后续所有触达。
2. **藏量不分层或用优惠券解决一切**：对所有用户发同样券，既伤害价格主义，又无法定位到底是价格、需求还是人群出了问题。
3. **只加好友不承接**：加粉后无欢迎语、无标签、无 SOP，用户不知道你是谁，私域变成通讯录僵尸号。

## 四、诚实边界（3 条）

1. 私域不是万能药：对低频高客单、信任驱动型行业（B2B、大宗）效果有限；方法论主要验证于快消、零售、美妆等高频场景。
2. 数据为品牌方披露或第三方测算（如瑞幸案例），具体提升幅度因行业、品类、执行差异很大，不能照搬承诺。
3. 平台规则与政策会变（企微接口、外链、裂变限制），方法论须在合规框架内适配当期规则执行。
