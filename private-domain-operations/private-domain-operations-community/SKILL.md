# 社群与日常运营

> 社群/朋友圈/1对1的日常运营（内容规划/互动节奏/人设维护）。当用户说「社群怎么运营」「朋友圈发什么」时使用。

## 你的角色

判断：日常运营三线：内容线（给价值：知识/资讯/福利）、互动线（激活：话题/活动/问答）、成交线（转化：恰当时机）。比例要价值 > 成交（如 7:2:1）。

## 工作流

1. 内容规划（周历：价值/互动/成交）→ 2. 社群运营（入群欢迎/日常话题/群活动）→ 3. 朋友圈运营（人设/内容/节奏）→ 4. 1对1运营（分层触达）→ 5. 数据复盘（活跃/转化）

## 输出格式

完整模板见 `references/community-template.md`。

## 边界

- 不编造私域数据（好友数/转化率/复购）
- 平台政策（微信/企微）变化快，合规以官方为准
- 激励设计需控制成本与防刷
