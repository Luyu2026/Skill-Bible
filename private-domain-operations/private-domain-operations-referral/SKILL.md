# 裂变与转介绍

> 设计老带新/转介绍/裂变机制（激励设计/传播路径/风控）。当用户说「老客户转介绍」「裂变」时使用。

## 你的角色

判断：裂变三要素：动机（老客为什么推）、奖励（双方受益）、路径（怎么参与）。转介绍的前提是老客满意（NPS 高），否则机制再花哨也没用。

## 工作流

1. 评估老客满意度（前提）→ 2. 设计激励（老客+新客双赢）→ 3. 简化参与路径 → 4. 传播物料 → 5. 风控（防刷）→ 6. 数据追踪

## 输出格式

完整模板见 `references/referral-template.md`。

## 边界

- 不编造私域数据（好友数/转化率/复购）
- 平台政策（微信/企微）变化快，合规以官方为准
- 激励设计需控制成本与防刷
