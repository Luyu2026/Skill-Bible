# 几何辅助线证明

## 适合什么场景

从原题条件反推缺失关系，解释辅助线的用途并写出逐步有依据的证明，避免答案正确却留下关键跳步。

发原题文字和清晰图，说明年级、已学定理、卡住哪行，以及只要提示还是完整证明。

可以只处理眼前的一件事，不要求先整理完整档案。

## 解决什么

把已有材料推进为本轮能使用的结果，并说明哪些判断还缺证据。

例如：模拟题：△ABC中AB=AC，D是BC中点，证明AD⊥BC。学生已学SSS，要完整证明。

本轮会完成一个明确目标，后续问题按实际反馈继续。

## 一个重要机制

点名看不清时先转写可确认部分，列出“D在BC上还是延长线上”等具体问题。

输入不足会改变交付范围，缺失事实不会用猜测补齐。

关键步骤会解释依据，方便你发现哪里不符合实际。

## 你会拿到什么

- 校对题面与条件清单。
- 分层提示及构造说明。
- 陈述与依据对应的完整证明。
- 同时说明关键缺口与结论适用范围。

可看 [完整模拟成品](references/review-validation.md)，输入与输出一一对应。

## 怎么开始

1. 发原题文字和清晰图，说明年级、已学定理、卡住哪行，以及只要提示还是完整证明。
2. 写明本轮最想拿到的结果和不能接受的做法。
3. 先使用返回的本轮成品，注意其中标明的执行前提。
4. 如果要继续，交回真实结果或指出最不适用的一处。

无法打开链接或截图时，直接粘贴关键文字也能开始。

```text
原题：△ABC中AB=AC，D为BC中点，证明AD垂直BC

交付偏好：完整证明，逐行写依据
请先交付本轮能直接使用的成品，说明关键缺口和下一步。
```
