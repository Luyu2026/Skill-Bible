# 几何辅助线证明

## 适合什么场景

辅助线不知道怎么画、几何证明看不懂、希望先获得分步提示时，可以从手头材料开始。

- 原题文字与清晰图片。
- 学生已有草稿与卡点。
- 可以只处理眼前的一件事。

## 解决什么

从原题条件反推缺失关系，解释辅助线的用途并写出逐步有依据的证明，避免答案正确却留下关键跳步。

- 不用先写完整报告。
- 信息不够时会指出具体影响。
- 结果回到你实际提供的材料。

## 一个重要机制

图上看起来相等或垂直不属于已知。

识别不清的点名和数值必须确认，不靠比例猜。

这决定怎样理解材料，以及哪些结论可以直接使用。

## 你会拿到什么

- 校对题面与条件清单。
- 分层提示及构造说明。
- 陈述与依据对应的完整证明。

先看 [模拟演示](demo.md)，了解实际返回的样子。

## 怎么开始

1. 发来已有原文、截图或记录。
2. 说清这次最想解决的一个问题。
3. 补充现实限制或不能接受的结果。
4. 收到成品后按下一步使用。
5. 如需继续，交回实际结果或不适用的一处。

## 可直接复制的调用模板

```text
使用 geometry-proof-builder。
我的情况：
已有材料：
最想解决的问题：

```

不用为了调用重新写一份说明书。
