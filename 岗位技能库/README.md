## 使用原则

1. **第一次使用，从岗位总控开始。** 描述目标、已有材料和当前卡点，让它判断路径。
2. **任务明确，直接调专项。** 例如“分析 D7 留存下降原因”或“为这次活动设计传播机制”。
3. **有分歧，再调顾问团。** 顾问团适合判断“该不该做”“资源放在哪里”，不是每次执行任务的必经步骤。
