# 《爆款文案》· 转化文案方法论

> 本 Skill 由陆羽Skill生成。

> 四步转化框架 + 标题 6 式 + 痛点→方案→证据结构，判断/产出带货文案与种草内容。

## 核心框架

### 1. 文案四步转化框架
- **适用场景**：新媒体带货文案、推文、商品种草内容
- **步骤**：激发兴趣（标题/开头）→ 建立信任（数据/背书/细节）→ 刺激购买（价值感/从众）→ 引导下单（明确指令/低门槛）
- **输出物**：一篇四步结构的带货文案

### 2. 标题 6 式
- **适用场景**：任何需要打开率的内容标题
- **步骤**：痛点式（直击问题）/ 好奇式（留悬念）/ 数字式（量化）/ 反差式（反转）/ 利益式（承诺）/ 身份式（圈层）
- **输出物**：3-5 个标题候选

### 3. 痛点→方案→证据→行动（转化结构）
- **适用场景**：产品种草、课程/服务转化内容
- **步骤**：放大痛点 → 给出方案 → 证据支撑（案例/数据/背书）→ 临门一脚（限时/风险承诺）
- **输出物**：转化文案（含证据链）

## 决策规则（8条）

1. 标题没点击率 → 换标题公式重写
2. 读者不信任 → 补证据（数据/背书/细节）
3. 没有购买冲动 → 放大痛点或强化价值感
4. 读完不行动 → 给明确指令+降低门槛
5. 写转化文案 → 按"痛点→方案→证据→行动"四步走
6. 描述产品 → 用细节场景而非抽象功能
7. 做品牌内容 → 克制销售话术，先价值后转化
8. 文案数据差 → 逐环节拆解找卡点

## 检查清单

- [ ] 标题用了公式
- [ ] 开头 3 秒抓住注意力
- [ ] 有信任证据（数据/背书/案例/细节）
- [ ] 放大痛点并给出方案
- [ ] 有明确行动指令+低门槛
- [ ] 无合规风险（极限词/虚假宣传）

## 反模式

- 标题党（打开率高但伤信任）
- 空口说"很好/很棒"没有证据
- 全文销售腔（读者反感）
- 没有行动指令（看完就划走）
- 忽略合规（广告法极限词）

## 边界声明（≥3条）

- 以公众号/电商文案语境为主，短视频/直播话术需适配
- 内容平台先价值后转化，交易平台可直接转化
- 文案提高转化概率不保证销量（产品力是基础）
- 作者立场：实战经验总结，非实证研究
