# 《引爆点》· 传播引爆方法论

> 三法则（个别人物/附着力/环境威力）+ 记忆点设计 + 引爆点判断，分析内容/事件能否引爆传播。

## 核心框架

### 1. 引爆点三法则
- **适用场景**：判断/设计内容能否引爆、传播设计
- **步骤**：个别人物法则（联系员/内行/推销员触达）→ 附着力因素（内容粘人：记忆点/细节/故事）→ 环境威力（借势：热点/氛围/时机）
- **输出物**：传播引爆设计（种子人群+附着力改造+时机借势）

### 2. 附着力 = 内容"记忆点"设计
- **适用场景**：内容/文案/活动的传播力改造
- **步骤**：提炼一句话核心（可转述钩子）→ 加具体细节（数字/场景/故事）→ 加高唤醒情绪 → 简化表达
- **输出物**：一句话传播核心 + 内容改造方案

### 3. 引爆点判断（小变化引发大效应）
- **适用场景**：判断"为什么突然爆了"、增长拐点识别
- **步骤**：观察临界点 → 识别引爆信号（种子浓度/环境催化/附着力变化）→ 判断已过/未到 → 全力承接或继续种子运营
- **输出物**：引爆点判断 + 承接/继续策略

## 决策规则（8条）

1. 内容想传播 → 先触达"联系员+内行+推销员"三类关键人
2. 内容不粘人（看完就忘）→ 设计附着力（记忆点/细节/故事）
3. 传播要借势 → 匹配环境时机（热点/氛围/场景）
4. 内容要可转述 → 提炼一句话核心（转述不变形）
5. 做传播内容 → 加高唤醒情绪（惊喜/愤怒/好奇）驱动分享
6. 增长未达引爆点 → 继续种子用户运营而非全面推广
7. 已达引爆点 → 全力承接流量（产能/转化/服务跟上）
8. 小改变大影响 → 找关键杠杆点（不平均用力）

## 检查清单

- [ ] 明确种子人群（联系员/内行/推销员）
- [ ] 内容有记忆点（一句话能复述）
- [ ] 有高唤醒情绪
- [ ] 匹配环境时机
- [ ] 传播路径最短（分享成本低）
- [ ] 判断了引爆点阶段（未到/已到）

## 反模式

- 全面撒网不做种子运营
- 内容没记忆点（看过就忘）
- 冷冰冰信息堆砌（无情绪无细节）
- 逆势传播（不看时机硬推）
- 引爆后无承接（浪费流量）

## 边界声明（≥3条）

- 案例基于 2000 年前后美国语境，数字时代算法推荐机制已变，需适配
- 引爆有非线性与随机性，方法论提高概率不保证引爆
- 个别人物法则在去中心化算法时代作用减弱
- 作者立场：社会学观察总结，非实证研究
