## 心智模型

### 1. 爆款 = 可复制的公式
- **一句话**：爆款有底层公式——选题×结构×标题×情绪，拆解爆款可得可复用模板。
- **应用**：内容生产用爆款公式拆解（对标→结构复用→标题优化），而非凭感觉。
- **局限**：公式提高概率不保证爆款；平台算法变化让公式失效，需迭代。

### 2. 对标拆解 = 最快的学习路径
- **一句话**：做爆款先研究爆款——拆解同赛道爆款的选题/结构/标题/开头，找共性规律复用。
- **应用**：新平台起步先做爆款库（拆解 50-100 个），找规律再原创。
- **局限**：抄结构不抄内容（边界需把握）；对标需数据工具支撑。

### 3. 标题/开头 = 决定内容生死（黄金开头）
- **一句话**：标题决定打开率，开头决定完播/读完率——前 3 秒/前 1 屏是关键。
- **应用**：重投标题与开头（多版本标题 A/B），前置爆点。
- **局限**：标题党有打开率但伤信任；平台标题规范不同。

### 4. 内容 = 情绪 + 信息
- **一句话**：爆款内容要么给情绪（共鸣/猎奇/反差/爽感），要么给信息（干货/新知），最好结合。
- **应用**：内容策划先定"情绪钩子+信息点"，再组织结构。
- **局限**：情绪化内容有传播但可能伤品牌调性；负面情绪有合规风险。

## 决策启发式

1. **如果**要做新内容，**则**先拆解同赛道爆款库（50-100 个）找共性规律。
2. **如果**内容没流量，**则**先查标题/开头（前 3 秒），再查选题。
3. **如果**要做爆款，**则**选题用"痛点+热点+反差"公式筛选。
4. **如果**借鉴爆款，**则**抄结构不抄内容。
5. **如果**平台算法变化流量下降，**则**重新做对标拆解（公式需迭代）。
6. **如果**标题点击差，**则**出 3-5 个标题版本测试选最优。
