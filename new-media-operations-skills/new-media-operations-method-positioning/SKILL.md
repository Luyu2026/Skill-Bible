# 《定位》· 账号定位方法论

> 心智抢占（第一法则/二元法则/关联法则）+ 定位四步法，判断账号/品牌定位与差异化。

## 核心框架

### 1. 定位 = 抢占用户心智
- **适用场景**：账号定位、品牌定位、内容赛道选择
- **步骤**：分析心智（已有认知/竞品占位）→ 找空位（品类/特性/人群/场景）→ 抢占（长期一致表达）→ 简化聚焦（一句话能说清）
- **输出物**：定位卡（一句话定位+差异点+支持证据）

### 2. 心智定律（第一/二元/关联法则）
- **适用场景**：赛道选择、差异化策略
- **步骤**：第一法则（成为品类/细分第一）→ 二元法则（做不了第一做"更X"第二）→ 关联法则（"XX界的YY"锚定）
- **输出物**：差异化定位策略（第一/第二/关联路径）

### 3. 定位四步法
- **适用场景**：新账号/新内容线启动前的定位流程
- **步骤**：分析（市场/竞品/心智）→ 定位（选空位）→ 验证（小范围测试）→ 传播（触点一致化）
- **输出物**：定位落地计划（验证方式+一致性规范）

## 决策规则（8条）

1. 做新账号 → 先做心智分析再定位
2. 赛道拥挤 → 找细分空位而非正面竞争
3. 做不了第一 → 做"更X"的第二
4. 定位复杂 → 简化到一句话（心智怕复杂）
5. 解释新事物 → 用关联（"XX界的YY"）锚定
6. 定位确定 → 所有内容/触点一致化
7. 定位不被认可 → 验证并调整（不是自嗨）
8. 定位与产品力不匹配 → 先修产品力

## 检查清单

- [ ] 差异化明确（品类/特性/人群/场景空位）

## 反模式

- 定位是口号不是事实（与产品力脱节）
- 定位复杂（一句话说不清）
- 无差异化（跟风模仿头部）
- 定位摇摆（今天A明天B）
- 忽视竞品（不了解占位就入场）

## 边界声明（≥3条）

- 基于 1980 年代美国品牌营销语境，算法推荐时代心智争夺方式已变，需适配
- "第一"在成熟品类难实现，细分定位可能限制规模
- 个人IP定位需与真实能力匹配，过度定位有人设崩塌风险
- 作者立场：营销咨询背景，"营销万能论"倾向，产品力仍是基础
