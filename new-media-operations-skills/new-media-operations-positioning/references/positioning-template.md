# 账号定位卡模板

> 说明：以下是账号定位的完整结构。生成时按此结构输出，「说明」文字是写作指引，不复制进最终文档。

## 一、一句话定位
> 用一句话说明：我是什么（标签）× 给谁（人群）× 在什么场景（价值）。

## 二、赛道与竞争分析
| 项 | 内容 |
|---|---|
| 赛道 | |

| 头部账号 | （占位分析） |
| 空位机会 | （品类/特性/人群/场景空位） |

## 三、目标人群画像
- 年龄/性别/兴趣/消费力/使用场景
- 用户痛点与需求

## 四、人设设计
