# 《定位》（Positioning）方法论提炼

## 一、核心框架

### 1.1 定位 = 抢占用户心智（不是产品本身）
- **适用场景**：账号定位、品牌定位、内容赛道选择（新媒体账号人设/赛道决策）
- **步骤**：
  1. **分析心智**：目标用户心智中已经有什么（已有认知/竞品占位）
  2. **找空位**：在心智中找到一个未被占据的位置（品类空位/特性空位/人群空位）
  3. **抢占**：用所有内容/表达反复强化这个位置（定位不是一句话，是长期一致的表达）
  4. **简化和聚焦**：定位要足够简单，一句话能说清（心智怕复杂）
- **输出物**：账号定位卡（一句话定位 + 差异点 + 支持证据）

### 1.2 心智定律（第一法则 / 二元法则 / 关联法则）
- **适用场景**：判断赛道选择、差异化策略
- **步骤**：
  1. **第一法则**：成为品类第一（或某细分第一），第一容易被记住
  2. **二元法则**：用户心智通常只容纳前两名（做不了第一就做"更专业/更年轻"的第二）
  3. **关联法则**：用用户已知事物锚定新事物（"XX界的YY"）
- **输出物**：差异化定位策略（第一/第二/关联路径）

### 1.3 定位四步法（分析→定位→验证→传播）
- **适用场景**：任何新账号/新内容线启动前的定位流程
- **步骤**：
  1. **分析**：市场/竞品/用户心智盘点
  2. **定位**：选定位（品类/特性/人群/场景空位）
  3. **验证**：小范围验证（内容反馈/用户认知测试）
  4. **传播**：所有触点一致化表达（内容/视觉/话术统一）
- **输出物**：定位落地计划（验证方式 + 一致性规范）

## 二、决策规则（8条，标注章节）

1. **如果**做新账号/品牌，**则**先做心智分析（用户脑中已有什么）再定位（第2章 心智）
2. **如果**赛道已拥挤，**则**找细分空位（品类/特性/人群/场景）而非正面竞争（第4章 空位）
3. **如果**做不了第一，**则**做"更X"的第二（更专业/更便宜/更年轻）（第3章 二元法则）
4. **如果**定位复杂，**则**简化到一句话（心智怕复杂，定位要聚焦）（第2章 简化）
5. **如果**要解释新事物，**则**用关联（"XX界的YY"）锚定用户认知（第3章 关联法则）
6. **如果**定位确定，**则**所有内容/触点一致化（不能今天A明天B）（第5章 传播）
7. **如果**定位不被用户认可，**则**验证并调整（定位需用户心智验证，不是自嗨）（第4章 验证）
8. **如果**定位与产品力不匹配，**则**先修产品力（定位不是吹牛，是放大真实差异）（第2章 心智）

## 三、检查清单

- [ ] 一句话定位（用户能复述）
- [ ] 定位基于心智分析（不是自嗨）
- [ ] 差异化明确（品类/特性/人群/场景空位）
- [ ] 定位与产品力匹配（能兑现）
- [ ] 所有触点一致化（内容/视觉/话术）
- [ ] 定位经过验证（小范围测试）

## 四、反模式

- 定位是口号不是事实（与产品力脱节）
- 定位复杂（一句话说不清）
- 无差异化（跟风模仿头部）
- 定位摇摆（今天A明天B，心智混乱）
- 忽视竞品（不了解已有占位就入场）

## 五、边界声明（≥3条）

- 本书基于 1980 年代美国品牌营销语境，互联网/新媒体时代心智争夺方式已变（算法推荐降低心智依赖），需适配
- 定位理论强调"第一"在成熟品类难以实现，细分定位可能限制市场规模
- 对个人 IP/内容账号，定位需与真实能力匹配，过度定位有人设崩塌风险
- 作者立场：广告/营销咨询背景，理论有"营销万能论"倾向，产品力仍是基础
