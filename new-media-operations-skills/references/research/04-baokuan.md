# 《爆款文案》方法论提炼

## 一、核心框架

### 1.1 文案四步转化框架（激发兴趣 → 建立信任 → 刺激购买 → 引导下单）
- **适用场景**：新媒体带货文案、推文、商品种草内容（公众号/小红书/抖音图文）
- **步骤**：
  1. **激发兴趣**：标题与开头制造好奇/痛点/反差，让读者愿意读下去
  2. **建立信任**：用事实（数据/资质/案例）、权威（背书）、细节（场景）建立可信度
  3. **刺激购买**：用价值感（超值/限时）、痛点放大、从众（销量/口碑）推动决策
  4. **引导下单**：明确的行动指令（点击/扫码/下单），降低行动门槛（优惠/赠品/零风险承诺）
- **输出物**：一篇四步结构的带货文案/种草内容

### 1.2 标题 6 式（如何写出点击率高的标题）
- **适用场景**：任何需要打开率的内容（推文标题/小红书标题/视频标题）
- **步骤**：从 6 种标题公式中选适合的——
  1. 痛点式（直击问题："敏感肌救星"）
  2. 好奇式（留悬念："为什么90%的人都做错了"）
  3. 数字式（量化："3个技巧让你涨粉10倍"）
  4. 反差式（反转："越努力越穷的人，都栽在这件事上"）
  5. 利益式（承诺："看完这篇，你也能写出爆款"）
  6. 身份式（圈层："写给30岁还在迷茫的你"）
- **输出物**：3-5 个标题候选

### 1.3 痛点→解决方案→证据（转化文案结构）
- **适用场景**：产品种草、课程/服务转化内容
- **步骤**：
  1. 放大痛点（让读者"对号入座"）
  2. 给出解决方案（产品/内容如何解决）
  3. 证据支撑（案例/数据/背书/细节）
  4. 临门一脚（限时/限量/风险承诺）
- **输出物**：转化文案（含证据链）

## 二、决策规则（8条，标注章节）

1. **如果**标题没有点击率，**则**换标题公式重写（标题决定打开率）（第1章 标题）
2. **如果**读者不信任，**则**补证据（数据/背书/细节），空口承诺无效（第2章 信任）
3. **如果**没有购买冲动，**则**放大痛点或强化价值感（第3章 刺激购买）
4. **如果**文案读完不行动，**则**给明确指令+降低门槛（优惠/风险承诺）（第4章 引导下单）
5. **如果**写转化文案，**则**按"痛点→方案→证据→行动"四步走（第2-4章 结构）
6. **如果**描述产品，**则**用细节场景（让读者"看见"）而非抽象功能（第2章 细节）
7. **如果**做品牌内容，**则**克制销售话术，先给价值再转化（第4章 价值前置）
8. **如果**文案数据差，**则**逐环节拆解（标题/开头/信任/转化）找卡点（全书结构）

## 三、检查清单

- [ ] 标题用了哪种公式（痛点/好奇/数字/反差/利益/身份）
- [ ] 开头是否 3 秒内抓住注意力
- [ ] 是否有信任证据（数据/背书/案例/细节）
- [ ] 是否放大痛点并给出方案
- [ ] 是否有明确行动指令 + 低门槛
- [ ] 是否有合规风险（极限词/虚假宣传）

## 四、反模式

- 标题党（打开率高但伤信任，取关风险）
- 空口说"很好/很棒"没有证据
- 全文销售腔（读者反感，无价值前置）
- 没有行动指令（读者看完就划走）
- 忽略合规（广告法极限词：最/第一/国家级）

## 五、边界声明（≥3条）

- 本书以公众号/电商文案语境为主，短视频/直播话术需适配
- 转化文案要区分内容平台与交易平台：内容平台先价值后转化
- 文案方法论提高转化概率，不保证销量（产品力是基础）
- 作者立场：基于实战经验总结，非实证研究
