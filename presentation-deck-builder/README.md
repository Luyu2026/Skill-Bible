# AI 汇报演示稿生成

## 适合什么场景

你需要把主题、已有报告或数据变成可讲的 PPT。
已有零散材料也可以开始，不必先整理成标准格式。
如果只想处理一小段，请明确本轮范围。

## 解决什么

把散乱汇报材料变成有结论、有证据、能按时讲完的逐页演示稿，而不是只给漂亮标题。

以已有材料为起点，区分确认事实和仍需核对的内容。
先完成一版可以使用的结果，再按反馈修改。

## 一个重要机制

主题不等于结论：先确定本次要争取的决定，再决定页面顺序。

已有数据与建议分开：每项业务结论要能回到原表或原文。
遇到无法确认的地方会留下具体位置，不会悄悄补写。

## 你会拿到什么

- 逐页演示稿：页码、结论标题、正文、视觉建议、讲稿
- 数据与来源表：保留口径、周期、原材料位置
- 文件状态：已生成并检查，或仅交付可编辑文字稿

交付会说明处理范围，以及哪些材料还没有覆盖。
工具无法生成目标文件时，会提供可复制的文字版本并说明差异。

## 怎么开始

1. 直接提供现有材料，附上你最想解决的问题。
2. 说明本次处理范围、使用对象和希望的输出形式。
3. 如果已有旧稿或参考风格，一并提供。
4. 收到结果后，指出需要修改的具体位置和原因。

不确定格式时，可以先要求一个小范围成品。
请只提供你有权使用的材料；分享范围也可以一起说明。

## 可直接复制的调用模板

```text
请使用 presentation-deck-builder。
我的任务：把主题、已有报告或数据变成可讲的 PPT。
现有材料：粘贴文字或附上文件。
本轮范围：填写页面、时间段、主题或章节。
使用对象与目标：填写给谁看、希望完成什么。
输出形式：可复制文稿；如工具支持，再生成可编辑文件。
必须保留：填写事实、表达或格式要求。
请标明无法确认的内容，先交付本轮成品和必要下一步。
```

### 看一个小例子

模拟输入：内部周会，3 分钟；本周处理 40 件工单，上周 32 件；其中 8 件仍待客户补资料。要求说明下周行动。

可以先按这个范围试用，再决定是否处理其余材料。
