# AI 汇报演示稿生成

## 适合什么场景

你有周报、表格或旧 PPT，明天需要向团队或负责人汇报。

你知道主题，但还没想清楚希望听众批准什么、关注什么。

适合内部同步、方案说明和资源申请；只给主题也能先搭结构，但业务结论需要真实材料。

## 解决什么

把原材料收成逐页可讲的演示稿，每页含结论标题、正文、图表建议和讲稿。

把解释放进讲稿，把决策需要的信息留在投影页。

证据不足的结论会改成待核问题，不用示例数字填满页面。

## 一个重要机制

先写最后一页希望听众做出的决定，再反推前面需要哪些证据。

例如本周工单 40 件、上周 32 件，可以写增加 8 件、25%。

没有闭环数就不能声称闭环率提高；处理量与闭环量会分开。

## 你会拿到什么

- 逐页演示稿，可直接复制到幻灯片。

- 含单位、周期和来源位置的数据底表。

- 逐页时长预算、待补证据与具体决策请求。

- 有可用生成工具时提供可编辑文件及检查状态；否则交文字稿，不冒称 PPTX。

## 怎么开始

1. 提供已有报告、表格或旧稿，说明汇报听众。

2. 告诉我汇报多久，以及希望听众听完决定什么。

3. 有品牌模板、必保数字或不能展示的内容，一并附上。

4. 排练后交回超时的页码或听众质疑点，继续定点修改。

## 可直接复制的调用模板

```text

请使用 presentation-deck-builder。

现有材料：本周处理 40 件工单，上周 32 件；8 件待客户补资料。

听众：内部周会同事。时长：3 分钟。

目标：确认下周补资料跟进分工。

输出：两页逐页稿、讲稿、证据表和时长预算。

不要推断闭环率；没有文件工具就直接交可复制稿。

```
