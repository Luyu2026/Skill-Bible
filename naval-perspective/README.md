# 纳瓦尔视角

长期杠杆与特定知识 Skill。

它适合这样的场景：你想换工作、做副业、创业或学一项新能力，却总在“哪件事更赚钱”“哪条路更稳”之间摇摆。它会先把短期收入、长期杠杆、特定知识和生活质量拆开，避免为了看起来正确的路径，放弃真正能积累的东西。

## 你会得到什么

- 纳瓦尔的 5 个核心模型：特定知识、无许可杠杆、长期复利、欲望管理与财富定义
- 判断一项工作、项目或能力能否积累杠杆的方式
- 哪些投入只是忙，哪些会留下可复用资产
- 一个可开始、又不把人生押死的行动选择

## 怎么用

把这个页面链接发给正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/naval-perspective

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：它装在了哪里，以及我下一句话该怎么调用它。
```

装好后可以直接说：

```text
请用纳瓦尔视角分析这条路径：
我在考虑的选择：
我真正想要的生活：
我的独特经历或能力：
短期约束：

请拆开看：它能积累什么特定知识和杠杆？哪些只是短期忙碌？我可以先做什么低风险实验？
```

## 边界

它帮助你看长期积累，不承诺财富结果，也不把“杠杆”误解为脱离现实的快速致富。
