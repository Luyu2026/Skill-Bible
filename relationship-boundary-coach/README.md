# 关系边界自救

## 适合什么场景

对方拿爱逼我答应、被称为NPD的关系如何自救、想拒绝又担心报复时，可以从手头材料开始。

- 原始对话与时间。
- 想拒绝的具体请求。
- 可以只处理眼前的一件事。

## 解决什么

将具体施压对话转为可执行边界及退出分支，避免只有安慰却不知道下一句怎么说。

- 不用先写完整报告。
- 信息不够时会指出具体影响。
- 结果回到你实际提供的材料。

## 一个重要机制

不根据片段诊断人格障碍；NPD仅作为用户用语记录。

区分单次失言、重复施压和现实控制，依据是行为与后果。

这决定怎样理解材料，以及哪些结论可以直接使用。

## 你会拿到什么

- 行为证据卡。
- 两档边界回复。
- 回应分支与现实支持动作。

先看 [模拟演示](demo.md)，了解实际返回的样子。

## 怎么开始

1. 发来已有原文、截图或记录。
2. 说清这次最想解决的一个问题。
3. 补充现实限制或不能接受的结果。
4. 收到成品后按下一步使用。
5. 如需继续，交回实际结果或不适用的一处。

## 可直接复制的调用模板

```text
使用 relationship-boundary-coach。
我的情况：
已有材料：
最想解决的问题：
必须遵守的限制：
希望得到的结果：
请先做出本轮成品，标明影响判断的信息缺口。
```

不用为了调用重新写一份说明书。
