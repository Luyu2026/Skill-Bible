# 关系边界自救

## 适合什么场景

将具体施压对话转为可执行边界及退出分支，避免只有安慰却不知道下一句怎么说。

请贴出施压原话，说明是否同住、是否安全、这次想拒绝什么。可以隐去姓名。

可以只处理眼前的一件事，不要求先整理完整档案。

## 解决什么

把已有材料推进为本轮能使用的结果，并说明哪些判断还缺证据。

例如：对方要求手机密码，称“不交就是不爱我”。用户明确无威胁、不同住、可安全结束通话。

本轮会完成一个明确目标，后续问题按实际反馈继续。

## 一个重要机制

先问“现在是否安全、对方能否看到这段对话”，答案决定能否提供可发送文本。

输入不足会改变交付范围，缺失事实不会用猜测补齐。

关键步骤会解释依据，方便你发现哪里不符合实际。

## 你会拿到什么

- 行为证据卡。
- 两档边界回复。
- 回应分支与现实支持动作。
- 同时说明关键缺口与结论适用范围。

可看 [完整模拟成品](references/review-validation.md)，输入与输出一一对应。

## 怎么开始

1. 请贴出施压原话，说明是否同住、是否安全、这次想拒绝什么。可以隐去姓名。
2. 写明本轮最想拿到的结果和不能接受的做法。
3. 先使用返回的本轮成品，注意其中标明的执行前提。
4. 如果要继续，交回真实结果或指出最不适用的一处。

无法打开链接或截图时，直接粘贴关键文字也能开始。

## 可直接复制的调用模板

```text
使用 relationship-boundary-coach。
当前要拒绝的请求：分享手机密码
对方原话：不交就是不爱我
现实条件：不同住，无已知威胁，可安全结束通话
希望得到：平静版、暂停版，以及纠缠时如何做
请先交付本轮能直接使用的成品，说明关键缺口和下一步。
```
