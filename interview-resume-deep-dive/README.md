# 面试简历深挖准备

它适合这样的场景：你明明做过不少项目，简历上也写了结果，但一被问“为什么这么做”“数据怎么算”“你本人贡献是什么”，就开始讲得很散；或者明天要面试，不知道该先把哪段经历练透。

这个 Skill 不会再给你一份泛泛的 50 道题库。它会先把简历里的每一句话拆成可核验的证据，再挑出最值得讲的项目，提前把面试官会追问的 Why、How 和结果口径挖出来。

## 你会拿到什么

- 简历证据卡：哪些内容能直接讲，哪些数据还要确认；
- 2-3 个最值得带去面试的项目故事；
- 一份只有“表层问题”和“追问问题”两章的深挖题库；
- 每一道问题直接出现在目录里，方便你逐题练习；
- 每道题下都有可直接开口的量化答案与下一层追问；
- 按“背景 + 任务 + 问题 + 解决方案 + 量化结果”组织的回答逻辑；
- 只练最关键问题的开口卡、Why 卡和追问卡。

## 它和普通题库有什么不同

普通题库问所有人同一批问题。

面试官更可能沿着你的简历往下问：

> 你写“社群 7 日留存 90%”，这个留存怎么定义？为什么判断问题在留存？做了哪些动作？数据变化能证明是你的动作带来的吗？

这才是这个 Skill 要提前练掉的部分。

## 可以读取哪些材料

- 简历、项目方案、复盘、周报、作品集、面试记录；
- 已授权的个人经历库，例如 E 码；
- 目标岗位 JD 和已有面经。

个人经历库只用来检索与面试相关的证据。它会把“已经确认的事实”“需要你确认的信息”“基于 JD 的推断”分开，不把私人材料原文搬进最终备书。

## 怎么开始

把本页面链接发给你正在使用的 Agent：

```text
请帮我安装这个 Skill：
https://github.com/Luyu2026/Skill-Bible/tree/main/resume-interview-deep-dive

我只想安装这一个 Skill，不需要下载整个仓库。
请你自己判断我当前使用的 Agent、正确的 Skill 安装目录和下载方式，并直接完成安装。
安装完成后告诉我：装在了哪里，以及我下一句该怎么调用它。
```

装好后，直接说：

```text
请使用「面试简历深挖准备 Skill」深挖我的简历。

目标岗位：
JD：
我的简历/项目材料：
可读取的经历库：E 码（如已授权）

要求：先输出简历证据卡和最值得深挖的 2-3 个项目；
再为每个项目生成横向问题树、纵向追问链、90 秒回答和今天的练习卡。
所有数字、职责和结果必须基于我的真实材料；不确定的地方单列给我确认。
```

## 示例：校媒体部负责人如何被深挖

简历里的一句“开学 Vlog 活动参与作品达 150+，同比增长 28%”，不会只得到“讲讲这个项目”。

它会顺着拆成：

1. 为什么当时把目标定为作品数增长，而不是曝光或报名？
2. 同比的基线是什么，增长 28% 怎么算？
3. 你从调研中看到什么，才决定做开学 Vlog？
4. 你负责的是选题、招募、分发还是复盘？
5. 如果作品多了但质量变差，你怎么判断活动算成功？
6. 为什么不用另一种拉新方式？
7. 下次重做会改哪一步？

最后收成一份你能按题直接开口练、也经得起追问的题库。
