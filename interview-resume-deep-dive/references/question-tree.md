## 最终文档模板

```markdown
# 表层问题

## P0｜[直接可问的完整问题]

| 考察点 | 可直接开口答案 | 追问预判 |
| --- | --- | --- |
|  |  |  |

# 追问问题

## P0-追问｜[围绕上一题继续深挖的问题]

| 考察点 | 可直接开口答案 | 下一层追问 |
| --- | --- | --- |
|  |  |  |
```

具体问题全部使用二级标题；活动策划、增长、社群运营、数据、协作和复盘只作为表格中的考察维度或回答内容出现。

## 横向问题树

| 维度 | 问题 | 面试官想确认什么 | 证据来源 | 优先级 |
| --- | --- | --- | --- | --- |
| 背景 | 为什么当时必须做这件事？ | 问题是否真实 |  | P0 |
| 目标 | 目标和成功标准怎么定？ | 是否有目标感 |  | P0 |
| 判断 | 为什么选这个方案，不选另一个？ | 决策与取舍 |  | P0 |
| 执行 | 你本人具体负责什么？ | 所有权 |  | P0 |
| 影响 | 数据如何计算和归因？ | 结果真实性 |  | P0 |
| 风险 | 最大挑战和失败尝试是什么？ | 韧性与复盘 |  | P1 |
| 复盘 | 今天重做会改什么？ | 学习能力 |  | P1 |

## 90 秒回答检查

- 开头 15 秒：先说项目要解决什么问题、你负责什么。
- 中间 50 秒：只讲 2-3 个关键判断和动作。
- 结尾 25 秒：结果、数据口径、复盘与岗位关联。
- 至少说明一个“没有选择的方案”或一次真实取舍。
- 不确定数据必须说清口径或标为待确认，不要编。
