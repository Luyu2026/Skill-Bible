**S（情境）**

抖音生活服务目前有覆盖餐饮、休闲娱乐、丽人医美、旅游酒店等多个领域，商户规模和用户基数在快速增长，同时生活服务的外部竞争十分激烈，平台要保持高增长，就需要不断挖掘新的增长点，并将其与平台战略目标和制定的OKR紧密结合。

**T（任务）**

业务中的主要对象是商户、用户、平台三方。核心目标是通过识别抖音生活服务的核心增长点，并制定相应的运营策略，让 **商户、用户、平台** 三方都能实现价值最大化。

**A（行动）**

我会从三个维度拆解增长点，并匹配策略：

**1、商家增长**

-  **增长点**：新商户入驻 + 老商户活跃度提升。
-  **策略**：通过地推和招商引入本地商户，同时建立商家成长体系，提供短视频脚本库、直播培训和投放工具，提升他们的内容化运营能力。

**2、用户增长**

-  **增长点**：拉新、转化、复购。
-  **策略**：

  -  用短视频+达人探店种草，提高曝光和兴趣度；
  -  结合直播间秒杀、优惠券促使转化；
  -  通过会员体系和社群运营，提升复购率和用户黏性。

3、**平台生态增长**

-  **增长点**：ROI 提升、履约效率、内容场景创新。
-  **策略**：

  -  利用 AI 推荐和精准投放优化流量分配，提高商户 ROI；
  -  优化到店核销和配送履约，提升整体用户体验；
  -  推动短视频+直播联动，形成高效的转化闭环。

**R（结果/数据支撑）**

比如我曾参与过一个区域餐饮项目，我们通过“短视频种草+直播转化”，重点提升了中小商户的曝光和转化。最终 ROI 提升，新客转化率提高 **15%**，区域整体订单量增长 10**%+**。

10. 你如何快速理解新项目并制定运营策略？

**S（情境）**

新项目是挑战也是机遇。运营需要快速理解业务逻辑和目标，制定合适的增长策略，否则就会错失窗口期。

**T（任务）**

核心任务是：在有限时间内全面理解新项目，抓住关键指标，并制定可执行的运营方案，推动项目快速起量。

**A（行动）**

**1、行业调研**：通过竞品分析、市场趋势研究，了解行业最佳实践和差异化机会；

**2、数据拆解**：结合用户画像、流量分布、转化路径，找到影响增长的核心环节；

**3、制定增长方案**：围绕短视频引流、直播转化、精准投放，搭建完整的增长闭环。

**R（结果/数据支撑）**

 在一次本地服务类新项目中，我通过竞品调研发现用户决策周期长，于是设计了**短视频种草+直播促转化** 的组合策略，并结合精准投放优化人群触达。最终，该项目的 GMV 在上线 3 个月内提升了，新客转化率提高 **15%**。

4. 提供数字营销解决方案时，你如何进行生意的诊断与分析？S：当时我们给品牌在新兴市场提供数字营销解决方案给代理商，品牌在该市场已有基础认知，但在某些渠道投入回报不稳定，代理商投诉投放效果下滑T：对品牌 X 当前线上投放 / 渠道表现做“生意诊断”，识别关键瓶颈，提出优化策略A：1、**明确目标与 KPI 拆解。**跟品牌方 / 代理商确认他们的目标：是提高曝光？拉新？提高转化？提升复购？将总目标拆解至各渠道 / 投放阶段（例如曝光指标、点击指标、转化指标、成本控制指标）。**2、数据拆解与漏斗分析。**我把平台给的投放数据（按渠道、素材、时段、人群等维度）拆解：看哪一步骤流失大（比如点击少？转化率低？退单率高？）。交叉对比各渠道间表现。拿外部竞品 / 第三方行业数据做参考标杆，判断当前表现是否偏低或有潜力上涨空间**3、竞品 / 行业对标分析。**选几个本地或区域内做得不错的品牌 / 同类快消品，分析它们在哪些渠道投放、用什么创意、人群策略如何，比较我们和竞品在预算分布、投放节奏、素材风格上的差距**4、用户/ 渠道分析。**基于 DMP 或媒体平台数据，把用户按兴趣、行为、地域、设备等分层。分析不同层级人群在各渠道的响应行为，判断哪些人群在某些渠道上效果更优。判断是否存在“冷人群 / 热人群 / 潜在人群”切分策略可做**5、策略诊断 + 方法论输出。**针对识别出的瓶颈环节（例如转化率低、人群覆盖不精准、素材吸引力不足、预算倾斜不合理等）分别给出优化建议。构建可操作的方案：如预算重配、渠道淘汰/增补、素材迭代规则 + 测试机制、人群分层投放、时段调优等**6、落地规划 + 复盘机制：**执行时间表／节奏；设定监控指标与周期；安排反馈机制：代理商、业务方、媒体团队每周期复盘、调整方案**R**：通过这样的诊断与优化方案，我们帮助品牌在三个关键渠道（社交广告、短视频、展示广告）重新调整投放结构后，整体 ROI 提升了约 25%，CPA 降低了 15%。部分低效渠道被剔除，预算得以集中到高效组合上。建立的诊断 + 优化流程后来也被我们团队应用到其他客户，成效也比较稳定。
5. 你如何研究和分析广告主需求及行业数据，并提炼优化方法论？S&T：从更上游角度，在拿到项目之前，要先评估这个市场、理解品牌痛点、预判渠道趋势A：1、**行业 & 趋势研究。**查阅和收集多家行业报告（如本地市场的媒体广告白皮书、移动 / 电商 / 消费品行业趋势报告）；关注平台规则变化（例如广告算法升级、自助投放工具、隐私政策调整等）；观察竞争品牌 / 平台广告新品 / 流行素材形式（比如短视频、直播、沉浸式广告、互动广告）**2、广告主需求访谈：**与品牌方 / 代理商沟通，问他们在这个市场的阶段目标、产品主打卖点、预算周期、过去有效失败案例。探寻隐性诉求（比如某类用户覆盖不足、品牌渗透率提升缓慢、广告素材迭代困难、跨渠道整合难等）**3、跨项目数据对比 / 案例分析：**我把平台历史项目中表现好的案例 / 失败案例做对比分析，用这些经验做横向对标，以找出通用规律**4、提炼方法论 / 模型：**把诊断 + 优化步骤抽象出框架（比如“目标 → 数据拆解 → 瓶颈识别 → 优化方案 → 测试验证 → 复盘迭代”六步法）。在这个框架下，我再细化常用策略模板（如创意优化模板、预算滚动法、渠道优选法、人群层级打法等）**5、落地指导 + 方法输出，**与代理商 / 内部团队分享**R：**最终，在项目中取得了较好效果，还把这套方法在后续给 5–6 家其他广告主的项目中复用，用时缩短了约 20–30%，客户满意度与续单率提升

## 面试须知
### 面试流程
一般情况下，面试会进行 3-4 轮：
- 第一轮：直属 leader 面试 主要考察你是否能胜任这个岗位，帮助他完成工作。
- 第二轮：隔级 leader 面试 除了胜任岗位要求，还会考察你的潜力、通用能力和关键问题的决策能力。
- 第三轮：其他岗位交叉面试 如果需要，会安排其他相关岗位的同事进行面试，主要考察你与其他岗位的协作能力。
- 第四轮：HR 面试 主要从 “人” 的角度，考察你的素质、性格、价值观等，以及是否符合团队文化。

## 面试必学框架
**背景+任务+存在问题+解决方案+量化结果**
这个结构通常用于描述一个项目或工作任务，它可以帮助你清晰地阐述问题、解决方案和最终成果。
- 背景： 描述项目或任务的背景信息，包括为什么要做这个项目，以及项目的目标是什么。
- 任务： 明确描述项目或任务的目标，以及需要完成哪些具体工作。
- 存在问题： 分析项目或任务中存在的问题，这些问题可能阻碍项目目标的实现。
- 解决方案： 提出解决存在问题的方案，并解释方案的可行性和优势。
- 量化结果： 用数据或指标来衡量解决方案的效果，证明方案的有效性
回答示范：提升网站用户留存率
- 背景： 网站的用户留存率一直处于较低水平，影响了网站的长期发展。我们需要提升用户留存率，以提高用户粘性和网站的盈利能力。
- 任务： 提升网站用户留存率，目标是将用户留存率从目前的 10% 提升至 20%。
- 存在问题： 用户体验差、内容缺乏吸引力、缺乏用户互动等问题导致用户流失率高。
- 解决方案：

  - 优化网站用户体验： 改进网站设计、提升页面加载速度、优化搜索功能等。
  - 提供更优质的内容： 增加原创内容、提高内容质量、丰富内容类型等。
  - 增强用户互动： 增加评论功能、用户投票功能、社交分享功能等。
- 量化结果： 经过优化后，网站用户留存率提升至 15%，用户活跃度提高了 20%，网站流量增长了 10%
注意事项
- 每个部分都要简洁明了，避免冗长复杂的描述。
- 使用数据和指标来衡量结果，使描述更具说服力。
- 要保持逻辑清晰，每个部分之间要相互关联。
