# 涨停候选条件筛选与风险复核

## 一句话主餐

普通聊天容易给过期热点名单；这里按可核验行情逐项筛选，交付带数据时间、排除原因和失效条件的研究清单。

## 输入

优先读取用户已经给出的材料，不要求为本 Skill 重新抄写。

- 市场、交易日、盘中或盘后、带来源和时间戳的行情快照
- 股票代码、板块、交易状态、最新价、涨停价、成交额等所需字段
- 用户明确的阈值、排除条件和观察目标

没有实时行情就处理用户快照或标注模拟数据；缺涨停价、交易状态或关键阈值时不编造今日候选，交待核验清单。

输入识别要求：
- 保留原始材料和来源定位，生成文件默认另存。
- 区分真实用户材料、待确认项与明确模拟输入。
- 用户目标明确时直接制作；只有影响结果的歧义才提出具体问题。
- 一次只解决本轮目标，不顺手扩展为其他业务流程。

## 核心判断

- 观察条件命中不是买入建议，排序不是收益预测。
- 盘中快照和收盘数据分开，统一时区和截点，不混用不同时间。
- 不同板块、风险警示、上市阶段及特殊状态规则不能用同一涨幅阈值替代。
- 优先用可信行情给出的涨停价并核对规则，不凭四舍五入后的涨幅判断涨停。
- 封单、成交额和流通市值单位不同；比例计算先统一单位。
- 回测只允许使用当时可见数据；盘后信息不能伪装成盘中可知。

比较按涨幅百分比粗筛与有效涨停价逐项筛选：采用后者，先匹配证券状态与交易日，避免跨板块套阈值。
借鉴 Excel 异常隔离和可追溯汇总，只输出命中、未命中与待核验，不把排序包装成预测模型。

### 容易误判的边界

- 每项条件计算 true、false、unknown；任一已知条件为 false 则整体未命中，全部 true 才命中，其余待核验，同时保留所有缺失字段。
- 明确阈值为大于还是大于等于；成交额 1 亿元在“≥1 亿元”时命中，不用显示四舍五入值判断。
- 若需容许异步行情，先让用户确定最大时间差；未确认时不同采样时刻分组展示，不任意设默认秒数。
- 无当期规则依据时只给基于用户已确认涨停价的快照条件计算；规则状态标“未独立核验”，不得称完整风险复核通过。

## 编号工作流

### 1. 锁定市场与时点

- 确认市场、交易日、行情来源、截点和时区。
- 周末或休市日不把最近交易日称作今日实时。
- 多源时间差过大时分组或停止横向排名。
- 产出数据适用范围与缺失字段列表。

### 2. 核对有效规则

- 按交易所、板块、证券状态和规则生效日匹配。
- 查询交易所正式规则、暂缓实施条文及当日特殊状态公告，区分发布、生效和实际实施日期。
- 核验涨停价、价格最小单位及无涨跌幅限制情形。
- 规则无法确认的证券标为待核验，不进入已确认候选。

### 3. 整理行情底表

- 代码按文本保留，统一金额、股数与价格精度。
- 逐项记录原字段、来源、采样时刻及转换方式。
- 停牌、数据缺失或过时记录进入排除清单。
- 产出可复算底表，不补写不存在的分钟数据。

### 4. 执行硬性筛选

- 按用户给定条件逐条计算命中、未命中、待核验。
- 涨停判定比较有效涨停价与价格，不统一硬编码百分比。
- 缺值不能按零放行；没有已知失败条件但关键字段缺失时待核验，已知失败则未命中并附缺失标签。
- 产出每只证券的规则路径和排除原因。

### 5. 展示观察排序

- 只在已命中且时间可比的样本中按指定字段排序。
- 封单金额占成交额等指标写出分子分母和单位。
- 没有用户指定排序时按代码展示，不自造胜率分。
- 产出观察表，保留并列值与数据新鲜度。

### 6. 复核风险与失效

- 列出已核实的公告、特殊交易状态与快照时效。
- 盘中炸板、涨停价变化或数据更新使旧结果失效时明确标注。
- 一字板、封单并不代表可成交，滑点与排队不应省略。
- 产出风险字段，不编造利好解释或资金身份。

### 7. 交付并检查口径

- 清单含代码、时间、条件、证据、排除项和失效条件。
- 抽查阈值边界、缺值、不同板块与时间混用情形。
- 核对所有数值可回到快照，不宣称全市场覆盖除非数据完整。
- 产出复算结果与覆盖范围。

### 8. 接收新快照复筛

- 用户回传同口径新快照后重新计算，而不是沿用旧结论。
- 记录新增、退出、数据补齐与规则变化分别造成的差异。
- 模拟复盘保留决策时点，不能用后来涨跌修改当时规则。
- 完成条件为条件可复算、时间明确、风险和未知项可定位。

## 直接交付与下一步

默认交付以下成果；按用户目标裁剪，不为凑齐数量生成无关附件。

- 带时间戳的条件命中观察表
- 排除与待核验清单，逐项列规则和字段缺口
- 数据来源、规则生效日期与结果失效条件

交接规则：
- 先给可使用的成品入口，再说明仍影响使用的缺口。
- 核验必须写明执行了什么、结果如何、哪些能力没有执行。
- 本轮能完成的一次性交付到此结束，不附加通用调研作业。
- 需要继续时，只要求用户交回具体异常位置、确认口径或新材料。
- 复交后沿用已确认事实，检查本次修复及其影响的原有部分。

工具不可用时：

无法访问官方规则时保留用户确认的快照字段，交历史条件计算和待核验状态；没有快照则交字段表与筛选表达式，不给“今日候选”。无实时接口时让用户导出同一截点 CSV，上传后重算，不声称持续盯盘。

### 外部参考与延展

- 每次涉及当前行情、规则有效性或特殊交易状态时核验官方来源。
- 优先查上交所、深交所、北交所正式交易规则、风险提示与证券公告。
- 关键词包含交易所、板块、涨跌幅限制、规则生效日与证券状态。
- 行情工具文档用于校准单位、复权方式和字段时间，不作为规则效力来源。
- 比较规则实施日期和适用证券范围，不能把旧搜索摘要直接当现行规则。
- 先以边界价格、缺失字段和不同板块案例验证，再用于本轮筛选。

实际采用外部内容时保留必要许可与来源；仅比较机制不复制正文。
