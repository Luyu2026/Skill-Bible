# 涨停候选条件筛选与风险复核

## 适合什么场景

适合已有行情快照、想按自己的条件筛出观察对象，并复盘哪些股票因什么条件被排除。

快照更新后需要重筛；命中只代表给定条件成立，不代表可以买到或会获得收益。

## 解决什么

普通聊天容易给过期热点名单；这里按可核验行情逐项筛选，交付带数据时间、排除原因和失效条件的研究清单。

先读取现有材料，直接处理你指定的这一轮任务。
需要确认的口径会和可用成品分开列出。

## 一个重要机制

缺涨停价不会当零值放行；已知成交额不达标则判未命中，同时保留涨停价缺失这一核验问题。

你能核对修改依据，并针对具体问题复交。

## 你会拿到什么

- 带时间戳的条件命中观察表
- 排除与待核验清单，逐项列规则和字段缺口
- 数据来源、规则生效日期与结果失效条件

另有一份[模拟演示](demo.md)，可先看实际交付长什么样。
真实任务的核验范围会随文件与工具环境说明。

边界示例见[复审案例](references/review-cases.md)。

## 怎么开始

1. 上传同一截点的行情 CSV，保留来源、交易日和采样时间。
2. 明确市场、板块与盘中或收盘口径。
3. 给出筛选条件的数值、单位和是否包含边界。
4. 说明按什么字段排序；没有排序要求按代码展示。

快照更新后需要重筛；命中只代表给定条件成立，不代表可以买到或会获得收益。
收到成品后，如仍有问题，回传具体位置和希望调整的结果即可。

