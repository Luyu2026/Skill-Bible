# 涨停候选条件筛选与风险复核

## 适合什么场景

基于带交易日和时间戳的行情快照、用户筛选规则及有效交易规则，生成可追溯的涨停研究观察清单。用户说打板筛选、涨停候选、封板复盘或按条件筛股票时使用；只交条件筛选与风险核验，不执行交易。

你手里已有材料，希望直接得到可使用的结果。
只有方向而没有材料时，也可先明确缺什么和本轮能做的范围。

## 解决什么

普通聊天容易给过期热点名单；这里按可核验行情逐项筛选，交付带数据时间、排除原因和失效条件的研究清单。

保留来源与待确认项，避免为了看起来完整补造事实。
围绕当前卡点交付，不把多个无关任务捆在一起。

## 一个重要机制

先核对交易规则与行情时间，再筛选；缺关键字段进入待核验，绝不靠猜测补全候选。

结果可以回到原材料核验，而不只是看起来更漂亮。

## 你会拿到什么

- 带时间戳的条件命中观察表
- 排除与待核验清单，逐项列规则和字段缺口
- 数据来源、规则生效日期与结果失效条件

另有一份[模拟演示](demo.md)，可先看实际交付长什么样。
真实任务的核验范围会随文件与工具环境说明。

## 怎么开始

1. 提供原始材料或可读取的文件路径。
2. 用一句话说明本轮最想完成什么。
3. 告诉我必须保留的内容、口径和输出格式。
4. 已经有模板或旧成品时一并提供，优先沿用。

材料不足时会先交能可靠完成的部分，并列出具体缺口。
有问题时回传问题所在页、行、段落或数据记录即可继续。
