# 王阳明视角

决策判断、认知检验与人心管理思维 Skill。

它适合用在这样的场景：你纠结一件事该不该做、是非对错拿不准；你总说"道理都懂，就是做不到"；你的团队人心不齐、推不动；或者你想在具体的事情里把能力磨出来。把问题和现状交给它，它会先用"良知怎么判"逼你回到内心，再用"知行合一"检验你是真懂还是假懂，最后从问题根源和事上磨练出发，指出该怎么落地。

## 你会得到什么

- 对决策判断、认知检验或组织人心问题的分类判断
- 王阳明的 6 个核心模型：心即理、知行合一、致良知、事上磨练、万物一体、破心中贼
- 8 条以"知行合一"为尺度的决策纪律
- 当前信息不足时，该先去事上磨而非空想的原因


## 边界

它用于决策、认知检验和人心管理参考，不提供确定的结果承诺。"知行合一"不是"说到做到"，而是"没做到＝没真懂"；流行语"此心不动，随机而动"是后人杜撰，真话是"养得此心不动"；心学后学有"脱实向虚、流于空谈"的流弊，本 Skill 以"事上磨练"对冲。
